+++ practice | Channels over the limit
--- task
A thermal model reports one temperature per channel, in kelvin, as a dictionary from channel name to temperature. Write a function `over_limit(temps, limit)` that returns the list of channel names whose temperature is strictly above `limit`, in the order the dictionary holds them.

- A channel exactly at the limit is not over it.
- An empty dictionary gives `[]`.
- Build the list with one list comprehension, not a loop that appends.

So `over_limit({"tc_1": 612.0, "tc_2": 587.5}, 600.0)` returns `["tc_1"]`.
--- starter
def over_limit(temps, limit):
    pass
--- solution
def over_limit(temps, limit):
    """Names of the channels hotter than limit, in the table's order."""
    return [name for name, t in temps.items() if t > limit]
--- hint
`temps.items()` hands out `(name, temperature)` pairs, and `for name, t in ...` unpacks each one.
--- hint
Collect `name`, walk the pairs, and keep only the pairs where `t > limit`: all three parts go inside one pair of square brackets.
--- check case | Two channels over, in table order
over_limit({"tc_1": 612.0, "tc_2": 587.5, "tc_3": 640.2}, 600.0)
=> ["tc_1", "tc_3"]
--- check case | Exactly at the limit is not over it
over_limit({"a": 600.0, "b": 600.1}, 600.0)
=> ["b"]
--- check case | An empty table
over_limit({}, 0.0)
=> []

+++ practice | Accelerations in SI units
--- task
A telemetry record is a dictionary from channel name to value. The acceleration channels end in `_g` and are measured in g. Write a function `to_si(record)` that returns a **new** dictionary holding only the acceleration channels, converted to m/s²:

- Each key loses its `_g` ending and gains `_ms2` instead: `ax_g` becomes `ax_ms2`.
- Each value is multiplied by standard gravity, 9.80665.
- Keep the order of the input. Leave `record` itself unchanged.
- Only a name that ends in `_g`, underscore included, is an acceleration: `flag` is not.

Write it as one dict comprehension.
--- starter
def to_si(record):
    pass
--- solution
G0 = 9.80665  # standard gravity, m/s^2


def to_si(record):
    """The *_g channels of record, renamed *_ms2 and converted to m/s^2."""
    return {name[:-2] + "_ms2": value * G0 for name, value in record.items() if name.endswith("_g")}
--- hint
A dict comprehension has `key: value` at the front, then the `for`, then the `if`.
--- hint
`name.endswith("_g")` is the test. `name[:-2]` is the name without its last two characters.
--- check case | Keeps and converts the acceleration channels only
to_si({"t_s": 12.5, "ax_g": 1.0, "ay_g": -0.5, "q_psf": 412.7})

--- check case | Keeps the order of the input

+++ practice | Channels into samples
--- task
A recorder stores data channel by channel: `[[ax0, ax1, ...], [ay0, ay1, ...], ...]`. A plotting tool wants it sample by sample: `[[ax0, ay0, ...], [ax1, ay1, ...], ...]`.

Write a function `transpose(channels)` that turns the first shape into the second, as a list of new lists.

- No channels at all, `[]`, gives `[]`. Channels with no samples, such as `[[], []]`, also give `[]`.
- One channel of two samples, `[[5.0, 6.0]]`, gives `[[5.0], [6.0]]`.
- If the channels do not all have the same length, raise `ValueError`. Do not cut them to the shortest.

So `transpose([[1.0, 2.0], [9.8, 9.7]])` returns `[[1.0, 9.8], [2.0, 9.7]]`. Use a comprehension for the result.
--- starter
def transpose(channels):
    pass
--- solution
def transpose(channels):
    """Rows of samples from columns of channels; ValueError if the lengths differ."""
    if not channels:
        return []
    n = len(channels[0])
    if any(len(ch) != n for ch in channels):
        raise ValueError("channels have different lengths")
    return [[ch[i] for ch in channels] for i in range(n)]
--- hint
Sample `i` of the result is the list of item `i` of every channel. A comprehension can sit inside another one: the inner one builds one row, the outer one walks `i`.
--- hint
Deal with the empty input before you look at `channels[0]`, and compare every channel's length with the first one's before you build anything.
--- check case | Two channels of three samples
transpose([[1.0, 2.0, 3.0], [9.8, 9.7, 9.9]])
=> [[1.0, 9.8], [2.0, 9.7], [3.0, 9.9]]
--- check case | One channel
transpose([[5.0, 6.0]])
=> [[5.0], [6.0]]
--- check case | No channels, and channels with no samples
(transpose([]), transpose([[], []]))
=> ([], [])
--- check test | Channels of different lengths raise ValueError
raises(ValueError, lambda: transpose([[1.0, 2.0], [3.0]])) and raises(ValueError, lambda: transpose([[1.0], [2.0, 3.0]]))

+++ practice | Channels grouped by unit
--- task
`by_unit(units)` takes a dictionary from channel name to unit and should return a dictionary from each unit to the list of channels measured in it:

- the channels in each list keep the order of the input;
- the units appear in the order of their first appearance in the input.

So `{"ax": "g", "pc": "kPa", "ay": "g"}` should give `{"g": ["ax", "ay"], "kPa": ["pc"]}`. Instead it gives `{"g": ["ay"], "kPa": ["pc"]}`: each unit keeps only its last channel. Fix the comprehension.
--- starter
def by_unit(units):
    """Map each unit to the channels measured in it, in table order."""
    return {unit: [name] for name, unit in units.items()}
--- solution
def by_unit(units):
    """Map each unit to the channels measured in it, in table order."""
    return {unit: [name for name, u in units.items() if u == unit] for unit in units.values()}
--- hint
In a dict comprehension, a key that comes up again replaces the earlier value. So one pass that writes one channel per key can only ever keep the last channel.
--- hint
Make the value itself a list comprehension: for each unit, every channel whose unit is that one. A repeated unit then writes the same full list again, and the key keeps its first position.
--- check case | Every channel of each unit
by_unit({"ax": "g", "pc": "kPa", "ay": "g", "tc": "K", "az": "g"})
=> {"g": ["ax", "ay", "az"], "kPa": ["pc"], "K": ["tc"]}
--- check case | Units in order of first appearance
list(by_unit({"pc": "kPa", "ax": "g", "po": "kPa"}))
=> ["kPa", "g"]
--- check case | An empty table
by_unit({})
=> {}

+++ practice | Exceedances by configuration
--- task
A dispersion sweep produces one dictionary per case, such as `{"id": 7, "config": "hot_high", "q_kpa": 36.1}`: the case number, the configuration it was run in, and its peak dynamic pressure in kPa.

Write a function `exceedances(cases, limit)` that returns a dictionary from each configuration to the sorted list of case ids whose `q_kpa` is strictly above `limit`.

- Every configuration that appears in `cases` is a key, even if none of its cases is over the limit; its list is then empty.
- The keys are in alphabetical order.
- No cases give `{}`.

Build the result with comprehensions: a set of the configurations, and a dict of the lists.
--- starter
def exceedances(cases, limit):
    pass
--- solution
def exceedances(cases, limit):
    """Config -> sorted ids of the cases over limit; every config present, keys sorted."""
    configs = sorted({c["config"] for c in cases})
    return {
        cfg: sorted(c["id"] for c in cases if c["config"] == cfg and c["q_kpa"] > limit)
        for cfg in configs
    }
--- hint
First find the distinct configurations with a set comprehension, and sort them: a dictionary keeps the order its keys go in.
--- hint
For each configuration, the value is the sorted ids of the cases that belong to it and are over the limit. A generator expression inside `sorted(...)` does it.

exceedances([{"id": 7, "config": "hot_high", "q_kpa": 36.1}, {"id": 2, "config": "nominal", "q_kpa": 31.0}, {"id": 4, "config": "hot_high", "q_kpa": 35.2}, {"id": 9, "config": "cold_low", "q_kpa": 29.9}], 35.0)
=> {"cold_low": [], "hot_high": [4, 7], "nominal": []}
--- check case | Keys in alphabetical order
list(exceedances([{"id": 1, "config": "nominal", "q_kpa": 36.0}, {"id": 2, "config": "cold_low", "q_kpa": 30.0}], 35.0))
=> ["cold_low", "nominal"]
--- check case | Exactly at the limit is not over it
exceedances([{"id": 1, "config": "a", "q_kpa": 35.0}], 35.0)

--- check case | No cases
exceedances([], 35.0)

+++ question | Which loop is outside
--- ask
What does this print?

```python
grid = [[1, 2, 3], [4, 5, 6]]
print([row[i] for i in range(3) for row in grid])
```
--- answer
[1, 4, 2, 5, 3, 6]
--- why
The first `for` written is the outer loop. So `i` takes 0, then 1, then 2, and for each `i` the inner loop visits both rows: `row[0]` of each row gives 1 and 4, then `row[1]` gives 2 and 5, then `row[2]` gives 3 and 6. Swapping the two clauses would change the order, and with the clauses as written it reads the grid column by column.

+++ practice | A running maximum
--- task
Write a generator function `running_max(samples)` that yields, for each sample in turn, the largest sample seen so far.

- `samples` can be any iterable: a list, a file's values, or a stream that never ends.
- It must be a generator: nothing is worked out until someone asks for the next value.
- An empty input yields nothing. The samples can all be negative.

So `list(running_max([3.0, 1.0, 4.0]))` is `[3.0, 3.0, 4.0]`.
--- starter
def running_max(samples):
    pass
--- solution
def running_max(samples):
    """Yield the largest sample seen so far, once per sample."""
    best = None
    for s in samples:
        if best is None or s > best:
            best = s
        yield best
--- hint
Keep the best value so far in a local variable. A generator keeps its local variables between one `yield` and the next.
--- hint
Do not start the best value at 0: with only negative samples it would never be replaced. Start with "nothing yet" and take the first sample as it is.
--- check case | Yields the maximum so far
list(running_max([3.0, 1.0, 4.0, 1.0, 5.0]))
=> [3.0, 3.0, 4.0, 4.0, 5.0]
--- check case | Only negative samples
list(running_max([-5.0, -7.0, -2.0]))
=> [-5.0, -5.0, -2.0]
--- check case | An empty input
list(running_max([]))
=> []
--- check case | It is a generator
type(running_max([1.0])).__name__
=> "generator"
--- check case | Works on a stream that never ends
list(__import__("itertools").islice(running_max(__import__("itertools").count()), 4))
=> [0, 1, 2, 3]

+++ practice | The first reading over the limit
--- task
Write a function `first_over(samples, limit)` that returns a tuple `(index, value)` for the first sample strictly above `limit`, or `None` if there is none.

- `samples` may be a stream that never ends, or a generator whose later items are expensive or even broken. Stop reading as soon as you have found the answer.
- An empty input, or one with nothing over the limit, gives `None`.

So `first_over([9.8, 12.4, 14.2], 10.0)` returns `(1, 12.4)`.
--- starter
def first_over(samples, limit):
    pass
--- solution
def first_over(samples, limit):
    """(index, value) of the first sample above limit, or None; reads no further."""
    return next(((i, s) for i, s in enumerate(samples) if s > limit), None)
--- hint
A generator expression over `enumerate(samples)` with a filter produces the matching `(index, value)` pairs one at a time, without looking past the one you take.
--- hint
`next(gen, None)` takes the first item of a generator, or gives `None` when it has none.
--- check case | The first sample over the limit
first_over([9.8, 9.9, 12.4, 14.2], 10.0)
=> (2, 12.4)
--- check case | Nothing over the limit, and no samples
(first_over([9.8, 10.0], 10.0), first_over([], 10.0))
=> (None, None)
--- check case | Stops reading at the answer
first_over((s if s < 99.0 else 1 / 0 for s in [1.0, 12.0, 99.0]), 10.0)
=> (1, 12.0)
--- check case | Works on a stream that never ends

+++ practice | Rates between neighboring samples
--- task
Write a generator function `rates(samples, dt)` that yields the rate of change between each pair of neighboring samples, `(next - previous) / dt`.

- `samples` can be any iterable, including a generator or an endless stream, so do not index it or take its length.
- Fewer than two samples yield nothing, and must not raise.
- If `dt` is zero or negative, raise `ValueError`. Being a generator, it raises when the first value is asked for, so `list(rates([1.0, 2.0], 0.0))` raises.

So `list(rates([0.0, 0.5, 1.5], 0.5))` is `[1.0, 2.0]`.
--- starter
def rates(samples, dt):
    pass
--- solution
def rates(samples, dt):
    """Yield (next - previous) / dt for each neighboring pair of samples."""
    if dt <= 0:
        raise ValueError(f"dt must be positive, got {dt}")
    it = iter(samples)
    previous = next(it, None)
    if previous is None:
        return
    for current in it:
        yield (current - previous) / dt
        previous = current
--- hint
Take one iterator with `iter(samples)`, pull the first sample off it, then loop over the rest of the same iterator.
--- hint
A bare `next(it)` on an empty input raises `StopIteration` inside the generator, which Python turns into a `RuntimeError`. `next(it, None)` returns `None` instead, and a bare `return` ends the generator quietly.
--- check case | Three rates from four samples
list(rates([0.0, 0.5, 1.5, 1.5], 0.5))
=> [1.0, 2.0, 0.0]
--- check case | Works on a generator
list(rates((x * x for x in range(4)), 1.0))
=> [1.0, 3.0, 5.0]
--- check case | No samples, and one sample
(list(rates([], 0.1)), list(rates([4.0], 0.1)))
=> ([], [])
--- check test | A time step that is not positive raises ValueError
raises(ValueError, lambda: list(rates([1.0, 2.0], 0.0))) and raises(ValueError, lambda: list(rates([1.0, 2.0], -0.1)))
--- check case | Works on a stream that never ends
next(rates(__import__("itertools").count(), 2.0))
=> 0.5

+++ practice | The reader that closes too soon
--- task
`channel(path, name)` should hand out the column called `name` of a CSV run file as floats, one row at a time, without reading the whole file into memory. The file has a header row, and every data row has a value in every column.

`list(channel(path, "az"))` should give the column's values. Instead it raises `ValueError: I/O operation on closed file`. Fix it, keeping it lazy.
--- starter
def channel(path, name):
    """Yield the named column of a CSV run file as floats, one row at a time."""
    with open(path, encoding="utf-8") as f:
        header = f.readline().strip().split(",")
        col = header.index(name)
        return (float(line.split(",")[col]) for line in f)
--- solution
def channel(path, name):
    """Yield the named column of a CSV run file as floats, one row at a time."""
    with open(path, encoding="utf-8") as f:
        header = f.readline().strip().split(",")
        col = header.index(name)
        for line in f:
            yield float(line.split(",")[col])
--- hint
The function returns a generator expression, and then the `with` block ends and closes the file. The generator reads the file only later, when `list` asks for values.
--- hint
Make `channel` itself a generator function: loop over the file inside the `with` and `yield` each value. The file then stays open until the last value has been handed out.

+++ practice | Episodes over the limit
--- task
A vibration channel crosses its limit now and then. Each crossing is an **episode**: a run of consecutive samples strictly above the limit. Write a generator function `episodes(samples, limit)` that yields one tuple `(start, end, peak)` per episode:

- `start` is the index of its first sample, `end` the index of its last sample, and `peak` its largest sample.
- An episode still going on when the samples run out is yielded too.
- `samples` can be any iterable, including a stream that never ends, so yield each episode as soon as it is over.

So `list(episodes([1.0, 5.0, 7.0, 2.0, 6.0, 1.0], 4.0))` is `[(1, 2, 7.0), (4, 4, 6.0)]`.
--- starter
def episodes(samples, limit):
    pass
--- solution
def episodes(samples, limit):
    """Yield (start, end, peak) for each run of consecutive samples above limit."""
    start = end = peak = None
    for i, s in enumerate(samples):
        if s > limit:
            if start is None:
                start, peak = i, s
            elif s > peak:
                peak = s
            end = i
        elif start is not None:
            yield start, end, peak
            start = None
    if start is not None:
        yield start, end, peak
--- hint
Walk the samples with `enumerate`, keeping the open episode's start, end and peak in local variables, or `None` while no episode is open.
--- hint
Yield when a sample at or under the limit closes an open episode. After the loop, one episode may still be open: yield it too.
--- check case | Two episodes
list(episodes([1.0, 5.0, 7.0, 2.0, 6.0, 1.0], 4.0))
=> [(1, 2, 7.0), (4, 4, 6.0)]
--- check case | An episode still open at the end
list(episodes([5.0, 6.0, 5.5], 4.0))
=> [(0, 2, 6.0)]
--- check case | No episode, and no samples
(list(episodes([1.0, 4.0], 4.0)), list(episodes([], 4.0)))
=> ([], [])
--- check case | Works on a stream that never ends
list(__import__("itertools").islice(episodes((i % 5 for i in __import__("itertools").count()), 2.5), 2))
=> [(3, 4, 4), (8, 9, 4)]

+++ question | When the body runs
--- ask
What does this print? Type the printed lines on one line, separated by spaces.

```python
def g():
    print("a")
    yield 1
    print("b")
    yield 2
    print("c")

it = g()
print("start")
print(next(it))
for x in it:
    print(x)
```
--- answer
start a 1 b 2 c
--- why
`g()` runs none of the body, so `start` comes first. The first `next` runs the body up to the first `yield`: it prints `a` and hands back 1, which is printed. The `for` loop then carries on from where the generator paused: it prints `b`, gets 2 and prints it, and on the next request prints `c` and runs off the end, which stops the loop quietly. The `for` loop does not start the generator again; it continues the same one.

+++ practice | Worst and best case
--- task
Dispersion results arrive as a list of `(case_id, margin)` tuples. Write a function `extremes(results)` that returns a tuple `(worst, best)`: the result with the smallest margin and the result with the largest margin.

- If several results share the smallest margin, `worst` is the first of them in the list. The same goes for `best`.
- No results give `(None, None)`.
- Find each one in a single pass. Do not sort the table to find two rows.
--- starter
def extremes(results):
    pass
--- solution
from operator import itemgetter


def extremes(results):
    """(smallest-margin result, largest-margin result); ties go to the earlier one."""
    if not results:
        return None, None
    return min(results, key=itemgetter(1)), max(results, key=itemgetter(1))
--- hint
`min` and `max` take the same `key=` as `sorted`, and each walks the list once.
--- hint
`operator.itemgetter(1)` is a ready-made key that pulls out item 1 of each tuple. Check for an empty list first: `min` of nothing raises.

+++ practice | Summary per configuration
--- task
Dispersion results arrive as a list of `(config, case_id, margin)` tuples, in no particular order. Write a function `config_summary(results)` that returns one tuple `(config, count, mean_margin)` per configuration:

- `count` is how many results that configuration has, and `mean_margin` the mean of their margins.
- The tuples are ordered by mean margin, smallest first. Configurations with the same mean are in alphabetical order.
- No results give `[]`.

Group with `itertools.groupby`.
--- starter
def config_summary(results):
    pass
--- solution
from itertools import groupby
from operator import itemgetter


def config_summary(results):
    """(config, count, mean margin) per configuration, lowest mean first."""
    by_config = sorted(results, key=itemgetter(0))
    rows = []
    for config, group in groupby(by_config, key=itemgetter(0)):
        margins = [r[2] for r in group]
        rows.append((config, len(margins), sum(margins) / len(margins)))
    return sorted(rows, key=itemgetter(2))
--- hint
`groupby` only groups neighbors. Sort by the configuration first, with the same key you then give `groupby`.
--- hint
Build the rows in configuration order, then sort them by the mean. The sort is stable, so equal means stay in alphabetical order without a second key.

+++ practice | Cases that did not converge go last
--- task
Each dispersion case is a dictionary such as `{"id": 4, "margin": 0.9}`. A case that did not converge has `"margin": None`. Write a function `by_margin(cases)` that returns the case ids ordered by margin, smallest first:

- cases whose margin is `None` come after all the others, in their input order;
- cases with the same margin keep their input order;
- a margin of `0.0` is a real margin, not a missing one;
- no cases give `[]`.

A plain sort by margin raises `TypeError` here, because `None` and a float cannot be compared.
--- starter
def by_margin(cases):
    pass
--- solution
def by_margin(cases):
    """Case ids by margin, smallest first; cases with no margin last, in input order."""
    ranked = sorted(cases, key=lambda c: (c["margin"] is None, c["margin"] if c["margin"] is not None else 0.0))
    return [c["id"] for c in ranked]
--- hint
A key can return a tuple. Tuples compare item by item, and `False` sorts before `True`.
--- hint

def merge_passes(passes):
    """Merge each station's overlapping or touching passes; sorted by station, then start."""
    merged = []

class Battery:
    """A battery whose charge can never leave the range 0 to capacity."""

    def __init__(self, name, capacity_wh, charge_wh):
        self.name = name
        self.capacity_wh = float(capacity_wh)
        self.charge_wh = charge_wh

    @property
    def charge_wh(self):
        """Stored energy, Wh."""
        return self._charge_wh

    @charge_wh.setter
    def charge_wh(self, value):
        value = float(value)
        if not 0.0 <= value <= self.capacity_wh:
            raise ValueError(f"charge must be between 0 and {self.capacity_wh} Wh, got {value}")
        self._charge_wh = value

    @property
    def soc(self):
        """State of charge, percent."""
        return 100.0 * self.charge_wh / self.capacity_wh

    def draw(self, wh):
        """Take wh out of the battery; ValueError, and no change, if there is not enough."""
        self.charge_wh = self.charge_wh - wh
        return self.charge_wh
--- hint

class Engine:
    """A rocket engine: thrust and specific impulse."""

    G0 = 9.80665  # standard gravity, m/s^2

    def __init__(self, name, thrust_n, isp_s):
        self.name = name
        self.thrust_n = float(thrust_n)
        self.isp_s = float(isp_s)

    @classmethod

--- solution
class Window:
    """The time from t0 up to, but not including, t1, in seconds."""

    def __init__(self, t0, t1):
        self.t0 = float(t0)
        self.t1 = float(t1)
        if not self.t1 > self.t0:
            raise ValueError(f"a window must end after it starts: {t0} to {t1}")

    @property
    def duration(self):
        return self.t1 - self.t0

    def contains(self, t):
        return self.t0 <= t < self.t1

    def overlaps(self, other):
        return self.t0 < other.t1 and other.t0 < self.t1

    def intersection(self, other):
        """The shared window, or None if the two do not overlap."""
        if not self.overlaps(other):
            return None
        return Window(max(self.t0, other.t0), min(self.t1, other.t1))

Write two classes for a staged rocket.

--- solution
import math

G0 = 9.80665  # standard gravity, m/s^2


class Stage:
    """One stage: dry mass, propellant and specific impulse."""

    def __init__(self, dry_kg, propellant_kg, isp_s):
        self.dry_kg = float(dry_kg)
        self.propellant_kg = float(propellant_kg)
        self.isp_s = float(isp_s)

    @property
    def wet_kg(self):
        return self.dry_kg + self.propellant_kg


class Rocket:
    """Stages bottom first, and a payload on top."""

    def __init__(self, stages, payload_kg):
        self.stages = list(stages)
        self.payload_kg = float(payload_kg)

    @classmethod
    def from_config(cls, config):
        """Build a rocket from {"payload_kg": ..., "stages": [{...}, ...]}."""
        stages = [Stage(s["dry_kg"], s["propellant_kg"], s["isp_s"]) for s in config["stages"]]
        return cls(stages, config["payload_kg"])

    @property
    def liftoff_kg(self):
        return self.payload_kg + sum(s.wet_kg for s in self.stages)

    def delta_v(self):
        """Ideal delta-v of the whole stack, m/s, burning the stages bottom first."""
        total = 0.0
        m0 = self.liftoff_kg
        for stage in self.stages:
            mf = m0 - stage.propellant_kg
            total += stage.isp_s * G0 * math.log(m0 / mf)
            m0 = mf - stage.dry_kg
        return total

+++ practice | A delta-v that adds up
--- task
A mission's delta-v budget is a list of burns. Write a class `DeltaV` so that burns add and scale like numbers, and `sum` of a list of them works.

- `DeltaV(ms)` stores the speed change as a float in `ms`.
- `repr` gives `DeltaV(9400.0)`, and `str` gives the value with one decimal and the unit: `9400.0 m/s`.
- `==` compares two `DeltaV` values exactly, and a `DeltaV` is never equal to something that is not a `DeltaV`.
- `a + b` of two `DeltaV` values gives a new `DeltaV`. `sum(burns)` starts from the number `0`, so `0 + d` must give `d` back.
- `d * k` and `k * d`, for a number `k`, give a scaled `DeltaV`.
- Anything else, such as `d + 1.0` or `d * d`, raises `TypeError`. Get that by returning `NotImplemented`, never by raising it yourself.
--- starter
class DeltaV:
    def __init__(self, ms):
        self.ms = ms
--- solution
class DeltaV:
    """A change in speed, m/s, that adds and scales like a number."""

    def __init__(self, ms):
        self.ms = float(ms)

    def __repr__(self):
        return f"DeltaV({self.ms!r})"

    def __str__(self):
        return f"{self.ms:.1f} m/s"

    def __eq__(self, other):
        if not isinstance(other, DeltaV):
            return NotImplemented
        return self.ms == other.ms

    def __add__(self, other):
        if not isinstance(other, DeltaV):
            return NotImplemented
        return DeltaV(self.ms + other.ms)

    def __radd__(self, other):
        if other == 0:
            return self
        return NotImplemented

    def __mul__(self, k):
        if not isinstance(k, (int, float)):
            return NotImplemented
        return DeltaV(self.ms * k)

    __rmul__ = __mul__
--- hint
`sum` computes `0 + first`, then adds the rest. For `0 + d`, the number 0 does not know about `DeltaV` and declines, so Python asks `d.__radd__(0)`.
--- hint
Multiplying by a number commutes, so `__rmul__ = __mul__` is enough. Adding does not need to accept numbers: `__radd__` only has to handle the starting 0.

A flight plan is built from waypoints merged from several files, so the same waypoint often appears twice. Write a class `Waypoint` and a function `dedupe(waypoints)`.

- `Waypoint(name, lat, lon)` stores the name, and the latitude and longitude as floats.
- Its `repr` is `Waypoint('kiwi', 12.5, -45.0)`, with the name in quotes.
- Two waypoints are equal when name, latitude and longitude are all equal. A waypoint is never equal to something that is not a waypoint.
- Waypoints can go in a set and be dictionary keys, and equal waypoints behave as the same key.
- `dedupe(waypoints)` returns a new list without the repeats, keeping the first of each in the original order. Remember what you have seen in a set.
--- starter

        self.name = name
        self.lat = lat
        self.lon = lon

--- solution
class Waypoint:
    """A named point: equal by value, and hashable over the same fields."""

    def __init__(self, name, lat, lon):
        self.name = name
        self.lat = float(lat)
        self.lon = float(lon)

    def __repr__(self):
        return f"Waypoint({self.name!r}, {self.lat!r}, {self.lon!r})"

    def __eq__(self, other):
        if not isinstance(other, Waypoint):
            return NotImplemented
        return (self.name, self.lat, self.lon) == (other.name, other.lat, other.lon)

    def __hash__(self):
        return hash((self.name, self.lat, self.lon))


def dedupe(waypoints):
    """The waypoints without repeats, first of each kept, in order."""
    seen = set()
    unique = []
    for wp in waypoints:
        if wp not in seen:
            seen.add(wp)
            unique.append(wp)
    return unique
--- hint
Defining `__eq__` switches off the default hash. Define `__hash__` over the same three fields, for example by hashing a tuple of them.
--- hint
A set has no order, so `list(set(...))` loses the original order. Walk the list, and keep each waypoint the first time it is not yet in `seen`.

--- task
A measurement known only to lie between two bounds can be carried through a calculation as an interval. Write a class `Interval`:

- `Interval(lo, hi)` stores both as floats. `lo` equal to `hi` is allowed; `lo` above `hi` raises `ValueError`.

- `a * k` and `k * a`, for a number `k`, scale both ends. A negative `k` swaps them: `Interval(1, 2) * -3` is `Interval(-6.0, -3.0)`.
- An interval times an interval, and adding anything else, raise `TypeError`, through `NotImplemented`.

--- solution
class Interval:
    """A value known only to lie between lo and hi."""

    def __init__(self, lo, hi):
        lo, hi = float(lo), float(hi)
        if lo > hi:
            raise ValueError(f"lo {lo} is above hi {hi}")
        self.lo, self.hi = lo, hi

    def __repr__(self):
        return f"Interval({self.lo!r}, {self.hi!r})"

    def __eq__(self, other):
        if not isinstance(other, Interval):
            return NotImplemented
        return (self.lo, self.hi) == (other.lo, other.hi)

    @property
    def width(self):
        return self.hi - self.lo

    def __add__(self, other):
        if isinstance(other, Interval):
            return Interval(self.lo + other.lo, self.hi + other.hi)
        if isinstance(other, (int, float)):
            return Interval(self.lo + other, self.hi + other)
        return NotImplemented

    __radd__ = __add__

    def __mul__(self, k):
        if not isinstance(k, (int, float)):
            return NotImplemented
        a, b = self.lo * k, self.hi * k
        return Interval(min(a, b), max(a, b))

    __rmul__ = __mul__
--- hint
Adding commutes, and so does scaling by a number, so each reflected method can be the same function as the forward one.
--- hint
Scale both ends, then take the smaller as the new low and the larger as the new high. That handles a negative factor without a special case.

+++ practice | Polynomials
--- task
Write a class `Poly` for polynomials with float coefficients, lowest power first: `Poly([1, 0, 2])` is 1 + 2x².

- Store the coefficients as a tuple of floats in `coeffs`. Trailing zero coefficients are dropped, so `Poly([1, 2, 0])` equals `Poly([1, 2])`, and the zero polynomial has no coefficients at all: `Poly([0, 0])` has `coeffs == ()`.
- `repr` gives `Poly([1.0, 0.0, 2.0])`, and `Poly([])` for zero.
- `==` compares coefficients, and is never true against something that is not a `Poly`. Polys are hashable, consistently with `==`.
- `len(p)` is the number of coefficients, so the zero polynomial is falsy. Looping over a `Poly` gives its coefficients, lowest first.
- `+` and `*` work between two polys, and between a poly and a number on either side. `*` of two polys is the polynomial product.
- `p.at(x)` returns the value at `x`; the zero polynomial gives `0.0` everywhere.
- Anything else, such as adding text, raises `TypeError`.
--- starter
class Poly:
    def __init__(self, coeffs):
        self.coeffs = coeffs
--- solution
class Poly:
    """A polynomial c0 + c1 x + c2 x^2 + ..., coefficients lowest power first."""

    def __init__(self, coeffs):
        c = [float(a) for a in coeffs]
        while c and c[-1] == 0.0:
            c.pop()
        self.coeffs = tuple(c)

    def __repr__(self):
        return f"Poly({list(self.coeffs)!r})"

    def __eq__(self, other):
        if not isinstance(other, Poly):
            return NotImplemented
        return self.coeffs == other.coeffs

    def __hash__(self):
        return hash(self.coeffs)

    def __len__(self):
        return len(self.coeffs)

    def __iter__(self):
        return iter(self.coeffs)

    def __add__(self, other):
        if isinstance(other, (int, float)):
            other = Poly([other])
        if not isinstance(other, Poly):
            return NotImplemented
        n = max(len(self), len(other))
        a = self.coeffs + (0.0,) * (n - len(self))
        b = other.coeffs + (0.0,) * (n - len(other))
        return Poly([x + y for x, y in zip(a, b)])

    __radd__ = __add__

    def __mul__(self, other):
        if isinstance(other, (int, float)):
            other = Poly([other])
        if not isinstance(other, Poly):
            return NotImplemented
        if not self or not other:
            return Poly([])
        out = [0.0] * (len(self) + len(other) - 1)
        for i, a in enumerate(self):
            for j, b in enumerate(other):
                out[i + j] += a * b
        return Poly(out)

    __rmul__ = __mul__

    def at(self, x):
        """The value of the polynomial at x."""
        total = 0.0
        for c in reversed(self.coeffs):
            total = total * x + c
        return total
--- hint
Drop the trailing zeros once, in `__init__`, and every other method can trust the coefficients. A number can be turned into a constant polynomial, `Poly([k])`, so the operators only need the poly-and-poly case.
--- hint
In the product, coefficient `i` of one times coefficient `j` of the other adds to the coefficient of power `i + j`. For `at`, start from the highest coefficient and repeatedly multiply by `x` and add the next one down.
--- check case | Trailing zeros are dropped

=> ("Poly([1.0, 0.0, 2.0])", 3, "Poly([])")
--- check case | Adding polys and numbers
(Poly([1, 2]) + Poly([0, 0, 3]), Poly([1, 2]) + 5, 5 + Poly([1, 2]), Poly([1, 2]) + Poly([-1, -2]))
=> (Poly([1, 2, 3]), Poly([6, 2]), Poly([6, 2]), Poly([]))
--- check case | Multiplying polys and numbers
(Poly([1, 1]) * Poly([1, -1]), 2 * Poly([1, 2]), Poly([1, 2]) * 0)
=> (Poly([1, 0, -1]), Poly([2, 4]), Poly([]))
--- check case | Evaluating

=> (19.0, 0.0)
--- check case | Truth, looping and hashing

import math
from dataclasses import dataclass


@dataclass(frozen=True)
class Limit:
    """An allowed range for one channel; checked when it is built."""

    channel: str
    low: float
    high: float

    def __post_init__(self):
        if not (math.isfinite(self.low) and math.isfinite(self.high)):
            raise ValueError(f"{self.channel}: limits must be finite, got {self.low}, {self.high}")
        if self.low > self.high:
            raise ValueError(f"{self.channel}: low {self.low} is above high {self.high}")

    def check(self, value):
        """Return "low", "high" or "ok"; "nan" for a value that is not a number."""
        if math.isnan(value):
            return "nan"
        if value < self.low:
            return "low"
        if value > self.high:
            return "high"
        return "ok"
--- hint
`__post_init__` runs at the end of the generated `__init__`: that is where the checks go. `math.isfinite` is false for `nan` and for both infinities.
--- hint
Test for `nan` first in `check`: every comparison with `nan` is false, so without that test it would slip through as `"ok"`.

import dataclasses
from dataclasses import dataclass


@dataclass(frozen=True)
class Tank:
    """One tank at one moment. Value semantics: never changed in place."""

    name: str
    propellant_kg: float
    capacity_kg: float

    def __post_init__(self):
        if not 0.0 <= self.propellant_kg <= self.capacity_kg:
            raise ValueError(f"{self.name}: {self.propellant_kg} kg does not fit 0 to {self.capacity_kg} kg")


def transfer(tanks, source, target, kg):
    """A new tuple of tanks with kg moved from source to target."""
    names = [t.name for t in tanks]
    for name in (source, target):
        if name not in names:

class Gyro:

        self.bias_rps = float(bias_rps)

class SensorBank:
    """Any number of sensors, each with a name and a measure(truth) method."""

    def __init__(self, sensors):
        self.sensors = []
        for s in sensors:
            self.add(s)

    def add(self, sensor):
        if sensor.name in self.names():
            raise ValueError(f"two sensors named {sensor.name!r}")
        self.sensors.append(sensor)

    def names(self):
        return [s.name for s in self.sensors]

    def readings(self, truth):
        return {s.name: s.measure(truth) for s in self.sensors}

    def spread(self, truth):
        if not self.sensors:
            raise ValueError("an empty bank has no spread")
        values = self.readings(truth).values()
        return max(values) - min(values)

--- task
Write an abstract base class `SensorModel`, from `abc`, and two sensor models built on it.

--- solution
from abc import ABC, abstractmethod


class SensorModel(ABC):
    """A sensor model: subclasses write measure(), and inherit error() and within()."""

    def __init__(self, name):
        self.name = name

    @abstractmethod
    def measure(self, truth):
        """The measured value of truth."""

    def error(self, truth):
        return self.measure(truth) - truth

    def within(self, truth, tol):
        return abs(self.error(truth)) <= tol


class Biased(SensorModel):
    def __init__(self, name, bias):
        super().__init__(name)
        self.bias = float(bias)

    def measure(self, truth):
        return truth + self.bias


class Scaled(SensorModel):
    def __init__(self, name, factor):
        super().__init__(name)
        self.factor = float(factor)

    def measure(self, truth):
        return truth * self.factor
--- hint
Mark `measure` with `@abstractmethod`; its body can be just a docstring. `error` and `within` are written once, in the base class, in terms of `measure`.
--- hint
Each subclass's `__init__` calls `super().__init__(name)` before storing its own number.

from typing import Protocol, runtime_checkable


class Valve:
    def __init__(self, name):
        self.name = name
        self.open = True

    def reset(self):
        self.open = False


class Thermistor:
    def __init__(self, name):
        self.name = name


@runtime_checkable
class Resettable(Protocol):
    """Anything with a name and a reset() method."""

    name: str

    def reset(self) -> None: ...


def reset_all(devices):

    return done

+++ practice | A chain of filter stages
--- task
A signal chain passes each value through a series of stages. Write:

- a runtime-checkable Protocol `Stage` with one method, `apply(x: float) -> float`;
- three stage classes: `Offset(d)` adds `d`, `Scale(k)` multiplies by `k`, and `Clamp(lo, hi)` limits the value to the range `lo` to `hi` (and raises `ValueError` if `lo` is above `hi`);
- a class `Chain(stages)` that holds its own copy of the stages and whose `apply(x)` passes `x` through them in order. An empty chain returns `x` unchanged. `Chain` raises `TypeError` if any of its stages does not fit `Stage`.

A chain has an `apply` method, so a chain is itself a stage, and chains can hold chains. Any object with an `apply` method counts as a stage.
--- starter
from typing import Protocol, runtime_checkable
--- solution
from typing import Protocol, runtime_checkable


@runtime_checkable
class Stage(Protocol):
    """Anything that turns one value into another."""

    def apply(self, x: float) -> float: ...


class Offset:
    def __init__(self, d):
        self.d = float(d)

    def apply(self, x):
        return x + self.d


class Scale:
    def __init__(self, k):
        self.k = float(k)

    def apply(self, x):
        return x * self.k


class Clamp:
    def __init__(self, lo, hi):
        if lo > hi:
            raise ValueError(f"lo {lo} is above hi {hi}")
        self.lo, self.hi = float(lo), float(hi)

    def apply(self, x):
        return min(max(x, self.lo), self.hi)


class Chain:
    """Stages applied in order; a Chain is a Stage too, so chains nest."""

    def __init__(self, stages):
        self.stages = list(stages)
        for s in self.stages:
            if not isinstance(s, Stage):
                raise TypeError(f"{s!r} has no apply() method")

    def apply(self, x):
        for s in self.stages:
            x = s.apply(x)
        return x
--- hint
No stage class needs a common base class: each only needs an `apply` method. The Protocol writes that requirement down, and `isinstance` against it checks it when a chain is built.
--- hint
`Chain.apply` feeds each stage's output to the next. Because it has the same method as every stage, a chain can go wherever a stage can.

from contextlib import contextmanager


@contextmanager
def temporarily(obj, name, value):
    """Set obj.<name> to value for one block; restore the old value on every way out."""
    old = getattr(obj, name)
    setattr(obj, name, value)
    try:
        yield obj
    finally:
        setattr(obj, name, old)

class Tally:
    """Swallow and count the exception types given; let every other one through."""

    def __init__(self, *kinds):
        self.kinds = kinds
        self.count = 0
        self.last = None

    def __enter__(self):
        return self

    def __exit__(self, exc_type, exc, tb):
        if exc_type is not None and issubclass(exc_type, self.kinds):
            self.count += 1
            self.last = exc
            return True
        return False

from contextlib import contextmanager


@contextmanager
def atomic_write(path):
    """Write to path.tmp, then rename it onto path; on failure, leave path alone."""
    tmp = path.with_name(path.name + ".tmp")
    try:
        with open(tmp, "w", encoding="utf-8") as f:
            yield f
    except BaseException:
        tmp.unlink()
        raise
    tmp.replace(path)

When the block raises, the exception arrives at the `yield`. Catch it around the `yield`, clean up, and send it on with a bare `raise`.
--- hint

class Stand:
    """Power on at the outermost entry; safe and power off at the outermost exit."""

    def __init__(self, log):
        self.log = log
        self.depth = 0
        self._reported = None

    def __enter__(self):
        if self.depth == 0:
            self.log.append("power on")
        self.depth += 1
        return self

    def __exit__(self, exc_type, exc, tb):
        if exc is not None and exc is not self._reported:
            self.log.append(f"abort: {exc_type.__name__}")
            self._reported = exc
        self.depth -= 1
        if self.depth == 0:
            self.log.append("safe")
            self.log.append("power off")
            self._reported = None
        return False

import functools


def trace(log):
    """Return a decorator that logs each call and result, indented by call depth."""

    def decorator(fn):
        depth = 0

        @functools.wraps(fn)
        def wrapper(*args):
            nonlocal depth
            pad = "  " * depth
            log.append(f"{pad}{fn.__name__}({', '.join(repr(a) for a in args)})")
            depth += 1
            try:
                result = fn(*args)
            except Exception as exc:
                log.append(f"{pad}!! {type(exc).__name__}")
                raise
            finally:
                depth -= 1
            log.append(f"{pad}-> {result!r}")
            return result

        return wrapper

    return decorator

    """Count down to zero, recursively; returns the number of steps."""
    if n < 0:
        raise ValueError("negative")
    return 0 if n == 0 else 1 + depth_to(n - 1)

def distinct_within(values: Iterable[float], tol: float) -> list[float]:

import functools
import inspect
import typing

CHECKED = (float, int, str, bool)


def _fits(value, ann):
    """Whether value fits the plain annotation ann, the way a type checker sees it."""
    if isinstance(value, bool):
        return ann is bool
    if ann is float:
        return isinstance(value, (int, float))
    return isinstance(value, ann)


def enforce(fn):
    """Check float, int, str and bool annotations on every call of fn."""
    hints = typing.get_type_hints(fn)
    names = list(inspect.signature(fn).parameters)

    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        for name, value in list(zip(names, args)) + list(kwargs.items()):
            ann = hints.get(name)
            if ann in CHECKED and not _fits(value, ann):
                raise TypeError(f"{fn.__name__}: {name} should be {ann.__name__}, got {type(value).__name__}")
        return fn(*args, **kwargs)

    return wrapper


@enforce
def scale(value: float, factor: float) -> float:
    return value * factor


@enforce
def label(name: str, count: int, flag: bool = False, notes=None, tags: list[str] | None = None) -> str:
    return f"{name}:{count}:{flag}"

import logging


def make_logger(name, path):
    """A DEBUG logger with a WARNING console and a full log file at path."""
    log = logging.getLogger(name)
    for old in list(log.handlers):
        log.removeHandler(old)
        old.close()
    log.setLevel(logging.DEBUG)

    console.setLevel(logging.WARNING)

    return log

import logging

LEVELS = {
    "DEBUG": logging.DEBUG,
    "INFO": logging.INFO,
    "WARNING": logging.WARNING,
    "ERROR": logging.ERROR,
    "CRITICAL": logging.CRITICAL,
}


def set_levels(spec):
    """Apply "name=LEVEL, ..." to the loggers; ValueError, and no change, on a bad item."""
    wanted = {}
    for item in spec.split(","):
        if not item.strip():
            continue
        parts = item.split("=")
        if len(parts) != 2:
            raise ValueError(f"expected name=LEVEL, got {item.strip()!r}")
        name, level = parts[0].strip(), parts[1].strip().upper()
        if not name or level not in LEVELS:
            raise ValueError(f"bad logging setting {item.strip()!r}")
        wanted[name] = LEVELS[level]
    for name, level in wanted.items():
        logging.getLogger(None if name == "root" else name).setLevel(level)
    return wanted

import functools
import logging
import time


def logged(log):
    """Return a decorator that times each call and logs it to log."""

    def decorator(fn):
        @functools.wraps(fn)
        def wrapper(*args, **kwargs):
            t0 = time.perf_counter()
            try:
                result = fn(*args, **kwargs)
            except Exception:
                log.exception("%s failed", fn.__name__)
                raise
            log.debug("%s returned %r in %.6f s", fn.__name__, result, time.perf_counter() - t0)
            return result

        return wrapper

    return decorator

import argparse
import sys
from pathlib import Path


def build_parser():
    """The command-line interface of count_over.py."""
    parser = argparse.ArgumentParser(prog="count_over.py", description="Count the values above a limit.")
    parser.add_argument("path", type=Path, help="a text file, one number per line")
    parser.add_argument("--limit", type=float, default=35.0, help="count values above this")
    return parser


def run(args):
    """How many values in the file are above the limit."""
    count = 0
    with open(args.path, encoding="utf-8") as f:
        for n, line in enumerate(f, start=1):
            text = line.strip()
            if not text:
                continue
            try:
                value = float(text)
            except ValueError:
                raise ValueError(f"line {n} is not a number")
            if value > args.limit:
                count += 1
    return count


def main(argv=None):
    """Run the tool; return the exit status."""
    args = build_parser().parse_args(argv)
    try:
        count = run(args)
    except FileNotFoundError:
        print(f"error: {args.path} not found", file=sys.stderr)
        return 1
    except ValueError as exc:
        print(f"error: {exc}", file=sys.stderr)
        return 1
    print(count)
    return 0

+++ question | What runs on import
--- ask
`gnc/__init__.py` contains `from .frames import body_to_inertial`, and `gnc/frames.py` begins with `from .units import deg_to_rad`. Nothing else in the package imports anything. A fresh interpreter runs `import gnc.units`. Which files run, in which order?
--- choice correct
`gnc/__init__.py` starts, then `frames.py`, then `units.py`; `units` is then already loaded, so the requested import runs nothing more.
--- choice
Only `units.py`: importing a submodule by its full name skips the package's `__init__.py`.
--- choice
`units.py`, then `gnc/__init__.py`, then `frames.py`: the requested module is loaded first.
--- choice
`gnc/__init__.py`, then `units.py`, then `frames.py`, then `units.py` a second time.

Importing any submodule imports its package first, so `gnc/__init__.py` runs. Its first line imports `frames`, whose first line imports `units`. That is why everything in `__init__.py` is paid for by every import of every submodule.

from dataclasses import dataclass


@dataclass(frozen=True)
class Frame:
    """One telemetry frame: time, altitude and vertical speed."""

    t: float
    alt_m: float
    vel_ms: float


def read_frames(path):
    """Yield a Frame per data line; comment and blank lines are skipped."""
    with open(path, encoding="utf-8") as f:
        for n, line in enumerate(f, start=1):
            text = line.strip()
            if not text or text.startswith("#"):
                continue
            fields = text.split()
            if len(fields) != 3:
                raise ValueError(f"line {n}: expected 3 fields, got {len(fields)}")
            try:
                t, alt, vel = (float(x) for x in fields)
            except ValueError:
                raise ValueError(f"line {n}: not a number in {text!r}")
            yield Frame(t, alt, vel)


def apogee(frames):
    """The frame with the greatest altitude (the first of equals), or None."""
    best = None
    for frame in frames:
        if best is None or frame.alt_m > best.alt_m:
            best = frame
    return best

UNITS = {"m": 1.0, "km": 1000.0, "ft": 0.3048}


class Quantity:
    """A length and its unit; equal and hashed by its value in metres."""

    def __init__(self, value, unit):
        if unit not in UNITS:
            raise ValueError(f"unknown unit {unit!r}")
        self.value = float(value)
        self.unit = unit

    @classmethod
    def parse(cls, text):
        """A Quantity from text such as "12.5 km"."""
        parts = text.split()
        if len(parts) != 2:

    """Log a stage's start and end, record how long it took, and log its failure."""

import functools


def cached_by(key):
    """Return a decorator that caches results under key(*args, **kwargs)."""

    def decorator(fn):
        cache = {}

        @functools.wraps(fn)
        def wrapper(*args, **kwargs):
            k = key(*args, **kwargs)
            if k in cache:
                wrapper.hits += 1
                return cache[k]
            wrapper.misses += 1
            result = fn(*args, **kwargs)
            cache[k] = result
            return result

        def cache_clear():
            cache.clear()
            wrapper.hits = 0
            wrapper.misses = 0

        wrapper.hits = 0
        wrapper.misses = 0
        wrapper.cache_clear = cache_clear
        return wrapper

    return decorator

from typing import Protocol, runtime_checkable


class Baro:
    """A barometric altimeter: noisy, but it never fails."""

    def __init__(self, name, variance, altitude_m):
        self.name = name
        self.variance = variance
        self.altitude_m = altitude_m

    def read(self):
        return self.altitude_m

    def healthy(self):
        return True


@runtime_checkable
class Altimeter(Protocol):
    """Anything that reads an altitude, knows its variance and reports its health."""

    name: str
    variance: float

    def read(self) -> float: ...

    def healthy(self) -> bool: ...


class Fused:
    """An inverse-variance weighted blend of whichever altimeters are healthy."""

    def __init__(self, sensors):
        self.sensors = list(sensors)
        if not self.sensors:
            raise ValueError("no sensors")
        names = set()
        for s in self.sensors:
            if not isinstance(s, Altimeter):
                raise TypeError(f"{s!r} is not an Altimeter")
            if s.variance <= 0:
                raise ValueError(f"{s.name}: variance must be positive, got {s.variance}")
            if s.name in names:
                raise ValueError(f"two sensors named {s.name!r}")
            names.add(s.name)

    def _healthy(self):
        good = [s for s in self.sensors if s.healthy()]
        if not good:
            raise ValueError("no healthy sensor")
        return good

    def weights(self):
        good = self._healthy()
        total = sum(1.0 / s.variance for s in good)
        return {s.name: (1.0 / s.variance) / total for s in good}

    def estimate(self):
        good = self._healthy()
        total = sum(1.0 / s.variance for s in good)
        return sum(s.read() / s.variance for s in good) / total

def build_parser():
    """The command-line interface of margins.py."""
    parser = argparse.ArgumentParser(prog="margins.py", description="Report dispersion cases over a q limit.")
    parser.add_argument("path", type=Path, help="CSV file with the columns case and q_kpa")

def over_limit(path, limit):
    """Names of the cases whose q_kpa is above limit, in file order."""
    over = []
    with open(path, newline="", encoding="utf-8") as f:
        for row in csv.DictReader(f):
            q = float(row["q_kpa"])
            log.debug("case %s: q=%.1f kPa", row["case"], q)
            if q > limit:
                log.warning("case %s: q=%.1f kPa over %.1f", row["case"], q, limit)

    return 1 if over else 0

import math
from dataclasses import dataclass
from itertools import groupby
from operator import attrgetter


@dataclass(frozen=True)
class CaseResult:
    """One dispersion case; the margin must be a finite number."""

    case_id: int
    config: str
    margin: float

    def __post_init__(self):
        if not math.isfinite(self.margin):
            raise ValueError(f"case {self.case_id}: margin is {self.margin}")


def worst_by_config(results, n):
    """Config -> ids of its n smallest margins, smallest first; keys sorted."""
    if n < 1:
        raise ValueError(f"n must be at least 1, got {n}")
    ordered = sorted(results, key=attrgetter("config", "margin", "case_id"))
    return {config: [r.case_id for r in group][:n] for config, group in groupby(ordered, key=attrgetter("config"))}

import typing
from dataclasses import dataclass, field


def _convert(text, kind, name):
    """text converted by the annotation kind; ValueError or TypeError when it cannot be."""
    if kind is bool:
        word = text.strip().lower()
        if word not in ("true", "false"):
            raise ValueError(f"{name}: expected true or false, got {text!r}")
        return word == "true"
    if kind is int or kind is float:
        return kind(text)
    if kind is str:
        return text
    raise TypeError(f"{name}: cannot convert text to {kind!r}")


def parse_record(cls, fields):
    """An instance of the dataclass cls, each text converted by its field's annotation."""
    hints = typing.get_type_hints(cls)
    values = {}
    for name, text in fields.items():
        if name not in hints:
            raise TypeError(f"{cls.__name__} has no field {name!r}")
        values[name] = _convert(text, hints[name], name)
    return cls(**values)

    duration_s: float

--- solution
import csv


class Channel:
    """One column of a CSV run file, read afresh on every loop."""

    def __init__(self, path, name):
        self.path = path
        self.name = name

    def __repr__(self):
        return f"Channel({self.name!r}, {self.path.name!r})"

    def __iter__(self):
        with open(self.path, newline="", encoding="utf-8") as f:
            for row in csv.DictReader(f):
                text = row[self.name].strip()
                if text:
                    yield float(text)

    def __len__(self):
        return sum(1 for _ in self)


def stats(values):
    """(mean, peak) of a collection in two walks; TypeError for an iterator."""
    if hasattr(values, "__next__"):
        raise TypeError("stats needs a collection it can walk twice, not an iterator")
    total = 0.0
    count = 0
    for v in values:
        total += v
        count += 1
    if count == 0:
        return None, None
    return total / count, max(values)

