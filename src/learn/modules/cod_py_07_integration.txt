import numpy as np

F = 15000.0      # thrust, N
VE = 3000.0      # exhaust velocity, m/s
G_MOON = 1.62    # lunar gravity, m/s^2


def lander(t, y):
    """Rates of [altitude, velocity, mass] for a lander under constant thrust."""
    h, v, m = y
    return np.array([v, F / m - G_MOON, -F / VE])

+++ practice | Scaling an error to a new step
--- task
You measured an error `err` at step size `h` for a method of order `order`. Write a function `predict_error(err, h, h_new, order, kind)` that predicts the error at the step `h_new`.

- `kind` is `"local"` for the error of one step, or `"global"` for the error at the end of a fixed run.
- A method of order p has a local error that scales like h to the power p + 1, and a global error that scales like h to the power p.
- For any other `kind`, raise `ValueError`.
- Return a float.

So an Euler run (order 1) that ends 24.52 m off at `h = 0.5` should end about 12.26 m off at `h = 0.25`: `predict_error(24.52, 0.5, 0.25, 1, "global")` is `12.26`.
--- starter

--- solution
def predict_error(err, h, h_new, order, kind):
    """Scale an error measured at step h to step h_new for a method of the given order."""
    if kind == "local":
        power = order + 1
    elif kind == "global":
        power = order
    else:
        raise ValueError(f"kind must be 'local' or 'global', not {kind!r}")
    return err * (h_new / h) ** power
--- hint
The unknown constant in front of h to the power cancels when you take a ratio: the new error is the old one times `(h_new / h)` to the right power.
--- hint
Pick the power first: `order + 1` for one step, `order` for the whole run.

+++ practice | Measuring both powers at once
--- task
Write a function `euler_orders(f, exact, t0, t1, n)` that measures, for Euler's method, how the error of one step and the error of a whole run scale with the step size.

- `f(t, y)` is a right-hand side and `exact(t)` returns the true state at time `t` as a NumPy array.
- Let `h = (t1 - t0) / n`.
- **Local:** start at the true state `exact(t0)`, take one Euler step of size `h`, and compare with `exact(t0 + h)`. Do it again with `h / 2`. The local power is the base-2 logarithm of the first error over the second.
- **Global:** run `n` Euler steps from `t0` to `t1` starting from `exact(t0)`, compare the end with `exact(t1)`, then do the same with `2 * n` steps. The global power is the base-2 logarithm of the ratio of the two final errors.
- Measure each error as the length (`np.linalg.norm`) of the difference.
- Return `(local_power, global_power)` as two plain floats.

For `y' = y` from 0 to 1 with `n = 100`, the result is close to `(2.0, 1.0)`.
--- starter

--- solution
import numpy as np


def euler_orders(f, exact, t0, t1, n):
    """Measured powers of h for Euler's one-step error and its end-of-run error."""
    def one_step_error(h):
        y = np.asarray(exact(t0), dtype=float)
        return np.linalg.norm(y + h * np.asarray(f(t0, y)) - exact(t0 + h))

    def run_error(steps):
        h = (t1 - t0) / steps
        y = np.asarray(exact(t0), dtype=float)
        for i in range(steps):
            y = y + h * np.asarray(f(t0 + i * h, y))
        return np.linalg.norm(y - exact(t1))

    h = (t1 - t0) / n
    local = np.log2(one_step_error(h) / one_step_error(h / 2))
    whole = np.log2(run_error(n) / run_error(2 * n))
    return float(local), float(whole)
--- hint
Write two small helpers inside the function: one that returns the error of a single step of a given size, and one that returns the error at `t1` after a given number of steps.
--- hint
Each power is `np.log2(error_at_h / error_at_half_h)`. For the run, the halved step means twice as many steps.

+++ practice | A step size that does not divide the span
--- task
Write a function `euler_by_step(f, y0, t0, t1, h)` that runs Euler's method from `t0` to `t1` with steps of a given size `h`, and returns the final state. Here `t1 > t0` and `h > 0`.

- The number of steps is the whole number nearest to `(t1 - t0) / h`. Floating-point division can land a hair off: `0.3 / 0.1` is `2.9999999999999996`, and that is still 3 steps.
- If that number of steps times `h` misses the span `t1 - t0` by more than `1e-9` times the span, `h` does not divide the span: raise `ValueError`. That includes a step longer than the whole span.
- Step `i` starts at time `t0 + i * h`.
- `y0` may be a list or an array. Return a new float array, and do not change `y0`.

So `euler_by_step(lambda t, y: np.array([t]), [0.0], 0.0, 0.3, 0.1)` takes 3 steps and returns `[0.03]`.
--- starter

--- solution
import numpy as np


def euler_by_step(f, y0, t0, t1, h):
    """Final state after Euler steps of size h from t0 to t1; h must divide the span."""
    span = t1 - t0
    n = round(span / h)
    if n < 1 or abs(n * h - span) > 1e-9 * span:
        raise ValueError(f"a step of {h} does not divide the span {span}")
    y = np.array(y0, dtype=float)
    for i in range(n):
        y = y + h * np.asarray(f(t0 + i * h, y))
    return y
--- hint
`int(0.3 / 0.1)` is 2, because `int` cuts off the fraction. `round` goes to the nearest whole number.
--- hint
After rounding, multiply back: if `n * h` is not the span (to within a tiny relative amount), or `n` is 0, the step does not fit.

import numpy as np


def euler(f, y0, t0, t1, n):

+++ practice | Apogee from Euler steps
--- task
A small rocket coasts straight up from altitude 0 with speed `v0` (m/s). Gravity is `G0 = 9.80665` m/s² and air drag slows it: the velocity changes at the rate `-G0 - c * v * |v|`, where `c` is a drag constant in 1/m. The altitude changes at the rate `v`.

Write a function `euler_apogee(v0, c, h)` that finds the top of the climb with Euler steps of size `h`:

- start at time 0, altitude 0, velocity `v0`;
- take Euler steps until the new velocity is 0 or less;
- in that last step the velocity went from `v_old > 0` to `v_new <= 0`, so the top is a fraction `frac = v_old / (v_old - v_new)` of the way through the step. Return `(t_top, alt_top)`: the time and the altitude at that fraction, both found by going the same fraction along the straight line from the start to the end of the step;
- if `v0` is 0 or less, return `(0.0, 0.0)`.

Return plain floats. With `c = 0`, gravity is constant, Euler's velocity is exact, and `t_top` must be `v0 / G0`.
--- starter
G0 = 9.80665


def euler_apogee(v0, c, h):
    pass
--- solution
G0 = 9.80665


def euler_apogee(v0, c, h):
    """Time and altitude of the top of a drag-slowed coast, from Euler steps of size h."""
    if v0 <= 0:
        return 0.0, 0.0
    t, alt, v = 0.0, 0.0, float(v0)
    while True:
        accel = -G0 - c * v * abs(v)
        alt_new, v_new = alt + h * v, v + h * accel
        if v_new <= 0:
            frac = v / (v - v_new)
            return t + frac * h, alt + frac * (alt_new - alt)
        t, alt, v = t + h, alt_new, v_new
--- hint
Keep three numbers, time, altitude and velocity, and update them together in a `while` loop. Work out the new altitude and velocity from the old values before you overwrite anything.
--- hint
When the new velocity is 0 or less, stop and interpolate: the time is `t + frac * h` and the altitude is `alt + frac * (alt_new - alt)`.

+++ practice | Ralston's second-order step
--- task
The midpoint method is one member of the RK2 family. Another is **Ralston's method**, which takes its second slope two thirds of the way through the step and weights the two slopes one quarter and three quarters:

- `k1 = f(t, y)`
- `k2 = f(t + 2h/3, y + (2h/3) * k1)`

One step of `h = 0.1` on `y' = y cos t` from `y = [1.0]` at `t = 0` gives about `[1.1048223]`.

--- solution
import numpy as np


def ralston_step(f, t, y, h):
    """One step of Ralston's second-order Runge-Kutta method."""
    k1 = np.asarray(f(t, y))
    k2 = np.asarray(f(t + 2.0 * h / 3.0, y + (2.0 * h / 3.0) * k1))
    return y + h * (0.25 * k1 + 0.75 * k2)
--- hint
Two stages: the slope at the start, then the slope at the point you reach by walking two thirds of a step along it. The stage time moves by two thirds of a step too.
--- hint
The weights 1/4 and 3/4 add up to 1, so the update is `y + h * (0.25 * k1 + 0.75 * k2)`.

+++ practice | Orders from a list of runs
--- task
Write a function `observed_orders(step, f, y0, t0, t1, exact_end, ns)` that measures a method's order from several runs.

- `step(f, t, y, h)` is a one-step method, such as an Euler or RK4 step. `exact_end` is the true state at `t1`, as an array.
- For each number of steps `n` in the list `ns`, run `n` equal steps of `step` from `t0` to `t1`, starting from a float array copy of `y0`, and measure the error as the length (`np.linalg.norm`) of the final state minus `exact_end`. Step `i` starts at `t0 + i * h`.
- For each pair of neighbouring runs, the order is the logarithm of the error ratio divided by the logarithm of the ratio of step counts: `log(e1 / e2) / log(n2 / n1)`. When each run has twice the steps of the last, that is the base-2 logarithm of the ratio.
- Return a list of plain floats, one shorter than `ns`.

So for the midpoint method on `y' = y cos t` from 0 to 2 with `ns = [10, 20, 40, 80]`, the result is about `[1.68, 1.84, 1.92]`, climbing toward 2.
--- starter
import numpy as np


def observed_orders(step, f, y0, t0, t1, exact_end, ns):
    pass
--- solution
import numpy as np


def observed_orders(step, f, y0, t0, t1, exact_end, ns):
    """Measured order between each pair of neighbouring runs in ns."""
    errors = []
    for n in ns:
        h = (t1 - t0) / n
        y = np.array(y0, dtype=float)
        for i in range(n):
            y = np.asarray(step(f, t0 + i * h, y, h), dtype=float)
        errors.append(np.linalg.norm(y - exact_end))
    return [float(np.log(errors[i] / errors[i + 1]) / np.log(ns[i + 1] / ns[i]))
            for i in range(len(ns) - 1)]
--- hint
First collect one final error per entry of `ns`. Then walk the neighbouring pairs of that list.
--- hint
The step count ratio matters: tripling the steps of a first-order method cuts the error by 3, and `log(3) / log(3)` is 1.

+++ practice | The period of a big swing
--- task
A pendulum of length `L` meters swings under gravity `G0 = 9.80665` m/s². Its angle `theta` obeys `theta'' = -(G0 / L) * sin(theta)`. For small swings the period is `2 * pi * sqrt(L / G0)`, but a big swing takes longer, and there is no simple formula.

Write a function `pendulum_period(theta0, L, h)` that measures the period with classic RK4:

- the state is `[theta, omega]`, with `omega` the angular rate; start at `[theta0, 0.0]` at time 0, where `0 < theta0 < pi`;
- take RK4 steps of size `h`. The pendulum swings back, so `omega` goes negative, and half a period later it comes back up to zero at the far side;
- stop at the first step where `omega` goes from below zero to zero or above. Find the moment it crossed zero by going along the straight line between the two values of `omega`, as a fraction of the step;
- the period is twice that moment. Return it as a float.

For `theta0 = 1.0` and `L = 1.0`, the period is about 2.13950 s, against 2.00641 s for a small swing.
--- starter

--- solution
import numpy as np

G0 = 9.80665


def rk4_step(f, t, y, h):
    k1 = f(t, y)
    k2 = f(t + h / 2, y + h / 2 * k1)
    k3 = f(t + h / 2, y + h / 2 * k2)
    k4 = f(t + h, y + h * k3)
    return y + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)


def pendulum_period(theta0, L, h):
    """Period of a pendulum released at rest from theta0, from RK4 steps of size h."""
    def swing(t, y):
        return np.array([y[1], -(G0 / L) * np.sin(y[0])])

    t, y = 0.0, np.array([theta0, 0.0])
    while True:
        y_new = rk4_step(swing, t, y, h)
        if y[1] < 0.0 <= y_new[1]:

import numpy as np


def integrate(step, f, y0, t0, t1, n):
    """n equal steps of `step` from t0 to t1. Returns ts (n+1,) and ys (n+1, states)."""
    if n < 1:
        raise ValueError("n must be at least 1")
    y0 = np.atleast_1d(np.asarray(y0, dtype=float))
    ts = np.linspace(t0, t1, n + 1)
    h = (t1 - t0) / n
    ys = np.empty((n + 1, y0.size))
    ys[0] = y0
    for i in range(n):
        ys[i + 1] = step(f, ts[i], ys[i], h)
    return ts, ys

def error_norm(err, y, y_new, rtol, atol):

import numpy as np


def controlled_step(f, t, y, h, rtol, atol):
    """Retry the midpoint-Euler pair from (t, y) until a step passes the error test."""
    rejections = 0
    while True:
        if h < 1e-12 * max(1.0, abs(t)):
            raise RuntimeError("the step size collapsed")
        k1 = np.asarray(f(t, y))
        k2 = np.asarray(f(t + 0.5 * h, y + 0.5 * h * k1))
        y_new = y + h * k2
        scale = atol + rtol * np.maximum(np.abs(y), np.abs(y_new))
        norm = float(np.sqrt(np.mean((h * (k2 - k1) / scale) ** 2)))
        factor = 5.0 if norm == 0 else min(5.0, max(0.2, 0.9 * (1.0 / norm) ** 0.5))
        if norm <= 1.0:
            return h, y_new, h * factor, rejections
        h *= factor
        rejections += 1

def bs23_step(f, t, y, h, k1=None):
    """One Bogacki-Shampine 3(2) step: (third-order answer, error estimate, slope at the end)."""
    if k1 is None:
        k1 = np.asarray(f(t, y))
    k2 = np.asarray(f(t + 0.5 * h, y + 0.5 * h * k1))
    k3 = np.asarray(f(t + 0.75 * h, y + 0.75 * h * k2))

import numpy as np
from scipy.integrate import solve_ivp


def trusted_final(fun, t_span, y0, methods, rtol, atol, tol):
    """The cheapest method's final state, once every method has succeeded and they agree."""
    runs = []
    for method in methods:
        sol = solve_ivp(fun, t_span, y0, method=method, rtol=rtol, atol=atol)
        if not sol.success:
            raise RuntimeError(f"{method}: {sol.message}")
        runs.append((sol.nfev, method, sol.y[:, -1]))
    finals = np.array([r[2] for r in runs])
    if np.max(finals.max(axis=0) - finals.min(axis=0)) > tol:
        raise ValueError("the methods disagree by more than tol")
    nfev, name, final = min(runs, key=lambda r: r[0])
    return name, final

--- hint
Two finals differ by more than `tol` somewhere exactly when, in some component, the largest final minus the smallest is more than `tol`. `min` with `key=` finds the cheapest record, and on a tie keeps the first.

import numpy as np


def allowance(y, y_new, rtol, atol):
    """Per-component error allowance: atol + rtol * the bigger of the old and new size."""
    return atol + rtol * np.maximum(np.abs(y), np.abs(y_new))


def in_charge(y, rtol, atol):
    """For each component, which term of the allowance is bigger."""
    rel = rtol * np.abs(np.asarray(y, dtype=float))
    floor = np.broadcast_to(atol, rel.shape)
    return ["rtol" if r > a else "atol" for r, a in zip(rel, floor)]

def rerun_estimate(fun, t_span, y0, rtol, scales, **options):
    """Final state of a run, and its error estimated from a rerun at rtol / 10."""
    scales = np.asarray(scales, dtype=float)
    loose = solve_ivp(fun, t_span, y0, method="DOP853", rtol=rtol, atol=rtol * scales, **options)

import numpy as np


def output_grid(t0, t1, dt):
    """Output times t0, t0 + dt, ... up to t1, never past it, ending exactly on t1 when it lands there."""
    k = int(np.floor((t1 - t0) / dt + 1e-9))
    grid = t0 + dt * np.arange(k + 1)
    if abs(grid[-1] - t1) <= 1e-9 * dt:

    return np.minimum(grid, t1)

def time_to_level(h0, v0, level, t_max):

--- solution
import numpy as np
from scipy.integrate import solve_ivp

G0 = 9.80665


def coast(t, y, k):
    return [y[1], -G0 - k * y[1] * abs(y[1])]


def time_above(h0, v0, k, level):
    """Seconds spent above `level` by a drag-slowed coast, found phase by phase."""
    def top(t, y, k):
        return y[1]
    top.terminal = True
    top.direction = -1

    def through(t, y, k):
        return y[0] - level
    through.terminal = True

    opts = dict(args=(k,), rtol=1e-12, atol=1e-9)
    up = solve_ivp(coast, (0.0, 1e4), [h0, v0], events=top, **opts)
    t_top, y_top = up.t[-1], up.y[:, -1]
    if y_top[0] <= level:
        return 0.0
    t_in = 0.0
    if h0 < level:                      # the climb crosses the level exactly once
        through.direction = 1
        climb = solve_ivp(coast, (0.0, t_top), [h0, v0], events=through, **opts)
        t_in = climb.t_events[0][0]
    through.direction = -1              # so does the fall
    fall = solve_ivp(coast, (t_top, t_top + 1e4), y_top, events=through, **opts)
    return float(fall.t_events[0][0] - t_in)

--- hint

def growth(method, h, lam):
    """Factor one step multiplies y by on y' = -lam * y."""
    x = h * lam
    if method == "euler":
        return 1.0 - x
    if method == "backward_euler":

    if method == "midpoint":

    if method == "rk4":

import numpy as np
from scipy.optimize import brentq


def stability_limit(coeffs):
    """Largest x = h * lam for which |R(-x)| stays at most 1."""
    def excess(x):
        z = -x
        return abs(sum(c * z ** k for k, c in enumerate(coeffs))) - 1.0

    x = 0.001
    while excess(x) <= 0.0:
        x += 0.001
    return float(brentq(excess, x - 0.001, x, xtol=1e-12))

import numpy as np


def backward_euler(A, y0, h, n):
    """n backward Euler steps of size h on y' = A y."""
    A = np.asarray(A, dtype=float)
    y = np.array(y0, dtype=float)
    M = np.eye(len(y)) - h * A
    for _ in range(n):

    return y

import numpy as np


def stiffness_ratio(J):
    """Fastest decay rate over slowest, among the decaying modes of J."""
    eig = np.linalg.eigvals(np.asarray(J, dtype=float))
    size = np.abs(eig)
    keep = (eig.real < 0) & (size > 1e-12 * size.max())
    rates = -eig.real[keep]
    if rates.size < 2:
        return 1.0
    return float(rates.max() / rates.min())

from scipy.integrate import solve_ivp

MU = 3.986004418e14


def two_body(t, y):
    r = y[:3]
    return np.concatenate([y[3:], -MU * r / np.linalg.norm(r) ** 3])


def energy(Y):
    return 0.5 * np.sum(Y[3:] ** 2, axis=0) - MU / np.linalg.norm(Y[:3], axis=0)


def max_energy_drift(method, rtol, n_revs, a):
    """Largest relative energy drift over n_revs revolutions of a circular orbit."""
    v = np.sqrt(MU / a)
    y0 = np.array([a, 0.0, 0.0, 0.0, v, 0.0])
    t_end = n_revs * 2 * np.pi * np.sqrt(a ** 3 / MU)

def broken_invariants(y_start, y_end, mu, tol):
    """The set of two-body invariants whose relative change is more than tol."""
    a = np.asarray(y_start, dtype=float)
    b = np.asarray(y_end, dtype=float)

        return 0.5 * y[3:] @ y[3:] - mu / np.linalg.norm(y[:3])

import numpy as np


def jacobi(s, mu):
    """Jacobi constant of a rotating-frame CR3BP state."""
    x, y, z, vx, vy, vz = s
    r1 = np.sqrt((x + mu) ** 2 + y ** 2 + z ** 2)
    r2 = np.sqrt((x - 1 + mu) ** 2 + y ** 2 + z ** 2)
    omega = 0.5 * (x ** 2 + y ** 2) + (1 - mu) / r1 + mu / r2
    return float(2 * omega - (vx ** 2 + vy ** 2 + vz ** 2))


def jacobi_from_inertial(S, t, mu):
    """Jacobi constant of an inertial state at time t, via the rotating frame."""
    X, Y, Z, VX, VY, VZ = S
    c, s = np.cos(t), np.sin(t)
    x = c * X + s * Y
    y = -s * X + c * Y
    vx = (c * VX + s * VY) + y
    vy = (-s * VX + c * VY) - x
    return jacobi([x, y, Z, vx, vy, VZ], mu)

import numpy as np


def pendulum_symplectic(q0, p0, h, n):
    """n symplectic Euler steps (kick, then drift) of the unit pendulum."""
    qs = np.empty(n + 1)
    ps = np.empty(n + 1)
    qs[0], ps[0] = q0, p0
    q, p = q0, p0
    for i in range(n):
        p = p - h * np.sin(q)
        q = q + h * p
        qs[i + 1], ps[i + 1] = q, p
    return qs, ps

import numpy as np


def area_factor(step, h):
    """Determinant of one step's linear map on the unit spring."""
    q1, p1 = step(1.0, 0.0, h)
    q2, p2 = step(0.0, 1.0, h)

import numpy as np

W1 = 1.0 / (2.0 - 2.0 ** (1.0 / 3.0))
W0 = 1.0 - 2.0 * W1


def leapfrog_step(accel, r, v, h):
    """Kick, drift, kick."""
    v = v + 0.5 * h * accel(r)
    r = r + h * v
    v = v + 0.5 * h * accel(r)
    return r, v


def yoshida_step(accel, r, v, h):
    """Three leapfrog substeps with weights W1, W0, W1: fourth order and symplectic."""
    for w in (W1, W0, W1):
        r, v = leapfrog_step(accel, r, v, w * h)
    return r, v

import numpy as np


def round_trip(step, q0, p0, h, n):
    """Distance from the start after n steps of h and then n steps of -h."""
    q, p = q0, p0
    for _ in range(n):

def librates(q0, p0, h, n):
    """True if a leapfrog pendulum never passes |q| = pi in n steps."""
    q, p = q0, p0
    a = -np.sin(q)

--- choice

import numpy as np
from scipy.integrate import solve_ivp


def run_phases(fun, y0, t0, phases, **options):
    """Integrate phase after phase, each with its own args; join the histories."""
    t, y = t0, np.array(y0, dtype=float)
    ts, ys = [], []
    for t_end, params in phases:
        if t_end < t:
            raise ValueError(f"a phase ends at {t_end}, before the current time {t}")
        if t_end == t:
            continue
        sol = solve_ivp(fun, (t, t_end), y, args=params, **options)
        ts.append(sol.t)
        ys.append(sol.y)
        t, y = sol.t[-1], sol.y[:, -1].copy()
    if not ts:
        return np.array([t]), y[:, None]
    return np.concatenate(ts), np.hstack(ys)

import numpy as np
from scipy.integrate import solve_ivp

D, A = 2e-4, 1e-3
THETA_ON, OMEGA_OFF = 0.01, -0.002


def attitude(t, y, accel):
    return [y[1], accel]


def deadband(t_end):
    """Firings, total on-time and final [theta, omega] of a hysteresis thruster loop."""
    def turn_on(t, y, accel):
        return y[0] - THETA_ON
    turn_on.terminal = True
    turn_on.direction = 1

    def turn_off(t, y, accel):
        return y[1] - OMEGA_OFF
    turn_off.terminal = True
    turn_off.direction = -1

    t, y = 0.0, np.array([0.0, 0.0])
    firing, firings, on_time = False, 0, 0.0
    while t < t_end:
        accel, event = (D - A, turn_off) if firing else (D, turn_on)
        sol = solve_ivp(attitude, (t, t_end), y, args=(accel,), events=event,
                        rtol=1e-10, atol=1e-12)
        if firing:
            on_time += sol.t[-1] - t
        t, y = sol.t[-1], sol.y[:, -1].copy()
        if sol.status != 1:
            break
        firing = not firing
        if firing:
            firings += 1
    return firings, float(on_time), y

+++ question | A flag set inside an event function
--- ask
To switch from stage 1 to stage 2, this code has the event function set a global flag that the right-hand side reads, and makes a single call to `solve_ivp`:

```python
stage = 1

def burnout(t, y):
    global stage
    if y[2] <= M_DRY_1:
        stage = 2
    return y[2] - M_DRY_1

def rhs(t, y):
    thrust, mdot = (T1, MDOT1) if stage == 1 else (T2, MDOT2)
    ...
```

What is wrong with it?
--- choice
Nothing: `solve_ivp` calls the event function exactly once per accepted step, right after the step.
--- choice correct
The solver calls event functions and the right-hand side at trial points, including rejected steps and the root search, so the flag flips at the wrong moment, and the step that straddles burnout still mixes both stages.
--- choice
Global variables cannot be read inside a function passed to `solve_ivp`.
--- choice
It is fine as long as `burnout.terminal` is set to `True`.
--- why
Event functions and right-hand sides are called far more often than once per step: at every stage, at trial steps that are later thrown away, and many times while the crossing is hunted down on the interpolant. A flag flipped inside them changes the model at a time the solver never committed to. Even with the flag right, one integration straight through the switch still straddles a jump. The fix is a terminal event that only returns a number, then your own code switches the stage and starts a new `solve_ivp` call.

import numpy as np


def lag_exact(y0, commands, h, tau):
    """States of a first-order lag after each held command, from the exact one-frame update."""
    decay = np.exp(-h / tau)
    out = np.empty(len(commands))
    y = float(y0)
    for k, u in enumerate(commands):
        y = decay * y + (1.0 - decay) * u
        out[k] = y
    return out

import numpy as np


def substeps_for(frame, tau, tol):
    """Fewest RK4 substeps per frame that are stable and match e^(-frame/tau) to tol."""
    def growth(x):
        return 1 - x + x ** 2 / 2 - x ** 3 / 6 + x ** 4 / 24

    exact = np.exp(-frame / tau)
    m = 1
    while True:
        r = growth(frame / (m * tau))
        if abs(r) <= 1.0 and abs(r ** m - exact) <= tol:
            return m
        m += 1

def simulate_zoh(commands, frame, h, tau, y0=0.0):
    """A first-order lag under held commands, fixed-step RK4 with steps that divide the frame."""
    m = round(frame / h)
    if m < 1 or abs(m * h - frame) > 1e-9 * frame:
        raise ValueError(f"a step of {h} does not divide the frame {frame}")
    y = float(y0)
    for u in commands:
        for _ in range(m):
            k1 = (u - y) / tau
            k2 = (u - (y + h / 2 * k1)) / tau
            k3 = (u - (y + h / 2 * k2)) / tau
            k4 = (u - (y + h * k3)) / tau
            y += h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
    return y

--- solution
import numpy as np

MU = 3.986004418e14
A = 6.778e6


def rates(y):
    r = y[:3]
    return np.concatenate([y[3:], -MU * r / np.linalg.norm(r) ** 3])


def rk4_run(y, h, steps):
    for _ in range(steps):
        k1 = rates(y)
        k2 = rates(y + h / 2 * k1)
        k3 = rates(y + h / 2 * k2)
        k4 = rates(y + h * k3)
        y = y + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
    return y


def choose_step(horizon, req_m, budget_calls, candidates):
    """Largest candidate step that fits the call budget and meets the accuracy requirement."""
    n = np.sqrt(MU / A ** 3)
    y0 = np.array([A, 0.0, 0.0, 0.0, A * n, 0.0])
    exact = A * np.array([np.cos(n * horizon), np.sin(n * horizon), 0.0])

+++ problem | Kutta's three-eighths rule
--- task
Classic RK4 is not the only fourth-order Runge-Kutta method. Kutta's **3/8 rule** takes its stages at a third and two thirds of the step:

- `k1 = f(t, y)`
- `k2 = f(t + h/3, y + (h/3) * k1)`
- `k3 = f(t + 2h/3, y + h * (-k1/3 + k2))`
- `k4 = f(t + h, y + h * (k1 - k2 + k3))`
- the new state is `y + (h/8) * (k1 + 3 k2 + 3 k3 + k4)`

The checks prove the order by step halving on a problem whose right-hand side uses both `t` and `y`.

import numpy as np


def rk38_step(f, t, y, h):
    """One step of Kutta's 3/8 rule, a fourth-order Runge-Kutta method."""
    k1 = np.asarray(f(t, y))
    k2 = np.asarray(f(t + h / 3, y + (h / 3) * k1))
    k3 = np.asarray(f(t + 2 * h / 3, y + h * (-k1 / 3 + k2)))
    k4 = np.asarray(f(t + h, y + h * (k1 - k2 + k3)))
    return y + (h / 8) * (k1 + 3 * k2 + 3 * k3 + k4)


def rk38_solve(f, y0, t0, t1, n):
    """Final state after n equal 3/8-rule steps from t0 to t1."""
    if n < 1:
        raise ValueError("n must be at least 1")
    h = (t1 - t0) / n
    y = np.array(y0, dtype=float)
    for i in range(n):
        y = rk38_step(f, t0 + i * h, y, h)
    return y

import numpy as np


def ralston_adaptive(f, t0, t1, y0, h, rtol, atol):
    """Adaptive Ralston-Euler 2(1) integration. Returns accepted times, states and rejections."""
    t = t0
    y = np.array(y0, dtype=float)
    ts, ys, rejected = [t], [y.copy()], 0
    while t < t1:
        h = min(h, t1 - t)
        k1 = np.asarray(f(t, y))
        k2 = np.asarray(f(t + 2 * h / 3, y + (2 * h / 3) * k1))
        y_high = y + h * (0.25 * k1 + 0.75 * k2)
        err = y_high - (y + h * k1)
        scale = atol + rtol * np.maximum(np.abs(y), np.abs(y_high))
        norm = float(np.sqrt(np.mean((err / scale) ** 2)))
        if norm <= 1.0:
            t = t1 if h >= t1 - t else t + h
            y = y_high
            ts.append(t)
            ys.append(y.copy())
        else:
            rejected += 1
        h *= 5.0 if norm == 0 else min(5.0, max(0.2, 0.9 * (1.0 / norm) ** 0.5))
    return np.array(ts), np.array(ys), rejected

                v = v + 0.5 * h * acc
                w = max(w, abs((energy(r, v) - e0) / e0))
            worst.append(w)
    else:

        h = T / steps
        for _ in range(n_revs):
            w = 0.0
            for _ in range(steps):
                k1r, k1v = v, accel(r)
                k2r, k2v = v + h / 2 * k1v, accel(r + h / 2 * k1r)
                k3r, k3v = v + h / 2 * k2v, accel(r + h / 2 * k2r)
                k4r, k4v = v + h * k3v, accel(r + h * k3r)
                r = r + h / 6 * (k1r + 2 * k2r + 2 * k3r + k4r)
                v = v + h / 6 * (k1v + 2 * k2v + 2 * k3v + k4v)

import numpy as np
from scipy.linalg import expm


def zoh(A, B, h):
    """Exact zero-order-hold matrices: x_next = Phi x + Gamma u."""
    A = np.asarray(A, dtype=float)
    B = np.asarray(B, dtype=float)
    n, m = A.shape[0], B.shape[1]
    M = np.zeros((n + m, n + m))
    M[:n, :n] = A
    M[:n, n:] = B
    E = expm(M * h)
    return E[:n, :n], E[:n, n:]


def run_zoh(A, B, x0, commands, h):
    """Final state after one exact held-input frame per command."""
    Phi, Gamma = zoh(A, B, h)
    x = np.array(x0, dtype=float)
    for u in commands:
        x = Phi @ x + Gamma @ np.atleast_1d(np.asarray(u, dtype=float))
    return x

import numpy as np


def rk4_run(f, y0, t0, t1, n):
    h = (t1 - t0) / n
    y = np.array(y0, dtype=float)
    for i in range(n):
        t = t0 + i * h
        k1 = np.asarray(f(t, y))
        k2 = np.asarray(f(t + h / 2, y + h / 2 * k1))
        k3 = np.asarray(f(t + h / 2, y + h / 2 * k2))
        k4 = np.asarray(f(t + h, y + h * k3))
        y = y + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
    return y

    fine = rk4_run(f, y0, t0, t1, 2 * n)
    diff = (fine - coarse) / 15.0
    return fine, float(np.linalg.norm(diff)), fine + diff

+++ question | RK4 at three time constants
--- ask
For a decaying mode with time constant `tau`, classic RK4 multiplies the state each step by `R = 1 - x + x**2/2 - x**3/6 + x**4/24`, with `x = h / tau`. What is `R` at `h = 3 tau`? Type the number.
--- answer
1.375
11/8
--- why
`1 - 3 + 4.5 - 4.5 + 81/24 = 1 - 3 + 4.5 - 4.5 + 3.375 = 1.375`. It is bigger than 1, so every step makes the gap bigger and the simulation explodes, while the true factor is `e^(-3)`, about 0.05. RK4 is stable only up to `h / tau` of about 2.785; at `h = 3 tau` you need substeps, an exact update, or an implicit step.
