+++ practice | The report a test run prints
--- task
GoogleTest cannot be linked in this editor, so in this set you build small pieces of it by hand. The first piece is the report a run prints, and the exit code that `ctest` and CI read.

The starter defines `Result`: one finished test, with its suite name, its test name and whether it passed. Write two functions.

`std::string report(const std::vector<Result>& results)` returns the text of the run. For each result, in order, two lines:

```
[ RUN      ] Suite.Name
[       OK ] Suite.Name
```

with `[  FAILED  ] Suite.Name` as the second line when the test failed. The full name is the suite name, a dot, and the test name. After all the tests comes the line `[  PASSED  ] N tests.`, where N is how many passed. If any test failed, it is followed by `[  FAILED  ] M tests, listed below:` and then one line `[  FAILED  ] Suite.Name` for each failed test, in run order. Write `1 test` rather than `1 tests` in both summary lines. Every line ends with a newline, `\n`.

`int exit_code(const std::vector<Result>& results)` returns 0 when every test passed, and 1 otherwise. An empty run passed: its report is the single line `[  PASSED  ] 0 tests.` and its exit code is 0.

Copy the spacing inside the brackets exactly: `[ RUN      ]` has six spaces after `RUN`, `[       OK ]` has seven spaces before `OK`, and `[  FAILED  ]` and `[  PASSED  ]` have two spaces on each side.
--- starter
#include <string>
#include <vector>

struct Result {
    std::string suite;
    std::string name;
    bool passed;
};

std::string report(const std::vector<Result>& results) {
    return "";
}

int exit_code(const std::vector<Result>& results) {
    return -1;
}
--- solution
#include <cstddef>
#include <string>
#include <vector>

struct Result {
    std::string suite;
    std::string name;
    bool passed;
};

// "1 test" or "N tests", as GoogleTest writes its summary lines.
std::string count_of(std::size_t n) {
    return std::to_string(n) + (n == 1 ? " test" : " tests");
}

std::string report(const std::vector<Result>& results) {
    std::string out;
    std::vector<std::string> failed;
    for (const Result& r : results) {
        const std::string full = r.suite + "." + r.name;   // the name --gtest_filter matches
        out += "[ RUN      ] " + full + "\n";
        if (r.passed) {
            out += "[       OK ] " + full + "\n";
        } else {
            out += "[  FAILED  ] " + full + "\n";
            failed.push_back(full);
        }
    }
    out += "[  PASSED  ] " + count_of(results.size() - failed.size()) + ".\n";
    if (!failed.empty()) {
        out += "[  FAILED  ] " + count_of(failed.size()) + ", listed below:\n";
        for (const std::string& f : failed) out += "[  FAILED  ] " + f + "\n";
    }
    return out;
}

// What ctest and CI look at: 0 only when every test passed.
int exit_code(const std::vector<Result>& results) {
    for (const Result& r : results) {
        if (!r.passed) return 1;
    }
    return 0;
}
--- hint
Build the full name once per test, `suite + "." + name`, and keep a list of the failed full names for the summary at the end.
--- hint
The count of passed tests is the number of results minus the number of failed ones. A small helper that returns "1 test" or "N tests" saves writing the plural rule twice.
--- check test | One passing test
report({{"AltimeterTest", "StartsAtZero", true}}) == "[ RUN      ] AltimeterTest.StartsAtZero\n[       OK ] AltimeterTest.StartsAtZero\n[  PASSED  ] 1 test.\n"
--- check test | A pass and a failure, with the failure listed at the end
report({{"Imu", "Rate", true}, {"Imu", "Range", false}}) == "[ RUN      ] Imu.Rate\n[       OK ] Imu.Rate\n[ RUN      ] Imu.Range\n[  FAILED  ] Imu.Range\n[  PASSED  ] 1 test.\n[  FAILED  ] 1 test, listed below:\n[  FAILED  ] Imu.Range\n"
--- check test | Two failures are listed in run order
report({{"A", "One", false}, {"B", "Two", true}, {"A", "Three", false}}).substr(report({{"A", "One", false}, {"B", "Two", true}, {"A", "Three", false}}).find("[  PASSED  ]")) == "[  PASSED  ] 1 test.\n[  FAILED  ] 2 tests, listed below:\n[  FAILED  ] A.One\n[  FAILED  ] A.Three\n"
--- check test | An empty run passed
report({}) == "[  PASSED  ] 0 tests.\n" && exit_code({}) == 0
--- check test | Exit code 0 when everything passed
exit_code({{"Gps", "Fix", true}, {"Gps", "Time", true}}) == 0
--- check test | Exit code 1 when one test failed
exit_code({{"Gps", "Fix", true}, {"Gps", "Time", false}, {"Gps", "Week", true}}) == 1

+++ practice | Run a test the way TEST_F does
--- task
Write the part of GoogleTest that runs one `TEST_F`.

```cpp
template <class F>
bool run_test(void (*body)(F&));
```

`run_test` must follow the five steps of the lesson, in this order:

1. construct a brand-new fixture object of type `F`, used by this test only;
2. call its `SetUp()`;
3. call `body` with the fixture, unless `SetUp` set the fixture's `fatal` flag to `true` (a fatal failure in `SetUp` skips the body);
4. call its `TearDown()`, always, even when the body was skipped;
5. destroy the fixture before `run_test` returns.

It returns `true` if the body ran and `false` if it was skipped.

The starter gives you the `Fixture` base class, and `LogFixture`, which writes every step into the global `g_log`. It also gives `count_shot`, a test body that adds one to the fixture's `shots` and logs the new value. Do not change them: the checks read `g_log`.
--- starter
#include <string>
#include <vector>

std::vector<std::string> g_log;   // every step of every test, in order
bool g_break_setup = false;       // when true, the next SetUp fails fatally

// Plays the part of ::testing::Test.
class Fixture {
public:
    virtual ~Fixture() = default;
    virtual void SetUp() {}
    virtual void TearDown() {}
    bool fatal = false;           // set by SetUp when a fatal check fails
};

class LogFixture : public Fixture {
public:
    LogFixture() { g_log.push_back("ctor"); }
    ~LogFixture() override { g_log.push_back("dtor"); }
    void SetUp() override {
        g_log.push_back("SetUp");
        if (g_break_setup) fatal = true;
    }
    void TearDown() override { g_log.push_back("TearDown"); }
    int shots = 0;
};

// A test body.
void count_shot(LogFixture& f) {
    ++f.shots;
    g_log.push_back("body shots=" + std::to_string(f.shots));
}

template <class F>
bool run_test(void (*body)(F&)) {
    return false;
}
--- solution

#include <vector>

bool g_break_setup = false;       // when true, the next SetUp fails fatally

public:
    virtual ~Fixture() = default;
    virtual void SetUp() {}
    virtual void TearDown() {}
    bool fatal = false;           // set by SetUp when a fatal check fails
};

class LogFixture : public Fixture {
public:
    LogFixture() { g_log.push_back("ctor"); }
    ~LogFixture() override { g_log.push_back("dtor"); }
    void SetUp() override {
        g_log.push_back("SetUp");
        if (g_break_setup) fatal = true;
    }
    void TearDown() override { g_log.push_back("TearDown"); }
    int shots = 0;

// A test body.
void count_shot(LogFixture& f) {
    ++f.shots;
    g_log.push_back("body shots=" + std::to_string(f.shots));
}

template <class F>
bool run_test(void (*body)(F&)) {
    F fixture;                          // a new object for this test alone
    fixture.SetUp();
    const bool run_body = !fixture.fatal;
    if (run_body) body(fixture);        // a fatal SetUp skips the body...
    fixture.TearDown();                 // ...but never the cleanup
    return run_body;
}                                       // the fixture is destroyed here
--- hint
Declare the fixture as an ordinary local variable inside `run_test`. Its constructor runs at the declaration and its destructor runs when the function returns, which gives you steps 1 and 5 for free.
--- hint
Read `fatal` after `SetUp` returns, and call `TearDown` whether or not the body ran.

--- check test | After a failed SetUp, the next test runs normally
[] { g_log.clear(); g_break_setup = true; run_test<LogFixture>(count_shot); g_break_setup = false; bool ran = run_test<LogFixture>(count_shot); return ran && g_log.size() == 9 && g_log[6] == "body shots=1"; }()

+++ practice | Two tests that only pass alone
--- task
The starter tests a `BurnTimer`, which adds up engine burn times. Its fixture, `BurnTimerTest`, gives every test a timer that already holds the 1.5 s igniter check burn. Each test builds its own fixture object, the way `TEST_F` does, and returns whether its checks passed.

Each test passes when it runs alone. But whichever test runs second fails, and running the same test twice fails the second time. Find the line that shares state between tests and fix the fixture, so that every test passes in any order and any number of times.

Do not change `BurnTimer` or the two test functions.

class BurnTimer {
public:

        ++burns_;

    int burns() const { return burns_; }

+++ practice | Find the tests that depend on order
--- task
A test that passes alone and fails in the full run, or the other way round, depends on what ran before it. Write a tool that finds such tests, the way you would with `--gtest_filter` and `--gtest_shuffle`.

```cpp
struct NamedTest {
    std::string name;
    std::function<bool()> body;   // runs the test, returns true if it passed
};

std::vector<std::string> order_dependent(const std::vector<NamedTest>& tests,
                                         const std::function<void()>& reset_world);
```

The tests share some outside state, and `reset_world` puts that state back to its starting value. Run the tests three ways:

- **alone**: for each test, call `reset_world()` and then run that one test;
- **forward**: call `reset_world()` once, then run every test in the given order;
- **backward**: call `reset_world()` once, then run every test in the reverse order.

Return the names of the tests whose result is not the same in all three runs, in the order the tests were given. Return an empty vector when every test gives the same result every time.
--- starter
#include <functional>
#include <string>
#include <vector>

struct NamedTest {
    std::string name;
    std::function<bool()> body;
};

std::vector<std::string> order_dependent(const std::vector<NamedTest>& tests,
                                         const std::function<void()>& reset_world) {
    return {"not written yet"};
}
--- solution
#include <cstddef>
#include <functional>
#include <string>
#include <vector>

struct NamedTest {
    std::string name;
    std::function<bool()> body;
};

std::vector<std::string> order_dependent(const std::vector<NamedTest>& tests,
                                         const std::function<void()>& reset_world) {
    const std::size_t n = tests.size();
    std::vector<bool> alone(n), forward(n), backward(n);

    for (std::size_t i = 0; i < n; ++i) {       // each test alone, from a clean world
        reset_world();
        alone[i] = tests[i].body();
    }
    reset_world();                              // the full run, as written
    for (std::size_t i = 0; i < n; ++i) forward[i] = tests[i].body();
    reset_world();                              // the full run, reversed
    for (std::size_t i = n; i-- > 0;) backward[i] = tests[i].body();

    std::vector<std::string> out;
    for (std::size_t i = 0; i < n; ++i) {
        if (alone[i] != forward[i] || alone[i] != backward[i]) out.push_back(tests[i].name);
    }
    return out;
}
--- hint
Store three results per test, one for each kind of run, and compare them at the end.
--- hint
A test that leaves the world broken hurts the tests after it. Running backward as well as forward is what exposes a test that only passes because it happens to run early.
--- check test | A test that needs another test to run first

--- check test | A test broken by the one before it

--- check test | A test that only passes because it runs first

--- check test | Independent tests: nothing to report
[] { int x = 0; std::vector<NamedTest> t{{"A", [&] { x = 2; return x == 2; }}, {"B", [&] { x = 7; return x == 7; }}}; return order_dependent(t, [&] { x = 0; }).empty(); }()
--- check test | A test that always fails is not order dependent

+++ question | Which objects are fresh
--- ask
GoogleTest runs these three tests in the order they are written. Leaving out GoogleTest's own report lines, what do the tests print? Type it exactly.

```cpp
class CountTest : public ::testing::Test {
protected:
    CountTest() { ++built; }
    void SetUp() override { ++member; }
    static int built;
    int member = 0;
};
int CountTest::built = 0;

TEST_F(CountTest, A) { std::cout << built << member << " "; }
TEST_F(CountTest, B) { std::cout << built << member << " "; }
TEST_F(CountTest, C) { ++member; std::cout << built << member << "\n"; }
```
--- answer
11 21 32
--- why
`built` is `static`: one variable for the whole class, which the constructor bumps once per test, so it reads 1, 2 and 3. `member` is an ordinary member: every test gets a brand-new fixture where it starts at 0, and `SetUp` makes it 1. Test C adds one more, so it prints 2. A fixture resets its own members for every test, and nothing that lives outside the object.

+++ question | Private members in a fixture
--- ask
A teammate writes a fixture with its members under `private:`, then uses them in a `TEST_F`. What happens?

```cpp
class GainTest : public ::testing::Test {
private:
    GainTable table{2.0, 0.5, 0.1};
};

TEST_F(GainTest, HasThreeGains) {
    EXPECT_EQ(table.size(), 3u);
}
```
--- choice
It compiles and passes: `TEST_F` runs the body inside the fixture, so it can see private members.
--- choice correct
It does not compile: each `TEST_F` becomes a class derived from `GainTest`, and a derived class cannot reach private members. They must be `protected` or `public`.
--- choice
It compiles, but GoogleTest stops at run time with a message that the fixture is not usable.
--- choice
It compiles and runs, but every test shares one `table`, because private members are not rebuilt per test.
--- why
The `TEST_F` macro writes a class named after the fixture and the test, derived from the fixture, and your braces become its `TestBody()` function. A derived class sees `protected` and `public` members of its base, never `private` ones, so the compiler rejects `table`. Access has nothing to do with freshness: every member, whatever its access, is rebuilt with each new fixture object.

+++ practice | Your own EXPECT_EQ and ASSERT_EQ
--- task
Write the two macros at the heart of the lesson, so you see exactly how they differ.

- `EXPECT_EQ(a, b)`: if `(a) == (b)` is false, add one entry to the global `g_failures`, and carry on.
- `ASSERT_EQ(a, b)`: the same, and then leave the current function at once with `return;`.

The entry is the text of the two arguments joined by `" == "`, exactly as they were written in the call. For example, a failed `EXPECT_EQ(2 + 2, 5)` adds `"2 + 2 == 5"`. The preprocessor's `#` operator turns a macro argument into that text.

Each macro must evaluate each argument exactly once, and must work as one statement, so that `if (ok) EXPECT_EQ(x, 1); else EXPECT_EQ(x, 2);` compiles and does the right thing.
--- starter
#include <string>
#include <vector>

std::vector<std::string> g_failures;   // one entry per failed check

#define EXPECT_EQ(a, b) do { } while (0)
#define ASSERT_EQ(a, b) do { } while (0)
--- solution
#include <string>
#include <vector>

std::vector<std::string> g_failures;   // one entry per failed check

// Nonfatal: record the failure and let the next line run.
#define EXPECT_EQ(a, b)                                       \
    do {                                                      \
        if (!((a) == (b))) g_failures.push_back(#a " == " #b); \
    } while (0)

// Fatal: record the failure, then a hidden return leaves the function it is written in.
#define ASSERT_EQ(a, b)                                       \
    do {                                                      \
        if (!((a) == (b))) {                                  \
            g_failures.push_back(#a " == " #b);               \
            return;                                           \
        }                                                     \
    } while (0)
--- hint
`#a` inside a macro body is the text of the argument `a` as a string literal, and two string literals written side by side, `#a " == " #b`, join into one.
--- hint
Wrap each body in `do { ... } while (0)` so the macro is one statement. A `return;` inside that loop still leaves the enclosing function.
--- check test | EXPECT records every failure and keeps going
[] { g_failures.clear(); auto t = [] { EXPECT_EQ(2 + 2, 5); EXPECT_EQ(3, 3); EXPECT_EQ(1, 0); }; t(); return g_failures == std::vector<std::string>{"2 + 2 == 5", "1 == 0"}; }()
--- check test | A failed ASSERT stops the function
[] { g_failures.clear(); int reached = 0; auto t = [&] { ASSERT_EQ(1, 2); reached = 1; }; t(); return g_failures == std::vector<std::string>{"1 == 2"} && reached == 0; }()
--- check test | A passing ASSERT lets the function go on
[] { g_failures.clear(); int reached = 0; auto t = [&] { ASSERT_EQ(4, 4); reached = 1; }; t(); return g_failures.empty() && reached == 1; }()
--- check test | An ASSERT in a helper leaves only the helper
[] { g_failures.clear(); int after = 0; auto helper = [] { ASSERT_EQ(0, 1); }; auto t = [&] { helper(); after = 1; }; t(); return after == 1 && g_failures.size() == 1; }()
--- check test | Works as the branches of an if and else
[] { g_failures.clear(); int x = 2; if (x == 1) EXPECT_EQ(x, 1); else EXPECT_EQ(x, 3); return g_failures == std::vector<std::string>{"x == 3"}; }()
--- check test | Each argument is evaluated once
[] { g_failures.clear(); int n = 0; auto t = [&] { EXPECT_EQ(++n, 1); ASSERT_EQ(++n, 2); }; t(); return n == 2 && g_failures.empty(); }()

+++ practice | Guard first, then the fields
--- task
The starter has a packet decoder and four check macros that work like GoogleTest's: `EXPECT_TRUE`, `ASSERT_TRUE`, `EXPECT_EQ` and `ASSERT_EQ`, each adding one entry to `g_failures` when it fails. Do not change them.

Write the test `void test_packet(const std::vector<std::uint8_t>& bytes)`. It decodes `bytes` with `decode` and checks that the packet is the one the flight table expects: `id` 7, `seq` 300 and `temp` -12.

Choose each check's family so that the report is honest:

- a packet with wrong fields must report **every** wrong field, one failure each;
- a packet that does not decode at all (too short, wrong sync byte, bad checksum) must report **exactly one** failure, because checking the fields of a packet that was never decoded only adds noise;
- a correct packet reports nothing.
--- starter
#include <cstdint>
#include <string>
#include <vector>

std::vector<std::string> g_failures;

#define EXPECT_TRUE(c) do { if (!(c)) g_failures.push_back(#c); } while (0)
#define ASSERT_TRUE(c) do { if (!(c)) { g_failures.push_back(#c); return; } } while (0)
#define EXPECT_EQ(a, b) do { if (!((a) == (b))) g_failures.push_back(#a " == " #b); } while (0)
#define ASSERT_EQ(a, b) do { if (!((a) == (b))) { g_failures.push_back(#a " == " #b); return; } } while (0)

struct Packet { int id; int seq; int temp; };

// Byte 0 is the sync byte 0xA5, byte 1 the id, bytes 2 and 3 the sequence number (big-endian),
// byte 4 the temperature as a signed byte, byte 5 the low byte of the sum of bytes 0 to 4.
bool decode(const std::vector<std::uint8_t>& b, Packet& out) {
    if (b.size() != 6 || b[0] != 0xA5) return false;
    unsigned sum = 0;
    for (int i = 0; i < 5; ++i) sum += b[i];
    if ((sum & 0xFFu) != b[5]) return false;
    out.id = b[1];
    out.seq = (b[2] << 8) | b[3];
    out.temp = static_cast<std::int8_t>(b[4]);
    return true;
}

void test_packet(const std::vector<std::uint8_t>& bytes) {
}

struct Packet { int id; int seq; int temp; };

// Byte 0 is the sync byte 0xA5, byte 1 the id, bytes 2 and 3 the sequence number (big-endian),
// byte 4 the temperature as a signed byte, byte 5 the low byte of the sum of bytes 0 to 4.
bool decode(const std::vector<std::uint8_t>& b, Packet& out) {
    if (b.size() != 6 || b[0] != 0xA5) return false;
    unsigned sum = 0;
    for (int i = 0; i < 5; ++i) sum += b[i];
    if ((sum & 0xFFu) != b[5]) return false;
    out.id = b[1];
    out.seq = (b[2] << 8) | b[3];
    out.temp = static_cast<std::int8_t>(b[4]);
    return true;
}

void test_packet(const std::vector<std::uint8_t>& bytes) {
    Packet p{};
    ASSERT_TRUE(decode(bytes, p));   // guard: the fields mean nothing if this fails
    EXPECT_EQ(p.id, 7);              // independent checks: report every wrong one
    EXPECT_EQ(p.seq, 300);
    EXPECT_EQ(p.temp, -12);
}

--- solution
#include <sstream>
#include <string>
#include <vector>

std::vector<std::string> g_failures;

// Collects the << message of a failed check, and records the failure when the
// temporary dies at the end of the full statement, after every << has run.
class FailureRecord {
public:
    explicit FailureRecord(const char* expr) : expr_(expr) {}
    FailureRecord(const FailureRecord&) = delete;
    FailureRecord& operator=(const FailureRecord&) = delete;
    ~FailureRecord() {
        const std::string msg = msg_.str();
        g_failures.push_back(msg.empty() ? expr_ : expr_ + ": " + msg);
    }
    template <class T>
    FailureRecord& operator<<(const T& v) {
        msg_ << v;
        return *this;
    }

private:
    std::string expr_;
    std::ostringstream msg_;
};

// On success the else branch never runs, so nothing after << is evaluated.
#define EXPECT_TRUE(cond) \
    if (cond)             \
        ;                 \
    else                  \
        FailureRecord(#cond)

--- solution
#include <algorithm>
#include <cmath>

// Written as "difference <= tol": every comparison with NaN is false, so NaN fails.
// "!(difference > tol)" would look the same and pass a NaN.
bool near(double actual, double expected, double tol) {
    return std::fabs(actual - expected) <= tol;
}

// A relative tolerance, with an absolute floor so an expected value of zero still works.
double scaled_tol(double expected, double rel, double floor_abs) {
    return std::max(rel * std::fabs(expected), floor_abs);
}

+++ practice | Counting ULPs
--- task
Write the comparison behind `EXPECT_DOUBLE_EQ`.

- `std::uint64_t ulps_between(double a, double b)` returns how many steps of one ULP separate `a` and `b`: 0 for equal values, 1 for neighbors. Plus zero and minus zero are 0 apart, and the count works across zero: the smallest positive double and its negative are 2 steps apart, one on each side of zero.
- `bool double_eq(double a, double b)` returns `true` when `a` and `b` are at most 4 ULPs apart, and `false` if either is NaN.

The usual method: read the 64 bits of each double with `std::bit_cast<std::uint64_t>` (from `<bit>`). Those bits are sign and size, not an ordinary integer, so turn each into a **biased** number first. If the sign bit is set, the biased value is the two's complement negation of the bits, `~bits + 1`. Otherwise it is the bits with the sign bit set, `bits | (1ull << 63)`. On biased numbers, neighboring doubles are neighboring integers, and the distance is the larger minus the smaller.
--- starter

#include <cstdint>

    return false;

--- solution
#include <bit>
#include <cmath>
#include <cstdint>

constexpr std::uint64_t kSign = 1ull << 63;

// Maps the sign-and-size bits of a double onto an ordered unsigned line,
// so that neighboring doubles become neighboring integers.
std::uint64_t biased(double x) {
    const std::uint64_t bits = std::bit_cast<std::uint64_t>(x);
    return (bits & kSign) ? ~bits + 1 : bits | kSign;
}

std::uint64_t ulps_between(double a, double b) {
    const std::uint64_t ba = biased(a);
    const std::uint64_t bb = biased(b);
    return ba >= bb ? ba - bb : bb - ba;
}

bool double_eq(double a, double b) {
    if (std::isnan(a) || std::isnan(b)) return false;   // NaN equals nothing
    return ulps_between(a, b) <= 4;
}

--- hint

double rk4_decay(double w0, double lambda, double t_end, int n) {

    double w = w0;
    for (int i = 0; i < n; ++i) {

    }

double rk4_decay_typo(double w0, double lambda, double t_end, int n) {
    const double h = t_end / n;
    double w = w0;
    for (int i = 0; i < n; ++i) {
        const double k1 = lambda * w;
        const double k2 = lambda * (w + 0.5 * h * k1);
        const double k3 = lambda * (w + 0.5 * h * k1);   // should use k2
        const double k4 = lambda * (w + h * k3);
        w += (h / 6.0) * (k1 + 2.0 * k2 + 2.0 * k3 + k4);

// RK4 drops the (lambda h)^5 / 120 term of e^(lambda h) on every step. Over t_end / h
// steps that adds up to |w(T)| T |lambda|^5 h^4 / 120. Allow three times that bound.
double rk4_tolerance(double w0, double lambda, double t_end, int n) {
    const double h = t_end / n;
    const double exact = w0 * std::exp(lambda * t_end);
    return 3.0 * std::fabs(exact) * t_end * std::pow(std::fabs(lambda), 5) * std::pow(h, 4) / 120.0;
}

bool within_tolerance(double got, double w0, double lambda, double t_end, int n) {
    const double exact = w0 * std::exp(lambda * t_end);
    return std::fabs(got - exact) <= rk4_tolerance(w0, lambda, t_end, n);
}

#include <vector>

// Like ::testing::Range: add step to the previous value, stop before end.
std::vector<double> range_values(double begin, double end, double step) {

#include <set>
#include <string>
#include <vector>

// Letters, digits and '_' only: '.', '/', '*', '-' and ':' all mean something in a filter.
bool legal_char(char c) {
    return (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') || (c >= '0' && c <= '9') || c == '_';
}

std::string param_name(const std::string& printed) {
    if (printed.empty()) return "empty";
    std::string out;
    for (char c : printed) {
        if (c == '-') out += "minus";
        else if (c == '.') out += 'p';
        else if (legal_char(c)) out += c;
        else out += '_';
    }
    return out;
}

bool names_ok(const std::vector<std::string>& names) {
    std::set<std::string> seen;
    for (const std::string& n : names) {
        if (n.empty()) return false;
        for (char c : n) {
            if (!legal_char(c)) return false;
        }
        if (!seen.insert(n).second) return false;   // a second row with the same name
    }
    return true;
}

#include <tuple>
#include <vector>

using Row = std::tuple<double, double, bool>;

// Nested loops: the innermost loop, over the last list, changes fastest.
std::vector<Row> combine(const std::vector<double>& a, const std::vector<double>& b,
                         const std::vector<bool>& c) {
    std::vector<Row> rows;
    for (double x : a) {
        for (double y : b) {
            for (bool z : c) rows.emplace_back(x, y, z);
        }
    }
    return rows;
}

// Each step of i skips a whole block of size_b * size_c rows; each step of j, size_c rows.
int row_index(int i, int j, int k, int size_b, int size_c) {
    return (i * size_b + j) * size_c + k;
}

--- solution
#include <array>
#include <cstddef>
#include <cstdint>
#include <type_traits>

// Integers are summed in 64 bits, so four 16-bit or two 32-bit samples can never wrap.
template <class T, std::size_t N>
T mean_of(const std::array<T, N>& samples) {
    if constexpr (std::is_integral_v<T>) {
        std::int64_t sum = 0;
        for (T s : samples) sum += s;
        return static_cast<T>(sum / static_cast<std::int64_t>(N));
    } else {
        T sum{};
        for (T s : samples) sum += s;
        return sum / static_cast<T>(N);
    }
}
--- hint
`if constexpr (std::is_integral_v<T>)` (from `<type_traits>`) lets one template take a different path for integer types. The branch not taken is not even compiled for that type.
--- hint
Divide in 64 bits too, and only convert back to `T` at the very end. The mean of values that fit in a `T` always fits in a `T`.

    const T lo = T(-10);
    const T hi = T(20);
    bool ok = true;
    ok = ok && clamp(T(5), lo, hi) == T(5);      // inside: unchanged
    ok = ok && clamp(T(-50), lo, hi) == lo;      // below: the lower end

+++ practice | Did the child die the right way?
--- task
A death test runs the dangerous statement in a child process, then judges how the child ended and what it wrote to standard error. Write that judging step. The starter's `ChildEnd` describes how a child ended.

- `bool death_passes(const ChildEnd& c, const std::string& text)`, like `EXPECT_DEATH`: the child died, meaning it was killed by a signal or it exited with a code other than 0, **and** `text` appears somewhere in its standard error, `c.err`.

GoogleTest matches a regular expression. Here `text` is plain text to search for, and an empty `text` matches anything. Standard output, `c.out`, is never searched.

#include <string>

struct ChildEnd {
    bool exited;       // true: it exited (exit or return from main); false: a signal killed it
    int code;          // the exit code, when exited is true
    int signal;        // the signal number, when exited is false
    std::string err;   // everything it wrote to standard error
    std::string out;   // everything it wrote to standard output

// Only standard error is searched; an empty pattern is found in any text.
bool said(const ChildEnd& c, const std::string& text) {
    return c.err.find(text) != std::string::npos;
}

bool death_passes(const ChildEnd& c, const std::string& text) {
    const bool died = !c.exited || c.code != 0;
    return died && said(c, text);
}

bool exit_passes(const ChildEnd& c, int code, const std::string& text) {
    return c.exited && c.code == code && said(c, text);
}

bool signal_passes(const ChildEnd& c, int sig, const std::string& text) {
    return !c.exited && c.signal == sig && said(c, text);
}

+++ practice | A contract check that vanishes in release
--- task
The starter is built the way the flight release is: the line `#define RELEASE_BUILD` plays the part of `-DNDEBUG`. Its contract checks use `DEBUG_EXPECTS`, which, like `assert`, compiles to nothing in a release build. So when a caller asks `gain_at` for index 3 of a 3-gain table, or passes `rate_limit` a negative limit, the violation is never reported.

The flight rule is that a violated contract is reported through `on_violation` in **every** build. Add a macro `FLIGHT_EXPECTS(cond)` that does not depend on `RELEASE_BUILD`: when `cond` is false, it calls `on_violation` with the text of `cond`. Use it for both contract checks, in place of `DEBUG_EXPECTS`. Keep the safe return values the functions already have.

(A real contract check would then stop the program, and a death test would prove it. Here the handler only counts, so the checks can see it.)
--- starter

#include <string>

    ++g_violations;
    g_last_violation = what;

#ifdef RELEASE_BUILD

#define DEBUG_EXPECTS(cond) do { if (!(cond)) on_violation(#cond); } while (0)

+++ question | A missing this->
--- ask
Inside a typed test, a teammate writes `buf_.push(TypeParam(1));` instead of `this->buf_.push(TypeParam(1));`, where `buf_` is a member of the fixture template. What happens, and why?
--- choice
It works the same: `this->` is optional in any member function.
--- choice correct
It does not compile: the test body is in a class template whose base, `RingBufferTest<TypeParam>`, depends on the type, and a plain name is not looked up in such a base. `this->` postpones the lookup until the type is known.
--- choice
It compiles, but each type then shares one `buf_`, because without `this->` the member is treated as static.
--- choice
It compiles, and GoogleTest reports "uninstantiated typed test" at run time.
--- why
When the compiler first reads a template, it cannot see inside a base class that depends on a template parameter, because some specialization of that base might not have the member. So a plain `buf_` is an error. Writing `this->buf_` makes the name depend on the type, and it is looked up when the test is compiled for each type in the list.

+++ question | Which suite runs first
--- ask
A test program holds three suites, written in this order in the file: `AttitudeTest`, `GainTableDeathTest` and `BarometerTest`. Which suite does GoogleTest run first? Type its name.
--- answer
GainTableDeathTest
--- why
GoogleTest runs every suite whose name ends in `DeathTest` before all the others. #include <deque>
#include <optional>
#include <vector>

class IThermometer {
public:
    virtual ~IThermometer() = default;
    virtual std::optional<double> read_c() = 0;   // no value: the read failed
};

class IHeater {
public:
    virtual ~IHeater() = default;
    virtual void set_on(bool on) = 0;
};

// Handed its thermometer and heater: the flight main passes real drivers, a test passes fakes.
class BatteryThermostat {
public:
    BatteryThermostat(IThermometer& t, IHeater& h) : therm_(t), heater_(h) {}

    void step() {
        const std::optional<double> t = therm_.read_c();
        if (!t) {                 // no temperature: a heater left on could cook the battery
            fault_ = true;
            command(false);
            return;
        }
        fault_ = false;
        if (*t < kOnBelow) command(true);
        else if (*t > kOffAbove) command(false);
    }

    bool fault() const { return fault_; }

private:
    void command(bool on) {       // only talk to the heater when its state must change
        if (on == on_) return;
        heater_.set_on(on);
        on_ = on;
    }

    static constexpr double kOnBelow = 5.0;
    static constexpr double kOffAbove = 15.0;
    IThermometer& therm_;
    IHeater& heater_;
    bool on_ = false;
    bool fault_ = false;
};

class FakeThermometer : public IThermometer {
public:
    std::deque<std::optional<double>> script;
    std::optional<double> read_c() override {
        if (script.empty()) return std::nullopt;
        const std::optional<double> next = script.front();
        script.pop_front();
        return next;
    }
};

class FakeHeater : public IHeater {
public:
    std::vector<bool> commands;
    void set_on(bool on) override { commands.push_back(on); }
};

--- solution
#include <concepts>

// Any type with a const now_s() that gives a time in seconds.
template <class C>
concept Clock = requires(const C& c) {
    { c.now_s() } -> std::convertible_to<double>;
};

template <Clock C>
class Timeout {
public:
    Timeout(const C& clock, double limit_s) : clock_(clock), limit_s_(limit_s) {}

    void start() {
        started_ = true;
        t0_ = clock_.now_s();
    }

    bool expired() const {
        return started_ && clock_.now_s() - t0_ >= limit_s_;
    }

private:
    const C& clock_;   // a reference: the test moves this clock forward after construction
    double limit_s_;
    double t0_ = 0.0;
    bool started_ = false;
};

// Time that moves only when the test says so.
struct ManualClock {
    double t = 0.0;
    double now_s() const { return t; }
    void advance(double dt) { t += dt; }
};
--- hint
A concept with a `requires` expression: `requires(const C& c) { { c.now_s() } -> std::convertible_to<double>; }`.
--- hint
Store `const C& clock_`, not a copy. If `Timeout` copied the clock, a test that advances its own `ManualClock` would never see the timeout expire.

--- check test | Expires once the limit has passed, and not a moment before

class LandingDetector {
public:
    explicit LandingDetector(IAccelerometer& accel) : accel_(accel) {}

    void update() {
        const std::optional<double> a = accel_.read_mps2();
        if (!a) {                // a gap in the data breaks the run of still readings
            fault_ = true;
            still_ = 0;
            return;
        }
        fault_ = false;
        still_ = std::fabs(*a - kGravity) <= kBand ? still_ + 1 : 0;
        if (still_ >= kNeeded) landed_ = true;   // latched: once down, always down

--- ask
The test build of a flight program links `fake_baro.cpp` in place of `baro_driver.cpp`. Both files define the same functions, and `apogee.cpp` is compiled once and used in both builds. Which kind of seam is this, and where is its enabling point?

+++ practice | How many calls an expectation allows
--- task
Write the cardinality rules of `EXPECT_CALL`. A cardinality is a range of allowed call counts.

```cpp
struct Cardinality { int min; int max; };   // max == -1 means no upper limit
```

- `Cardinality times(int n)`, `at_least(int n)`, `at_most(int n)` and `between(int a, int b)`: what `.Times(n)`, `.Times(AtLeast(n))`, `.Times(AtMost(n))` and `.Times(Between(a, b))` allow.
- `Cardinality inferred(int will_once, bool will_repeatedly)`: the count GoogleMock infers when `.Times` is left out, from the number of `WillOnce` actions and whether a `WillRepeatedly` follows them. No actions at all means exactly once; `n` `WillOnce` and no `WillRepeatedly` means exactly `n`; `n` `WillOnce` followed by a `WillRepeatedly` means at least `n`.
- `bool satisfied(Cardinality c, int calls)`: the call count is inside the range.
- `bool over_saturated(Cardinality c, int calls)`: the call count is above the upper limit, so the last call already failed the moment it arrived.
--- starter

struct Cardinality { int min; int max; };   // max == -1 means no upper limit

Cardinality times(int n) { return {n, n}; }
Cardinality at_least(int n) { return {n, -1}; }
Cardinality at_most(int n) { return {0, n}; }
Cardinality between(int a, int b) { return {a, b}; }

// With no .Times, the actions say how many calls are expected.
Cardinality inferred(int will_once, bool will_repeatedly) {
    if (will_repeatedly) return at_least(will_once);
    if (will_once == 0) return times(1);
    return times(will_once);
}

bool over_saturated(Cardinality c, int calls) {
    return c.max != -1 && calls > c.max;
}

bool satisfied(Cardinality c, int calls) {
    return calls >= c.min && !over_saturated(c, calls);
}

#include <optional>
#include <vector>

class IPressureSensor {
public:
    virtual ~IPressureSensor() = default;
    virtual bool read(int ch, double& kpa) = 0;   // false on a bus error

    bool ok;
    std::optional<double> kpa;
};

class ScriptedSensor : public IPressureSensor {
public:
    std::vector<int> channels;

    void will_once(Action a) { once_.push_back(a); }
    void will_repeatedly(Action a) { repeated_ = a; }

    bool read(int ch, double& kpa) override {
        channels.push_back(ch);
        Action a{false, std::nullopt};         // the default action: false, kpa untouched
        if (!once_.empty()) {
            a = once_.front();
            once_.pop_front();
        } else if (repeated_) {
            a = *repeated_;
        }
        if (a.kpa) kpa = *a.kpa;               // SetArgReferee<1>(...)
        return a.ok;                           // Return(...)
    }

private:
    std::deque<Action> once_;
    std::optional<Action> repeated_;
};

+++ practice | Matchers, and judging one expectation
--- task
Write GoogleMock's matchers for a `double` argument, and the verdict on one expectation.

```cpp
using Matcher = std::function<bool(double)>;
Matcher any();                       // like _
Matcher eq(double v);                // like Eq(v)
Matcher gt(double v);                // like Gt(v)
Matcher lt(double v);                // like Lt(v)
Matcher near(double v, double tol);  // like DoubleNear(v, tol): difference at most tol

struct Verdict { int matched; int unexpected; bool satisfied; };
Verdict verify(const Matcher& m, int min_calls, int max_calls, const std::vector<double>& calls);
bool passes(const Verdict& v);
```

`verify` judges the calls in order against one expectation that allows between `min_calls` and `max_calls` calls (`max_calls` of -1 means no limit). A call whose argument the matcher accepts, while the expectation has room left, is **matched**. Any other call is **unexpected**: either its argument fails the matcher, or the expectation is already full. `satisfied` is whether `matched` is at least `min_calls`. `passes` is true when nothing was unexpected and the expectation is satisfied.

For example, `set_open(DoubleNear(0.6, 1e-9)).Times(1)` with the single call `set_open(0.1)` gives 0 matched, 1 unexpected, not satisfied: the two failures the lesson printed.
--- starter

--- solution
#include <cmath>
#include <functional>
#include <vector>

using Matcher = std::function<bool(double)>;

Matcher any() { return [](double) { return true; }; }
Matcher eq(double v) { return [v](double x) { return x == v; }; }
Matcher gt(double v) { return [v](double x) { return x > v; }; }
Matcher lt(double v) { return [v](double x) { return x < v; }; }
Matcher near(double v, double tol) { return [v, tol](double x) { return std::fabs(x - v) <= tol; }; }

struct Verdict { int matched; int unexpected; bool satisfied; };

Verdict verify(const Matcher& m, int min_calls, int max_calls, const std::vector<double>& calls) {
    Verdict v{0, 0, false};
    for (double arg : calls) {
        const bool room = max_calls == -1 || v.matched < max_calls;
        if (m(arg) && room) ++v.matched;   // this call counts toward the expectation
        else ++v.unexpected;               // wrong argument, or one call too many
    }
    v.satisfied = v.matched >= min_calls;  // judged at the end, when the mock is destroyed
    return v;
}

bool passes(const Verdict& v) { return v.unexpected == 0 && v.satisfied; }

`method_has_expectation` says whether the test wrote any `EXPECT_CALL` for the called method on this mock. `accepted` says whether one of those expectations accepted this call (it is ignored when there are none).

#include <utility>
#include <vector>

enum class Mood { Naggy, Nice, Strict };
enum class Outcome { Silent, Warning, Failure };

Outcome on_call(Mood mood, bool method_has_expectation, bool accepted) {
    if (method_has_expectation) {
        // The test spoke about this method: the call must fit what it said.
        return accepted ? Outcome::Silent : Outcome::Failure;
    }
    // Uninteresting: the test said nothing, so the mood decides.
    switch (mood) {
        case Mood::Naggy: return Outcome::Warning;
        case Mood::Nice: return Outcome::Silent;
        case Mood::Strict: return Outcome::Failure;
    }
    return Outcome::Failure;
}

bool test_passes(Mood mood, const std::vector<std::pair<bool, bool>>& calls) {
    for (const auto& [has_expectation, accepted] : calls) {
        if (on_call(mood, has_expectation, accepted) == Outcome::Failure) return false;
    }
    return true;
}

#include <string>
#include <vector>

enum class Mood { Naggy, Nice, Strict };

class IGauge {
public:
    virtual ~IGauge() = default;
    virtual double level() = 0;   // fraction of propellant left, 0 to 1

class MockGauge : public IGauge {
public:
    explicit MockGauge(Mood mood) : mood_(mood) {}

    // ON_CALL: what to return, with no demand attached.
    void on_call(double v) { value_ = v; }

    // EXPECT_CALL: a demand, which makes the method interesting.
    void expect_calls(int min, int max) {
        interesting_ = true;
        min_ = min;
        max_ = max;
    }

    double level() override {
        ++calls_;
        if (!interesting_) {
            if (mood_ == Mood::Naggy) messages_.push_back("warning: uninteresting call");
            if (mood_ == Mood::Strict) messages_.push_back("failure: uninteresting call");
        } else if (max_ != -1 && calls_ > max_) {
            messages_.push_back("failure: called more times than expected");
        }
        return value_;
    }

    // Like a mock's destructor: the minimum can only be judged at the end.
    std::vector<std::string> finish() const {
        std::vector<std::string> out = messages_;
        if (interesting_ && calls_ < min_) out.push_back("failure: too few calls");
        return out;
    }

private:
    Mood mood_;
    double value_ = 0.0;
    bool interesting_ = false;
    int min_ = 0;
    int max_ = -1;
    int calls_ = 0;
    std::vector<std::string> messages_;
};

--- solution
#include <string>
#include <vector>

struct Call { std::string method; int arg; };
struct Expect { Call call; std::vector<int> after; };

int order_error(const std::vector<Expect>& expected, const std::vector<Call>& actual) {
    std::vector<bool> used(expected.size(), false);
    for (int i = 0; i < static_cast<int>(actual.size()); ++i) {
        int match = -1;
        for (int e = 0; e < static_cast<int>(expected.size()) && match < 0; ++e) {
            const Expect& x = expected[e];
            if (used[e] || x.call.method != actual[i].method || x.call.arg != actual[i].arg) continue;
            bool ready = true;                       // every prerequisite already met?
            for (int before : x.after) ready = ready && used[before];
            if (ready) match = e;
        }
        if (match < 0) return i;                     // out of order, repeated or unexpected
        used[match] = true;
    }
    for (bool u : used) {
        if (!u) return static_cast<int>(actual.size());   // a call that never came
    }
    return -1;
}

+++ practice | The --gtest_filter language
--- task
Write the matcher behind `--gtest_filter`.

- `bool glob(const std::string& text, const std::string& pattern)`: `*` matches any run of characters, including none; `?` matches exactly one character; every other character matches only itself. The whole text must match, not just a part.

For example, `Nav.*:Gnc.*-*Soak*` selects every test in suites `Nav` and `Gnc` except those with `Soak` anywhere in the name.

--- solution
#include <cstddef>
#include <string>
#include <vector>

// Wildcards, not a regular expression: '*' is any run, '?' one character, '.' just a dot.
bool glob(const std::string& text, const std::string& pattern) {
    std::size_t t = 0, p = 0;
    std::size_t star = std::string::npos, mark = 0;   // last '*' seen, and where its run started
    while (t < text.size()) {
        if (p < pattern.size() && (pattern[p] == '?' || pattern[p] == text[t])) {
            ++t;
            ++p;
        } else if (p < pattern.size() && pattern[p] == '*') {
            star = p++;
            mark = t;
        } else if (star != std::string::npos) {
            p = star + 1;          // let the last '*' swallow one more character
            t = ++mark;
        } else {
            return false;
        }
    }
    while (p < pattern.size() && pattern[p] == '*') ++p;
    return p == pattern.size();
}

std::vector<std::string> split(const std::string& s, char sep) {
    std::vector<std::string> parts;
    std::size_t start = 0;
    while (true) {
        const std::size_t at = s.find(sep, start);
        parts.push_back(s.substr(start, at - start));
        if (at == std::string::npos) return parts;
        start = at + 1;
    }
}

bool matches_any(const std::string& name, const std::string& list) {
    for (const std::string& pat : split(list, ':')) {
        if (!pat.empty() && glob(name, pat)) return true;
    }
    return false;
}

bool selected(const std::string& full_name, const std::string& filter) {
    const std::size_t dash = filter.find('-');
    std::string positive = filter.substr(0, dash);
    const std::string negative = dash == std::string::npos ? "" : filter.substr(dash + 1);
    if (positive.empty()) positive = "*";
    return matches_any(full_name, positive) && !matches_any(full_name, negative);
}
--- hint
For `glob`, remember the position of the last `*` you passed. When a character fails to match, go back and let that `*` swallow one more character of the text. If there was no `*`, the match fails.

#include <string>
#include <vector>

struct CtTest { std::string name; std::vector<std::string> labels; };

bool label_match(const std::string& label, const std::string& pattern) {
    std::string p = pattern;
    const bool at_start = !p.empty() && p.front() == '^';
    if (at_start) p.erase(0, 1);
    const bool at_end = !p.empty() && p.back() == '$';
    if (at_end) p.pop_back();
    if (at_start && at_end) return label == p;
    if (at_start) return label.size() >= p.size() && label.compare(0, p.size(), p) == 0;
    if (at_end) return label.size() >= p.size() && label.compare(label.size() - p.size(), p.size(), p) == 0;
    return label.find(p) != std::string::npos;   // unanchored: anywhere in the label
}

bool any_label_matches(const CtTest& t, const std::string& pattern) {
    for (const std::string& l : t.labels) {
        if (label_match(l, pattern)) return true;
    }
    return false;
}

std::vector<std::string> ctest_select(const std::vector<CtTest>& tests, const std::string& L,
                                      const std::string& LE) {
    std::vector<std::string> out;
    for (const CtTest& t : tests) {
        const bool in = L.empty() || any_label_matches(t, L);
        const bool out_by_le = !LE.empty() && any_label_matches(t, LE);
        if (in && !out_by_le) out.push_back(t.name);
    }
    return out;
}

+++ practice | Catch2's trick: seeing both sides
--- task
Catch2 prints both sides of a plain comparison when it fails: `CHECK(bad_reads == 0)` reports `3 == 0`. It does it by rewriting the check as `Decomposer() <= bad_reads == 0`. Because `<=` binds more tightly than `==`, `Decomposer() <= bad_reads` runs first and captures the left value in an object, and that object's own `operator==` then captures the right value. Write that machinery.

- `struct Result { bool ok; std::string expansion; };`
- `Decomposer() <= a` returns an object holding `a`. That object has the six comparison operators `==`, `!=`, `<`, `<=`, `>` and `>=`, each taking any right-hand value `b` and returning a `Result`: `ok` is the comparison's value, and `expansion` is `a`, a space, the operator, a space and `b`, each value written as `std::ostringstream` writes it. So `Decomposer() <= 3 == 0` gives `{false, "3 == 0"}`.
- A macro `CHECK(expr)` that records a failed check in the global `g_log` as the text of `expr`, then `" with expansion: "`, then the expansion, and adds nothing for a passing check. For example, with `int bad_reads = 3;`, `CHECK(bad_reads == 0)` adds `"bad_reads == 0 with expansion: 3 == 0"`.
--- starter

--- solution
#include <sstream>
#include <string>
#include <vector>

std::vector<std::string> g_log;

struct Result { bool ok; std::string expansion; };

// Holds the captured left value; each operator captures the right value and the comparison.
template <class L>
struct LeftSide {
    const L& lhs;   // valid until the end of the full expression that made it

    template <class R>
    Result make(bool ok, const char* op, const R& rhs) const {
        std::ostringstream out;
        out << lhs << ' ' << op << ' ' << rhs;
        return {ok, out.str()};
    }
    template <class R> Result operator==(const R& r) const { return make(lhs == r, "==", r); }
    template <class R> Result operator!=(const R& r) const { return make(lhs != r, "!=", r); }
    template <class R> Result operator<(const R& r) const { return make(lhs < r, "<", r); }
    template <class R> Result operator<=(const R& r) const { return make(lhs <= r, "<=", r); }
    template <class R> Result operator>(const R& r) const { return make(lhs > r, ">", r); }
    template <class R> Result operator>=(const R& r) const { return make(lhs >= r, ">=", r); }
};

struct Decomposer {
    template <class L>
    LeftSide<L> operator<=(const L& lhs) const { return LeftSide<L>{lhs}; }
};

inline void record_check(const char* text, const Result& r) {
    if (!r.ok) g_log.push_back(std::string(text) + " with expansion: " + r.expansion);
}

// "Decomposer() <= a == b" parses as "(Decomposer() <= a) == b".
#define CHECK(expr) record_check(#expr, Decomposer() <= expr)

+++ practice | Reading a gcov report
--- task
Write the arithmetic behind gcov's summary lines from its annotated file.

```cpp
struct Summary {
    int lines_total;        // lines that hold code
    int lines_run;          // lines that hold code and ran at least once
    int branches_total;     // every branch line
    int branches_executed;  // branch lines whose condition was evaluated ("taken N", N may be 0)
    int branches_taken;     // branch lines taken at least once (N > 0)
};

```

`gcov_text` holds the annotated file, one line per `\n`. Two kinds of line matter:

- **A source line**: a count field, a colon, the line number, a colon, and the source. The count field, with its spaces removed, is `-` for a line with no code, `#####` for a line with code that never ran, or a number of runs. The number may end with `*`, which gcov adds when part of the line did not run; it still counts as a line that ran.
- **A branch line**, which starts with `branch` (after any spaces): either `branch  N taken K`, maybe followed by ` (fallthrough)`, or `branch  N never executed`, for a branch on a line that never ran.

Every other line, such as `function limit_rate called 3 returned 100% blocks executed 80%`, is ignored.

--- solution
#include <cctype>
#include <sstream>
#include <string>

struct Summary {
    int lines_total;
    int lines_run;
    int branches_total;
    int branches_executed;
    int branches_taken;
};

std::string strip(const std::string& s) {
    const auto a = s.find_first_not_of(' ');
    if (a == std::string::npos) return "";
    return s.substr(a, s.find_last_not_of(' ') - a + 1);
}

Summary summarize(const std::string& gcov_text) {
    Summary s{0, 0, 0, 0, 0};
    std::istringstream in(gcov_text);
    std::string line;
    while (std::getline(in, line)) {
        const std::string t = strip(line);
        if (t.rfind("branch", 0) == 0) {
            ++s.branches_total;
            const auto at = t.find("taken ");
            if (at == std::string::npos) continue;        // "never executed"
            ++s.branches_executed;                         // the condition was evaluated
            if (std::stoi(t.substr(at + 6)) > 0) ++s.branches_taken;
            continue;
        }
        const auto colon = line.find(':');
        if (colon == std::string::npos) continue;          // "function ..." and the like
        const std::string count = strip(line.substr(0, colon));
        if (count == "#####") {
            ++s.lines_total;                               // code that never ran
        } else if (!count.empty() && std::isdigit(static_cast<unsigned char>(count[0]))) {
            ++s.lines_total;                               // "3" or "2*": it ran
            ++s.lines_run;
        }                                                  // "-": no code on this line
    }
    return s;
}

+++ practice | A shadow map, like AddressSanitizer's
--- task
AddressSanitizer keeps a shadow map that says, for each byte, whether it may be used, and holds freed memory back from reuse. Build a small version over 256 bytes of pretend memory, addresses 0 to 255.

`ShadowHeap` has three operations. Every byte starts as a **redzone** byte, which may not be touched.

- `int alloc(int n)`, with `n` at least 1: the block starts at the next free address, which is 8 for the first block. Its `n` bytes become **usable**. The next block starts 8 bytes after this one ends, so at least 8 redzone bytes separate blocks. If the block and the 8 bytes after it do not fit below 256, return -1 and change nothing. Freed memory is never reused.
- `std::string release(int addr)`: if `addr` is the start of a live block, all of its bytes become **freed** and the result is `"ok"`. If it is the start of a block that was already released, `"double-free"`. For any other address, `"bad-free"`.
- `std::string access(int addr, int size)`: check the bytes `addr` to `addr + size - 1` in order. At the first byte that is outside 0 to 255 or is not usable, return `"heap-use-after-free"` if that byte is freed, and `"heap-buffer-overflow"` otherwise. If every byte is usable, return `"ok"`.
--- starter
#include <string>

class ShadowHeap {
public:
    int alloc(int n) { return -1; }
    std::string release(int addr) { return ""; }
    std::string access(int addr, int size) { return ""; }
};
--- solution
#include <array>
#include <map>
#include <string>

class ShadowHeap {
public:
    ShadowHeap() { shadow_.fill(State::Redzone); }

    int alloc(int n) {
        const int start = next_;
        if (start + n + kRedzone > kSize) return -1;   // no room: change nothing
        for (int i = start; i < start + n; ++i) shadow_[i] = State::Usable;
        blocks_[start] = Block{n, false};
        next_ = start + n + kRedzone;                   // freed blocks are never handed out again
        return start;
    }

    std::string release(int addr) {
        const auto it = blocks_.find(addr);
        if (it == blocks_.end()) return "bad-free";
        if (it->second.freed) return "double-free";
        it->second.freed = true;
        for (int i = addr; i < addr + it->second.size; ++i) shadow_[i] = State::Freed;
        return "ok";
    }

    std::string access(int addr, int size) {
        for (int i = addr; i < addr + size; ++i) {
            if (i < 0 || i >= kSize) return "heap-buffer-overflow";
            if (shadow_[i] == State::Freed) return "heap-use-after-free";
            if (shadow_[i] != State::Usable) return "heap-buffer-overflow";
        }
        return "ok";
    }

private:
    enum class State { Redzone, Usable, Freed };
    struct Block { int size; bool freed; };
    static constexpr int kSize = 256;
    static constexpr int kRedzone = 8;
    std::array<State, kSize> shadow_{};
    std::map<int, Block> blocks_;   // start address -> block
    int next_ = kRedzone;
};
--- hint
Keep one state per byte (redzone, usable or freed), a map from each block's start address to its size and whether it was released, and the address where the next block will start.
--- hint
In `access`, check the address range before you look at the shadow, so a byte outside the 256 is never read.

+++ practice | The observed order of a method
--- task
Write the arithmetic of a convergence-order test.

- `double observed_order(double e_h, double e_half)` returns log2(e_h / e_half), where `e_h` is the error at step h and `e_half` the error at step h/2.
- `bool looks_like_order(double e_h, double e_half, int p, double tol)` returns `true` when the observed order is within `tol` of `p` (a difference of at most `tol`). If either error is not a finite number greater than zero, it returns `false`: an error of exactly zero, or a NaN, means the run is at the rounding floor or broken, and says nothing about the order.

#include <cmath>

struct State { double x; double v; };

// Whole-state error at t = 10 s for x'' = -x, x(0) = 1, v(0) = 0, with n RK4 steps.
double spring_error(int n, bool typo) {
    const double h = 10.0 / n;
    auto f = [](State s) { return State{s.v, -s.x}; };
    State s{1.0, 0.0};
    for (int i = 0; i < n; ++i) {
        const State k1 = f(s);
        const State k2 = f({s.x + 0.5 * h * k1.x, s.v + 0.5 * h * k1.v});
        const State in3 = typo ? k1 : k2;
        const State k3 = f({s.x + 0.5 * h * in3.x, s.v + 0.5 * h * in3.v});
        const State k4 = f({s.x + h * k3.x, s.v + h * k3.v});
        s.x += (h / 6.0) * (k1.x + 2.0 * k2.x + 2.0 * k3.x + k4.x);
        s.v += (h / 6.0) * (k1.v + 2.0 * k2.v + 2.0 * k3.v + k4.v);
    }
    return std::hypot(s.x - std::cos(10.0), s.v + std::sin(10.0));
}

// E(h) = C h^p, so E(h) / E(h/2) = 2^p, whatever C is.
double observed_order(double e_h, double e_half) {
    return std::log2(e_h / e_half);
}

bool usable_error(double e) {
    return std::isfinite(e) && e > 0.0;
}

bool looks_like_order(double e_h, double e_half, int p, double tol) {
    if (!usable_error(e_h) || !usable_error(e_half)) return false;
    return std::fabs(observed_order(e_h, e_half) - p) <= tol;
}

+++ practice | A quaternion that must stay unit
--- task
Write a first-order attitude propagator and the norm that checks its invariant. A quaternion is four numbers (w, x, y, z), held as `std::array<double, 4>` in that order.

- `Quat multiply(const Quat& a, const Quat& b)`: the quaternion product a times b:
  - w = a.w b.w - a.x b.x - a.y b.y - a.z b.z
  - x = a.w b.x + a.x b.w + a.y b.z - a.z b.y
  - y = a.w b.y - a.x b.z + a.y b.w + a.z b.x
  - z = a.w b.z + a.x b.y - a.y b.x + a.z b.w
- `double norm(const Quat& q)`: the square root of the sum of the four squares.
- `Quat euler_step(const Quat& q, double wx, double wy, double wz, double dt, bool renormalize)`: one step of q + (dt / 2) times (q times the rate quaternion (0, wx, wy, wz)), component by component. When `renormalize` is true, divide the result by its norm.

The checks run 10,000 steps of 0.01 s at a rate of (0.3, -0.4, 0) rad/s, with and without renormalizing. Without it, the norm grows by a factor of the square root of 1 + (0.0025)^2 on every step.
--- starter

--- solution
#include <array>
#include <cmath>

using Quat = std::array<double, 4>;   // w, x, y, z

Quat multiply(const Quat& a, const Quat& b) {
    return {a[0] * b[0] - a[1] * b[1] - a[2] * b[2] - a[3] * b[3],
            a[0] * b[1] + a[1] * b[0] + a[2] * b[3] - a[3] * b[2],
            a[0] * b[2] - a[1] * b[3] + a[2] * b[0] + a[3] * b[1],
            a[0] * b[3] + a[1] * b[2] - a[2] * b[1] + a[3] * b[0]};
}

double norm(const Quat& q) {
    return std::sqrt(q[0] * q[0] + q[1] * q[1] + q[2] * q[2] + q[3] * q[3]);
}

// q_dot = 0.5 * q * (0, w): the step is at right angles to q, so without
// renormalizing, every step makes q a little longer.
Quat euler_step(const Quat& q, double wx, double wy, double wz, double dt, bool renormalize) {
    const Quat qdot = multiply(q, {0.0, wx, wy, wz});
    Quat next;
    for (int i = 0; i < 4; ++i) next[i] = q[i] + 0.5 * dt * qdot[i];
    if (renormalize) {
        const double n = norm(next);
        for (double& c : next) c /= n;
    }
    return next;
}

        out += line;
    }
    return out;
}

struct Row { double t; double x; double v; };

std::vector<Row> parse_golden(const std::string& text) {
    std::vector<Row> rows;
    std::istringstream in(text);
    std::string line;
    while (std::getline(in, line)) {
        if (line.empty() || line[0] == '#') continue;   // header and blank lines
        const char* p = line.c_str();
        char* end = nullptr;
        Row r{};
        r.t = std::strtod(p, &end);
        r.x = std::strtod(end + 1, &end);                // skip the comma
        r.v = std::strtod(end + 1, &end);
        rows.push_back(r);
    }
    return rows;
}

int first_miss(const std::string& golden, double h, double tol, Stepper step) {
    const std::vector<Row> rows = parse_golden(golden);
    if (rows.size() < 2) return -2;                      // missing or truncated: say so, compare nothing
    State s{rows[0].x, rows[0].v};
    for (std::size_t k = 1; k < rows.size(); ++k) {
        const long long n = std::llround((rows[k].t - rows[k - 1].t) / h);
        for (long long i = 0; i < n; ++i) s = step(s, h);
        const double miss = std::hypot(s.x - rows[k].x, s.v - rows[k].v);   // the whole state
        if (miss > tol) return static_cast<int>(k);
    }
    return -1;
}

+++ question | Reading a convergence study
--- ask
A new integrator gives an error of 6.4e-3 at step h and 4.0e-4 at step h/2, both well above the rounding floor. What is its observed order? Type the number.
--- answer
4
four
--- why
The ratio is 6.4e-3 / 4.0e-4 = 16, and log2(16) = 4, because 2^4 = 16. The method behaves like a fourth-order one, as RK4 should. A ratio near 4 would have meant second order, the signature of a typo such as `k1` in place of `k2`.

+++ problem | A test framework that registers itself
--- task
Write the core of a test framework, the way GoogleTest works inside, so that the tests at the bottom of the starter run and report. Do not change anything below the line that says so.

- `MY_TEST(Suite, Name) { ... }` defines a test. Like `TEST`, it must register the test **by itself** before `main` runs, with no list written anywhere. Tests run in the order they are written. (A namespace-scope variable initialized by a function call runs that call before `main`; the preprocessor's `##` joins two tokens into one name, such as `Suite##_##Name`.)
- `EXPECT_TRUE(cond)`: a nonfatal check. `ASSERT_TRUE(cond)`: a fatal one, which records the failure and leaves the test with `return;`. Each failure is recorded as the text of `cond`.
- `int run_all(std::string& report)` runs every registered test in order, writes the report into `report`, and returns 0 if every test passed and 1 otherwise. It can be called more than once, and each call starts from a clean slate.

The report, line by line, each ending with `\n`: for each test, `[ RUN      ] Suite.Name`, then one line `Failure: <text of cond>` per failed check in the order they failed, then `[       OK ] Suite.Name` or `[  FAILED  ] Suite.Name`. Then `[  PASSED  ] N tests.`, and, if any failed, `[  FAILED  ] M tests, listed below:` followed by one `[  FAILED  ] Suite.Name` per failed test in run order. Write `1 test` rather than `1 tests`.

#include <cmath>
#include <string>
#include <vector>

struct TestCase {
    std::string suite;
    std::string name;
    void (*body)();
};

// Built on first use, so it exists before any registration runs.
std::vector<TestCase>& registry() {
    static std::vector<TestCase> tests;
    return tests;
}

std::vector<std::string> g_current_failures;   // failures of the test that is running

bool register_test(const char* suite, const char* name, void (*body)()) {
    registry().push_back({suite, name, body});
    return true;
}

// A declaration, a registering variable whose initializer runs before main, then the body.
#define MY_TEST(suite, name)                                                        \
    void suite##_##name##_body();                                                   \
    const bool suite##_##name##_registered = register_test(#suite, #name, &suite##_##name##_body); \
    void suite##_##name##_body()

#define EXPECT_TRUE(cond) \
    do { if (!(cond)) g_current_failures.push_back(#cond); } while (0)

#define ASSERT_TRUE(cond) \
    do { if (!(cond)) { g_current_failures.push_back(#cond); return; } } while (0)

std::string count_of(std::size_t n) {
    return std::to_string(n) + (n == 1 ? " test" : " tests");
}

int run_all(std::string& report) {
    report.clear();
    std::vector<std::string> failed;
    for (const TestCase& t : registry()) {
        const std::string full = t.suite + "." + t.name;
        report += "[ RUN      ] " + full + "\n";
        g_current_failures.clear();          // each test starts clean
        t.body();
        for (const std::string& f : g_current_failures) report += "Failure: " + f + "\n";
        if (g_current_failures.empty()) {
            report += "[       OK ] " + full + "\n";
        } else {
            report += "[  FAILED  ] " + full + "\n";
            failed.push_back(full);
        }
    }
    report += "[  PASSED  ] " + count_of(registry().size() - failed.size()) + ".\n";
    if (!failed.empty()) {
        report += "[  FAILED  ] " + count_of(failed.size()) + ", listed below:\n";
        for (const std::string& f : failed) report += "[  FAILED  ] " + f + "\n";
    }
    return failed.empty() ? 0 : 1;
}

#include <cmath>
#include <string>
#include <vector>

double rk4_run(double y0, double lambda, double t_end, int n, bool typo) {
    const double h = t_end / n;
    double y = y0;
    for (int i = 0; i < n; ++i) {
        const double k1 = lambda * y;
        const double k2 = lambda * (y + 0.5 * h * k1);
        const double k3 = lambda * (y + 0.5 * h * (typo ? k1 : k2));
        const double k4 = lambda * (y + h * k3);
        y += (h / 6.0) * (k1 + 2.0 * k2 + 2.0 * k3 + k4);
    }
    return y;
}
double rk4(double y0, double lambda, double t_end, int n) { return rk4_run(y0, lambda, t_end, n, false); }
double rk4_typo(double y0, double lambda, double t_end, int n) { return rk4_run(y0, lambda, t_end, n, true); }

struct TableRow { std::string name; double error; double tol; bool passed; };

// -1.5 -> "m15", 0.5 -> "5": letters and digits only, as a parameterized name must be.
std::string lambda_code(double lambda) {
    const long long tenths = std::llround(lambda * 10.0);
    return tenths < 0 ? "m" + std::to_string(-tenths) : std::to_string(tenths);
}

std::vector<TableRow> run_decay_table(const std::vector<double>& lambdas, const std::vector<int>& steps,
                                      double y0, double t_end, double safety,
                                      double (*integrate)(double, double, double, int)) {
    std::vector<TableRow> rows;
    for (double lambda : lambdas) {
        for (int n : steps) {                 // the last list changes fastest
            const double h = t_end / n;
            const double exact = y0 * std::exp(lambda * t_end);
            // RK4 global error for y' = lambda y: |y(T)| T |lambda|^5 h^4 / 120, times a safety factor.
            const double tol = safety * std::fabs(exact) * t_end * std::pow(std::fabs(lambda), 5) * std::pow(h, 4) / 120.0;
            const double error = std::fabs(integrate(y0, lambda, t_end, n) - exact);
            rows.push_back({"lam" + lambda_code(lambda) + "_n" + std::to_string(n), error, tol, error <= tol});
        }
    }
    return rows;
}

#include <cstdint>
#include <type_traits>
#include <vector>

template <class T> struct Stats { T min; T max; T mean; };

template <class T>
bool summarize(const std::vector<T>& v, Stats<T>& out) {
    if (v.empty()) return false;               // nothing to report: out untouched
    Stats<T> s{v[0], v[0], T{}};
    // A wide accumulator: 64-bit for integers, double for floating types.
    using Wide = std::conditional_t<std::is_integral_v<T>, std::int64_t, double>;
    Wide sum = 0;
    for (T x : v) {
        if (x < s.min) s.min = x;
        if (x > s.max) s.max = x;
        sum += x;
    }
    s.mean = static_cast<T>(sum / static_cast<Wide>(v.size()));
    out = s;
    return true;
}

// Test doubles: record every pyro call, and let the test set the time.
class RecordingPyro : public IPyro {
public:

class Separation {
public:
    Separation(IPyro& pyro, IClock& clock) : pyro_(pyro), clock_(clock) {}

    void step() {
        switch (state_) {
            case State::NotStarted:
                armed_at_ = clock_.now_s();
                if (pyro_.arm()) {
                    state_ = State::Armed;
                } else {
                    pyro_.disarm();               // a failed arm: make safe, never fire
                    state_ = State::Fault;

                break;
            case State::Armed:
                if (clock_.now_s() - armed_at_ >= kDelayS) {
                    pyro_.fire(1);
                    pyro_.fire(2);
                    pyro_.disarm();
                    state_ = State::Done;
                }
                break;
            case State::Done:
            case State::Fault:
                break;                            // the end: nothing more, ever
        }
    }

    bool done() const { return state_ == State::Done; }
    bool fault() const { return state_ == State::Fault; }

private:
    enum class State { NotStarted, Armed, Done, Fault };
    static constexpr double kDelayS = 0.5;
    IPyro& pyro_;
    IClock& clock_;
    State state_ = State::NotStarted;
    double armed_at_ = 0.0;
};

#include <cstddef>
#include <functional>
#include <string>
#include <vector>

enum class Mood { Naggy, Nice, Strict };
struct Expectation { std::string method; std::function<bool(double)> matcher; int min; int max; };
struct Call { std::string method; double arg; };
struct Report { int warnings; int failures; };

Report judge(Mood mood, const std::vector<Expectation>& expectations, const std::vector<Call>& calls) {
    Report r{0, 0};
    std::vector<int> count(expectations.size(), 0);
    for (const Call& c : calls) {
        int e = -1;
        for (std::size_t i = 0; i < expectations.size(); ++i) {
            if (expectations[i].method == c.method) e = static_cast<int>(i);
        }
        if (e < 0) {                                        // uninteresting: the mood decides
            if (mood == Mood::Naggy) ++r.warnings;
            if (mood == Mood::Strict) ++r.failures;
            continue;
        }
        const Expectation& x = expectations[e];
        if (!x.matcher(c.arg)) { ++r.failures; continue; }  // unexpected arguments
        if (x.max != -1 && count[e] == x.max) { ++r.failures; continue; }   // one call too many
        ++count[e];
    }
    for (std::size_t i = 0; i < expectations.size(); ++i) {
        if (count[i] < expectations[i].min) ++r.failures;   // judged when the mock is destroyed
    }
    return r;
}

#include <set>
#include <sstream>
#include <string>
#include <vector>

std::string no_spaces(const std::string& s) {
    std::string out;
    for (char c : s) {
        if (c != ' ' && c != '\t') out += c;
    }
    return out;
}

std::vector<std::string> add_tests_entries(const std::string& source) {
    std::vector<std::string> out;
    std::istringstream in(source);
    std::string line;
    while (std::getline(in, line)) {
        const auto start = line.find_first_not_of(" \t");
        if (start == std::string::npos) continue;
        const std::string t = line.substr(start);
        bool param = false;
        std::size_t open = 0;
        if (t.rfind("TEST(", 0) == 0) open = 4;
        else if (t.rfind("TEST_F(", 0) == 0) open = 6;
        else if (t.rfind("TEST_P(", 0) == 0) { open = 6; param = true; }
        else continue;                                   // comments and every other macro
        const auto comma = t.find(',', open);
        const auto close = t.find(')', comma);
        if (comma == std::string::npos || close == std::string::npos) continue;
        const std::string suite = no_spaces(t.substr(open + 1, comma - open - 1));
        const std::string name = no_spaces(t.substr(comma + 1, close - comma - 1));
        // The source cannot know a TEST_P's rows: they exist only when the program runs.
        out.push_back(param ? "*/" + suite + "." + name + "/*" : suite + "." + name);
    }
    return out;
}

std::vector<std::string> without_own_entry(const std::string& source, const std::vector<std::string>& discovered) {
    const std::vector<std::string> entries = add_tests_entries(source);
    const std::set<std::string> own(entries.begin(), entries.end());
    std::vector<std::string> out;
    for (const std::string& d : discovered) {
        if (!own.count(d)) out.push_back(d);
    }
    return out;
}

4. A is an `unlock` of a mutex, and B is a later `lock` of the same mutex.

Return the trace index of the later event of the first race, scanning the trace in order: the smallest index `j` such that some earlier event races with event `j`. Return -1 if the trace has no race.

--- solution
#include <cstddef>
#include <string>
#include <vector>

struct Event { int thread; std::string op; std::string target; };

bool is_access(const Event& e) { return e.op == "read" || e.op == "write"; }

int first_race(const std::vector<Event>& trace) {
    const int n = static_cast<int>(trace.size());
    // before[j][i]: event i happens before event j. Every rule points forward in the
    // trace, so each event's set can be built from the sets of events before it.
    std::vector<std::vector<bool>> before(n, std::vector<bool>(n, false));
    for (int j = 0; j < n; ++j) {
        const Event& b = trace[j];
        std::vector<int> direct;
        for (int i = 0; i < j; ++i) {
            const Event& a = trace[i];
            const bool same_thread = a.thread == b.thread;
            const bool started_it = a.op == "start" && std::stoi(a.target) == b.thread;
            const bool joined_it = b.op == "join" && std::stoi(b.target) == a.thread;
            const bool lock_chain = a.op == "unlock" && b.op == "lock" && a.target == b.target;
            if (same_thread || started_it || joined_it || lock_chain) direct.push_back(i);
        }
        for (int i : direct) {
            before[j][i] = true;
            for (int k = 0; k < i; ++k) {
                if (before[i][k]) before[j][k] = true;   // chains of the rules
            }
        }
    }
    for (int j = 0; j < n; ++j) {
        if (!is_access(trace[j])) continue;
        for (int i = 0; i < j; ++i) {
            const Event& a = trace[i];
            const Event& b = trace[j];
            if (!is_access(a) || a.target != b.target || a.thread == b.thread) continue;
            if (a.op != "write" && b.op != "write") continue;   // two reads never race
            if (!before[j][i]) return j;
        }
    }
    return -1;
}

struct State { double x; double v; };
using Step = State (*)(State, double);

State rate(State s) { return {s.v, -s.x}; }

State euler(State s, double h) { return {s.x + h * s.v, s.v - h * s.x}; }

State midpoint(State s, double h) {
    const State k1 = rate(s);
    const State k2 = rate({s.x + 0.5 * h * k1.x, s.v + 0.5 * h * k1.v});
    return {s.x + h * k2.x, s.v + h * k2.v};
}

State rk4_general(State s, double h, bool typo) {
    const State k1 = rate(s);
    const State k2 = rate({s.x + 0.5 * h * k1.x, s.v + 0.5 * h * k1.v});
    const State in3 = typo ? k1 : k2;
    const State k3 = rate({s.x + 0.5 * h * in3.x, s.v + 0.5 * h * in3.v});
    const State k4 = rate({s.x + h * k3.x, s.v + h * k3.v});
    return {s.x + (h / 6.0) * (k1.x + 2.0 * k2.x + 2.0 * k3.x + k4.x),
            s.v + (h / 6.0) * (k1.v + 2.0 * k2.v + 2.0 * k3.v + k4.v)};
}
State rk4(State s, double h) { return rk4_general(s, h, false); }
State rk4_typo(State s, double h) { return rk4_general(s, h, true); }

// The whole state, not one component: x alone can pass near zero by accident.
double whole_error(Step step, int n) {
    const double h = 10.0 / n;
    State s{1.0, 0.0};
    for (int i = 0; i < n; ++i) s = step(s, h);
    return std::hypot(s.x - std::cos(10.0), s.v + std::sin(10.0));
}

int measured_order(Step step, int n) {
    const double e_h = whole_error(step, n);
    const double e_half = whole_error(step, 2 * n);
    if (e_half < 1e-11) return -1;                 // near the rounding floor: the ratio is noise
    const double p = std::log2(e_h / e_half);
    const double whole = std::round(p);
    if (std::fabs(p - whole) > 0.25) return -1;    // not yet in the asymptotic range
    return static_cast<int>(whole);
}

Symmetry is checked first: a positivity test assumes a symmetric matrix and means nothing without one.

#include <cmath>
#include <string>

struct M2 { double a, b, c, d; };   // [[a, b], [c, d]]

M2 mul(const M2& x, const M2& y) {
    return {x.a * y.a + x.b * y.c, x.a * y.b + x.b * y.d, x.c * y.a + x.d * y.c, x.c * y.b + x.d * y.d};
}

M2 transpose(const M2& x) { return {x.a, x.c, x.b, x.d}; }

M2 predict(const M2& P, double dt, double q) {
    const M2 F{1.0, dt, 0.0, 1.0};
    const M2 FP = mul(mul(F, P), transpose(F));
    return {FP.a + q * dt * dt * dt / 3.0, FP.b + q * dt * dt / 2.0,
            FP.c + q * dt * dt / 2.0, FP.d + q * dt};
}

M2 joseph_update(const M2& P, double r) {
    const double S = P.a + r;
    const double k0 = P.a / S;
    const double k1 = P.c / S;
    const M2 A{1.0 - k0, 0.0, -k1, 1.0};                 // I - K H
    const M2 APAt = mul(mul(A, P), transpose(A));
    const M2 KrKt{k0 * r * k0, k0 * r * k1, k1 * r * k0, k1 * r * k1};
    return {APAt.a + KrKt.a, APAt.b + KrKt.b, APAt.c + KrKt.c, APAt.d + KrKt.d};
}

std::string invariant_problem(const M2& P, double rel) {
    if (std::fabs(P.b - P.c) > rel * (std::fabs(P.a) + std::fabs(P.d))) return "asymmetric";
    if (!(P.a > 0.0 && P.a * P.d - P.b * P.c > 0.0)) return "not positive";
    return "";
}

--- check test | Fifty cycles settle to the known variances, with no problem found

#define NDEBUG   // built as release: assert does nothing in this file
#include <cassert>
#include <cstddef>
#include <cstdio>
#include <string>
#include <vector>

using Handler = void (*)(const char* what);

int g_default_calls = 0;
std::vector<std::string> g_seen;
int g_counted = 0;

void default_handler(const char* what) {
    std::fprintf(stderr, "%s\n", what);
    ++g_default_calls;
}
void record(const char* what) { g_seen.push_back(what); }
void count_only(const char*) { ++g_counted; }

Handler g_handler = &default_handler;

Handler set_violation_handler(Handler h) {
    const Handler previous = g_handler;
    g_handler = h;
    return previous;
}

void report_violation(const char* what) { g_handler(what); }

// Does not look at NDEBUG: the check is in the build that flies.
#define FLIGHT_EXPECTS(cond) \
    do { if (!(cond)) report_violation("contract violated: " #cond); } while (0)

// Installs a handler for one scope and always puts the old one back, like a TearDown.
class ScopedHandler {
public:
    explicit ScopedHandler(Handler h) : previous_(set_violation_handler(h)) {}
    ~ScopedHandler() { set_violation_handler(previous_); }
    ScopedHandler(const ScopedHandler&) = delete;
    ScopedHandler& operator=(const ScopedHandler&) = delete;

private:
    Handler previous_;
};

double gain_at(const std::vector<double>& gains, std::size_t i) {
    FLIGHT_EXPECTS(i < gains.size());
    return i < gains.size() ? gains[i] : 0.0;
}

A failure everywhere is a plain wrong answer; one only under `tsan` is a race; one only under `release` usually means undefined behavior, which the optimizer is allowed to assume never happens. +++ question | Energy drift at half the step
--- ask
An RK4 orbit test measures a relative energy change of 3.2e-11 per orbit with 555 steps per orbit. Its tolerance comment says RK4 loses about 2 pi theta^5 / 72 of the energy per cycle, with theta the angle turned per step. If the test is run with 1,110 steps per orbit instead, about what drift should it measure?
--- choice
About 1.6e-11: half the step, half the error.
--- choice
About 2e-12: sixteen times smaller, because RK4 is fourth order.
--- choice correct
About 1e-12: thirty-two times smaller, because the loss per cycle goes as theta to the fifth power.
--- choice
About 3.2e-11: energy drift does not depend on the step.
--- why
Halving the step halves theta, and (1/2)^5 = 1/32, so 3.2e-11 / 32 is about 1e-12. The fifth power comes from a loss of about theta^6 / 72 per step over 2 pi / theta steps per cycle. Checking that the drift really falls by 32 is itself a good test: an invariant with a derived tolerance, and a convergence law, in one.

+++ question | Two coverage tools, two numbers
--- ask
The same test run is measured with gcov and with llvm-cov. gcov reports 83% line coverage for a file, and llvm-cov reports 76% for the same file. What should the team conclude?
--- choice
llvm-cov found lines that gcov missed, so the tests are weaker than gcov says.
--- choice
One of the two tools is broken, because line coverage is a fact about the code.
--- choice correct
Nothing from the difference: the tools decide differently which lines hold code, so their percentages are not comparable. Track coverage over time with one tool, and compare branch results, which here should agree.
--- choice
Take the average, 79.5%, as the true line coverage.
--- why
gcov counts arcs of the compiled program and maps them back to lines; llvm-cov counts regions of the source and, for example, counts closing braces inside a region. So the same run gives different line totals. The uncovered roads themselves, the branch findings that matter, agree between honest tools.
