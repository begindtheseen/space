+++ question | How much prints before the error
--- ask
How many lines does this script print before Python stops it?

```python
# limits.py
print("checking limits")
print("peak:", peek)
print("done"
```

Type the number.
--- answer
0
zero
none
0 lines
no lines
--- why
None at all. The whole file is compiled before any line runs, and the unclosed bracket on the last line is a SyntaxError found at that stage. So the first `print` never runs, and the misspelled `peek` on line 3 is never reached. +++ question | Permission denied
--- ask
You write `tool.py`, whose first line is `#!/usr/bin/env python3`. `python3 tool.py` works. But `./tool.py` answers `Permission denied`. What fixes it?
--- choice
Rename the file to `tool`, because the shell will not run a file ending in `.py`.
--- choice correct
Run `chmod +x tool.py`, so the file is allowed to be executed.
--- choice
Move the shebang to the second line, under a comment that names the file.
--- choice
Change the shebang to `#!python3`, so the shell does not need `env`.
--- why
Running a file by name needs two things: a shebang on the very first line, so the system knows which program should read it, and permission to execute, which `chmod +x` gives. The shebang is already right, so the missing permission is the problem. The `.py` ending does not matter to the shell. A shebang on the second line is only a comment, and `env` is what finds `python3` on the path.

+++ question | Remainder and floor with a negative number
--- ask
What does this print?

```python
print(-17 % 5, -17 // 5)
```
--- answer
3 -4
3, -4
--- why
`-17 / 5` is -3.4, and `//` rounds down, toward minus infinity, so `-17 // 5` is -4. The remainder has the sign of the divisor, 5, and makes the two agree: 5 × (-4) + 3 = -17, so `-17 % 5` is 3. Expecting `-2 -3` is expecting Python to chop toward zero, which is what `int` does, not `//`.

def normalize(values):
    """Return a new list scaled so the largest magnitude is 1.0; zeros stay zeros."""
    if not values:
        return []
    biggest = max(max(values), -min(values))
    if biggest == 0:
        return list(values)
    result = []
    for v in values:
        result.append(v / biggest)
    return result

def parse_duration(text):
    """Seconds in a duration like "12.5 s", "3 min" or "2 h"; ValueError otherwise."""
    parts = text.split()
    if len(parts) != 2:
        raise ValueError(f"expected a number and a unit, got {text!r}")

    elif unit == "h":
        return value * 3600
    else:
        raise ValueError(f"unknown unit in {text!r}")

def process_all(items, work):

    results = []

def summarize(csv_path, json_path):

--- solution
import math

def compare_runs(old, new, rel_tol=1e-9, abs_tol=1e-12):
    """Indices where old and new disagree beyond the tolerances; nan agrees only with nan."""
    if len(old) != len(new):
        raise ValueError(f"runs differ in length: {len(old)} and {len(new)}")
    bad = []
    for i, a in enumerate(old):
        b = new[i]
        if math.isnan(a) or math.isnan(b):
            if not (math.isnan(a) and math.isnan(b)):
                bad.append(i)
        elif not math.isclose(a, b, rel_tol=rel_tol, abs_tol=abs_tol):
            bad.append(i)
    return bad
--- hint

--- hint

+++ question | Adding two to a big number
--- ask
What does this print?

```python
print(1e16 + 2 - 1e16)
```
--- answer
2.0
--- why
Near 10¹⁶ the gap between neighboring floats is 2. So 10¹⁶ + 2 is itself a float that exists, stored exactly, and subtracting 10¹⁶ leaves exactly 2.0. Adding 1 instead would have been lost, because 10¹⁶ + 1 falls halfway between two floats and rounds back to 10¹⁶. Whether a small addition survives depends on the ulp of the big number, not on the small number's own precision.

--- solution
def parse_packet(line):
    """{name: float} from "name=value; name=value" text; ValueError on a malformed field."""
    packet = {}
    for field in line.split(";"):
        field = field.strip()
        if not field:
            continue
        pieces = field.split("=")
        if len(pieces) != 2:
            raise ValueError(f"expected one '=' in field {field!r}")
        name = pieces[0].strip().lower()
        if not name:
            raise ValueError(f"no name in field {field!r}")
        if name in packet:
            raise ValueError(f"field {name!r} appears twice")
        try:
            packet[name] = float(pieces[1])
        except ValueError:
            raise ValueError(f"not a number in field {field!r}")
    return packet

+++ problem | A per-axis report from a CSV file
--- task
Write a function `axis_report(path)` that reads a CSV file of accelerometer samples and reports statistics for each axis.

- The file has a header row naming its columns. It holds at least `t`, `ax`, `ay` and `az`, in any order, and possibly other columns, which you ignore.
- If any of a row's three axis fields cannot be converted to a float (it is empty, or text), skip the whole row and count it as skipped.
- A value of `-999.0` is a dropout marker. Leave it out of that axis's statistics only; the row still counts as used.
- Return a dictionary with these keys:
  - `"rows"`: how many rows were used; `"skipped"`: how many were skipped;
  - `"ax"`, `"ay"` and `"az"`: each a dictionary `{"min": ..., "max": ..., "mean": ..., "rms": ...}` over that axis's values, or `None` if the axis has no values at all.
- The RMS is the square root of the mean of the squares.

`path` is a `pathlib.Path` in a temporary folder.
--- starter
def axis_report(path):
    pass
--- solution
import csv
import math

AXES = ("ax", "ay", "az")
DROPOUT = -999.0

def stats(values):
    """min, max, mean and rms of a list, or None when it is empty."""
    if not values:
        return None
    squares = 0.0
    for v in values:
        squares += v * v
    return {
        "min": min(values),
        "max": max(values),
        "mean": sum(values) / len(values),
        "rms": math.sqrt(squares / len(values)),
    }

def axis_report(path):
    """Per-axis statistics of a CSV of t, ax, ay, az; bad rows skipped, dropouts left out."""
    values = {"ax": [], "ay": [], "az": []}
    used = 0
    skipped = 0
    with open(path, newline="", encoding="utf-8") as f:
        for row in csv.DictReader(f):
            try:
                reading = (float(row["ax"]), float(row["ay"]), float(row["az"]))
            except ValueError:
                skipped += 1
                continue
            used += 1
            for axis, v in zip(AXES, reading):
                if v != DROPOUT:
                    values[axis].append(v)
    report = {"rows": used, "skipped": skipped}
    for axis in AXES:
        report[axis] = stats(values[axis])

def make_window_mean(n):
    """Return add(x): the mean of the last n samples given (all of them while fewer)."""
    if n < 1:

    window = []

    def add(x):

def apply_overrides(base, overrides):
    """A deep copy of base with each "section.key" in overrides set; base is never changed."""
    result = copy.deepcopy(base)

import math

def grid(start, stop, step):
    """start, start + step, ... up to stop inclusive, each as start + i * step."""
    if step <= 0:
        raise ValueError(f"step must be positive, got {step}")
    times = []
    i = 0
    t = start
    while t <= stop or math.isclose(t, stop, rel_tol=1e-9, abs_tol=1e-12):
        times.append(t)
        i += 1
        t = start + i * step
    return times

import math

def audit(limits, data):
    """Sort channels into missing, extra, over and ok against their limits."""
    result = {"missing": [], "extra": [], "over": [], "ok": []}
    for name, limit in limits.items():
        samples = data.get(name)
        if not samples:
            result["missing"].append(name)
            continue
        for s in samples:
            if not math.isfinite(s) or s > limit:
                result["over"].append(name)
                break
        else:
            result["ok"].append(name)
    for name in data:
        if name not in limits:
            result["extra"].append(name)
    for key in result:
        result[key] = sorted(result[key])
    return result

def descend(h0, v0, accel, dt, max_steps):
    """(steps, t, v) at the first Euler step with height <= 0; None if not down in max_steps."""
    if dt <= 0:
        raise ValueError(f"dt must be positive, got {dt}")
    if h0 <= 0:
        return 0, 0.0, v0
    h = h0
    v = v0
    steps = 0
    while steps < max_steps:
        v += accel * dt
        h -= v * dt
        steps += 1
        if h <= 0:
            return steps, steps * dt, v
    return None

None of the numbers is even, so the loop never breaks. A loop's `else` runs exactly when the loop finished without a `break`, so `n = 0` runs and replaces the 7 the loop left behind. Had any number been even, the `break` would have skipped the `else` and `n` would be that number.

+++ question | A limit that updates itself
--- ask
What happens when this runs? Type what it prints, or the name of the exception it raises.

```python
limit = 10

def check(v):
    if v > limit:
        limit = v
    return limit

print(check(5))
```
--- answer
UnboundLocalError
UnboundLocalError: cannot access local variable 'limit' where it is not associated with a value
UnboundLocalError: local variable 'limit' referenced before assignment
--- why
`limit = v` is an assignment somewhere in the body, so `limit` is local for the whole function, from its first line. `check(5)` then reads the local `limit` in `v > limit` before anything has been assigned to it, and raises `UnboundLocalError`, even though the assignment itself would never run for 5. The global `limit = 10` is never consulted.

+++ question | The mean that crashes on its first row
--- ask
This function should return the mean of the `az` column of a CSV file with the header `t,ax,ay,az`. It raises an exception on every file. Which line is wrong, and why?

```python
import csv

def mean_az(path):
    total = 0.0
    count = 0
    with open(path, newline="", encoding="utf-8") as f:
        for row in csv.reader(f):
            total += float(row[3])
            count += 1
    return total / count
```
--- choice correct
`total += float(row[3])`: `csv.reader` also returns the header row, and `float("az")` raises `ValueError`.
--- choice
`with open(...)`: the file is closed before the loop can read it.
--- choice
`count = 0`: it should start at 1, or the mean is divided by one too few.
--- choice
`return total / count`: it always divides by zero, because `count` is reset on every row.
--- why
`csv.reader` gives every row, the header included, as a list of strings, and the first one is `["t", "ax", "ay", "az"]`. `float("az")` raises `ValueError` before any data is read. Skip the header, or use `csv.DictReader`, which reads the header for you and gives `row["az"]`: that also keeps working if someone inserts a column.

+++ question | What JSON gives back
--- ask
What does this print?

```python
import json
print(json.loads(json.dumps({1: (2, 3)})))
```
--- answer
{'1': [2, 3]}
{"1": [2, 3]}
--- why
JSON object keys are always strings, so the key `1` is written as `"1"` and comes back as the string `'1'`. JSON has one kind of sequence, the array, so the tuple comes back as a list. JSON keeps values, not Python types; convert at the boundary if the types matter.

+++ question | Exact and inexact products
--- ask
What does this print?

```python
print(0.1 * 3 == 0.3, 0.5 * 3 == 1.5)
```
--- answer
False True
False, True
--- why
0.5 and 1.5 are fractions with a power of two at the bottom (1/2 and 3/2), so they are stored exactly, and the product is exact. 0.1 and 0.3 are not: `0.1 * 3` gives `0.30000000000000004`, a different float from the stored 0.3. Whether `==` works on floats depends on the particular numbers, which is why computed floats are compared with a tolerance.

+++ question | The name of an imported module
--- ask
`b.py` contains one line, `print(__name__)`. `a.py` contains `import b`. In the folder holding both, you run `python3 a.py`. What is printed?
--- answer
b
--- why
Importing a file runs its body, and inside an imported module `__name__` is the module's own name, `b`. Only the file handed to `python3`, here `a.py`, has `__name__` equal to `"__main__"`. That difference is exactly what the main guard tests.

+++ question | Finally and a handled error
--- ask
What does this print?

```python
def load(path):
    try:
        with open(path, encoding="utf-8") as f:
            return f.read()
    except FileNotFoundError:
        return ""
    finally:
        print("closing")

print(repr(load("missing.txt")))
```

The file does not exist.
--- choice correct
`closing` on the first line, then `''`
--- choice
`''` on the first line, then `closing`
--- choice
Only `''`: `finally` is skipped when a handler returns
--- choice
A `FileNotFoundError` traceback, because `finally` re-raises it
--- why
`open` raises `FileNotFoundError`, the handler catches it and starts to return `""`. Before the function actually returns, `finally` runs and prints `closing`. Only then does the empty string reach `print(repr(...))`, which shows it as `''`. `finally` runs on every way out, and a handled exception is not re-raised.
