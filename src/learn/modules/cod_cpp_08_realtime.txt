+++ practice | Timing with a counter that wraps
--- task
You time a task with the processor's free-running 32-bit cycle counter: read it before the task, read it after, and subtract. The counter goes back to 0 after 4 294 967 295, so the second reading can be smaller than the first. The two reads also cost some cycles of their own, measured once on an empty section and called the overhead.

Write two functions:

```cpp
std::uint32_t elapsed_cycles(std::uint32_t start, std::uint32_t end, std::uint32_t overhead);
double cycles_to_us(std::uint32_t cycles, std::uint32_t clock_hz);
```

- `elapsed_cycles` returns the cycles from `start` to `end`, correct even when the counter wrapped once in between, minus `overhead`. If the difference is not more than the overhead, it returns 0.
- `cycles_to_us` turns cycles into microseconds at a clock of `clock_hz`. For example, 42 000 cycles at 168 MHz is 250 µs. A clock of 0 returns -1.0.
--- starter
#include <cstdint>

std::uint32_t elapsed_cycles(std::uint32_t start, std::uint32_t end, std::uint32_t overhead) {
    return 0u;
}

double cycles_to_us(std::uint32_t cycles, std::uint32_t clock_hz) {
    return 0.0;
}
--- solution
#include <cstdint>

// Cycles between two reads of a free-running 32-bit counter, less the cost of the reads.
std::uint32_t elapsed_cycles(std::uint32_t start, std::uint32_t end, std::uint32_t overhead) {
    const std::uint32_t raw = end - start;   // unsigned subtraction is right across one wrap
    return raw > overhead ? raw - overhead : 0u;
}

double cycles_to_us(std::uint32_t cycles, std::uint32_t clock_hz) {
    if (clock_hz == 0u) return -1.0;
    return static_cast<double>(cycles) * 1e6 / static_cast<double>(clock_hz);
}
--- hint
Unsigned arithmetic in C++ works modulo 2 to the 32 for a 32-bit type. So `end - start` is already the right answer after one wrap, as long as you keep it unsigned.
--- hint
Compare the difference with the overhead before you subtract, or the unsigned result will wrap to a huge number.
--- check case | An ordinary measurement
elapsed_cycles(1000u, 43012u, 12u)
=> 42000u
--- check case | The counter wrapped between the reads
elapsed_cycles(0xFFFFFF00u, 0x00000100u, 0u)
=> 512u
--- check case | Less than the overhead gives zero
elapsed_cycles(500u, 505u, 12u)
=> 0u
--- check test | 42 000 cycles at 168 MHz is 250 µs
std::fabs(cycles_to_us(42000u, 168000000u) - 250.0) < 1e-9
--- check case | A clock of zero
cycles_to_us(100u, 0u)
=> -1.0

+++ practice | Reviewing a week of frame records
--- task
For each frame of a loop, you have two numbers in microseconds: its measured high-water mark (the longest time seen in testing) and its static bound (the analyzer's worst case). The project allows `limit_us` per frame.

Write:

```cpp
enum class Verdict { Fits, Investigate, Over, Inconsistent };
Verdict judge(int hwm_us, int bound_us, int limit_us);

struct FrameRecord { int hwm_us; int bound_us; };
struct Review { int fits = 0; int investigate = 0; int over = 0; int inconsistent = 0; int worst = -1; };
Review review(std::span<const FrameRecord> frames, int limit_us);
```

`judge` decides, checking in this order:

1. `Inconsistent` if the measurement is above the bound. A safe bound can never be beaten by a real run, so the analysis is wrong.
2. `Fits` if the bound is at most the limit.
3. `Investigate` if the bound is over the limit but the measurement is not. Find the path that produced the bound.
4. `Over` if both are over the limit.

`review` counts how many frames got each verdict, and sets `worst` to the index of the frame with the largest bound (the first one on a tie), or -1 when there are no frames.
--- starter
#include <span>

enum class Verdict { Fits, Investigate, Over, Inconsistent };

Verdict judge(int hwm_us, int bound_us, int limit_us) {
    return Verdict::Fits;
}

struct FrameRecord { int hwm_us; int bound_us; };
struct Review { int fits = 0; int investigate = 0; int over = 0; int inconsistent = 0; int worst = -1; };

Review review(std::span<const FrameRecord> frames, int limit_us) {
    return {};
}
--- solution
#include <cstddef>
#include <span>

enum class Verdict { Fits, Investigate, Over, Inconsistent };

Verdict judge(int hwm_us, int bound_us, int limit_us) {
    if (hwm_us > bound_us) return Verdict::Inconsistent;   // a real run beat the "safe" bound
    if (bound_us <= limit_us) return Verdict::Fits;
    if (hwm_us <= limit_us) return Verdict::Investigate;   // tests never reached the slow path
    return Verdict::Over;
}

struct FrameRecord { int hwm_us; int bound_us; };
struct Review { int fits = 0; int investigate = 0; int over = 0; int inconsistent = 0; int worst = -1; };

Review review(std::span<const FrameRecord> frames, int limit_us) {
    Review r;
    for (std::size_t i = 0; i < frames.size(); ++i) {
        switch (judge(frames[i].hwm_us, frames[i].bound_us, limit_us)) {
            case Verdict::Fits:         ++r.fits; break;
            case Verdict::Investigate:  ++r.investigate; break;
            case Verdict::Over:         ++r.over; break;
            case Verdict::Inconsistent: ++r.inconsistent; break;
        }
        if (r.worst < 0 || frames[i].bound_us > frames[static_cast<std::size_t>(r.worst)].bound_us) {
            r.worst = static_cast<int>(i);
        }
    }
    return r;
}
--- hint
Write `judge` first, with the four tests in exactly the order the task gives. The first one that is true decides.
--- hint
In `review`, a `switch` on the verdict updates one counter. Track the largest bound with a strict `>` so the first frame wins a tie.
--- check test | A frame the analyzer calls too slow
judge(520, 810, 800) == Verdict::Investigate
--- check test | A measurement above the bound means the analysis is wrong
judge(850, 810, 900) == Verdict::Inconsistent && judge(820, 810, 800) == Verdict::Inconsistent
--- check test | A bound exactly at the limit fits, and both over is Over
judge(700, 800, 800) == Verdict::Fits && judge(805, 900, 800) == Verdict::Over
--- check test | A week of records
[] { std::vector<FrameRecord> f{{500, 700}, {520, 810}, {850, 810}, {805, 900}, {400, 900}}; Review r = review(f, 800); return r.fits == 1 && r.investigate == 2 && r.over == 1 && r.inconsistent == 1 && r.worst == 3; }()
--- check test | No records
[] { Review r = review(std::vector<FrameRecord>{}, 800); return r.fits == 0 && r.investigate == 0 && r.over == 0 && r.inconsistent == 0 && r.worst == -1; }()

+++ practice | Paths that never run together
--- task
A frame's worst case is the sum of its tasks' worst cases, but the design can promise that some paths never run in the same frame. For example, the sensor re-calibration and the big telemetry packet are never scheduled together. Each such set of mutually exclusive paths gets a group number. At most one path of a group runs in any frame, so the group adds only its slowest path.

Write:

```cpp
struct Path { int group; int wcet_us; };
int frame_wcet_us(std::span<const Path> paths);
```

- Group 0 means "always runs": every group-0 path adds its full time.
- For every other group number, add only the largest `wcet_us` in that group.
- Group numbers can be any non-negative `int`, such as 7000. They are not small or in order.
- No paths gives 0. A negative group or a negative time makes the table bad: return -1.

For example, `{{0, 45}, {0, 310}, {1, 120}, {1, 260}, {2, 150}}` gives 45 + 310 + 260 + 150 = 765.
--- starter
#include <span>

struct Path { int group; int wcet_us; };

int frame_wcet_us(std::span<const Path> paths) {
    int total = 0;
    for (const Path& p : paths) total += p.wcet_us;
    return total;
}
--- solution
#include <map>
#include <span>

struct Path { int group; int wcet_us; };

// A ground tool: it may use std::map. Group 0 always runs; each other group adds its slowest path.
int frame_wcet_us(std::span<const Path> paths) {
    int always = 0;
    std::map<int, int> slowest;   // group number -> its slowest path
    for (const Path& p : paths) {
        if (p.group < 0 || p.wcet_us < 0) return -1;
        if (p.group == 0) {
            always += p.wcet_us;
        } else {
            int& w = slowest[p.group];
            if (p.wcet_us > w) w = p.wcet_us;
        }
    }
    int total = always;
    for (const auto& [group, w] : slowest) total += w;
    return total;
}
--- hint
Keep one running maximum per group. Because the group numbers can be large and scattered, an array indexed by group will not do; a `std::map<int, int>` will.
--- hint
Check for a negative group or time before using the path, and return -1 at once.
--- check case | Two exclusive groups
frame_wcet_us(std::vector<Path>{{0, 45}, {0, 310}, {1, 120}, {1, 260}, {2, 150}})
=> 765
--- check case | Large, scattered group numbers
frame_wcet_us(std::vector<Path>{{7000, 50}, {0, 100}, {7000, 80}, {123456, 5}})
=> 185
--- check case | Everything always runs
frame_wcet_us(std::vector<Path>{{0, 10}, {0, 20}, {0, 30}})
=> 60
--- check case | No paths
frame_wcet_us(std::vector<Path>{})
=> 0
--- check case | A negative time is a bad table
frame_wcet_us(std::vector<Path>{{0, 10}, {3, -1}})
=> -1

+++ practice | A budget check that always passes
--- task
This function should say whether a frame's tasks fit the project rule: the sum of their worst-case times must be at most `max_percent` percent of the frame period. With a 1000 µs frame, tasks totalling 980 µs and a rule of 80 percent, it should return `false`. It returns `true`. In fact it returns `true` for every set of tasks that fits inside one whole frame.

Find the line that loses the answer and fix it. Keep all the arithmetic in whole numbers. A total exactly at the limit (800 of 1000 at 80 percent) fits.
--- starter
#include <vector>

// True when the tasks' worst cases fit within max_percent of the frame.
bool fits(const std::vector<int>& wcet_us, int period_us, int max_percent) {
    int total = 0;
    for (int t : wcet_us) total += t;
    int used_percent = total / period_us * 100;
    return used_percent <= max_percent;
}
--- solution
#include <vector>

// True when the tasks' worst cases fit within max_percent of the frame.
bool fits(const std::vector<int>& wcet_us, int period_us, int max_percent) {
    long long total = 0;
    for (int t : wcet_us) total += t;
    // Multiply before comparing: total / period rounds down to 0 for any frame that is not full.
    return total * 100 <= static_cast<long long>(period_us) * max_percent;
}
--- hint
Work out `980 / 1000 * 100` the way C++ does with `int`, one operation at a time, from the left.
--- hint
Compare `total * 100` with `period_us * max_percent` instead. Nothing is divided, so nothing is rounded away.
--- check case | 98 percent does not fit an 80 percent rule
fits({45, 310, 120, 65, 30, 150, 260}, 1000, 80)
=> false
--- check case | Exactly at the limit fits
fits({500, 300}, 1000, 80)
=> true
--- check case | One microsecond over does not fit
fits({500, 301}, 1000, 80)
=> false
--- check case | A 20 ms frame at 75 percent
fits({9000, 6000}, 20000, 75)
=> true

+++ practice | The worst frame of a cyclic executive
--- task
A cyclic executive runs a 1 ms minor frame over and over. Each task runs every `period` frames: it runs in frame `f` when `f % period == offset`. The pattern repeats after `major_frames` frames.

Write:

```cpp
struct Slot { int period; int offset; int wcet_us; };
struct FrameLoad { int frame; int us; };
FrameLoad worst_frame(std::span<const Slot> tasks, int major_frames);
```

It returns the frame, from 0 to `major_frames - 1`, whose tasks add up to the most microseconds, and that total. On a tie, return the earliest frame.

- With no tasks, every frame is empty: return `{0, 0}`.
- Return `{-1, -1}` if `major_frames` is less than 1 or more than `kMaxFrames` (a constant you define as 1000, so the loop has a fixed bound), or if any task has a period less than 1, a negative offset, an offset not smaller than its period, or a negative time.

For example, tasks `{1, 0, 300}`, `{2, 1, 250}`, `{5, 0, 400}` and `{10, 3, 200}` over 10 frames give frame 5 as the worst: 300 + 250 + 400 = 950 µs.
--- starter
#include <span>

struct Slot { int period; int offset; int wcet_us; };
struct FrameLoad { int frame; int us; };

constexpr int kMaxFrames = 1000;

FrameLoad worst_frame(std::span<const Slot> tasks, int major_frames) {
    return {-1, -1};
}
--- solution
#include <span>

struct Slot { int period; int offset; int wcet_us; };
struct FrameLoad { int frame; int us; };

constexpr int kMaxFrames = 1000;   // the fixed bound on the frame loop

FrameLoad worst_frame(std::span<const Slot> tasks, int major_frames) {
    if (major_frames < 1 || major_frames > kMaxFrames) return {-1, -1};
    for (const Slot& t : tasks) {
        if (t.period < 1 || t.offset < 0 || t.offset >= t.period || t.wcet_us < 0) return {-1, -1};
    }
    FrameLoad worst{0, -1};
    for (int f = 0; f < major_frames; ++f) {
        int us = 0;
        for (const Slot& t : tasks) {
            if (f % t.period == t.offset) us += t.wcet_us;
        }
        if (us > worst.us) worst = {f, us};   // strict: the earliest frame wins a tie
    }
    return worst;
}
--- hint
Validate everything first, so the frame loop only ever runs over good data and at most `kMaxFrames` times.
--- hint
For each frame, add up the tasks whose `f % period` equals their offset. Keep the best with a strict `>` so the earliest frame wins a tie; starting the best total below zero makes an all-empty pattern return frame 0.
--- check test | Frame 5 is the worst
[] { FrameLoad w = worst_frame(std::vector<Slot>{{1, 0, 300}, {2, 1, 250}, {5, 0, 400}, {10, 3, 200}}, 10); return w.frame == 5 && w.us == 950; }()
--- check test | A tie goes to the earliest frame
[] { FrameLoad w = worst_frame(std::vector<Slot>{{2, 0, 100}, {2, 1, 100}}, 4); return w.frame == 0 && w.us == 100; }()
--- check test | No tasks
[] { FrameLoad w = worst_frame(std::vector<Slot>{}, 8); return w.frame == 0 && w.us == 0; }()
--- check test | An offset as large as its period is refused
[] { FrameLoad w = worst_frame(std::vector<Slot>{{4, 4, 10}}, 8); return w.frame == -1 && w.us == -1; }()
--- check test | Too many frames for the fixed bound
[] { FrameLoad a = worst_frame(std::vector<Slot>{{1, 0, 5}}, 1001); FrameLoad b = worst_frame(std::vector<Slot>{{1, 0, 5}}, 0); return a.frame == -1 && b.frame == -1; }()

+++ question | Clean numbers from the flight board
--- ask
To get clean timing numbers, a teammate runs the attitude controller one million times on the real flight board, with interrupts switched off and the controller's data already in cache from the run before. The largest time is 38 µs, and she proposes 38 µs as the controller's worst case in the frame budget. What is the main problem?
--- choice
One million runs is too few. Ten million runs would make the largest time a true worst case.
--- choice correct
She measured a system that will not fly. In flight, interrupts add their handlers' time and another task may have pushed the data out of cache, and paths her inputs never took may be slower still.
--- choice
Switching interrupts off makes the controller slower, so 38 µs is too pessimistic.
--- choice
Nothing. Measuring on the real flight board is what makes a high-water mark a worst case.
--- why
A measurement only covers the conditions and paths it ran. Switching interrupts off and keeping the cache warm removes two sources of delay that are present in flight, so every run is on the fast side of the spread. More runs of the same unrealistic setup cannot find a rare path or a cold cache. The real board is necessary but not enough: the practice is a static bound, checked against measurements taken under flight conditions, plus a margin.

+++ practice | A square root that cannot spin
--- task
Write a square root by Newton's method whose loop has a fixed bound:

```cpp
struct Root { double value; int iters; bool ok; };
constexpr int kMaxIter = 60;
Root bounded_sqrt(double a);
```

- Start at `x = a` when `a` is at least 1, and at `x = 1.0` otherwise.
- Each pass computes the step `dx = (x - a / x) / 2` and sets `x -= dx`.
- Stop, with `ok` true, after the pass in which `std::fabs(dx) <= 1e-14 * std::fabs(x)`. `iters` is the number of passes done.
- Never do more than `kMaxIter` passes. If the stopping test was never met, return `ok` false.
- `a == 0` is a special case: return `{0.0, 0, true}` at once. (Without it, `x` only halves each pass and the relative test is never met.)
- An input with no real square root, such as a negative number, NaN or infinity, must come back with `ok` false. It must never hang.
--- starter
#include <cmath>

struct Root { double value; int iters; bool ok; };
constexpr int kMaxIter = 60;

Root bounded_sqrt(double a) {
    return {0.0, 0, false};
}
--- solution
#include <cmath>

struct Root { double value; int iters; bool ok; };
constexpr int kMaxIter = 60;

// Newton's method for sqrt(a), at most kMaxIter passes. ok == false means: do not use value.
Root bounded_sqrt(double a) {
    if (a == 0.0) return {0.0, 0, true};
    double x = (a >= 1.0) ? a : 1.0;
    for (int k = 1; k <= kMaxIter; ++k) {        // the fixed bound
        const double dx = (x - a / x) / 2.0;
        x -= dx;
        if (std::fabs(dx) <= 1e-14 * std::fabs(x)) return {x, k, true};
    }
    return {x, kMaxIter, false};                 // bound reached: a fault, not an answer
}
--- hint
Write the loop as `for (int k = 1; k <= kMaxIter; ++k)` and return from inside it as soon as the step is small enough. Whatever falls out of the bottom of the loop did not converge.
--- hint
You do not need a special test for negative numbers, NaN or infinity. Any comparison with NaN is false, and a negative number has no point where the step becomes small, so the bound stops the loop and the code after it reports the failure.
--- check test | sqrt(2)
[] { Root r = bounded_sqrt(2.0); return r.ok && std::fabs(r.value - 1.4142135623730951) < 1e-15 && r.iters >= 1 && r.iters <= kMaxIter; }()
--- check test | A large and a small input
[] { Root a = bounded_sqrt(1e12); Root b = bounded_sqrt(1e-10); return a.ok && std::fabs(a.value - 1e6) < 1e-6 && b.ok && std::fabs(b.value - 1e-5) < 1e-18; }()
--- check test | Zero
[] { Root r = bounded_sqrt(0.0); return r.ok && r.value == 0.0 && r.iters == 0; }()
--- check test | A negative number is refused, within the bound
[] { Root r = bounded_sqrt(-4.0); return !r.ok && r.iters <= kMaxIter; }()
--- check test | NaN and infinity are refused
!bounded_sqrt(std::nan("")).ok && !bounded_sqrt(INFINITY).ok

+++ practice | Find an entry in an index-linked table
--- task
A table of 16 entries holds a linked list. Each entry has an `id` and the index of the next entry, with -1 marking the end. The list starts at index `head`, which is -1 for an empty list. A radiation upset or a bug can damage a `next` index, so the walk must be bounded and must notice damage.

Write:

```cpp
constexpr int kCapacity = 16;
struct Link { int id; int next; };
enum class Find { Found, NotFound, Corrupt };
Find find_id(const std::array<Link, kCapacity>& table, int head, int id, int& steps);
```

- Walk from `head`. If an entry with `id` is reached, return `Found` and set `steps` to the number of links followed to get there (0 when it is the head entry).
- Reaching the end (-1) without finding it returns `NotFound`.
- Return `Corrupt` if `head` or any `next` is an index other than -1 outside 0 to 15, or if the walk would visit more than 16 entries (a healthy list of 16 slots cannot be longer, so there must be a loop in the links).
- Leave `steps` alone unless the result is `Found`.
--- starter
#include <array>

constexpr int kCapacity = 16;
struct Link { int id; int next; };
enum class Find { Found, NotFound, Corrupt };

Find find_id(const std::array<Link, kCapacity>& table, int head, int id, int& steps) {
    return Find::NotFound;
}
--- solution
#include <array>

constexpr int kCapacity = 16;
struct Link { int id; int next; };
enum class Find { Found, NotFound, Corrupt };

// The bound comes from the table itself: a healthy list can hold at most kCapacity entries.
Find find_id(const std::array<Link, kCapacity>& table, int head, int id, int& steps) {
    int at = head;
    for (int visited = 0; visited < kCapacity; ++visited) {
        if (at == -1) return Find::NotFound;
        if (at < 0 || at >= kCapacity) return Find::Corrupt;
        const Link& link = table[static_cast<std::size_t>(at)];
        if (link.id == id) {
            steps = visited;
            return Find::Found;
        }
        at = link.next;
    }
    // Sixteen entries visited and the list still goes on: a loop in the links.
    return at == -1 ? Find::NotFound : Find::Corrupt;
}
--- hint
Make it a counting loop from 0 to `kCapacity`. Inside, first check for the end, then for a bad index, then compare the id.
--- hint
After 16 visits, the walk may have ended exactly on the last healthy entry. Only a `next` that is not -1 at that point means a loop.

+++ practice | Clearing from the end with an unsigned counter
--- task
Write a function that clears the tail of a buffer, walking backwards from the last element:

```cpp
std::size_t zero_tail(std::span<int> v, std::size_t keep);
```

It sets every element from the last one down to index `keep` to 0, working from the end toward the front, and returns how many elements it set. Elements before `keep` are not touched.

- `keep` of 0 clears everything.
- If `keep` is not smaller than the size, nothing is cleared and it returns 0.
- An empty span returns 0.

Take care: `std::size_t` is unsigned. A loop written `for (std::size_t i = v.size() - 1; i >= keep; --i)` never ends when `keep` is 0, and `v.size() - 1` wraps around to a huge number when the span is empty.
--- starter
#include <cstddef>
#include <span>

std::size_t zero_tail(std::span<int> v, std::size_t keep) {
    return 0;
}
--- solution
#include <cstddef>
#include <span>

// Clears v[keep .. size-1], last element first. The counter runs from size down to keep + 1
// and indexes i - 1, so it never has to go below zero.
std::size_t zero_tail(std::span<int> v, std::size_t keep) {
    if (keep >= v.size()) return 0;
    for (std::size_t i = v.size(); i > keep; --i) {
        v[i - 1] = 0;
    }
    return v.size() - keep;
}
--- hint
Let the counter stand one past the element you clear: start it at `v.size()`, clear `v[i - 1]`, and stop when `i` reaches `keep`. The test `i > keep` is false in time even when `keep` is 0.
--- hint
Handle `keep >= v.size()` first. That also covers the empty span.

+++ practice | A cube root that trusts NaN
--- task
This cube root by Newton's method has a proper loop bound, and it reports whether it converged. For 27 it gives 3 and for -8 it gives -2, both with `converged` true. But when a failed sensor read hands it NaN, or infinity, it also says `converged` is true, and the caller flies with garbage.

Find the line that decides `converged` and fix it, so that NaN and infinity come back with `converged` false. Keep the rest of the function as it is.
--- starter
#include <cmath>

struct Cbrt { double value; int iters; bool converged; };
constexpr int kMaxIter = 50;

Cbrt bounded_cbrt(double a) {
    if (a == 0.0) return {0.0, 0, true};
    double x = (a > 1.0 || a < -1.0) ? a : 1.0;
    double dx = 0.0;
    int k = 1;

        dx = (x * x * x - a) / (3.0 * x * x);
        x -= dx;
        if (std::fabs(dx) <= 1e-14 * std::fabs(x)) break;
    }
    const bool converged = !(std::fabs(dx) > 1e-14 * std::fabs(x));
    return {x, k > kMaxIter ? kMaxIter : k, converged};
}

+++ practice | Draining a telemetry backlog within a frame
--- task
A telemetry task must never spend more than a fixed number of sends in one frame, however long its backlog grows: "send until the queue is empty" is a loop whose length depends on the world. Simulate the bounded version over a run of frames:

```cpp
struct DrainReport { int sent; int dropped; int max_backlog; };
DrainReport simulate_drain(std::span<const int> arrivals, int cap_per_frame, int queue_capacity);
```

The queue starts empty. In each frame `f`, in this order:

1. `arrivals[f]` new messages join the backlog.
2. If the backlog is now above `queue_capacity`, the extra messages are dropped (add them to `dropped`) and the backlog becomes `queue_capacity`.
3. Update `max_backlog`, the largest backlog seen at this point of any frame.
4. Send `cap_per_frame` messages, or the whole backlog if it is smaller, and add them to `sent`.

Messages still waiting after the last frame are neither sent nor dropped. Return `{-1, -1, -1}` if `cap_per_frame` is less than 1, `queue_capacity` is negative, or any arrival count is negative.

For example, arrivals `{3, 0, 7, 1, 0, 0}` with a cap of 2 and a capacity of 5 give 9 sent, 2 dropped and a largest backlog of 5.
--- starter
#include <span>

struct DrainReport { int sent; int dropped; int max_backlog; };

    return {0, 0, 0};
}
--- solution
#include <algorithm>
#include <span>

struct DrainReport { int sent; int dropped; int max_backlog; };

// Each frame sends at most cap_per_frame messages: the bound, whatever the backlog.
DrainReport simulate_drain(std::span<const int> arrivals, int cap_per_frame, int queue_capacity) {
    if (cap_per_frame < 1 || queue_capacity < 0) return {-1, -1, -1};
    for (int a : arrivals) {
        if (a < 0) return {-1, -1, -1};
    }
    DrainReport r{0, 0, 0};
    int backlog = 0;
    for (int a : arrivals) {
        backlog += a;
        if (backlog > queue_capacity) {
            r.dropped += backlog - queue_capacity;
            backlog = queue_capacity;
        }
        r.max_backlog = std::max(r.max_backlog, backlog);
        const int send = std::min(backlog, cap_per_frame);
        r.sent += send;
        backlog -= send;
    }
    return r;
}
--- hint
Check all the inputs first, then run one pass over the frames. The four steps inside the frame loop are four short lines.
--- hint
The number sent in a frame is `std::min(backlog, cap_per_frame)`. That `min` is the bound: no frame can send more.

+++ question | Choosing the bound for a poll
--- ask
A magnetometer's data sheet says a new reading is ready within 40 polls of its status register. On your test board it was always ready within 7 polls. You are writing the bounded wait. Which bound is the right choice?
--- choice
7, because that is what the real hardware does, and a tighter bound catches a dead part sooner.
--- choice
40 exactly, because the data sheet is the specification.
--- choice correct
About 100: a constant taken from the data sheet's 40 with room to spare, with reaching it reported as a fault.
--- choice
No bound, because the data sheet already guarantees the loop ends.
--- why
The bound comes from the specification, not from how fast one test board happened to be, so 7 would raise false faults on a slow but healthy part, or in the cold. Exactly 40 leaves no room for a part at the edge of its specification. A generous constant such as 100 costs a few microseconds in the worst case and still stops a dead part quickly. "No bound" bets the vehicle on the part never failing, which is the one thing a bounded loop exists to avoid.

+++ practice | The deepest path of a call graph
--- task
Each function of a task has its own frame size in bytes, from the `.su` files, and a list of the functions it calls. The deepest stack use starting at a function is its own frame plus the deepest stack use of the callee that goes deepest.

Write:

```cpp
struct Fn { int frame; std::vector<int> callees; };
int worst_stack(const std::vector<Fn>& fns, int root);
```

`fns[i].callees` holds indices into `fns`. The table is promised to be in an order where every callee has a larger index than the function that calls it, so there is no recursion. Use that order: work out the answer for the last function first and move toward index 0. Do not write a recursive function.

- Return the deepest stack use starting at `root`.
- Return -1 if `root` is outside the table, or if any callee index is out of range or not larger than its caller's index (the promise is broken).

For example, with `main_loop` 24 bytes calling 1, 2 and 3; `read_imu` 48 calling 4; `nav_update` 96 calling 4 and 5; `send_tm` 32 calling 6; and leaves `spi_transfer` 40, `mat6_mul` 320 and `crc16` 16, the answer from index 0 is 24 + 96 + 320 = 440.
--- starter

struct Fn { int frame; std::vector<int> callees; };

    return 0;
}
--- solution
#include <cstddef>
#include <vector>

struct Fn { int frame; std::vector<int> callees; };

// S(f) = s(f) + max over callees of S(callee), worked from the leaves up: no recursion needed.
int worst_stack(const std::vector<Fn>& fns, int root) {
    const int n = static_cast<int>(fns.size());
    if (root < 0 || root >= n) return -1;
    std::vector<int> deepest(fns.size(), 0);
    for (int i = n - 1; i >= 0; --i) {
        int below = 0;
        for (int c : fns[static_cast<std::size_t>(i)].callees) {
            if (c <= i || c >= n) return -1;   // the ordering promise is broken
            if (deepest[static_cast<std::size_t>(c)] > below) below = deepest[static_cast<std::size_t>(c)];
        }
        deepest[static_cast<std::size_t>(i)] = fns[static_cast<std::size_t>(i)].frame + below;
    }
    return deepest[static_cast<std::size_t>(root)];
}
--- hint
Keep a vector `deepest` with one entry per function. Because callees always come later, by the time you reach index `i` going downward, every callee of `i` already has its answer.
--- hint
Take the largest `deepest` among the callees, not the largest callee frame. A small function can call a huge one.

#include <cstddef>
#include <string>
#include <vector>

struct SuSummary { int largest; std::string largest_name; int not_static; };

SuSummary summarize_su(const std::vector<std::string>& lines) {
    SuSummary s{0, "", 0};
    bool any_static = false;
    for (const std::string& line : lines) {
        const std::size_t tab1 = line.find('\t');
        if (tab1 == std::string::npos) continue;
        const std::size_t tab2 = line.find('\t', tab1 + 1);
        if (tab2 == std::string::npos) continue;
        const std::string kind = line.substr(tab2 + 1);
        if (kind != "static") {
            ++s.not_static;
            continue;
        }
        // The name starts after the third colon of "file:line:column:".
        std::size_t start = 0;
        for (int colons = 0; colons < 3 && start != std::string::npos; ++colons) {
            start = line.find(':', start);
            if (start != std::string::npos) ++start;
        }
        if (start == std::string::npos || start > tab1) continue;
        const int bytes = std::stoi(line.substr(tab1 + 1, tab2 - tab1 - 1));
        if (!any_static || bytes > s.largest) {
            s.largest = bytes;
            s.largest_name = line.substr(start, tab1 - start);
            any_static = true;
        }
    }
    return s;
}

+++ practice | A stack analyzer that knows when it cannot answer
--- task
A real call graph comes in any order, and it may hold the things that break a stack bound. Write the analyzer:

```cpp
enum class Kind { Bounded, Recursive, Dynamic };
struct Func { int frame; bool dynamic; std::vector<int> callees; };
struct StackResult { Kind kind; int bytes; };
StackResult analyze(const std::vector<Func>& fns, int root);
```

Callee indices can be in any order, but they are always valid indices, and `root` is valid. Only the functions reachable from `root` matter.

- If any cycle of calls can be reached from `root` (a function that reaches itself, including a function that calls itself), return `{Kind::Recursive, -1}`.
- Otherwise, if any reachable function has `dynamic` set (its `.su` kind was not `static`, such as a variable-length array), return `{Kind::Dynamic, -1}`.
- Otherwise return `{Kind::Bounded, deepest}`, where `deepest` is the largest sum of frames along any chain of calls from `root`.

The analyzer must follow the rules it checks: no recursive function. The table has at most 64 functions, so fixed-size arrays of 64 are enough. One way: mark what is reachable, then repeatedly take out a reachable function that no remaining reachable function calls; if some are left that can never be taken out, there is a cycle.
--- starter
#include <vector>

enum class Kind { Bounded, Recursive, Dynamic };
struct Func { int frame; bool dynamic; std::vector<int> callees; };
struct StackResult { Kind kind; int bytes; };

StackResult analyze(const std::vector<Func>& fns, int root) {
    return {Kind::Bounded, 0};
}
--- solution
#include <array>
#include <cstddef>
#include <vector>

enum class Kind { Bounded, Recursive, Dynamic };
struct Func { int frame; bool dynamic; std::vector<int> callees; };
struct StackResult { Kind kind; int bytes; };

constexpr int kMaxFns = 64;

StackResult analyze(const std::vector<Func>& fns, int root) {
    const int n = static_cast<int>(fns.size());
    if (n > kMaxFns) return {Kind::Dynamic, -1};   // outside what this tool can bound
    auto at = [&](int i) -> const Func& { return fns[static_cast<std::size_t>(i)]; };

    // 1. Reachable set, with a fixed-size work list instead of recursion.
    std::array<bool, kMaxFns> reach{};
    std::array<int, kMaxFns> work{};
    int top = 0;
    reach[static_cast<std::size_t>(root)] = true;
    work[static_cast<std::size_t>(top++)] = root;
    while (top > 0) {                                   // each function is pushed at most once
        const int f = work[static_cast<std::size_t>(--top)];
        for (int c : at(f).callees) {
            if (!reach[static_cast<std::size_t>(c)]) {
                reach[static_cast<std::size_t>(c)] = true;
                work[static_cast<std::size_t>(top++)] = c;
            }
        }
    }

    // 2. Count callers inside the reachable part, then peel off functions nobody still calls.
    std::array<int, kMaxFns> callers{};
    int reachable = 0;
    for (int f = 0; f < n; ++f) {
        if (!reach[static_cast<std::size_t>(f)]) continue;
        ++reachable;
        for (int c : at(f).callees) ++callers[static_cast<std::size_t>(c)];
    }
    std::array<int, kMaxFns> order{};   // callers before callees
    int done = 0;
    top = 0;
    for (int f = 0; f < n; ++f) {
        if (reach[static_cast<std::size_t>(f)] && callers[static_cast<std::size_t>(f)] == 0) work[static_cast<std::size_t>(top++)] = f;
    }
    while (top > 0) {
        const int f = work[static_cast<std::size_t>(--top)];
        order[static_cast<std::size_t>(done++)] = f;
        for (int c : at(f).callees) {
            if (--callers[static_cast<std::size_t>(c)] == 0) work[static_cast<std::size_t>(top++)] = c;
        }
    }
    if (done < reachable) return {Kind::Recursive, -1};   // some could never be peeled: a cycle

    for (int i = 0; i < done; ++i) {
        if (at(order[static_cast<std::size_t>(i)]).dynamic) return {Kind::Dynamic, -1};
    }

    // 3. Deepest chain, from the callees back to the callers.
    std::array<int, kMaxFns> deepest{};
    for (int i = done - 1; i >= 0; --i) {
        const int f = order[static_cast<std::size_t>(i)];
        int below = 0;
        for (int c : at(f).callees) {
            if (deepest[static_cast<std::size_t>(c)] > below) below = deepest[static_cast<std::size_t>(c)];
        }
        deepest[static_cast<std::size_t>(f)] = at(f).frame + below;
    }
    return {Kind::Bounded, deepest[static_cast<std::size_t>(root)]};
}
--- hint
Three passes: find what `root` can reach; put the reachable functions in an order where every caller comes before its callees (and notice if you cannot); then add frames up from the end of that order.
--- hint
For the ordering, count for each reachable function how many calls reach it from reachable functions. Start with those at zero. Each time you take one out, lower the count of each of its callees, and a callee that reaches zero is ready. Count each call separately, even if a function lists the same callee twice.
--- hint
Each function enters the work list at most once, so an array of 64 is a fixed bound for it. If fewer functions come out than were reachable, the rest sit on a cycle.

+++ question | Recursion turned into a growing vector
--- ask
A team removes the recursion from a function that walks a tree of flight-plan waypoints. The new version is a loop that pushes the nodes still to visit onto a `std::vector<Node*>` and pops them off, and a review marks it compliant with the rule against recursion. What is still wrong?
--- choice
Nothing. Without recursion there is no cycle in the call graph, so the stack and the memory are both bounded.
--- choice correct
The depth has only moved from the stack into the vector, which grows with the tree and allocates while it grows. It needs a fixed capacity and a fault result for when the capacity is reached.
--- choice
Popping from the back of a vector reverses the visit order, so the walk visits the waypoints in the wrong order.
--- choice
A loop is slower than recursion, so the worst-case time gets worse.
--- why
The rule exists so that the worst case can be bounded before flight. A loop over a vector that grows with the data has exactly the same unknown depth as the recursion did; it just keeps it on the heap instead of the stack, and adds allocation after initialization on top. The fix is an explicit stack with a fixed capacity, chosen from the largest tree the software will accept, and a defined fault result when the capacity is reached. The visit order is a separate design choice, and a loop is not slower than recursion.

// --- the allocation counter: one per program ------------------------------
std::atomic<long> g_allocs{0};

void* operator new(std::size_t n) {
    g_allocs.fetch_add(1);
    if (void* p = std::malloc(n == 0 ? 1 : n)) return p;
    std::abort();   // no exceptions in this build

void operator delete(void* p) noexcept { std::free(p); }
void operator delete(void* p, std::size_t) noexcept { std::free(p); }

struct Sample { double t; double accel; };

long steady_state_allocs(int cycles, int per_cycle, int reserve_n) {
    std::vector<Sample> window;
    window.reserve(static_cast<std::size_t>(reserve_n));   // start-up: may allocate
    const long before = g_allocs.load();                   // steady state starts here
    for (int c = 0; c < cycles; ++c) {

        for (int i = 0; i < per_cycle; ++i) window.push_back({c * 1e-3, 9.8});

    return g_allocs.load() - before;
}

+++ practice | Where each arena request lands
--- task
An arena hands out memory by moving an offset forward. For each request, it rounds the offset up to the request's alignment, hands out that position, and moves the offset past the bytes. A request that does not fit is refused, and the offset does not move.

Write a planner that works out the positions without any real memory:

```cpp
struct Req { std::size_t bytes; std::size_t align; };
std::vector<long long> place(std::span<const Req> reqs, std::size_t capacity);
```

Return one entry per request, in order: its offset, or -1 if it was refused.

- The alignment must be a power of two (1, 2, 4, 8, ...). Any other alignment, including 0, is refused.
- A request fits when its aligned start plus its bytes is at most `capacity`. Filling the arena exactly fits.
- A request of 0 bytes fits whenever its aligned start is at most `capacity`. It gets that start, and the offset moves up to it.

For example, requests of 10 bytes aligned to 1, 24 bytes aligned to 8 and 4 bytes aligned to 4 in 256 bytes land at 0, 16 and 40.
--- starter
#include <cstddef>
#include <span>
#include <vector>

struct Req { std::size_t bytes; std::size_t align; };

std::vector<long long> place(std::span<const Req> reqs, std::size_t capacity) {
    std::vector<long long> out;
    std::size_t offset = 0;
    for (const Req& r : reqs) {
        out.push_back(static_cast<long long>(offset));
        offset += r.bytes;
    }
    return out;
}
--- solution
#include <cstddef>
#include <span>
#include <vector>

struct Req { std::size_t bytes; std::size_t align; };

std::vector<long long> place(std::span<const Req> reqs, std::size_t capacity) {
    std::vector<long long> out;
    std::size_t offset = 0;
    for (const Req& r : reqs) {
        const bool power_of_two = r.align != 0 && (r.align & (r.align - 1)) == 0;
        if (!power_of_two) {
            out.push_back(-1);
            continue;
        }
        const std::size_t start = (offset + r.align - 1) / r.align * r.align;   // round up
        if (start > capacity || r.bytes > capacity - start) {                   // no overflow
            out.push_back(-1);                                                  // refused: offset stays
            continue;
        }
        out.push_back(static_cast<long long>(start));
        offset = start + r.bytes;
    }
    return out;
}
--- hint
Rounding up to a multiple of `a` is `(offset + a - 1) / a * a`. A power of two has exactly one bit set, so `a & (a - 1)` is 0 for it.
--- hint
Test "does not fit" as `start > capacity || bytes > capacity - start`, and only move the offset when the request is accepted.

This pool of four slots keeps its free slots in a chain of indices: `free_` is the first free slot and `next_[i]` is the free slot after `i`, with -1 ending the chain. `acquire` returns a slot index, or -1 when the pool is empty. `release` gives a slot back.

+++ practice | A pool that catches a double release
--- task
A pool that hands out raw pointers cannot tell when the same object is released twice. Hand out handles instead: a slot index plus a generation number that changes every time the slot is released.

Write:

```cpp
struct Handle { std::uint16_t index; std::uint16_t generation; };

template <typename T, std::size_t N>
class HandlePool {
public:
    HandlePool();
    std::optional<Handle> acquire(const T& value);   // copy value into a free slot
    bool release(Handle h);                           // false for a stale or bad handle
    T* get(Handle h);                                 // nullptr for a stale or bad handle
    std::size_t in_use() const;
};
```

- The storage for the objects is raw, correctly aligned bytes inside the pool. `acquire` builds the object with placement new, and `release` runs its destructor. No heap.
- Free slots form a last-in, first-out chain, so a released slot is the next one handed out. At the start, slots come out in the order 0, 1, 2, and so on. `acquire` on a full pool returns `std::nullopt`.
- Each slot has a generation, starting at 0. `release` adds one to it (letting it wrap around at 65 536).
- A handle is valid only while its index is less than `N`, its slot is in use, and its generation equals the slot's. So a second release of the same handle, and any use of it after its release, is refused.
- `N` is at most 65 535.

template <typename T, std::size_t N>
class HandlePool {
    static_assert(N > 0 && N < 65536, "slot indices must fit in 16 bits");
public:
    HandlePool() {
        for (std::size_t i = 0; i < N; ++i) {
            next_[i] = (i + 1 < N) ? static_cast<int>(i + 1) : -1;
        }
    }
    HandlePool(const HandlePool&) = delete;
    HandlePool& operator=(const HandlePool&) = delete;

    std::optional<Handle> acquire(const T& value) {
        if (free_ == -1) return std::nullopt;
        const auto i = static_cast<std::size_t>(free_);
        free_ = next_[i];
        ::new (static_cast<void*>(slots_[i].bytes)) T(value);   // build in place
        used_[i] = true;
        ++count_;
        return Handle{static_cast<std::uint16_t>(i), gen_[i]};
    }

    bool release(Handle h) {
        if (!valid(h)) return false;                             // stale, double or foreign
        const std::size_t i = h.index;
        object(i)->~T();                                         // end its lifetime
        used_[i] = false;
        ++gen_[i];                                               // old handles now fail
        next_[i] = free_;
        free_ = static_cast<int>(i);
        --count_;
        return true;
    }

    T* get(Handle h) { return valid(h) ? object(h.index) : nullptr; }
    std::size_t in_use() const { return count_; }

private:
    struct Slot { alignas(T) unsigned char bytes[sizeof(T)]; };
    bool valid(Handle h) const { return h.index < N && used_[h.index] && gen_[h.index] == h.generation; }
    T* object(std::size_t i) { return std::launder(reinterpret_cast<T*>(slots_[i].bytes)); }

    std::array<Slot, N> slots_{};
    std::array<std::uint16_t, N> gen_{};
    std::array<bool, N> used_{};
    std::array<int, N> next_{};
    int free_ = 0;
    std::size_t count_ = 0;
};

+++ practice | Slots for the hand-off queue
--- task
An interrupt delivers `samples_per_second` samples, and the task that empties the hand-off queue can leave a gap of up to `worst_gap_us` microseconds between two visits. The queue must hold every sample that can arrive in the worst gap, and its size must be a power of two so that `% N` is a cheap mask.

Write:

```cpp
std::uint32_t queue_slots(std::uint32_t samples_per_second, std::uint32_t worst_gap_us);
```

- The samples that can pile up are `samples_per_second × worst_gap_us / 1 000 000`, rounded up to a whole sample.
- Return the smallest power of two that is at least that number, and at least 1.
- If that power of two does not fit in `std::uint32_t` (it would be 2 to the 32 or more), return 0.
- Use whole-number arithmetic. The product can be far larger than 32 bits.

For example, 1000 samples a second and a worst gap of 15 000 µs give 15 samples, so 16 slots. A gap of 16 001 µs gives 16.001, which rounds up to 17, so 32 slots.
--- starter

}
--- solution
#include <cstdint>

std::uint32_t queue_slots(std::uint32_t samples_per_second, std::uint32_t worst_gap_us) {

--- task
Some interrupts only need to tell a task "this happened". The handler sets a bit in a shared word, and the task takes all the bits at once. A bit cannot count, so several signals of the same event before the task looks become one bit. When the count matters, keep a counter too.

Write, with these names at file scope:

- `signal_count` returns how many times the event has been signalled since the program started, or 0 for an event number of 4 or more.

#include <array>
#include <atomic>
#include <cstddef>
#include <cstdint>

enum class Event : std::uint32_t { GyroReady = 0, UartByte = 1, Tick = 2, SunSensor = 3 };
constexpr std::uint32_t kEvents = 4;

std::atomic<std::uint32_t> g_pending{0};
std::array<std::atomic<std::uint32_t>, kEvents> g_counts{};
static_assert(std::atomic<std::uint32_t>::is_always_lock_free);

// Called from interrupts: two lock-free operations, no waiting.
void isr_signal(Event e) {
    const auto n = static_cast<std::uint32_t>(e);
    if (n >= kEvents) return;   // never index past the array
    g_counts[n].fetch_add(1, std::memory_order_relaxed);
    g_pending.fetch_or(1u << n, std::memory_order_release);
}

// Called from the task: take and clear in one step, so nothing slips in between.
std::uint32_t task_take_pending() {
    return g_pending.exchange(0u, std::memory_order_acquire);
}

std::uint32_t signal_count(Event e) {
    const auto n = static_cast<std::uint32_t>(e);
    return n < kEvents ? g_counts[n].load(std::memory_order_relaxed) : 0u;
}
--- hint

--- hint

+++ practice | Worst-case interrupt latency
--- task
On this processor a lower priority number means more urgent, a more urgent interrupt preempts a less urgent handler at once, and a handler blocks every interrupt of its own priority until it returns. Tasks also switch interrupts off for short stretches. Model the worst-case latency of interrupt `k`, the cycles from its signal to its handler's first instruction, as the sum of three parts:

1. `hw_cycles`, the hardware's own entry time;
2. the blocking: the larger of `masked_cycles` (the longest stretch with interrupts off) and the longest handler among the other interrupts with the same priority as `k`;
3. the interference: the durations of every interrupt more urgent than `k`, each counted once.

A less urgent handler that is running does not delay `k` at all: `k` preempts it.

Write:

```cpp
struct IrqInfo { int priority; int duration_cycles; };
int worst_latency(std::span<const IrqInfo> irqs, int k, int hw_cycles, int masked_cycles);
```

Return -1 if `k` is not a valid index, or if any duration, `hw_cycles` or `masked_cycles` is negative.

For example, with interrupts of priority and duration (1, 120), (2, 300), (2, 80) and (3, 900), 12 cycles of hardware entry and 50 cycles masked, interrupt 1 waits 12 + 80 + 120 = 212 cycles.
--- starter
#include <span>

struct IrqInfo { int priority; int duration_cycles; };

int worst_latency(std::span<const IrqInfo> irqs, int k, int hw_cycles, int masked_cycles) {
    return hw_cycles;
}
--- solution
#include <cstddef>
#include <span>

struct IrqInfo { int priority; int duration_cycles; };

int worst_latency(std::span<const IrqInfo> irqs, int k, int hw_cycles, int masked_cycles) {
    if (k < 0 || static_cast<std::size_t>(k) >= irqs.size()) return -1;
    if (hw_cycles < 0 || masked_cycles < 0) return -1;
    const int mine = irqs[static_cast<std::size_t>(k)].priority;
    int blocking = masked_cycles;
    int interference = 0;
    for (std::size_t i = 0; i < irqs.size(); ++i) {
        const IrqInfo& q = irqs[i];
        if (q.duration_cycles < 0) return -1;
        if (static_cast<int>(i) == k) continue;
        if (q.priority == mine && q.duration_cycles > blocking) blocking = q.duration_cycles;   // same level cannot nest
        if (q.priority < mine) interference += q.duration_cycles;                             // more urgent: runs first
    }
    return hw_cycles + blocking + interference;
}
--- hint
One pass over the interrupts. Skip `k` itself. An equal priority can only block (take the largest), a smaller number interferes (add it up), and a larger number is ignored.
--- hint
Start the blocking at `masked_cycles`, so a same-priority handler only counts when it is longer than the masked stretch.

--- task
An interrupt pushes samples into this single-producer, single-consumer queue of 4 slots, and counts an overrun when the queue is full. A task pops them.

After four pushes with no pops, a fifth push should be refused and counted as an overrun. Instead it is accepted: it overwrites the oldest sample, the overrun is never counted, and the task later pops five samples, the newest one twice.

Find the faulty line in the queue and fix it.
--- starter
#include <array>
#include <atomic>
#include <cstdint>

template <typename T, std::uint32_t N>
class Spsc {
public:
    bool try_push(const T& v) {                       // interrupt side only
        const std::uint32_t h = head_.load(std::memory_order_relaxed);
        const std::uint32_t t = tail_.load(std::memory_order_acquire);
        if (h - t > N) return false;
        buf_[h % N] = v;
        head_.store(h + 1, std::memory_order_release);
        return true;
    }
    bool try_pop(T& out) {                            // task side only
        const std::uint32_t t = tail_.load(std::memory_order_relaxed);
        const std::uint32_t h = head_.load(std::memory_order_acquire);
        if (h == t) return false;
        out = buf_[t % N];
        tail_.store(t + 1, std::memory_order_release);
        return true;
    }
private:
    std::array<T, N> buf_{};
    std::atomic<std::uint32_t> head_{0};
    std::atomic<std::uint32_t> tail_{0};
};

#include <atomic>

template <typename T, std::uint32_t N>
class Spsc {
public:
    bool try_push(const T& v) {                       // interrupt side only

    std::atomic<std::uint32_t> tail_{0};
};

+++ practice | The smallest queue that loses nothing
--- task
An interrupt delivers one sample every `sample_period_us` microseconds, at times `sample_period_us`, `2 × sample_period_us`, and so on. The task empties the whole queue at the times in `drain_times_us`, which include any lateness it really had. A drain at time `t` takes every sample that arrived at or before `t`, including one that arrives at the same instant. The run lasts until `horizon_us`, and samples that arrive after the last drain are still in the queue at the horizon.

Write:

```cpp
struct QueuePlan { int max_backlog; std::uint32_t slots; };
QueuePlan plan_queue(std::span<const int> drain_times_us, int sample_period_us, int horizon_us);
```

- `max_backlog` is the most samples waiting at any one time: just before a drain, or at the horizon.
- `slots` is the smallest power of two that is at least `max_backlog`, and at least 1.
- Return `{-1, 0}` if the period is less than 1, the horizon is negative, or the drain times are not strictly increasing, include a negative time, or go past the horizon.

For example, samples every 1000 µs, drains at 5000, 10 000, 20 000 and 25 000 µs (the third one was late) and a horizon of 30 000 µs leave at most 10 samples waiting, so 16 slots.
--- starter

#include <span>

    return {0, 1};
}
--- solution
#include <cstdint>
#include <span>

struct QueuePlan { int max_backlog; std::uint32_t slots; };

QueuePlan plan_queue(std::span<const int> drain_times_us, int sample_period_us, int horizon_us) {
    if (sample_period_us < 1 || horizon_us < 0) return {-1, 0};
    int last = -1;
    for (int t : drain_times_us) {
        if (t < 0 || t <= last || t > horizon_us) return {-1, 0};
        last = t;
    }
    // Samples that have arrived by time t: one every period, the first at t = period.
    auto arrived = [sample_period_us](int t) { return t / sample_period_us; };
    int taken = 0;
    int worst = 0;
    for (int t : drain_times_us) {
        const int waiting = arrived(t) - taken;   // just before this drain
        if (waiting > worst) worst = waiting;
        taken = arrived(t);
    }
    const int at_end = arrived(horizon_us) - taken;
    if (at_end > worst) worst = at_end;
    std::uint32_t slots = 1;
    while (slots < static_cast<std::uint32_t>(worst)) slots *= 2;
    return {worst, slots};
}
--- hint
By time `t`, exactly `t / sample_period_us` samples have arrived, in whole-number division. A sample at the same instant as a drain is included, which is what that division gives.
--- hint
Keep how many samples have been taken so far. Before each drain, the waiting count is what has arrived minus what was taken. Do the same once more at the horizon.

+++ question | Why the push ends with a release store
--- ask
In the interrupt's `try_push`, the sample is copied into its slot, and then the head index is written with `head_.store(h + 1, std::memory_order_release)`. The task reads the head with `memory_order_acquire` before it copies the slot out. What would go wrong if the head were written with `memory_order_relaxed` instead?
--- choice
The store would no longer be atomic, so the task could read half of the old index and half of the new one.
--- choice correct
The task could see the new head before it sees the sample written into the slot, and copy out stale data. The release store is what orders the slot write before the index write for whoever acquires the index.
--- choice
The interrupt would have to wait for the task to finish reading, which is blocking.
--- choice
Nothing on any processor, because an interrupt and a task on one core always see memory in program order.
--- why
Relaxed stores are still atomic: the index is never torn. What they lose is ordering. Without release, the compiler, or a processor such as ARM, may make the index write visible before the slot write, and the task, trusting the index, reads a slot that is not filled yet. Release on the producer paired with acquire on the consumer makes "slot written" happen before "index seen". Neither side ever waits, so the queue stays lock-free. On a single core the processor itself keeps order, but the compiler can still reorder the two stores, so the ordering is needed there too.

Each task increments its own `std::uint32_t` heartbeat counter every time it finishes a run. Write the monitor that watches them and decides whether to pet the watchdog:

```cpp
class HealthMonitor {

```

- `add` registers a task's counter and the fewest beats it must show at each check. It remembers the counter's current value as its starting point and returns the task's number: 0 for the first task added, 1 for the next, and so on. It returns -1 for a null pointer, or when 8 tasks are already registered.

It returns true only when every task moved by at least its minimum, and only then adds one to the pet count. With no tasks registered it returns true.
- Counters wrap around after 4 294 967 295; the movement must still be right across a wrap.
- `first_unhealthy` is the lowest task number that fell short at the last check, or -1.
- `pets` is how many times the monitor has petted the watchdog.

#include <array>
#include <cstdint>

class HealthMonitor {
public:
    int add(const std::uint32_t* beats, std::uint32_t min_beats) {
        if (beats == nullptr || count_ == kMaxTasks) return -1;
        watch_[static_cast<std::size_t>(count_)] = {beats, min_beats, *beats};
        return count_++;
    }

    // Pet only on evidence: every task must have advanced enough since the last check.
    bool check() {
        first_bad_ = -1;
        for (int i = 0; i < count_; ++i) {
            Watch& w = watch_[static_cast<std::size_t>(i)];
            const std::uint32_t now = *w.beats;
            const std::uint32_t got = now - w.seen;   // unsigned: right across a wrap
            w.seen = now;
            if (got < w.min_beats && first_bad_ == -1) first_bad_ = i;
        }
        if (first_bad_ != -1) return false;
        ++pets_;
        return true;
    }

    int first_unhealthy() const { return first_bad_; }
    std::uint32_t pets() const { return pets_; }

private:
    struct Watch { const std::uint32_t* beats; std::uint32_t min_beats; std::uint32_t seen; };
    static constexpr int kMaxTasks = 8;
    std::array<Watch, kMaxTasks> watch_{};
    int count_ = 0;
    int first_bad_ = -1;
    std::uint32_t pets_ = 0;
};

+++ practice | A watchdog with a window
--- task
A windowed watchdog starts a new cycle at every accepted pet, and at time 0. A pet less than `window_open_ms` after the start of its cycle is too early and resets the processor at that moment. If no pet comes within `timeout_ms` of the start of the cycle, it resets at the start plus `timeout_ms`; a pet at exactly that moment is already too late. A pet exactly `window_open_ms` after the start is accepted.

Write:

```cpp
int window_reset_ms(std::span<const int> pet_times_ms, int timeout_ms, int window_open_ms);
```

The pet times are strictly increasing, and after the last one the software pets no more. Return the time of the reset. Return -1 if `timeout_ms` is not positive, `window_open_ms` is negative, or `window_open_ms` is not smaller than `timeout_ms`.

For example, with a 100 ms timeout and a window that opens at 60 ms, pets at 70, 150 and 230 are all accepted, and the reset comes at 330. Pets at 70 and 100 reset at 100: the second pet came only 30 ms into its cycle.
--- starter

}
--- solution
#include <span>

int window_reset_ms(std::span<const int> pet_times_ms, int timeout_ms, int window_open_ms) {
    if (timeout_ms <= 0 || window_open_ms < 0 || window_open_ms >= timeout_ms) return -1;
    int start = 0;                                   // the current cycle began here
    for (int pet : pet_times_ms) {
        const int into = pet - start;
        if (into >= timeout_ms) return start + timeout_ms;   // it already ran out
        if (into < window_open_ms) return pet;                // too early: a runaway loop
        start = pet;                                          // accepted: a new cycle
    }
    return start + timeout_ms;                       // the pets stopped
}
--- hint
Keep the start of the current cycle. For each pet, work out how far into the cycle it came, then test "too late" before "too early".
--- hint

+++ practice | A boot counter that survives the reset
--- task
After a reset, the flight software must not restart normal mode forever if the same fault keeps hanging it. A small record lives in RAM that the start-up code does not clear. It survives a watchdog reset, but after a power loss it holds random bits.

```cpp
enum class ResetCause { PowerOn, Pin, Software, Watchdog };
enum class BootMode { Normal, Safe };
struct NoInit { std::uint32_t magic; std::uint32_t wd_resets; std::uint32_t check; };

constexpr std::uint32_t kMaxWatchdogResets = 3;

BootMode on_boot(NoInit& ni, ResetCause cause);
void on_stable_running(NoInit& ni);
```

`on_boot`, in this order:

1. The record is valid when `magic == kMagic` and `check == ~(magic ^ wd_resets)`. If it is not valid, or the cause is `PowerOn`, start it again with `wd_resets` = 0.
2. A `Watchdog` cause adds one to `wd_resets` (stopping at the largest `std::uint32_t` rather than wrapping). `Pin` and `Software` leave it as it is.
3. Store `magic` and a fresh `check`, so the record is valid for the next boot.
4. Return `Safe` if `wd_resets` is at least `kMaxWatchdogResets`, otherwise `Normal`.

`on_stable_running` is called after a long stretch of normal running. It sets `wd_resets` to 0 and leaves a valid record.

--- solution
#include <cstdint>

enum class ResetCause { PowerOn, Pin, Software, Watchdog };
enum class BootMode { Normal, Safe };
struct NoInit { std::uint32_t magic; std::uint32_t wd_resets; std::uint32_t check; };
constexpr std::uint32_t kMagic = 0xB007C0DEu;
constexpr std::uint32_t kMaxWatchdogResets = 3;

namespace {
std::uint32_t check_of(const NoInit& ni) { return ~(ni.magic ^ ni.wd_resets); }
bool valid(const NoInit& ni) { return ni.magic == kMagic && ni.check == check_of(ni); }
void seal(NoInit& ni) {
    ni.magic = kMagic;
    ni.check = check_of(ni);
}
}  // namespace

BootMode on_boot(NoInit& ni, ResetCause cause) {
    if (!valid(ni) || cause == ResetCause::PowerOn) ni.wd_resets = 0;   // random bits, or a fresh start
    if (cause == ResetCause::Watchdog && ni.wd_resets != 0xFFFFFFFFu) ++ni.wd_resets;
    seal(ni);
    return ni.wd_resets >= kMaxWatchdogResets ? BootMode::Safe : BootMode::Normal;
}

void on_stable_running(NoInit& ni) {
    ni.wd_resets = 0;
    seal(ni);
}

+++ question | A watchdog on the main clock
--- ask
To save a part, a board's only watchdog counts from the processor's main clock instead of from its own oscillator. Which failure can this watchdog no longer catch?
--- choice
A task stuck in an endless loop that the health monitor notices.
--- choice
A deadlock between a task and an interrupt handler.
--- choice correct
The main clock itself stopping, which freezes the processor and the watchdog's countdown together.
--- choice
A runaway loop that pets far too often.
--- why
A watchdog only helps if it keeps counting when everything else has stopped. The endless loop and the deadlock both stop the pets while the main clock runs on, so the countdown still reaches zero. But if the main clock fails, the processor halts and the countdown freezes at the same instant, so the reset never comes. That is why the independent watchdog gets its own small oscillator. A runaway loop that pets too often is missed by any plain watchdog, whatever its clock; catching it needs a window.

+++ practice | A recovery ladder with budgets
--- task
Each confirmed fault gets the smallest response that still has budget left. Write:

```cpp
enum class Action { Retry, SwitchToSpare, ResetUnit, SafeMode };
class Ladder {
public:
    Ladder(int retries, int spares, int resets);
    Action on_fault();
    void on_ground_clear();
    bool in_safe_mode() const;
};
```

- The constructor sets the budget of each rung: how many times `Retry`, `SwitchToSpare` and `ResetUnit` may be used. A negative budget counts as 0.
- `on_fault` returns the lowest rung that still has budget, and uses one of its budget. When all three budgets are used up, it returns `SafeMode`, and from then on every fault returns `SafeMode`: safe mode is sticky.
- Nothing on board refills the budgets. Only `on_ground_clear`, a command from the ground, restores the original budgets and leaves safe mode.

For example, `Ladder(2, 1, 1)` answers six faults with Retry, Retry, SwitchToSpare, ResetUnit, SafeMode, SafeMode.
--- starter
enum class Action { Retry, SwitchToSpare, ResetUnit, SafeMode };

class Ladder {
public:
    Ladder(int retries, int spares, int resets) {}
    Action on_fault() { return Action::Retry; }
    void on_ground_clear() {}
    bool in_safe_mode() const { return false; }
};
--- solution
#include <array>
#include <cstddef>

enum class Action { Retry, SwitchToSpare, ResetUnit, SafeMode };

class Ladder {
public:
    Ladder(int retries, int spares, int resets)
        : budget_{clamp(retries), clamp(spares), clamp(resets)}, left_(budget_) {}

    // The smallest rung with budget left; safe mode once the ladder is used up.
    Action on_fault() {
        if (safe_) return Action::SafeMode;
        for (std::size_t r = 0; r < left_.size(); ++r) {
            if (left_[r] > 0) {
                --left_[r];
                return static_cast<Action>(r);
            }
        }
        safe_ = true;   // sticky: only the ground can bring it back
        return Action::SafeMode;
    }

    void on_ground_clear() {
        left_ = budget_;
        safe_ = false;
    }

    bool in_safe_mode() const { return safe_; }

private:
    static int clamp(int n) { return n < 0 ? 0 : n; }
    std::array<int, 3> budget_;
    std::array<int, 3> left_;
    bool safe_ = false;
};
--- hint

+++ practice | Three gyros, one manager
--- task
Build the whole detection, isolation and recovery loop for three gyros on one axis:

```cpp
enum class Mode { Nominal, Degraded, Safe };
class GyroManager {
public:
    GyroManager(float tol, int persist);
    float update(const std::array<float, 3>& w);
    Mode mode() const;
    bool healthy(int i) const;
};
```

Two readings agree when both are finite and differ by at most `tol`. Each call to `update` is one frame, and returns the rate to fly with.

**Nominal** (all three healthy):
- The odd one out is the reading that agrees with neither other while those two agree. Each gyro has a strike count: add one when it is the odd one out this frame, set it to 0 otherwise.
- When a gyro's strikes reach `persist`, isolate it for good (`healthy(i)` becomes false) and switch to Degraded.
- Output: if there is an odd one out this frame (confirmed or not), the mean of the other two; else if all three are finite, the median; else switch to Safe.

**Degraded** (two healthy):
- If the two healthy readings agree, output their mean, remember it as the last good output, and set the disagreement count to 0.
- If they do not agree (a NaN counts as not agreeing), add one to the disagreement count and output the last good output. When the count reaches `persist`, switch to Safe.

**Safe:** output 0.0 on that frame and every frame after. Isolation and safe mode are sticky: nothing on board undoes them.

The last good output is updated by every Nominal and Degraded frame that outputs a real value. `persist` is at least 1.
--- starter

public:

    float update(const std::array<float, 3>& w) { return w[0]; }
    Mode mode() const { return Mode::Nominal; }
    bool healthy(int i) const { return true; }
};
--- solution
#include <algorithm>
#include <array>
#include <cmath>
#include <cstddef>

enum class Mode { Nominal, Degraded, Safe };

class GyroManager {
public:
    GyroManager(float tol, int persist) : tol_(tol), persist_(persist < 1 ? 1 : persist) {}

    float update(const std::array<float, 3>& w) {
        if (mode_ == Mode::Nominal) return nominal(w);
        if (mode_ == Mode::Degraded) return degraded(w);
        return 0.0F;
    }

    Mode mode() const { return mode_; }
    bool healthy(int i) const { return i >= 0 && i < 3 && healthy_[static_cast<std::size_t>(i)]; }

private:
    bool agree(float x, float y) const {
        return std::isfinite(x) && std::isfinite(y) && std::fabs(x - y) <= tol_;
    }

    float nominal(const std::array<float, 3>& w) {
        int odd = -1;
        for (int i = 0; i < 3; ++i) {
            const float x = w[static_cast<std::size_t>(i)];
            const float y = w[static_cast<std::size_t>((i + 1) % 3)];
            const float z = w[static_cast<std::size_t>((i + 2) % 3)];
            if (!agree(x, y) && !agree(x, z) && agree(y, z)) odd = i;
        }
        for (int i = 0; i < 3; ++i) strikes_[static_cast<std::size_t>(i)] = (i == odd) ? strikes_[static_cast<std::size_t>(i)] + 1 : 0;
        if (odd >= 0) {
            if (strikes_[static_cast<std::size_t>(odd)] >= persist_) {
                healthy_[static_cast<std::size_t>(odd)] = false;   // isolate, for good
                mode_ = Mode::Degraded;
            }
            return good((w[static_cast<std::size_t>((odd + 1) % 3)] + w[static_cast<std::size_t>((odd + 2) % 3)]) / 2.0F);
        }
        if (std::isfinite(w[0]) && std::isfinite(w[1]) && std::isfinite(w[2])) {
            return good(std::max(std::min(w[0], w[1]), std::min(std::max(w[0], w[1]), w[2])));
        }
        return enter_safe();
    }

    float degraded(const std::array<float, 3>& w) {
        float pair[2] = {0.0F, 0.0F};
        int k = 0;
        for (std::size_t i = 0; i < 3; ++i) {
            if (healthy_[i]) pair[k++] = w[i];
        }
        if (agree(pair[0], pair[1])) {
            disagree_ = 0;
            return good((pair[0] + pair[1]) / 2.0F);
        }
        if (++disagree_ >= persist_) return enter_safe();   // two cannot isolate: give up safely
        return last_good_;
    }

    float good(float v) {
        last_good_ = v;
        return v;
    }

    float enter_safe() {
        mode_ = Mode::Safe;
        return 0.0F;
    }

    float tol_;
    int persist_;
    Mode mode_ = Mode::Nominal;
    std::array<bool, 3> healthy_{true, true, true};
    std::array<int, 3> strikes_{};
    int disagree_ = 0;
    float last_good_ = 0.0F;
};
--- hint
Split `update` by mode into two private functions, plus small helpers `agree`, `good` (remember and return a value) and `enter_safe`.
--- hint
In Nominal, find the odd one first, then update all three strike counts, then decide isolation, then the output. In Degraded, collect the two healthy readings into a pair.
--- hint
Two healthy gyros that disagree cannot say which is wrong, so Degraded never isolates a second gyro. It holds the last good value while it waits to see whether the disagreement persists.

+++ question | A gyro that looks fine again
--- ask
Gyro B was isolated an hour ago after it disagreed with A and C for many frames in a row. For the last ten minutes, B has agreed with A and C to well within the tolerance. What should the on-board fault software do?
--- choice
Put B back into use, because it has now passed far more frames than the persistence count.
--- choice
Put B back into use only after it has agreed for twice as long as it disagreed.
--- choice correct
Keep B isolated. Trusting it again is a decision for the ground, after engineers have looked at the telemetry.
--- choice
Reset the whole flight computer, so that all three gyros start again from a clean state.
--- why
Isolation is sticky on purpose. A part that failed once and then looked healthy can fail again, and software that keeps isolating and restoring it makes the controller jump between two answers. The ground can see the whole history and decide whether B is safe to trust. A processor reset is a far bigger response than this situation needs, and it would throw away the isolation that is protecting the vehicle.

+++ practice | How often to scrub
--- task
Memory is organised in 64-bit words protected by SECDED error-correcting code, which corrects one flipped bit per word but not two. Each bit flips with probability `p` per day. If a scrubber reads every word every `T` days, uncorrectable double errors happen about

`W × λ² × T / 2` per day,

where `W` is the number of words and `λ = 64 × p` is one word's upset rate per day.

Write:

```cpp
double double_errors_per_day(double mebibytes, double p_bit_per_day, double scrub_interval_days);
double scrub_interval_for(double mebibytes, double p_bit_per_day, double max_per_day);
```

- A mebibyte is 2²⁰ bytes of 8 bits each.
- `scrub_interval_for` returns the longest interval `T`, in days, that keeps double errors at or below `max_per_day`.
- Both return -1.0 if any input is not positive.

For example, 64 MiB with `p = 10⁻⁶` per bit per day, scrubbed daily, has about 0.0172 double errors a day.
--- starter

--- solution
namespace {
double words_in(double mebibytes) { return mebibytes * 1048576.0 * 8.0 / 64.0; }
}  // namespace

double double_errors_per_day(double mebibytes, double p_bit_per_day, double scrub_interval_days) {
    if (mebibytes <= 0.0 || p_bit_per_day <= 0.0 || scrub_interval_days <= 0.0) return -1.0;
    const double lambda = 64.0 * p_bit_per_day;   // upsets per word per day
    return words_in(mebibytes) * lambda * lambda * scrub_interval_days / 2.0;
}

double scrub_interval_for(double mebibytes, double p_bit_per_day, double max_per_day) {
    if (mebibytes <= 0.0 || p_bit_per_day <= 0.0 || max_per_day <= 0.0) return -1.0;
    const double lambda = 64.0 * p_bit_per_day;
    return 2.0 * max_per_day / (words_in(mebibytes) * lambda * lambda);   // solve the formula for T
}
--- hint
The number of words is the number of bits divided by 64, and the number of bits is mebibytes times 2 to the 20 times 8.
--- hint
The formula is linear in `T`, so solving `W λ² T / 2 = max` for `T` is one division.

+++ practice | A CRC that knows when the golden copy is bad too
--- task
A table of eight controller gains is protected by a CRC-16 stored at build time, and a golden copy sits in write-protected memory.

Write:

```cpp
std::uint16_t crc16_ccitt(std::span<const std::uint8_t> data);

struct GainTable { std::array<std::int16_t, 8> gains; };

```

- `crc16_ccitt` is the CRC-16 known as CCITT-FALSE: start with `0xFFFF`; for each byte, XOR it into the high 8 bits of the CRC, then 8 times: if the top bit (`0x8000`) is set, shift left by one and XOR with `0x1021`, otherwise just shift left by one; keep 16 bits. There is no final XOR. Its check value: the 9 bytes of the text `123456789` give `0x29B1`.
- `table_crc` feeds the gains in order, each as two bytes, high byte first. Using a fixed byte order means the answer does not depend on how the processor stores integers.
- `check_and_repair` returns `Ok` if the working table's CRC matches `stored_crc`. If it does not, it copies the golden table over the working one and returns `Repaired`, but only if the golden table's own CRC matches. If the golden copy does not match either, it leaves the working table alone and returns `GoldenBad`, so the fault can go up the recovery ladder.

--- solution
#include <array>
#include <cstddef>
#include <cstdint>
#include <span>

// CRC-16/CCITT-FALSE, one bit at a time. Bound: 8 passes per byte of a caller-sized buffer.
std::uint16_t crc16_ccitt(std::span<const std::uint8_t> data) {
    std::uint16_t crc = 0xFFFFu;
    for (std::uint8_t byte : data) {
        crc = static_cast<std::uint16_t>(crc ^ (byte << 8));
        for (int bit = 0; bit < 8; ++bit) {
            crc = (crc & 0x8000u) ? static_cast<std::uint16_t>((crc << 1) ^ 0x1021u)
                                  : static_cast<std::uint16_t>(crc << 1);
        }
    }
    return crc;
}

struct GainTable { std::array<std::int16_t, 8> gains; };

std::uint16_t table_crc(const GainTable& t) {
    std::array<std::uint8_t, 16> bytes{};
    for (std::size_t i = 0; i < t.gains.size(); ++i) {
        const auto u = static_cast<std::uint16_t>(t.gains[i]);
        bytes[2 * i] = static_cast<std::uint8_t>(u >> 8);       // high byte first
        bytes[2 * i + 1] = static_cast<std::uint8_t>(u & 0xFFu);
    }
    return crc16_ccitt(bytes);
}

enum class Check { Ok, Repaired, GoldenBad };

Check check_and_repair(GainTable& working, const GainTable& golden, std::uint16_t stored_crc) {
    if (table_crc(working) == stored_crc) return Check::Ok;
    if (table_crc(golden) != stored_crc) return Check::GoldenBad;   // never "repair" from a bad copy
    working = golden;
    return Check::Repaired;
}
--- hint
Keep the CRC in a `std::uint16_t` and cast back to it after every shift, since the shift works in `int` and would keep bits above 16.
--- hint
For `table_crc`, turn each gain into a `std::uint16_t` first, then take `u >> 8` and `u & 0xFF` as its two bytes, into a 16-byte array.

+++ practice | One scrubber step per frame
--- task
A background scrubber checks a few memory words every frame, so the whole region is covered over many frames. In this simulation each word carries a parity bit: `parity` is 1 when `data` has an odd number of 1 bits, and a word whose parity does not match its data has been hit.

Write:

```cpp
struct Word { std::uint32_t data; std::uint8_t parity; };

```

- Check `chunk` words starting at index `start`, wrapping around from the last word to word 0. Never check a word twice in one step: a `chunk` bigger than the memory checks every word once.
- `errors` is how many of the checked words have a wrong parity bit.
- `next` is the index where the following step should start, wrapped into the memory.
- A `start` past the end is first wrapped into the memory (use `start % size`). An empty memory returns `{0, 0}`. A `chunk` of 0 checks nothing and returns the wrapped start.

struct Word { std::uint32_t data; std::uint8_t parity; };
struct ScrubStep { std::size_t next; int errors; };

ScrubStep scrub_step(std::span<const Word> mem, std::size_t start, std::size_t chunk) {
    if (mem.empty()) return {0, 0};
    const std::size_t n = mem.size();
    const std::size_t count = chunk < n ? chunk : n;   // each word at most once per step
    std::size_t at = start % n;
    int errors = 0;
    for (std::size_t k = 0; k < count; ++k) {
        const Word& w = mem[at];
        const auto odd = static_cast<std::uint8_t>(std::popcount(w.data) & 1);
        if (odd != w.parity) ++errors;
        at = (at + 1 == n) ? 0 : at + 1;
    }
    return {at, errors};
}

+++ practice | A vote that forgets one pair
--- task
This class keeps a critical word in three copies and reads it by bitwise majority vote, repairing the copies whenever they disagree. When copy `b` gains a 1 bit, or copy `a` or `c` is hit in any way, the vote is right. But when copy `b` loses a 1 bit, the read returns the damaged value and even "repairs" the good copies to match it.

Find the faulty line and fix it.
--- starter
#include <cstdint>

class Voted {
public:
    explicit Voted(std::uint32_t v) { write(v); }
    std::uint32_t read() {
        const std::uint32_t a = a_, b = b_, c = c_;
        const std::uint32_t v = (a & b) | (b & c);
        if (a != v || b != v || c != v) {
            ++repairs_;
            write(v);
        }
        return v;
    }
    void write(std::uint32_t v) { a_ = v; b_ = v; c_ = v; }
    unsigned repairs() const { return repairs_; }
    void flip_bit(int copy, int bit) {
        volatile std::uint32_t& w = copy == 0 ? a_ : (copy == 1 ? b_ : c_);
        w = w ^ (1u << bit);
    }
private:
    volatile std::uint32_t a_{}, b_{}, c_{};
    unsigned repairs_ = 0;
};

    std::uint32_t read() {
        const std::uint32_t a = a_, b = b_, c = c_;
        const std::uint32_t v = (a & b) | (a & c) | (b & c);   // all three pairs
        if (a != v || b != v || c != v) {
            ++repairs_;
            write(v);
        }
        return v;
    }
    void write(std::uint32_t v) { a_ = v; b_ = v; c_ = v; }
    unsigned repairs() const { return repairs_; }
    void flip_bit(int copy, int bit) {
        volatile std::uint32_t& w = copy == 0 ? a_ : (copy == 1 ? b_ : c_);
        w = w ^ (1u << bit);
    }
private:
    volatile std::uint32_t a_{}, b_{}, c_{};
    unsigned repairs_ = 0;
};
--- hint

--- task

4. `Nominal` otherwise.

--- solution
#include <cstddef>
#include <span>

enum class Diagnosis { Nominal, Noise, Latchup, DoseTrend };

Diagnosis classify(std::span<const double> amps, double nominal) {
    const double high = 2.0 * nominal;
    int run = 0;
    bool any_high = false;
    for (double a : amps) {
        if (a > high) {
            any_high = true;
            if (++run >= 3) return Diagnosis::Latchup;   // jumped and stayed
        } else {
            run = 0;
        }
    }
    if (any_high) return Diagnosis::Noise;

    const std::size_t q = amps.size() / 4;
    if (amps.size() >= 8) {
        double first = 0.0;
        double last = 0.0;
        for (std::size_t i = 0; i < q; ++i) {
            first += amps[i];
            last += amps[amps.size() - q + i];
        }
        if ((last - first) / static_cast<double>(q) > 0.2 * nominal) return Diagnosis::DoseTrend;
    }
    return Diagnosis::Nominal;
}
--- hint
One pass finds both the longest run above the threshold (return as soon as it reaches 3) and whether any sample was above it.
--- hint

+++ practice | Q15 in and Q15 times Q15
--- task
Q15 stores a value `x` between -1 and 1 as a 16-bit integer `r = round(x × 32768)`. Write:

```cpp
std::int16_t to_q15(double x);
std::int16_t q15_mul(std::int16_t a, std::int16_t b);
```

- `to_q15` rounds to the nearest integer, with halves going away from zero, and saturates: anything that would be above 32767 becomes 32767, and anything below -32768 becomes -32768. NaN becomes 0.
- `q15_mul` multiplies the two raw values in 32 bits, adds `1 << 14` to round, shifts right by 15, and saturates to the Q15 range. The one product that overflows is -1 × -1, which would be +1: it must come back as 32767.

For example, `to_q15(0.1)` is 3277, and `q15_mul(to_q15(0.5), to_q15(-0.5))` is -8192, which is -0.25.
--- starter

--- solution
#include <cmath>
#include <cstdint>

std::int16_t to_q15(double x) {
    if (std::isnan(x)) return 0;
    const double scaled = x * 32768.0;
    if (scaled >= 32767.0) return 32767;       // saturate before converting
    if (scaled <= -32768.0) return -32768;
    return static_cast<std::int16_t>(std::lround(scaled));   // halves away from zero
}

std::int16_t q15_mul(std::int16_t a, std::int16_t b) {
    const std::int32_t wide = std::int32_t{a} * b;            // Q30
    const std::int32_t q = (wide + (1 << 14)) >> 15;          // round, back to Q15
    if (q > 32767) return 32767;                              // only -1 * -1 gets here
    return static_cast<std::int16_t>(q);
}
--- hint
Saturate on the `double` before you convert it: converting a value that does not fit into an integer type is undefined.
--- hint
The product of two Q15 values is Q30. Add half of the last kept step, `1 << 14`, then shift by 15. Only the top of the range can overflow.

--- solution
#include <cstddef>
#include <cstdint>
#include <span>

// Integer arithmetic only: the same raw outputs on every chip.
bool lowpass_q15(std::span<const std::int16_t> x, std::int16_t alpha, std::int16_t y0, std::span<std::int16_t> out) {
    if (out.size() != x.size()) return false;
    std::int32_t y = y0;
    for (std::size_t k = 0; k < x.size(); ++k) {
        const std::int32_t diff = std::int32_t{x[k]} - y;           // up to 65535: needs 32 bits
        const std::int32_t step = (alpha * diff + (1 << 14)) >> 15;  // Q15 multiply, rounded
        y += step;
        out[k] = static_cast<std::int16_t>(y);
    }
    return true;
}

--- task
Write one step of a proportional-integral controller in Q16.16, with saturation and anti-windup, so every build gives the same raw outputs:


- a Q16.16 multiply: multiply in 64 bits, add `1 << 15`, shift right by 16, and clamp to the `std::int32_t` range.

One step:

1. `p = mul(kp, error)`, `step = mul(ki, error)`, and the candidate integral `cand = add(integ, step)`.

#include <cstdint>
#include <limits>

struct PiQ16 { std::int32_t kp; std::int32_t ki; std::int32_t integ; std::int32_t out_min; std::int32_t out_max; };

namespace {
std::int32_t clamp32(std::int64_t v) {
    constexpr std::int64_t hi = std::numeric_limits<std::int32_t>::max();
    constexpr std::int64_t lo = std::numeric_limits<std::int32_t>::min();
    return static_cast<std::int32_t>(v > hi ? hi : (v < lo ? lo : v));
}
std::int32_t add(std::int32_t a, std::int32_t b) { return clamp32(std::int64_t{a} + b); }
std::int32_t mul(std::int32_t a, std::int32_t b) {
    return clamp32((std::int64_t{a} * b + (std::int64_t{1} << 15)) >> 16);
}
}  // namespace

std::int32_t pi_step(PiQ16& c, std::int32_t error) {
    const std::int32_t p = mul(c.kp, error);
    const std::int32_t cand = add(c.integ, mul(c.ki, error));
    const std::int32_t u = add(p, cand);
    if (u > c.out_max) {
        if (error <= 0) c.integ = cand;   // only integrate back out of the limit
        return c.out_max;
    }
    if (u < c.out_min) {
        if (error >= 0) c.integ = cand;
        return c.out_min;
    }
    c.integ = cand;
    return u;
}
--- hint

--- hint

#include <span>

enum class Kind { Vectors, Text, Rodata, Data, Bss, Noinit };
struct Section { Kind kind; std::uint32_t size; };

            case Kind::Data:   u.flash += s.size; u.ram += s.size; break;   // load copy and run copy

            case Kind::Noinit: u.ram += s.size; break;
        }
    }
    return u;
}

    return u.flash <= flash_len && std::uint64_t{u.ram} + stack_bytes <= ram_len;
}

+++ practice | Wait states for a faster clock
--- task
Flash needs `access_ns` nanoseconds to answer a read. At a clock of `clock_hz`, a read spans `access_ns × clock_hz / 10⁹` cycles, rounded up to a whole cycle. The first cycle is the ordinary one; every extra cycle is a wait state.

Write:

```cpp
int wait_states(std::uint32_t clock_hz, std::uint32_t access_ns);
```

It returns the number of wait states, which is the rounded-up cycles minus 1, but never less than 0. Work in whole numbers: the product can be far larger than 32 bits, and an exact whole number of cycles must not be rounded up to the next one.

For example, at 100 MHz a 30 ns flash needs exactly 3 cycles, so 2 wait states. At 216 MHz a 25 ns flash needs 5.4 cycles, rounded up to 6, so 5 wait states.
--- starter
#include <cstdint>

int wait_states(std::uint32_t clock_hz, std::uint32_t access_ns) {
    return static_cast<int>(clock_hz * access_ns / 1000000000u);
}
--- solution
#include <cstdint>

int wait_states(std::uint32_t clock_hz, std::uint32_t access_ns) {

}

+++ practice | Reading a MEMORY block
--- task
Write a small reader for the `MEMORY` part of a linker script, the kind a build tool uses to check a map file:

```cpp
struct MemRegion { std::string name; std::string attrs; std::uint64_t origin; std::uint64_t length; };
```

#include <cstddef>
#include <cstdint>
#include <optional>
#include <string>
#include <string_view>
#include <vector>

struct MemRegion { std::string name; std::string attrs; std::uint64_t origin; std::uint64_t length; };

namespace {
std::string_view trim(std::string_view s) {
    while (!s.empty() && (s.front() == ' ' || s.front() == '\t')) s.remove_prefix(1);
    while (!s.empty() && (s.back() == ' ' || s.back() == '\t' || s.back() == '\r')) s.remove_suffix(1);
    return s;
}

std::optional<std::uint64_t> number(std::string_view s) {
    s = trim(s);
    std::uint64_t scale = 1;
    if (!s.empty() && (s.back() == 'K' || s.back() == 'M')) {
        scale = s.back() == 'K' ? 1024u : 1024u * 1024u;
        s.remove_suffix(1);
    }
    std::uint64_t base = 10;
    if (s.size() > 2 && s[0] == '0' && (s[1] == 'x' || s[1] == 'X')) {
        base = 16;
        s.remove_prefix(2);
    }
    if (s.empty() || s.size() > 16) return std::nullopt;
    std::uint64_t v = 0;
    for (char c : s) {
        std::uint64_t d = 0;
        if (c >= '0' && c <= '9') d = static_cast<std::uint64_t>(c - '0');
        else if (base == 16 && c >= 'a' && c <= 'f') d = static_cast<std::uint64_t>(c - 'a' + 10);
        else if (base == 16 && c >= 'A' && c <= 'F') d = static_cast<std::uint64_t>(c - 'A' + 10);
        else return std::nullopt;
        v = v * base + d;
    }
    return v * scale;
}

// "KEY = number": the key must match, then the number.
std::optional<std::uint64_t> field(std::string_view s, std::string_view key) {
    s = trim(s);
    if (s.substr(0, key.size()) != key) return std::nullopt;
    s = trim(s.substr(key.size()));
    if (s.empty() || s.front() != '=') return std::nullopt;
    return number(s.substr(1));
}

std::optional<MemRegion> region(std::string_view line) {
    const std::size_t open = line.find('(');
    const std::size_t close = line.find(')');
    const std::size_t colon = line.find(':');
    if (open == std::string_view::npos || close == std::string_view::npos || !(open < close && close < colon)) return std::nullopt;
    const std::string_view name = trim(line.substr(0, open));
    if (name.empty() || !trim(line.substr(close + 1, colon - close - 1)).empty()) return std::nullopt;
    const std::string_view rest = line.substr(colon + 1);
    const std::size_t comma = rest.find(',');
    if (comma == std::string_view::npos) return std::nullopt;
    const auto origin = field(rest.substr(0, comma), "ORIGIN");
    const auto length = field(rest.substr(comma + 1), "LENGTH");
    if (!origin || !length) return std::nullopt;
    return MemRegion{std::string(name), std::string(line.substr(open + 1, close - open - 1)), *origin, *length};
}
}  // namespace

std::vector<MemRegion> parse_memory(std::string_view text) {
    std::vector<MemRegion> out;
    while (!text.empty()) {
        const std::size_t nl = text.find('\n');
        const std::string_view line = text.substr(0, nl);
        text = (nl == std::string_view::npos) ? std::string_view{} : text.substr(nl + 1);
        if (line.find(':') == std::string_view::npos) continue;
        const auto r = region(line);
        if (!r) return {};   // one bad line rejects the block
        out.push_back(*r);
    }
    return out;
}

bool regions_overlap(const std::vector<MemRegion>& regions) {
    for (std::size_t i = 0; i < regions.size(); ++i) {
        for (std::size_t j = i + 1; j < regions.size(); ++j) {
            const MemRegion& a = regions[i];
            const MemRegion& b = regions[j];
            if (a.origin < b.origin + b.length && b.origin < a.origin + a.length) return true;
        }
    }
    return false;
}
--- hint
Split the work: a `trim`, a `number` that handles `0x`, decimal and the `K`/`M` suffix, and a function for one region line that returns `std::optional<MemRegion>`.
--- hint
In a region line, find `(`, `)` and `:` first. The name is before the `(`, the attributes are between the brackets, and after the `:` a comma separates the `ORIGIN` part from the `LENGTH` part.
--- hint
Two half-open ranges `[a, a + la)` and `[b, b + lb)` overlap exactly when `a < b + lb` and `b < a + la`.

+++ question | A const table and a plain one
--- ask
A program for a Cortex-M has these two globals, each 256 four-byte words with non-zero starting values, and the usual linker script (`.rodata` in flash, `.data` in RAM at a load address in flash, `.bss` in RAM):


Both cost 1024 bytes of RAM only, because every global variable lives in RAM.
--- choice correct

--- choice
`crc_table` costs flash and RAM, because constants are copied to RAM for speed; `gain_table` costs RAM only.
--- choice
`gain_table` goes in `.bss` and costs RAM only, because the start-up code fills it in.

+++ practice | A tree depth without recursion
--- task
The natural way to find the depth of a tree calls itself on each child, which rule 1 forbids. Write it with an explicit stack of fixed capacity:

```cpp
struct TreeNode { int left; int right; };   // child indices, or -1 for none
constexpr int kMaxStack = 32;

```

- The depth is the number of nodes on the longest path from `root` down to a node with no children. A `root` of -1 is an empty tree, of depth 0.
- Keep a stack of (node, depth) pairs in a `std::array` of `kMaxStack` entries. Start with the root at depth 1. Each time, pop the top entry, and then push its right child and then its left child, each at one more depth, if they exist.
- If a push would need a 33rd entry, stop and return -1: the tree is bigger than this function accepts.
- Return -1 if an index is not -1 and not a valid index, or if more entries are popped than there are nodes (the links contain a loop, so this is not a tree).
--- starter

#include <span>

--- solution
#include <array>
#include <cstddef>
#include <span>

struct TreeNode { int left; int right; };
constexpr int kMaxStack = 32;

int tree_depth(std::span<const TreeNode> nodes, int root) {
    if (root == -1) return 0;
    const int n = static_cast<int>(nodes.size());
    struct Entry { int node; int depth; };
    std::array<Entry, kMaxStack> stack{};
    int top = 0;
    auto push = [&](int node, int depth) {
        if (top == kMaxStack) return false;               // the fixed capacity is the bound
        stack[static_cast<std::size_t>(top++)] = {node, depth};
        return true;
    };
    if (root < 0 || root >= n) return -1;
    push(root, 1);
    int deepest = 0;
    int popped = 0;
    while (top > 0) {
        const Entry e = stack[static_cast<std::size_t>(--top)];
        if (++popped > n) return -1;                      // more visits than nodes: a loop
        if (e.depth > deepest) deepest = e.depth;
        const TreeNode& t = nodes[static_cast<std::size_t>(e.node)];
        for (int child : {t.right, t.left}) {
            if (child == -1) continue;
            if (child < 0 || child >= n) return -1;
            if (!push(child, e.depth + 1)) return -1;
        }
    }
    return deepest;
}
--- hint

--- hint

#include <array>
#include <cstddef>
#include <cstdint>

enum class Status { Ok, BadCommand, BadArg };
struct Vehicle { int mode = 0; std::array<bool, 4> heater_armed{}; int gain = 0; };

enum class Cmd : std::uint8_t { SetMode = 1, ArmHeater = 2, SetGain = 3 };

[[nodiscard]] Status run_command(std::uint8_t code, int arg, Vehicle& v) {
    switch (static_cast<Cmd>(code)) {      // every target is visible at compile time
        case Cmd::SetMode:

            v.mode = arg;
            return Status::Ok;

--- task
Rule 7 says every function checks its parameters. Write:

--- solution
#include <cstddef>
#include <span>

[[nodiscard]] bool copy_window(std::span<const float> src, std::size_t first, std::size_t count, std::span<float> dst) {
    if (first > src.size()) return false;
    if (count > src.size() - first) return false;   // cannot wrap: first <= size here
    if (count > dst.size()) return false;
    for (std::size_t i = 0; i < count; ++i) dst[i] = src[first + i];
    return true;
}
--- hint
Check `first` against the size first. Once `first <= size`, the subtraction `size - first` cannot wrap, and you can compare `count` with it.

+++ practice | A buffer lost on the error path
--- task
`send_packet` takes a buffer from a pool of four, fills it and gives it back. It works for good packets. But after four packets that are too long, every later call fails with `NoBuffer`, even for good packets: the pool has run dry. This is the classic bug that C code "fixes" with `goto cleanup`, which rule 1 forbids.

Fix the function so that every path gives the buffer back. A small RAII guard whose destructor releases the slot is the C++ way; releasing on every return path also works.
--- starter
#include <array>
#include <cstddef>
#include <cstdint>

class BufferPool {
public:
    int acquire() {
        for (int i = 0; i < 4; ++i) {
            if (!used_[static_cast<std::size_t>(i)]) { used_[static_cast<std::size_t>(i)] = true; return i; }
        }
        return -1;
    }
    void release(int i) { used_[static_cast<std::size_t>(i)] = false; }
    int free_count() const {
        int n = 0;
        for (bool u : used_) n += u ? 0 : 1;
        return n;
    }
    std::array<std::uint8_t, 64>& buffer(int i) { return bufs_[static_cast<std::size_t>(i)]; }
private:
    std::array<bool, 4> used_{};
    std::array<std::array<std::uint8_t, 64>, 4> bufs_{};
};

enum class Status { Ok, NoBuffer, TooLong };
constexpr std::size_t kMaxPayload = 64;

Status send_packet(BufferPool& pool, const std::uint8_t* data, std::size_t len) {
    const int slot = pool.acquire();
    if (slot < 0) return Status::NoBuffer;
    if (len > kMaxPayload) return Status::TooLong;
    for (std::size_t i = 0; i < len; ++i) pool.buffer(slot)[i] = data[i];
    pool.release(slot);
    return Status::Ok;
}

// Gives the slot back on every path out of the scope: no goto needed.
class SlotGuard {
public:
    SlotGuard(BufferPool& pool, int slot) : pool_(pool), slot_(slot) {}
    ~SlotGuard() { pool_.release(slot_); }
    SlotGuard(const SlotGuard&) = delete;
    SlotGuard& operator=(const SlotGuard&) = delete;
private:
    BufferPool& pool_;
    int slot_;
};

Status send_packet(BufferPool& pool, const std::uint8_t* data, std::size_t len) {
    const int slot = pool.acquire();
    if (slot < 0) return Status::NoBuffer;
    const SlotGuard guard(pool, slot);
    if (len > kMaxPayload) return Status::TooLong;
    for (std::size_t i = 0; i < len; ++i) pool.buffer(slot)[i] = data[i];
    return Status::Ok;
}

--- task

--- solution
#include <array>
#include <cctype>
#include <cstddef>
#include <string>
#include <string_view>
#include <vector>

struct Finding { int line; int rule; };

namespace {
bool word_char(char c) { return std::isalnum(static_cast<unsigned char>(c)) != 0 || c == '_'; }

// True when `w` appears in `s` as a whole word.
bool has_word(std::string_view s, std::string_view w) {
    for (std::size_t at = s.find(w); at != std::string_view::npos; at = s.find(w, at + 1)) {
        const bool left = at == 0 || !word_char(s[at - 1]);
        const bool right = at + w.size() == s.size() || !word_char(s[at + w.size()]);
        if (left && right) return true;
    }
    return false;
}

bool any_word(std::string_view s, std::initializer_list<std::string_view> words) {
    for (std::string_view w : words) {
        if (has_word(s, w)) return true;
    }
    return false;
}
}  // namespace

std::vector<Finding> check_source(const std::vector<std::string>& lines) {
    std::vector<Finding> out;
    for (std::size_t i = 0; i < lines.size(); ++i) {
        std::string_view code = lines[i];
        code = code.substr(0, code.find("//"));   // npos keeps the whole line
        const int n = static_cast<int>(i) + 1;
        if (any_word(code, {"goto", "setjmp", "longjmp"})) out.push_back({n, 1});
        if (any_word(code, {"malloc", "calloc", "realloc", "new"})) out.push_back({n, 3});
        const std::size_t first = code.find_first_not_of(" \t");
        if (first != std::string_view::npos && code[first] == '#') {
            const std::string_view directive = code.substr(first);
            const bool pasting = directive.find("##") != std::string_view::npos;
            const bool variadic = directive.substr(0, 7) == "#define" && directive.find("...") != std::string_view::npos;
            if (pasting || variadic) out.push_back({n, 8});
        }
    }
    return out;
}

+++ question | Build variants from switches
--- ask
A flight file has six independent `#ifdef` switches, such as `USE_BACKUP_IMU` and `ENABLE_DEBUG_TM`, each of which can be on or off. How many different versions of the program can the file compile to, each of which would need its own testing? Type the number.
--- answer
64
--- why
Each independent switch doubles the number of versions: two choices, six times, is 2 × 2 × 2 × 2 × 2 × 2 = 2⁶ = 64. That is why rule 8 discourages conditional compilation: every switch doubles the testing. `if constexpr` over a `constexpr` setting keeps both branches type-checked by the compiler, which removes part of the risk, and a project can fix most switches for the flight build so only one version flies.

#include <algorithm>
#include <span>
#include <vector>

struct Interval { long long lo; long long hi; };
enum class Color { Green, Orange, Red, Gray };
enum class OpKind { AddConst, MulConst, DivideInto, CastInt16 };
struct Op { OpKind kind; long long k; };

namespace {
// k / x for every non-zero x in the interval: the extremes are at the non-zero ends, or at -1 and 1.
Interval divide_into(long long k, Interval x) {
    long long lo = 0;
    long long hi = 0;
    bool first = true;
    auto take = [&](long long v) {
        if (v == 0) return;
        const long long q = k / v;
        lo = first ? q : std::min(lo, q);
        hi = first ? q : std::max(hi, q);
        first = false;
    };
    take(x.lo);
    take(x.hi);
    if (x.lo <= -1 && -1 <= x.hi) take(-1);
    if (x.lo <= 1 && 1 <= x.hi) take(1);
    return {lo, hi};
}
}  // namespace

std::vector<Color> analyze(Interval x, std::span<const Op> ops) {
    std::vector<Color> out;
    bool stopped = false;
    for (const Op& op : ops) {
        if (stopped) {
            out.push_back(Color::Gray);   // unreachable after a certain error
            continue;
        }
        switch (op.kind) {
            case OpKind::AddConst:
                x = {x.lo + op.k, x.hi + op.k};
                out.push_back(Color::Green);
                break;
            case OpKind::MulConst: {
                const long long a = x.lo * op.k;
                const long long b = x.hi * op.k;
                x = {std::min(a, b), std::max(a, b)};
                out.push_back(Color::Green);
                break;
            }
            case OpKind::DivideInto:
                if (x.lo == 0 && x.hi == 0) {
                    out.push_back(Color::Red);
                    stopped = true;
                } else {
                    out.push_back(x.lo <= 0 && 0 <= x.hi ? Color::Orange : Color::Green);
                    x = divide_into(op.k, x);
                }
                break;
            case OpKind::CastInt16:
                if (x.lo >= -32768 && x.hi <= 32767) {
                    out.push_back(Color::Green);
                } else if (x.hi < -32768 || x.lo > 32767) {
                    out.push_back(Color::Red);
                    stopped = true;
                } else {
                    out.push_back(Color::Orange);
                    x = {std::max(x.lo, -32768LL), std::min(x.hi, 32767LL)};
                }
                break;
        }
    }
    return out;
}
--- hint
Keep the current interval and a "stopped" flag. A `switch` on the kind updates the interval and pushes one color.
--- hint

std::int16_t to_counts(int millivolts) {
    const long long counts = static_cast<long long>(millivolts) * 4;   // cannot overflow
    if (counts > 32767) return 32767;
    if (counts < -32768) return -32768;
    return static_cast<std::int16_t>(counts);
}

    for (int t : on_ms) total += t;   // a range-for cannot run past the end
    return total;
}

#include <algorithm>
#include <string>
#include <vector>

enum class Category { Mandatory, Required, Advisory };
struct Finding { std::string file; int line; std::string rule; Category category; bool deviation_approved; };
struct Permit { std::string rule; std::string file_prefix; };
struct Gate { bool merge; std::vector<std::string> blocking; };

namespace {
bool permitted(const Finding& f, const std::vector<Permit>& permits) {
    return std::any_of(permits.begin(), permits.end(), [&](const Permit& p) {
        return p.rule == f.rule && f.file.compare(0, p.file_prefix.size(), p.file_prefix) == 0;
    });
}

bool blocks(const Finding& f, const std::vector<Permit>& permits) {
    switch (f.category) {
        case Category::Mandatory: return true;                                  // never deviated
        case Category::Required:  return !f.deviation_approved && !permitted(f, permits);
        case Category::Advisory:  return false;
    }
    return true;
}
}  // namespace

Gate review_findings(const std::vector<Finding>& findings, const std::vector<Permit>& permits) {
    std::vector<const Finding*> bad;
    for (const Finding& f : findings) {
        if (blocks(f, permits)) bad.push_back(&f);
    }
    std::sort(bad.begin(), bad.end(), [](const Finding* a, const Finding* b) {
        return a->file != b->file ? a->file < b->file : a->line < b->line;
    });
    Gate g{bad.empty(), {}};
    for (const Finding* f : bad) g.blocking.push_back(f->file + ":" + std::to_string(f->line) + " " + f->rule);
    return g;
}

--- ask
Polyspace Code Prover marks a division in the navigation filter orange. What does that tell you?
--- choice

--- choice
The division is safe, but the tool reports it as a warning because divisions are risky in general.

+++ problem | Offsets that flatten the frame
--- task
A cyclic executive runs a 1 ms minor frame. Each task runs every `period` frames, in the frames where `f % period == offset`, and the pattern repeats every `major_frames` frames. You may choose each task's offset, from 0 to `period - 1`. Find the offsets that make the worst frame as light as possible:

```cpp
struct RateSlot { int period; int wcet_us; };
struct Plan { std::vector<int> offsets; int worst_us; };
Plan flatten(std::span<const RateSlot> tasks, int major_frames);
```

- Try every combination of offsets. For each, the worst frame is the frame from 0 to `major_frames - 1` with the largest total of worst-case times. Return the combination with the smallest worst frame, and that worst frame's total.
- On a tie, return the combination that comes first when compared task by task from the first task (so `{0, 1, 3}` comes before `{0, 3, 1}`).
- The search must have a fixed bound and must not use recursion. Refuse, returning `{{}, -1}`, if `major_frames` is less than 1 or more than 64, if any period is less than 1 or does not divide `major_frames` exactly, if any time is negative, or if the number of combinations (the product of all the periods) is more than 4096.
- With no tasks, return `{{}, 0}`.

For example, tasks of period 2 (300 µs), period 4 (250 µs), period 4 (200 µs) and period 8 (120 µs) over 8 frames are best with offsets `{0, 1, 3, 3}`, for a worst frame of 320 µs.
--- starter

#include <vector>

    return {{}, -1};
}
--- solution
#include <cstddef>
#include <span>
#include <vector>

struct RateSlot { int period; int wcet_us; };
struct Plan { std::vector<int> offsets; int worst_us; };

constexpr int kMaxFrames = 64;
constexpr long long kMaxCombos = 4096;

namespace {
int worst_frame(std::span<const RateSlot> tasks, const std::vector<int>& offs, int frames) {
    int worst = 0;
    for (int f = 0; f < frames; ++f) {
        int us = 0;
        for (std::size_t i = 0; i < tasks.size(); ++i) {
            if (f % tasks[i].period == offs[i]) us += tasks[i].wcet_us;
        }
        if (us > worst) worst = us;
    }
    return worst;
}
}  // namespace

Plan flatten(std::span<const RateSlot> tasks, int major_frames) {
    if (major_frames < 1 || major_frames > kMaxFrames) return {{}, -1};
    long long combos = 1;
    for (const RateSlot& t : tasks) {
        if (t.period < 1 || major_frames % t.period != 0 || t.wcet_us < 0) return {{}, -1};
        combos *= t.period;
        if (combos > kMaxCombos) return {{}, -1};
    }
    if (tasks.empty()) return {{}, 0};

    // An odometer over the offsets: the first task is the most significant digit,
    // so combinations come in lexicographic order and a strict < keeps the first best.
    std::vector<int> offs(tasks.size(), 0);
    Plan best{offs, worst_frame(tasks, offs, major_frames)};
    for (long long k = 1; k < combos; ++k) {       // fixed bound: at most 4096 combinations
        for (std::size_t d = tasks.size(); d-- > 0;) {
            if (++offs[d] < tasks[d].period) break;
            offs[d] = 0;
        }
        const int w = worst_frame(tasks, offs, major_frames);
        if (w < best.worst_us) best = {offs, w};
    }
    return best;
}

--- task
Write the scratch arena a control cycle uses for temporary data. Nested steps save a mark, allocate, and rewind to the mark when they finish:

```cpp
template <std::size_t N>
class ScratchArena {

    void* allocate(std::size_t bytes, std::size_t align);
```

#include <cstddef>
#include <cstdint>

template <std::size_t N>
class ScratchArena {
public:
    void* allocate(std::size_t bytes, std::size_t align) {
        const bool power_of_two = align != 0 && (align & (align - 1)) == 0;
        if (bytes == 0 || !power_of_two || align > 16) return nullptr;
        const std::size_t start = (used_ + align - 1) / align * align;   // buf_ is 16-aligned
        if (start > N || bytes > N - start) return nullptr;
        used_ = start + bytes;
        if (used_ > high_) high_ = used_;
        return buf_ + start;
    }
    std::size_t mark() const { return used_; }
    bool rewind(std::size_t m) {
        if (m > used_) return false;   // cannot rewind forward
        used_ = m;
        return true;
    }
    void reset() { used_ = 0; }
    std::size_t used() const { return used_; }
    std::size_t high_water() const { return high_; }
    std::size_t offset_of(const void* p) const {
        return static_cast<std::size_t>(static_cast<const std::byte*>(p) - buf_);
    }

private:
    alignas(16) std::byte buf_[N]{};
    std::size_t used_ = 0;
    std::size_t high_ = 0;
};

+++ problem | Packets from a serial interrupt
--- task
A serial port raises an interrupt for every byte. The handler stores the byte in a ring of 64 bytes and returns; a task later assembles the bytes into packets.

A packet is: the sync byte `0x7E`, a length byte from 1 to 16, that many payload bytes, and a check byte equal to the low 8 bits of the length plus the sum of the payload bytes.

Write, with these names at file scope:

```cpp
struct Packet { std::uint8_t len; std::array<std::uint8_t, 16> data; };
void uart_reset();
void uart_isr(std::uint8_t byte);
int poll_packets(std::span<Packet> out);
std::uint32_t uart_overruns();
std::uint32_t bad_frames();
```

- `uart_isr` is the interrupt side. It never waits: if the ring already holds 64 bytes, it drops the byte and adds one to the overrun count.
- `poll_packets` is the task side. It takes bytes out of the ring one at a time and feeds them to a parser whose state carries over from one call to the next, so a packet may arrive across several calls. It writes each complete, correct packet into `out` and returns how many it wrote. It stops as soon as `out` is full (without taking another byte), when the ring is empty, or after taking 64 bytes in this call, whichever comes first.
- The parser: while waiting for a packet, any byte other than `0x7E` is skipped. After a sync byte, a length of 0 or more than 16 is a bad frame: count it and go back to waiting. After the payload, a wrong check byte is a bad frame: count it and go back to waiting.
- `uart_reset` empties the ring, restarts the parser and sets both counts to 0. The checks call it before each test.

#include <array>
#include <atomic>
#include <cstddef>
#include <cstdint>
#include <span>

struct Packet { std::uint8_t len; std::array<std::uint8_t, 16> data; };

constexpr std::uint32_t kRing = 64;   // a power of two, so counter % kRing stays right across wraps
constexpr std::uint8_t kSync = 0x7E;
constexpr std::uint8_t kMaxLen = 16;

namespace {
std::array<std::uint8_t, kRing> g_ring{};
std::atomic<std::uint32_t> g_head{0};
std::atomic<std::uint32_t> g_tail{0};
std::atomic<std::uint32_t> g_overruns{0};
std::uint32_t g_bad = 0;

enum class State { Sync, Len, Payload, Check };
State g_state = State::Sync;
Packet g_cur{};
std::uint8_t g_got = 0;
std::uint8_t g_sum = 0;
}  // namespace

void uart_reset() {
    g_head.store(0);
    g_tail.store(0);
    g_overruns.store(0);
    g_bad = 0;
    g_state = State::Sync;
    g_got = 0;
    g_sum = 0;
}

// Interrupt side: capture, hand off, return. Never waits.
void uart_isr(std::uint8_t byte) {
    const std::uint32_t h = g_head.load(std::memory_order_relaxed);
    const std::uint32_t t = g_tail.load(std::memory_order_acquire);
    if (h - t == kRing) {
        g_overruns.fetch_add(1, std::memory_order_relaxed);
        return;
    }
    g_ring[h % kRing] = byte;
    g_head.store(h + 1, std::memory_order_release);
}

// Task side: at most kRing bytes per call, and never past a full output.
int poll_packets(std::span<Packet> out) {
    std::size_t n = 0;
    for (std::uint32_t k = 0; k < kRing && n < out.size(); ++k) {
        const std::uint32_t t = g_tail.load(std::memory_order_relaxed);
        const std::uint32_t h = g_head.load(std::memory_order_acquire);
        if (h == t) break;
        const std::uint8_t b = g_ring[t % kRing];
        g_tail.store(t + 1, std::memory_order_release);
        switch (g_state) {
            case State::Sync:
                if (b == kSync) g_state = State::Len;
                break;
            case State::Len:
                if (b >= 1 && b <= kMaxLen) {
                    g_cur.len = b;
                    g_got = 0;
                    g_sum = b;
                    g_state = State::Payload;
                } else {
                    ++g_bad;
                    g_state = State::Sync;
                }
                break;
            case State::Payload:
                g_cur.data[g_got++] = b;
                g_sum = static_cast<std::uint8_t>(g_sum + b);
                if (g_got == g_cur.len) g_state = State::Check;
                break;
            case State::Check:
                if (b == g_sum) {
                    out[n++] = g_cur;
                } else {
                    ++g_bad;
                }
                g_state = State::Sync;
                break;
        }
    }
    return static_cast<int>(n);
}

std::uint32_t uart_overruns() { return g_overruns.load(); }
std::uint32_t bad_frames() { return g_bad; }

```cpp
struct FrameIn { bool nav_done; float temp_c; };
```

constexpr int kCheckEvery = 10;
constexpr std::uint32_t kNavMin = 8;
constexpr float kTempLimit = 80.0F;
constexpr int kPersist = 3;

std::vector<std::string> run_timeline(std::span<const FrameIn> frames) {
    std::vector<std::string> events;
    int left = kWatchdogFrames;
    std::uint32_t beats = 0;
    std::uint32_t seen = 0;
    int bad_run = 0;
    int confirmations = 0;
    for (std::size_t i = 0; i < frames.size(); ++i) {
        const int t = static_cast<int>(i) + 1;
        auto report = [&](const char* what) { events.push_back("t=" + std::to_string(t) + " " + what); };

        if (--left == 0) {                                   // 1. watchdog
            report("watchdog reset");
            return events;

        if (frames[i].nav_done) ++beats;                     // 2. heartbeat

        const float temp = frames[i].temp_c;                 // 3. monitor with persistence
        const bool bad = std::isnan(temp) || temp > kTempLimit;

        if (bad_run == kPersist) {
            bad_run = 0;
            ++confirmations;
            if (confirmations <= 2) report("retry");
            else if (confirmations == 3) report("spare");
            else if (confirmations == 4) report("safe mode");   // sticky: nothing after

            seen = beats;
            if (got < kNavMin) report("nav unhealthy");
            else left = kWatchdogFrames;
        }
    }
    return events;

+++ problem | SECDED for one byte
--- task
Write the error-correcting code that flight memory uses, for one byte: a Hamming code that corrects any single flipped bit and detects any two.

```cpp
std::uint16_t secded_encode(std::uint8_t data);
enum class Ecc { Ok, Corrected, Uncorrectable };
struct Decoded { Ecc status; std::uint8_t data; };
Decoded secded_decode(std::uint16_t code);
```

The code uses bits 0 to 12 of the `std::uint16_t`, called positions 0 to 12:

- The data bits d0 (the lowest bit of `data`) to d7 go in positions 3, 5, 6, 7, 9, 10, 11 and 12, in that order.
- Positions 1, 2, 4 and 8 are check bits. The check bit at position `p` is set so that, among the positions from 1 to 12 whose number has bit `p` set (`pos & p`), an even number of bits are 1.
- Position 0 is the overall bit, set so that the whole code, positions 0 to 12, has an even number of 1 bits.
- Bits 13 to 15 are 0 after encoding and ignored when decoding.

To decode, the syndrome is the XOR of the position numbers, from 1 to 12, of every bit that is 1. It is 0 for an undamaged code, and equal to the position of a single flipped bit among 1 to 12.

- An even number of 1 bits and a syndrome of 0: `Ok`.
- An odd number of 1 bits: one bit flipped. If the syndrome is 0, the overall bit itself flipped; if it is from 1 to 12, flip that position back. Return `Corrected` with the data. (A syndrome of 13 to 15 cannot come from one flipped bit: return `Uncorrectable`.)
- An even number of 1 bits and a syndrome that is not 0: two bits flipped. Return `Uncorrectable`, with data 0.

For example, the byte 1 encodes as `0x000F`, and `0xA5` encodes as `0x144E`.

#include <array>
#include <bit>
#include <cstddef>
#include <cstdint>

enum class Ecc { Ok, Corrected, Uncorrectable };
struct Decoded { Ecc status; std::uint8_t data; };

namespace {
constexpr std::array<int, 8> kDataPos{3, 5, 6, 7, 9, 10, 11, 12};

bool bit(unsigned code, int pos) { return ((code >> pos) & 1u) != 0; }

std::uint8_t extract(unsigned code) {
    unsigned d = 0;
    for (std::size_t i = 0; i < kDataPos.size(); ++i) {
        if (bit(code, kDataPos[i])) d |= 1u << i;
    }
    return static_cast<std::uint8_t>(d);
}
}  // namespace

std::uint16_t secded_encode(std::uint8_t data) {
    unsigned code = 0;
    for (std::size_t i = 0; i < kDataPos.size(); ++i) {
        if ((data >> i) & 1u) code |= 1u << kDataPos[i];
    }
    for (int p = 1; p <= 8; p <<= 1) {                 // check bits at 1, 2, 4, 8
        unsigned parity = 0;
        for (int pos = 1; pos <= 12; ++pos) {
            if ((pos & p) != 0 && pos != p && bit(code, pos)) parity ^= 1u;
        }
        if (parity != 0) code |= 1u << p;
    }
    if (std::popcount(code) % 2 != 0) code |= 1u;      // overall bit: even parity
    return static_cast<std::uint16_t>(code);
}

Decoded secded_decode(std::uint16_t raw) {
    unsigned code = raw & 0x1FFFu;
    int syndrome = 0;
    for (int pos = 1; pos <= 12; ++pos) {
        if (bit(code, pos)) syndrome ^= pos;
    }
    const bool odd = std::popcount(code) % 2 != 0;
    if (!odd) {
        if (syndrome == 0) return {Ecc::Ok, extract(code)};
        return {Ecc::Uncorrectable, 0};                // two flipped bits: detect, never guess
    }
    if (syndrome > 12) return {Ecc::Uncorrectable, 0};
    if (syndrome != 0) code ^= 1u << syndrome;         // syndrome 0: the overall bit flipped
    return {Ecc::Corrected, extract(code)};
}

#include <cstdint>

namespace {
// The whole-number square root of any 64-bit n, one result bit per pass: exactly 32 passes.
std::uint64_t isqrt64(std::uint64_t n) {
    std::uint64_t root = 0;
    for (std::uint64_t bit = std::uint64_t{1} << 62; bit != 0; bit >>= 2) {
        if (n >= root + bit) {
            n -= root + bit;
            root = (root >> 1) + bit;
        } else {
            root >>= 1;
        }
    }
    return root;
}
}  // namespace

std::int32_t q16_sqrt(std::int32_t x) {
    if (x < 0) return -1;
    return static_cast<std::int32_t>(isqrt64(static_cast<std::uint64_t>(x) << 16));   // at most 2^23.5
}

std::int32_t q16_hypot(std::int32_t a, std::int32_t b) {
    const auto aa = static_cast<std::uint64_t>(std::int64_t{a} * a);   // at most 2^62
    const auto bb = static_cast<std::uint64_t>(std::int64_t{b} * b);
    const std::uint64_t r = isqrt64(aa + bb);                          // sum at most 2^63
    return r > 2147483647u ? 2147483647 : static_cast<std::int32_t>(r);
}

#include <cstddef>
#include <cstdint>
#include <optional>
#include <span>
#include <vector>

struct Region { std::uint32_t origin; std::uint32_t length; };
struct OutSection { std::uint32_t size; std::uint32_t align; int run; int load; };
struct Placed { std::uint32_t vma; std::uint32_t lma; };

namespace {
// Rounds the cursor up and reserves size bytes, or fails if that passes the region's end.
std::optional<std::uint32_t> take(std::uint64_t& cursor, const Region& r, std::uint32_t size, std::uint32_t align) {
    const std::uint64_t start = (cursor + align - 1) / align * align;
    const std::uint64_t end = std::uint64_t{r.origin} + r.length;
    if (start + size > end) return std::nullopt;
    cursor = start + size;
    return static_cast<std::uint32_t>(start);
}
}  // namespace

std::optional<std::vector<Placed>> place_sections(std::span<const Region> regions, std::span<const OutSection> secs) {
    std::vector<std::uint64_t> cursor;
    for (const Region& r : regions) cursor.push_back(r.origin);
    const int n = static_cast<int>(regions.size());
    std::vector<Placed> out;
    for (const OutSection& s : secs) {
        if (s.align == 0 || (s.align & (s.align - 1)) != 0) return std::nullopt;
        if (s.run < 0 || s.run >= n || s.load < -1 || s.load >= n) return std::nullopt;
        const auto run = static_cast<std::size_t>(s.run);
        const auto vma = take(cursor[run], regions[run], s.size, s.align);
        if (!vma) return std::nullopt;
        std::uint32_t lma = *vma;
        if (s.load != -1 && s.load != s.run) {
            const auto load = static_cast<std::size_t>(s.load);
            const auto at = take(cursor[load], regions[load], s.size, s.align);
            if (!at) return std::nullopt;
            lma = *at;
        }
        out.push_back({*vma, lma});
    }
    return out;
}

+++ problem | The size of a safe landing area
--- task
A lander's hazard map is a grid of rows, where `.` is a safe cell and any other character is a hazard. Find how many safe cells are connected to the cell at `row`, `col`, moving up, down, left and right:

```cpp
int safe_area(const std::vector<std::string>& grid, int row, int col);
```

This runs on the flight computer, so it must follow the flight rules: no recursion, and no memory that grows. Use this exact method:

- Keep a stack of cells in a `std::array` of 256 entries, and a fixed array of 32 × 32 marks.
- Mark the start cell and push it. Then, until the stack is empty: pop a cell, count it, and look at its neighbours in the order up, down, left, right. Push each neighbour that is inside the grid, safe and not yet marked, marking it as you push it.
- If a push would need a 257th entry, stop and return -1.

Return 0 if the start cell is a hazard. Return -1 if the grid is empty, has more than 32 rows, has rows of different lengths or longer than 32, or if the start is outside the grid.
--- starter
#include <string>
#include <vector>

int safe_area(const std::vector<std::string>& grid, int row, int col) {
    return 0;
}
--- solution
#include <array>
#include <cstddef>
#include <string>
#include <vector>

constexpr int kMaxSide = 32;
constexpr int kStackCells = 256;

int safe_area(const std::vector<std::string>& grid, int row, int col) {
    const int rows = static_cast<int>(grid.size());
    if (rows == 0 || rows > kMaxSide) return -1;
    const int cols = static_cast<int>(grid[0].size());
    if (cols == 0 || cols > kMaxSide) return -1;
    for (const std::string& r : grid) {
        if (static_cast<int>(r.size()) != cols) return -1;
    }
    if (row < 0 || row >= rows || col < 0 || col >= cols) return -1;
    auto safe = [&](int r, int c) { return grid[static_cast<std::size_t>(r)][static_cast<std::size_t>(c)] == '.'; };
    if (!safe(row, col)) return 0;

    struct Cell { int r; int c; };
    std::array<Cell, kStackCells> stack{};
    std::array<std::array<bool, kMaxSide>, kMaxSide> marked{};
    int top = 0;
    auto push = [&](int r, int c) {
        if (top == kStackCells) return false;           // the fixed capacity is the bound
        marked[static_cast<std::size_t>(r)][static_cast<std::size_t>(c)] = true;
        stack[static_cast<std::size_t>(top++)] = {r, c};
        return true;
    };
    push(row, col);
    int area = 0;
    constexpr int dr[4] = {-1, 1, 0, 0};                // up, down, left, right
    constexpr int dc[4] = {0, 0, -1, 1};
    while (top > 0) {                                   // each cell is pushed at most once
        const Cell cur = stack[static_cast<std::size_t>(--top)];
        ++area;
        for (int k = 0; k < 4; ++k) {
            const int r = cur.r + dr[k];
            const int c = cur.c + dc[k];
            if (r < 0 || r >= rows || c < 0 || c >= cols) continue;
            if (!safe(r, c) || marked[static_cast<std::size_t>(r)][static_cast<std::size_t>(c)]) continue;
            if (!push(r, c)) return -1;
        }
    }
    return area;
}

+++ problem | Response times with interrupts on top
--- task
Tasks run under fixed priorities, and interrupt handlers preempt all of them. Work out each task's worst-case response time with response-time analysis:

```cpp
struct Task { int c_us; int t_us; int d_us; };   // worst-case time, period, deadline
struct Irq { int c_us; int min_gap_us; };        // handler time, shortest time between two interrupts
std::vector<int> response_times(std::span<const Task> tasks, std::span<const Irq> irqs);
```

`tasks[0]` has the highest priority. For task `i`, everything that can preempt it is every interrupt and every task before it. Each preempting source `j` with time `C_j` and period (or shortest gap) `T_j` can run `ceil(R / T_j)` times in a window of length `R`, so

`R = C_i + sum over preempting sources of ceil(R / T_j) × C_j`.

- Solve it by repetition: start with `R = C_i` plus the times of all preempting sources, then put `R` into the right-hand side to get the next `R`, until it stops changing.
- If `R` ever exceeds the task's deadline, the task can miss it: its answer is -1. Also give -1 if `R` has not settled after 100 repetitions (a fixed bound).
- Return one answer per task. Return an empty vector if any time is negative, or any period, gap or deadline is not positive.

For example, tasks of (250, 1000, 1000) and (3000, 8000, 8000) µs under a 15 µs interrupt every 100 µs have response times of 295 and 5000 µs.
--- starter
#include <span>
#include <vector>

struct Task { int c_us; int t_us; int d_us; };
struct Irq { int c_us; int min_gap_us; };

std::vector<int> response_times(std::span<const Task> tasks, std::span<const Irq> irqs) {
    std::vector<int> out;
    for (const Task& t : tasks) out.push_back(t.c_us);
    return out;
}
--- solution
#include <cstddef>
#include <span>
#include <vector>

struct Task { int c_us; int t_us; int d_us; };
struct Irq { int c_us; int min_gap_us; };

constexpr int kMaxRepeats = 100;

std::vector<int> response_times(std::span<const Task> tasks, std::span<const Irq> irqs) {
    for (const Task& t : tasks) {
        if (t.c_us < 0 || t.t_us <= 0 || t.d_us <= 0) return {};
    }
    for (const Irq& q : irqs) {
        if (q.c_us < 0 || q.min_gap_us <= 0) return {};
    }
    struct Source { long long c; long long t; };
    std::vector<int> out;
    for (std::size_t i = 0; i < tasks.size(); ++i) {
        std::vector<Source> hp;
        for (const Irq& q : irqs) hp.push_back({q.c_us, q.min_gap_us});
        for (std::size_t j = 0; j < i; ++j) hp.push_back({tasks[j].c_us, tasks[j].t_us});

        long long r = tasks[i].c_us;
        for (const Source& s : hp) r += s.c;
        int answer = -1;
        for (int k = 0; k < kMaxRepeats; ++k) {        // the fixed bound on the repetition
            if (r > tasks[i].d_us) break;              // can miss its deadline
            long long next = tasks[i].c_us;
            for (const Source& s : hp) next += (r + s.t - 1) / s.t * s.c;   // ceil(r / t) * c
            if (next == r) {
                answer = static_cast<int>(r);
                break;
            }
            r = next;
        }
        out.push_back(answer);
    }
    return out;
}

+++ problem | A ring of 48 that corrupts itself
--- task
This queue carries samples from an interrupt to a task. Its capacity had to be 48 (the size the hardware's burst needs), so it is not a power of two, and its two counters are 8-bit. It passes every short test: fill it, drain it, fill it again. But in a long run where the task keeps about 16 samples waiting, it starts handing out samples out of order, and some are lost, although it never reports being full.

Fix the queue so that it holds exactly 48 samples and keeps them in order for any number of pushes and pops, forever. `push` must return false only when 48 samples are waiting, and `pop` false only when none are. Keep the interface as it is.
--- starter
#include <array>
#include <cstdint>

template <typename T, std::uint32_t N>

public:
    bool push(const T& v) {

        ++head_;
        return true;

        out = buf_[tail_ % N];
        ++tail_;
        return true;
    }

--- solution
#include <array>
#include <cstdint>

// Positions run from 0 to 2N - 1 and wrap there explicitly. The slot is position % N,
// and head - tail (mod 2N) tells full (N) from empty (0), for any N.
template <typename T, std::uint32_t N>
class Ring {
    static_assert(N > 0 && N < 0x80000000u, "positions must fit in 32 bits");
public:
    bool push(const T& v) {
        if (size() == N) return false;
        buf_[head_ % N] = v;
        head_ = next(head_);
        return true;
    }
    bool pop(T& out) {
        if (head_ == tail_) return false;
        out = buf_[tail_ % N];
        tail_ = next(tail_);
        return true;
    }
    std::uint32_t size() const { return (head_ + 2 * N - tail_) % (2 * N); }
private:
    static std::uint32_t next(std::uint32_t p) { return p + 1 == 2 * N ? 0 : p + 1; }
    std::array<T, N> buf_{};
    std::uint32_t head_ = 0;
    std::uint32_t tail_ = 0;
};

+++ question | A loop bound the analyzer cannot see
--- ask
A static WCET analyzer rejects this function, saying it cannot bound the loop. The test campaign never saw `n` above 12.

```cpp

    double angle = 0.0;
```

What is the right fix?
--- choice
None is needed: the loop has a counter and a limit, so the analyzer is being overly cautious.
--- choice
Tell the analyzer the loop runs at most 12 times, because that is the most the tests ever saw.
--- choice correct
Check `n` against a constant maximum before the loop and reject larger values (or pass a fixed-size span), so the constant is a bound a tool can prove.

+++ question | A monotonic arena under a growing vector
--- ask
A `std::pmr::vector<double>` gets its memory from a `std::pmr::monotonic_buffer_resource` over a 1024-byte array, whose upstream is `std::pmr::null_memory_resource()`. Nobody calls `reserve`. 128 doubles fit, because 128 × 8 = 1024 bytes.

It never fails, because each time the vector grows it gives its old block back to the resource.

+++ question | Interrupts off for a long copy
--- ask
A task switches interrupts off for 200 µs while it copies a 64 KB table, "so the interrupt cannot see half a table". A gyro raises its data-ready interrupt every 100 µs, and its data register is overwritten by each new sample. What goes wrong?
--- choice
Nothing: the pending interrupt runs as soon as interrupts come back on, so no data is lost.
--- choice correct
At least one gyro sample is lost. The interrupt can only be held pending once, and while interrupts are off a new sample overwrites the register before the handler can read it.
--- choice
The watchdog resets the processor, because 200 µs is longer than any watchdog timeout.
--- choice
The copy becomes slower, because the processor has to keep checking for interrupts.

+++ question | Why the median protects at once
--- ask
Three gyros are voted by taking the median every frame, while a monitor needs 3 bad frames in a row before it isolates a gyro. On the very first frame that gyro B jumps to a wild value, what does the controller receive?
--- choice
The wild value, because the fault is not confirmed yet.
--- choice correct
A value from A or C, because the median of three always discards the single most extreme reading.
--- choice
The mean of the three readings, pulled a third of the way toward the wild value.
--- choice
Nothing: the controller holds its last command until the monitor decides.
--- why
With one wild reading and two good ones, the wild reading is either the largest or the smallest, and the median is always one of the two good readings. +++ question | Three flipped bits under SECDED
--- ask
A 64-bit word protected by SECDED error-correcting memory takes three flipped bits before anyone reads it. What can the memory do when the word is read?

Correct all three, because it has 8 check bits for 64 data bits.
--- choice
Always detect the damage and raise an uncorrectable-error alarm, because it detects anything worse than one flip.
--- choice correct
It may take the damage for a single flipped bit, "correct" the wrong bit, and hand back a wrong value with no alarm. SECDED only promises to correct one flip and detect two.
