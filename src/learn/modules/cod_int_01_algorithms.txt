--- solution
def problems_per_week(hours, minutes_each=35):
    """Whole timed problems that fit into a week of `hours` hours."""
    if minutes_each <= 0 or hours < 0:
        raise ValueError("need hours >= 0 and minutes_each > 0")
    return int(hours * 60 // minutes_each)
--- hint

def problems_in_budget(total_hours, lesson_minutes, exercise_hours, minutes_each=35):

- Log entries whose pattern is not in `patterns` are ignored.
- A pattern with no entries at all has 0 reps.
--- starter

    pass
--- solution
def coverage_gaps(log, patterns, min_reps):
    """Patterns with fewer than min_reps solved-in-time problems, in list order."""
    reps = {p: 0 for p in patterns}
    for entry in log:
        p = entry["pattern"]
        if p in reps and entry["solved"] and entry["minutes"] <= 25:
            reps[p] += 1
    return [p for p in patterns if reps[p] < min_reps]
--- hint
Start a dictionary with every pattern at 0, so patterns that never appear in the log are still counted.
--- hint
An entry adds a rep only if all three hold: its pattern is being tracked, it was solved, and its minutes are at most 25.

+++ question | One small detail that changes between languages
--- ask
In C++, `v` is an empty `std::vector<int>`. What is the value of `v.size() - 1`?
--- choice
`-1`
--- choice
`0`
--- choice correct
A huge positive number, because `size()` is unsigned and subtracting 1 from 0 wraps around.
--- choice
It does not compile.
--- why
`size()` returns an unsigned type, which cannot hold a negative number, so 0 minus 1 wraps around to the largest value the type can hold. A loop such as `for (i = 0; i <= v.size() - 1; ++i)` then runs far past the end of an empty vector. Python's `len(xs) - 1` is simply -1. Small differences like this are why the lesson says to pick one live-coding language early and do every timed problem in it.

So `fits_budget(10**6, 10**8)` returns `["O(1)", "O(log n)", "O(n)", "O(n log n)"]`: n log n is about 2 × 10^7 steps, but n squared is 10^12.
--- starter
import math

def fits_budget(n, budget):
    pass
--- solution
import math

def fits_budget(n, budget):
    """The growth classes whose step count at size n is at most budget."""
    steps = [
        ("O(1)", 1),
        ("O(log n)", math.log2(n)),
        ("O(n)", n),
        ("O(n log n)", n * math.log2(n)),
        ("O(n^2)", n * n),
        ("O(2^n)", 2 ** n),
    ]
    return [name for name, count in steps if count <= budget]
--- hint
Make a list of (name, step count) pairs in the given order, then keep the names whose count is at most the budget.
--- hint
Python's whole numbers have no size limit, so `2 ** n` works even for a large `n`; comparing it with the budget is still quick.

+++ practice | Growing by a fixed step
--- task
The lesson showed that a growable array which doubles makes fewer than 2n copies for n pushes. Here is the other design. The array starts with room for `step` items. When it is full and one more item is pushed, it moves to a block `step` slots bigger and copies every item it holds.

Write `copies_fixed_growth(n, step)` that returns the total number of item copies made by `n` pushes into an empty array.

- So `copies_fixed_growth(35, 10)` is `60`: the array is full at 10, 20 and 30 items, and those three moves copy 10 + 20 + 30 items.
- Raise `ValueError` if `step` is less than 1.
- It must handle `n = 10**6` in well under a second.
--- starter
def copies_fixed_growth(n, step):
    pass
--- solution
def copies_fixed_growth(n, step):
    """Item copies made by n pushes into an array that grows by `step` slots."""
    if step < 1:
        raise ValueError("step must be at least 1")
    copies = 0
    capacity = step
    while capacity < n:          # pushing item capacity + 1 forces a move
        copies += capacity       # every item held is copied once
        capacity += step
    return copies
--- hint
A move happens only when the array is full and another item still has to go in: full at `step` items, then at `2 * step`, and so on, while that size is less than `n`.
--- hint
You only need one loop step per move, not one per push: add the current capacity to the total, then grow the capacity by `step`.
--- check case | Thirty-five pushes, step 10

=> 60
--- check case | Exactly full, but nothing more was pushed
copies_fixed_growth(10, 10)
=> 0
--- check case | One push past full
copies_fixed_growth(11, 10)
=> 10
--- check case | No pushes
copies_fixed_growth(0, 4)
=> 0
--- check case | A million pushes, growing by 1000: about n squared over 2000

=> 499500000
--- check test | A step below 1 raises ValueError

+++ practice | The closest pair of readings
--- task
Write `min_gap(readings)` that returns the smallest difference between two readings at different positions in the list. The readings are numbers in any order.

- Raise `ValueError` if there are fewer than two readings.
- Two equal readings give a gap of 0.
- The check runs it on 200,000 readings. Comparing every pair would be about 2 × 10^10 comparisons, far too many. Aim for O(n log n) time: after sorting, the closest pair must sit side by side.
--- starter
def min_gap(readings):
    pass
--- solution
def min_gap(readings):
    """Smallest difference between two readings. O(n log n) time, O(n) extra space."""
    if len(readings) < 2:
        raise ValueError("need at least two readings")
    s = sorted(readings)
    return min(s[k + 1] - s[k] for k in range(len(s) - 1))
--- hint
Sort a copy first. In sorted order, a reading's closest partner is one of its two neighbours.
--- hint
After sorting, walk the neighbours once and keep the smallest difference. Sorting is O(n log n) and the walk is O(n).

+++ practice | The sum that runs out of stack
--- task
`total(xs)` should add up a list of numbers of any length. It is right on short lists, but a flight log of 100,000 samples crashes it with `RecursionError`.

Every call waits on the call stack until the ones after it return, so it uses O(n) stack space. Each `xs[1:]` also copies the rest of the list, which makes the time O(n^2).

Rewrite it to run in O(n) time with O(1) extra space. Do not use the built-in `sum`.
--- starter
def total(xs):
    """Sum of a list of numbers."""
    if not xs:
        return 0
    return xs[0] + total(xs[1:])
--- solution
def total(xs):
    """Sum of a list of numbers. O(n) time, O(1) extra space."""
    running = 0
    for x in xs:
        running += x
    return running
--- hint
A loop needs no call stack at all. Keep one running total and add each number to it.

+++ question | Two sizes in one loop
--- ask
Let `n` be `len(xs)`, and let `k` be much smaller than `n`. What is the time complexity of this function?

```python
def later_bigger(xs, k):
    count = 0
    for i in range(len(xs)):
        for j in range(i + 1, min(i + k, len(xs))):
            if xs[j] > xs[i]:
                count += 1
    return count
```
--- choice
O(n)
--- choice
O(n^2)
--- choice correct
O(n · k)
--- choice
O(k)
--- why
The outer loop runs n times and the inner loop at most k - 1 times for each, so the inner line runs at most about n·k times: O(n·k). It is not O(n^2), because the inner loop never looks more than k places ahead. It is only O(n) if k is a fixed constant, so name both letters out loud instead of quietly saying "O(n)".

+++ practice | Pairs that fit a mass limit
--- task
A kit holds two spare parts, and their masses together must be at most a limit. Write `count_pairs_at_most(masses, limit)` that returns how many pairs of positions `i < j` have `masses[i] + masses[j] <= limit`.

- `masses` is sorted from lightest to heaviest.
- Use two pointers from opposite ends: O(n) time, O(1) extra space. The check runs it on 200,000 masses.

So `count_pairs_at_most([1, 2, 3, 5, 8], 7)` is `5`: the pairs (1, 2), (1, 3), (1, 5), (2, 3) and (2, 5).
--- starter
def count_pairs_at_most(masses, limit):
    pass
--- solution
def count_pairs_at_most(masses, limit):
    """masses sorted ascending. O(n) time, O(1) extra space."""
    i, j = 0, len(masses) - 1
    count = 0
    while i < j:
        if masses[i] + masses[j] <= limit:
            count += j - i      # masses[i] fits with every partner from i + 1 to j
            i += 1
        else:
            j -= 1              # masses[j] is too heavy even for the lightest part left
    return count
--- hint
Put `i` on the lightest part and `j` on the heaviest. If the pair fits, what does that tell you about `masses[i]` with every part between them?
--- hint
When the pair fits, all `j - i` partners of `masses[i]` fit, so add them at once and move `i` right. When it does not fit, `masses[j]` fits with nothing left, so move `j` left.

    pass
--- solution
def keep_in_range(readings, lo, hi):
    """Move in-range readings to the front, in order. O(n) time, O(1) extra space."""
    write = 0                               # readings[:write] holds the kept values
    for read in range(len(readings)):       # the fast pointer looks at every reading
        r = readings[read]
        if lo <= r <= hi:
            readings[write] = r
            write += 1
    return write
--- hint
The fast pointer visits every position. The slow pointer marks where the next kept reading goes.
--- hint
When a reading is in range, copy it to the slow pointer's position and move the slow pointer on. At the end, the slow pointer is the count.

+++ practice | The shortest charging stretch
--- task
A battery log has one positive energy value per minute, in watt-hours. Write `shortest_stretch(energy, target)` that returns the length of the shortest run of consecutive minutes whose total is at least `target`, or `0` if no run reaches it.

- Every value is positive and `target` is positive.
- Use a variable-size window: O(n) time, O(1) extra space. The check runs it on 200,000 minutes.

So `shortest_stretch([2, 3, 1, 2, 4, 3], 7)` is `2`: minutes 4 and 5 give 4 + 3 = 7.
--- starter
def shortest_stretch(energy, target):
    pass
--- solution
def shortest_stretch(energy, target):
    """Shortest run with total >= target, or 0. O(n) time, O(1) extra space."""
    best = 0
    left = 0
    window = 0                          # total of energy[left : right + 1]
    for right, e in enumerate(energy):
        window += e
        while window >= target:         # valid: record it, then try a shorter one
            length = right - left + 1
            if best == 0 or length < best:
                best = length
            window -= energy[left]
            left += 1
    return best
--- hint
Grow the window on the right one minute at a time. As long as its total reaches the target, it is a candidate: record its length and shrink it from the left.
--- hint
Because every value is positive, dropping the leftmost minute can only lower the total, so the left edge only ever moves forward. Each edge moves at most n times.

--- starter
def longest_k_channels(log, k):
    pass
--- solution
def longest_k_channels(log, k):
    """Longest substring with at most k distinct letters. O(n) time, O(k) extra space."""
    counts = {}                 # letter -> how many times it is in the window
    left = 0
    best = 0
    for right, ch in enumerate(log):
        counts[ch] = counts.get(ch, 0) + 1
        while len(counts) > k:  # too many letters: shrink from the left
            out = log[left]
            counts[out] -= 1
            if counts[out] == 0:
                del counts[out]
            left += 1
        best = max(best, right - left + 1)
    return best

The number of different letters in the window is the number of keys in your dictionary, as long as you delete a key when its count drops to 0.
--- hint
Add the new letter on the right. While there are more than `k` keys, remove letters from the left. Then the window is valid: compare its length with the best.
--- hint
With `k = 0` no letter is allowed, so every window shrinks back to nothing. Make sure your loop handles that without an error.

import bisect

def channel_counts(packets, queries):
    """Packets per (channel, start, end) query. O(n log n + m log n) time, O(n) space."""
    by_channel = {}
    for ch, t in packets:
        by_channel.setdefault(ch, []).append(t)
    for times in by_channel.values():
        times.sort()
    out = []
    for ch, start, end in queries:
        times = by_channel.get(ch, [])
        count = bisect.bisect_right(times, end) - bisect.bisect_left(times, start)
        out.append(max(0, count))
    return out

--- hint

def count_pairs(masses, target):

def spans(vals):

from collections import deque

class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def level_sums(root):
    """Sum of each level, top down. O(n) time, O(w) space for the widest level."""
    if root is None:
        return []
    sums = []
    q = deque([root])
    while q:
        total = 0
        for _ in range(len(q)):         # exactly the nodes of this level
            node = q.popleft()
            total += node.val
            for child in (node.left, node.right):
                if child is not None:
                    q.append(child)
        sums.append(total)
    return sums
--- hint
A queue holds the nodes still to visit. At the start of each round, everything in the queue is on the same level.
--- hint
Read how many nodes the queue holds, pop exactly that many while adding their children, and total their values as you go.

from collections import deque

def hops_from(links, start):
    """Fewest links from start to every reachable station. O(V + E) time, O(V) space."""
    dist = {start: 0}                   # also serves as the visited set
    q = deque([start])
    while q:
        here = q.popleft()
        for nxt in links.get(here, []):
            if nxt not in dist:         # mark it when it joins the queue
                dist[nxt] = dist[here] + 1
                q.append(nxt)
    return dist
--- hint

--- solution
def startup_waves(deps):
    """Tasks grouped into startup waves, or None on a cycle. O(V + E) plus sorting."""
    tasks = set(deps)
    for before in deps.values():
        tasks.update(before)
    needed_by = {t: [] for t in tasks}      # edge: before -> after
    waiting = {t: 0 for t in tasks}         # how many prerequisites each task still has
    for after, befores in deps.items():
        for b in befores:
            needed_by[b].append(after)
            waiting[after] += 1
    wave = sorted(t for t in tasks if waiting[t] == 0)
    waves = []
    started = 0
    while wave:
        waves.append(wave)
        started += len(wave)
        nxt = []
        for t in wave:
            for after in needed_by[t]:
                waiting[after] -= 1
                if waiting[after] == 0:
                    nxt.append(after)
        wave = sorted(nxt)
    return waves if started == len(tasks) else None

--- hint

--- solution
def has_cycle(graph):
    """True if some chain of needs loops back on itself. O(V + E) time, O(V) space."""
    on_path = set()     # grey: on the path being explored right now
    done = set()        # black: finished, with everything below it

    def visit(v):
        if v in on_path:
            return True                 # an edge back into our own path
        if v in done:
            return False                # a shared dependency, already checked
        on_path.add(v)
        for w in graph.get(v, []):
            if visit(w):
                return True
        on_path.discard(v)
        done.add(v)
        return False

    return any(visit(v) for v in list(graph))
--- hint
The lesson's three colors: not visited, on the current path, and finished. Only an arrow to a module that is still on the current path proves a cycle.
--- hint

def out_of_limits(readings, lo, hi, windows):
    """Out-of-limit counts for half-open windows. O(n + m) time, O(n) space."""
    P = [0]                                 # P[i] = bad readings among readings[:i]

    return [P[r] - P[l] for l, r in windows]

import heapq

def antennas_needed(passes):
    """Fewest antennas for all passes. O(n log n) time, O(n) space."""
    busy_until = []                     # min-heap: end times of passes in progress
    most = 0
    for start, end in sorted(passes):
        if busy_until and busy_until[0] <= start:
            heapq.heapreplace(busy_until, end)   # that antenna is free again: reuse it
        else:
            heapq.heappush(busy_until, end)      # every antenna is busy: add one
        most = max(most, len(busy_until))
    return most

def decode_status(two):
    """Decode a big-endian 16-bit status word."""
    if len(two) != 2:
        raise ValueError("need exactly 2 bytes")
    word = (two[0] << 8) | two[1]           # the first byte is the high byte

FRAME = 8

def decom(stream):
    """Good frames and the unread tail. O(n) time, O(f) space for f frames."""
    frames = []
    i, n = 0, len(stream)
    while i + FRAME <= n:                      # a whole frame must remain
        if stream[i] != 0xEB or stream[i + 1] != 0x90:
            i += 1                             # hunt for the sync word
            continue
        check = 0
        for b in stream[i:i + FRAME - 1]:
            check ^= b
        if check != stream[i + FRAME - 1]:
            i += 1                             # maybe a false start: resync
            continue
        counter, raw_kpa, raw_t = struct.unpack_from("<BhH", stream, i + 2)
        frames.append((counter, raw_kpa / 10, raw_t / 10))
        i += FRAME
    return frames, stream[i:]
--- hint
Keep one index into the stream and three cases: no sync word, sync word with a bad checksum, and a good frame. Only the good frame moves the index by 8.
--- hint
The loop condition `i + 8 <= len(stream)` is what stops you decoding half a frame. When it fails, everything from `i` on is the leftover.

import math

def clean_stats(values, lo, hi):
    """(count, mean, population std) of the usable values. O(n) time."""
    good = [v for v in values
            if v is not None and not math.isnan(v) and lo <= v <= hi]

+++ practice | A command ring that refuses when full
--- task
Commands waiting to go to a thruster must never be silently dropped. Write a class `CommandRing(capacity)`: a ring buffer whose overwrite policy is to **refuse** the newest item when full.

- `offer(cmd)` stores `cmd` and returns `True`, or returns `False` and stores nothing when the ring is full.

- `len(ring)` gives the number of commands stored.
- Every operation is O(1). No `append`, `pop` or `insert` on the list.
--- starter

        pass
--- solution
class CommandRing:
    """Fixed-capacity FIFO of commands that refuses new ones when full."""

    def __init__(self, capacity):
        if capacity < 1:
            raise ValueError("capacity must be at least 1")
        self.slots = [None] * capacity
        self.start = 0          # index of the oldest command
        self.count = 0          # how many commands are stored

    def offer(self, cmd):
        if self.count == len(self.slots):
            return False                        # full: refuse, never overwrite a command
        self.slots[(self.start + self.count) % len(self.slots)] = cmd
        self.count += 1
        return True

    def take(self):
        if self.count == 0:
            return None
        cmd = self.slots[self.start]
        self.slots[self.start] = None
        self.start = (self.start + 1) % len(self.slots)
        self.count -= 1
        return cmd

    def __len__(self):
        return self.count
--- hint
Keep the index of the oldest command and a count, as in the lesson. The next free slot is `(start + count) % capacity`.
--- hint
`offer` checks for full before writing anything. `take` checks for empty, reads the oldest slot, then moves `start` on by one, wrapping.

def hold_values(t, v, query_t):
    """Latest value at or before each query time. O(n + m) time, O(m) space."""
    out = []
    j = -1                          # index of the latest sample at or before the query
    for q in query_t:
        while j + 1 < len(t) and t[j + 1] <= q:
            j += 1                  # j only moves forward across all the queries
        out.append(v[j] if j >= 0 else None)
    return out

--- solution
class MaskRing:
    """Overwriting ring whose power-of-two capacity lets a mask do the wrap."""

    def __init__(self, capacity):
        if capacity < 1 or capacity & (capacity - 1):
            raise ValueError("capacity must be a power of two")
        self.slots = [None] * capacity
        self.mask = capacity - 1
        self.next = 0           # the slot the next push writes
        self.count = 0

    def push(self, x):
        self.slots[self.next] = x
        self.next = (self.next + 1) & self.mask
        if self.count < len(self.slots):
            self.count += 1

    def latest(self, k):
        k = min(k, self.count)
        return [self.slots[(self.next - 1 - i) & self.mask] for i in range(k)]

--- hint

+++ practice | A PID controller with back-calculation
--- task
Write a class `PIDController(kp, ki, kd, kb, u_max)` with a method `update(r, y, dt)` that returns the command `u`. The integrator starts at 0 and is kept in `self.integ`. Each call does exactly this:

1. The error is `e = r - y`.
2. The derivative is taken on the measurement: `d = -(y - y_prev) / dt`, where `y_prev` is the measurement from the previous call. On the first call there is no previous measurement, so `d = 0`.
3. The request is `v = kp * e + integ + kd * d`.
4. The command is `v` clipped to the range `-u_max` to `u_max`.
5. Back-calculation: `integ` grows by `(ki * e + kb * (u - v)) * dt`.
6. Remember `y` for the next call, and return `u`.

Raise `ValueError` if `dt` is 0 or less.
--- starter
class PIDController:
    def __init__(self, kp, ki, kd, kb, u_max):
        pass
--- solution
class PIDController:
    """Discrete PID with derivative on measurement and back-calculation anti-windup."""

    def __init__(self, kp, ki, kd, kb, u_max):
        self.kp, self.ki, self.kd, self.kb = kp, ki, kd, kb
        self.u_max = u_max
        self.integ = 0.0
        self.y_prev = None          # no measurement yet

    def update(self, r, y, dt):
        if dt <= 0:
            raise ValueError("dt must be positive")
        e = r - y
        d = 0.0 if self.y_prev is None else -(y - self.y_prev) / dt
        v = self.kp * e + self.integ + self.kd * d
        u = max(-self.u_max, min(self.u_max, v))
        self.integ += (self.ki * e + self.kb * (u - v)) * dt   # bleed off the excess
        self.y_prev = y
        return u
--- hint
Store `y_prev` as `None` at first, so the first call can tell there is nothing to take a difference from.
--- hint
Clip with `max(-u_max, min(u_max, v))`. The integrator update uses both `u` and `v`: when they are equal, the back-calculation term is zero.

+++ practice | A median filter over a sliding window
--- task
Write `median_filter(xs, w)` that returns the median of every window of `w` consecutive readings, in order. A median filter like this removes single spikes that would drag an average far off.

- `w` must be a positive odd number; otherwise raise `ValueError`. If `w` is more than `len(xs)`, return `[]`.
- Keep the current window as a sorted list. Each step, remove the reading that leaves (find it with a binary search) and add the new one with `bisect.insort`: O(w) per step.

So `median_filter([5, 7, 300, 6, 5, 8, 4], 3)` is `[7, 7, 6, 6, 5]`: the spike of 300 never comes through.

--- solution
import bisect

def median_filter(xs, w):
    """Median of each window of w readings (w odd). O(n · w) time, O(w) space."""
    if w < 1 or w % 2 == 0:
        raise ValueError("w must be a positive odd number")
    if w > len(xs):
        return []
    window = sorted(xs[:w])
    out = [window[w // 2]]
    for i in range(w, len(xs)):
        del window[bisect.bisect_left(window, xs[i - w])]     # the oldest reading leaves
        bisect.insort(window, xs[i])                          # the newest joins
        out.append(window[w // 2])
    return out
--- hint
Sort the first window once. Its middle item, at index `w // 2`, is the first median.
--- hint
When the window slides, the reading at `xs[i - w]` leaves. `bisect_left` finds a copy of it in the sorted window, and `del` removes it; then `insort` adds `xs[i]` in its sorted place.

--- solution
import heapq

class MedianTracker:
    """Lower median of a stream. add O(log n), median O(1), space O(n)."""

    def __init__(self):
        self.low = []       # max-heap of the lower half, stored as negatives
        self.high = []      # min-heap of the upper half

    def add(self, x):
        if not self.low or x <= -self.low[0]:
            heapq.heappush(self.low, -x)
        else:
            heapq.heappush(self.high, x)
        # low holds the same number as high, or one more
        if len(self.low) > len(self.high) + 1:
            heapq.heappush(self.high, -heapq.heappop(self.low))
        elif len(self.high) > len(self.low):
            heapq.heappush(self.low, -heapq.heappop(self.high))

    def median(self):
        if not self.low:
            raise ValueError("no readings yet")
        return -self.low[0]                 # the lower middle for an even count
--- hint
If the lower half always holds the same number of values as the upper half, or one more, then the lower median is always the top of the lower half.
--- hint
`heapq` only makes min-heaps: store the lower half as negated numbers, and negate again whenever a value comes out of it.

   - An APID seen once has 0 lost.
   - A packet cut off at the end of the stream (its header or its data incomplete) is ignored.

import struct

def read_header(six):
    """The fields of a 6-byte big-endian space packet primary header."""
    if len(six) != 6:
        raise ValueError("a primary header is 6 bytes")
    w1, w2, length = struct.unpack(">HHH", six)
    return {
        "version": w1 >> 13,
        "type": (w1 >> 12) & 1,
        "sec_hdr": (w1 >> 11) & 1,
        "apid": w1 & 0x7FF,
        "seq_flags": w2 >> 14,
        "seq_count": w2 & 0x3FFF,
        "length": length,
    }

def apid_losses(stream):
    """Packets lost per APID, from 14-bit sequence counts. O(n) time, O(a) space."""
    last = {}               # APID -> its last sequence count
    lost = {}               # APID -> packets lost so far
    i, n = 0, len(stream)
    while i + 6 <= n:
        h = read_header(stream[i:i + 6])
        end = i + 6 + h["length"] + 1
        if end > n:
            break                               # a cut-off packet: ignore it
        apid, count = h["apid"], h["seq_count"]
        if apid not in last:
            lost[apid] = 0
        elif count != last[apid]:               # an equal count is a duplicate
            lost[apid] += (count - last[apid] - 1) % 16384
        last[apid] = count
        i = end
    return lost

--- task
A beacon sends frames of different lengths:

| Part | Size | Meaning |
| --- | --- | --- |
| sync | 1 byte | always `0x5A` |
| length | 1 byte | N, the number of payload bytes, 1 to 32 |
| payload | N bytes | the data |
| checksum | 1 byte | (the length byte + the sum of the payload bytes) mod 256 |

4. If the rest of the frame is not all there yet, stop.
5. If the checksum does not match, count one bad start and step forward one byte.
6. Otherwise keep the payload and jump past the whole frame, all N + 3 bytes.

--- solution
SYNC = 0x5A

def parse(buf):
    """Payloads of good frames, the unread tail, and the bad starts. O(n) time."""
    payloads, bad = [], 0
    i, n = 0, len(buf)
    while i < n:
        if buf[i] != SYNC:
            i += 1                                  # hunt for the sync byte
            continue
        if i + 1 >= n:
            break                                   # the length byte has not arrived
        size = buf[i + 1]
        if not 1 <= size <= 32:
            bad += 1                                # an impossible length: a false start
            i += 1
            continue
        if i + size + 3 > n:
            break                                   # the frame is not all here yet
        if sum(buf[i + 1:i + 2 + size]) % 256 != buf[i + 2 + size]:
            bad += 1                                # damaged, or a false start: resync
            i += 1
            continue
        payloads.append(bytes(buf[i + 2:i + 2 + size]))
        i += size + 3
    return payloads, buf[i:], bad

--- solution
class TelemetryWindow:
    """The last `capacity` samples in fixed memory, with a dropout report."""

    def __init__(self, capacity):
        if capacity < 1:
            raise ValueError("capacity must be at least 1")
        self.slots = [None] * capacity
        self.start = 0              # index of the oldest sample
        self.count = 0
        self.last_t = None          # time of the last sample pushed

    def push(self, t, value):
        if self.last_t is not None and t <= self.last_t:
            raise ValueError("timestamps must increase")
        n = len(self.slots)
        self.slots[(self.start + self.count) % n] = (t, value)
        if self.count == n:
            self.start = (self.start + 1) % n       # the oldest was overwritten
        else:
            self.count += 1
        self.last_t = t

    def samples(self):
        n = len(self.slots)
        return [self.slots[(self.start + i) % n] for i in range(self.count)]

    def gaps(self, period, k=1.5):
        s = self.samples()
        out = []
        for (ta, _), (tb, _) in zip(s, s[1:]):
            if tb - ta > k * period:
                out.append((ta, tb, round((tb - ta) / period) - 1))
        return out

def align(fast_t, fast_v, slow_t, period, k=1.5):
    """Fast signal at each slow time; NaN outside the data or across a dropout. O(n + m)."""
    out = []
    j = 0
    n = len(fast_t)
    for t in slow_t:
        while j + 1 < n and fast_t[j + 1] <= t:     # j only moves forward
            j += 1
        if n == 0 or t < fast_t[0] or t > fast_t[-1]:
            out.append(float("nan"))                 # no extrapolation
        elif fast_t[j] == t:
            out.append(fast_v[j])                    # exactly on a sample
        elif fast_t[j + 1] - fast_t[j] > k * period:
            out.append(float("nan"))                 # do not bridge a dropout
        else:
            frac = (t - fast_t[j]) / (fast_t[j + 1] - fast_t[j])
            out.append(fast_v[j] + frac * (fast_v[j + 1] - fast_v[j]))
    return out

+++ problem | The slowest downlink that loses nothing
--- task
Samples arrive in bursts: `arrivals[i]` is how many arrive in tick `i`. They wait in an on-board buffer that holds `cap` samples. Each tick, after that tick's arrivals, a downlink of rate `r` sends up to `r` waiting samples. So the backlog after tick `i` is `max(0, backlog + arrivals[i] - r)`, starting from 0. If the backlog after any tick is more than `cap`, data is lost. A backlog still waiting at the end is fine.

Write `min_drain_rate(arrivals, cap)` that returns the smallest whole rate `r`, 0 or more, that never loses data.

- A faster downlink never does worse, so binary search the rate, checking each guess with a simulation: O(n log R).
- The check runs 100,000 ticks with bursts of up to a million samples, so trying every rate from 0 upward is far too slow.

So `min_drain_rate([5, 0, 0, 9, 1], 4)` is `5`: at rate 4, the backlog after the fourth tick would be 5.
--- starter

    pass
--- solution
def loses_nothing(arrivals, cap, rate):
    backlog = 0
    for a in arrivals:
        backlog = max(0, backlog + a - rate)
        if backlog > cap:
            return False
    return True

def min_drain_rate(arrivals, cap):
    """Smallest rate that never overflows the buffer. O(n log R) time, O(1) space."""
    lo, hi = 0, max(arrivals, default=0)    # at rate max(arrivals) nothing ever waits
    while lo < hi:
        mid = (lo + hi) // 2
        if loses_nothing(arrivals, cap, mid):
            hi = mid                        # mid works: the answer is mid or smaller
        else:
            lo = mid + 1                    # mid fails, and so does every slower rate
    return lo

from collections import deque

def earliest_finish(durations, deps):
    """Finish time of every task, or None on a cycle. O(V + E) time and space."""
    needed_by = {t: [] for t in durations}
    waiting = {t: 0 for t in durations}
    for after, befores in deps.items():
        for b in befores:
            needed_by[b].append(after)
            waiting[after] += 1
    start = {t: 0 for t in durations}          # latest finish among prerequisites so far
    ready = deque(t for t in durations if waiting[t] == 0)
    finish = {}
    while ready:
        t = ready.popleft()
        finish[t] = start[t] + durations[t]
        for after in needed_by[t]:
            start[after] = max(start[after], finish[t])
            waiting[after] -= 1
            if waiting[after] == 0:
                ready.append(after)
    return finish if len(finish) == len(durations) else None

--- solution
from collections import deque

def longest_stable(xs, tol):
    """Longest run with max - min <= tol. O(n) time, O(n) space."""
    hi_q = deque()          # indices; values fall from front to back (front = max)
    lo_q = deque()          # indices; values rise from front to back (front = min)
    left = 0
    best = 0
    for right, x in enumerate(xs):
        while hi_q and xs[hi_q[-1]] <= x:
            hi_q.pop()
        hi_q.append(right)
        while lo_q and xs[lo_q[-1]] >= x:
            lo_q.pop()
        lo_q.append(right)
        while xs[hi_q[0]] - xs[lo_q[0]] > tol:     # unstable: drop the leftmost reading
            left += 1
            if hi_q[0] < left:
                hi_q.popleft()
            if lo_q[0] < left:
                lo_q.popleft()
        best = max(best, right - left + 1)
    return best

from collections import deque

def fewest_moves_with_hop(grid, start, goal):
    """BFS over (row, column, hop used). O(R * C) time and space."""
    rows, cols = len(grid), len(grid[0])
    first = (start[0], start[1], False)
    dist = {first: 0}
    q = deque([first])
    while q:
        r, c, used = q.popleft()
        if (r, c) == tuple(goal):
            return dist[(r, c, used)]
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if not (0 <= nr < rows and 0 <= nc < cols):
                continue
            if grid[nr][nc] == "." and (nr, nc, used) not in dist:
                dist[(nr, nc, used)] = dist[(r, c, used)] + 1
                q.append((nr, nc, used))
            hr, hc = r + 2 * dr, c + 2 * dc
            if (not used and grid[nr][nc] == "#" and 0 <= hr < rows and 0 <= hc < cols
                    and grid[hr][hc] == "." and (hr, hc, True) not in dist):
                dist[(hr, hc, True)] = dist[(r, c, used)] + 1
                q.append((hr, hc, True))
    return -1

+++ problem | A throttle controller with a slew limit
--- task
A throttle valve can move only so fast, as well as only so far. Write a class `ThrottlePID(kp, ki, kd, u_max, slew)` with `update(r, y, dt)`, returning the command `u`. The integrator starts at 0 in `self.integ`, and the previous command starts at 0. Each call does exactly this:

1. `e = r - y`.
2. `d = -(y - y_prev) / dt` from the previous call's measurement, or `d = 0` on the first call.
3. `v = kp * e + integ + kd * d`.
4. `u` is `v` clipped to `-u_max .. u_max`, then clipped again to within `slew * dt` of the previous command: no lower than `u_prev - slew * dt` and no higher than `u_prev + slew * dt`.
5. Anti-windup by conditional integration: if the command was cut short in the direction the error is pushing, that is if `(v - u) * e > 0`, leave the integrator alone. Otherwise add `ki * e * dt` to it.
6. Remember `y` and `u` for the next call, and return `u`.

Raise `ValueError` if `dt` is 0 or less.
--- starter

    def __init__(self, kp, ki, kd, u_max, slew):
        pass
--- solution
class ThrottlePID:
    """PID with range and slew limits, derivative on measurement, conditional integration."""

    def __init__(self, kp, ki, kd, u_max, slew):
        self.kp, self.ki, self.kd = kp, ki, kd
        self.u_max, self.slew = u_max, slew
        self.integ = 0.0
        self.y_prev = None
        self.u_prev = 0.0

    def update(self, r, y, dt):
        if dt <= 0:
            raise ValueError("dt must be positive")
        e = r - y
        d = 0.0 if self.y_prev is None else -(y - self.y_prev) / dt
        v = self.kp * e + self.integ + self.kd * d
        u = max(-self.u_max, min(self.u_max, v))                   # how far it can go
        step = self.slew * dt
        u = max(self.u_prev - step, min(self.u_prev + step, u))    # how fast it can get there
        if (v - u) * e <= 0:        # not pushing against a limit: integrate
            self.integ += self.ki * e * dt
        self.y_prev, self.u_prev = y, u
        return u

+++ problem | Spikes against the running median
--- task
Write a class `SpikeDetector(limit)` with a method `check(x)` for a stream of readings.

- Then it adds `x` to the readings, whether or not it was a spike.
- The median is the middle reading for an odd count, and the average of the two middle readings for an even count.
- Keep the readings in two heaps: each `check` is O(log n). The check runs 200,000 readings.
--- starter

    def __init__(self, limit):
        pass
--- solution
import heapq

class SpikeDetector:
    """Flags readings far from the median of everything before them. O(log n) per check."""

    def __init__(self, limit):
        self.limit = limit
        self.low = []           # max-heap of the lower half, stored as negatives
        self.high = []          # min-heap of the upper half

    def median(self):
        if len(self.low) > len(self.high):
            return -self.low[0]
        return (-self.low[0] + self.high[0]) / 2

    def check(self, x):
        spike = bool(self.low) and abs(x - self.median()) > self.limit
        if not self.low or x <= -self.low[0]:
            heapq.heappush(self.low, -x)
        else:
            heapq.heappush(self.high, x)
        if len(self.low) > len(self.high) + 1:          # low may hold one extra
            heapq.heappush(self.high, -heapq.heappop(self.low))
        elif len(self.high) > len(self.low):
            heapq.heappush(self.low, -heapq.heappop(self.high))
        return spike

+++ question | The damage a checksum cannot see
--- ask
A frame's checksum is the XOR of its bytes. On the way down, two neighbouring bytes of the frame swap places. Which check would catch that?
--- choice
The XOR checksum, because the bytes are in the wrong place.
--- choice
An additive checksum, the sum of the bytes mod 256.
--- choice correct
A CRC, because every bit's position affects its value.
--- choice
None of them: no checksum can detect a reordering.
--- why
XOR and addition do not care about order: a ⊕ b = b ⊕ a and a + b = b + a, so both give the same check value after a swap, and the damaged frame passes.
