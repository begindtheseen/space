+++ practice | Where an element sits
--- task
Every array knows how many bytes to jump along each axis: its `strides`. Write a function `byte_offset(a, index)` that returns how many bytes from the start of the array's data the element at `index` begins.

- `index` is a tuple with one whole number, zero or more, per axis of `a`.
- It must work for any number of axes: `(6,)`, `(2, 3)` and `(2, 3, 4)` alike.
- It must also work for a view such as `a.T`, whose strides are not in the usual order. Use the array's own strides; do not work them out from the shape.
- Return a plain whole number.

So for a `float64` array of shape `(5, 4)`, whose strides are `(32, 8)`, `byte_offset(a, (3, 2))` is `3 * 32 + 2 * 8 = 112`.
--- starter
import numpy as np


def byte_offset(a, index):
    pass
--- solution
import numpy as np


def byte_offset(a, index):
    """Bytes from the start of a's data to the element at index (one entry per axis)."""
    return sum(i * s for i, s in zip(index, a.strides))
--- hint
`a.strides` holds one number of bytes per axis, in the same order as the index.
--- hint
Multiply each index by the stride of its own axis and add the products up. `zip` pairs the two tuples.

=> 112
--- check case | A (50, 7) float32 table

=> 104
--- check case | Three axes
byte_offset(np.zeros((2, 3, 4)), (1, 2, 3))
=> 184
--- check case | One axis
byte_offset(np.zeros(9, dtype=np.float32), (6,))
=> 24
--- check test | The transpose finds the same bytes for the same number
(lambda a: byte_offset(a.T, (2, 1)) == byte_offset(a, (1, 2)) == 40)(np.zeros((2, 3)))

+++ practice | Strides before the array exists
--- task
Write a function `c_strides(shape, itemsize)` that works out, without making any array, the strides NumPy gives a new array of that shape in its default row-major order.

- `shape` is a tuple of lengths, each at least 1. `itemsize` is the number of bytes per element.
- The last axis has a stride of `itemsize`: the next element along a row sits right after this one.
- Every earlier axis has a stride equal to the next axis's stride times the next axis's length.
- The empty shape `()`, a single number, has the empty strides `()`.
- Return a tuple.

So `c_strides((7, 5), 8)` is `(40, 8)`, and `c_strides((2, 3, 4), 4)` is `(48, 16, 4)`.
--- starter
def c_strides(shape, itemsize):
    pass
--- solution
def c_strides(shape, itemsize):
    """Row-major strides, in bytes, of an array with this shape and item size."""
    strides = []
    step = itemsize
    for length in reversed(shape):
        strides.append(step)
        step *= length
    return tuple(reversed(strides))
--- hint
Work from the last axis to the first. The step starts as one element; after each axis, a step along the axis before it jumps over that whole axis.
--- hint
Walk `reversed(shape)`, record the current step, then multiply the step by that axis's length. Reverse what you recorded at the end.
--- check case | Two axes
c_strides((7, 5), 8)
=> (40, 8)
--- check case | Three axes, four-byte items
c_strides((2, 3, 4), 4)
=> (48, 16, 4)
--- check case | One axis, and no axes
(c_strides((10,), 1), c_strides((), 8))
=> ((1,), ())
--- check test | Agrees with NumPy on several shapes
(lambda np: all(c_strides(s, 8) == np.zeros(s).strides and c_strides(s, 4) == np.zeros(s, dtype=np.float32).strides for s in [(3,), (4, 3), (2, 5, 6), (3, 1, 2, 7)]))(__import__("numpy"))

+++ practice | Read an element the way NumPy does
--- task
An array is a block of memory plus a small header. Write a function `read(memory, header, index)` that finds one element the way NumPy does, using only the header.

- `memory` is a Python list standing for the data block: each item is one 8-byte number, so the byte position `p` holds `memory[p // 8]`.
- `header` is a dictionary with three keys: `"offset"`, the byte where the array starts; `"shape"`, a tuple of lengths; and `"strides"`, a tuple of steps in bytes, one per axis. A stride can be negative.
- `index` is a tuple with one whole number per axis. A negative index counts from the end of its axis, as usual.
- Raise `IndexError` if `index` does not have one entry per axis, or if any entry is out of range for its axis.
- The byte position is the offset plus, for each axis, the index times the stride.

So with `memory = [0.0, 1.0, ..., 11.0]` and the header `{"offset": 0, "shape": (4, 3), "strides": (24, 8)}`, `read(memory, header, (3, 2))` is `11.0`. The header `{"offset": 0, "shape": (3, 4), "strides": (8, 24)}` reads the same memory as its transpose.
--- starter
def read(memory, header, index):
    pass
--- solution
def read(memory, header, index):
    """The element at index, found as NumPy finds it: offset plus index times stride."""
    shape = header["shape"]
    strides = header["strides"]
    if len(index) != len(shape):
        raise IndexError(f"expected {len(shape)} indexes, got {len(index)}")
    byte = header["offset"]
    for i, n, s in zip(index, shape, strides):
        if i < 0:
            i += n
        if not 0 <= i < n:
            raise IndexError(f"index out of range for an axis of length {n}")
        byte += i * s
    return memory[byte // 8]
--- hint
Deal with each axis in turn: turn a negative index into its positive partner by adding the axis length, check it is in range, then add index times stride to the byte position.
--- hint
Start the byte position at the header's offset, not at 0. Only divide by 8 at the very end, to turn bytes into a list position.
--- check case | A (4, 3) table

=> 11.0
--- check test | The transposed header reads every element NumPy's transpose does
(lambda m, T: all(read(m, {"offset": 0, "shape": (3, 4), "strides": (8, 24)}, (i, j)) == T[i, j] for i in range(3) for j in range(4)))([float(k) for k in range(12)], __import__("numpy").arange(12.0).reshape(4, 3).T)
--- check case | An offset and a step of two, like a slice

=> [4.0, 6.0, 8.0]
--- check case | Negative indexes, and a negative stride that walks backwards
(read([float(k) for k in range(12)], {"offset": 0, "shape": (4, 3), "strides": (24, 8)}, (-1, -2)), read([float(k) for k in range(12)], {"offset": 88, "shape": (12,), "strides": (-8,)}, (0,)), read([float(k) for k in range(12)], {"offset": 88, "shape": (12,), "strides": (-8,)}, (11,)))
=> (10.0, 11.0, 0.0)
--- check test | Out of range, or the wrong number of indexes, raises IndexError
(lambda m, h: raises(IndexError, lambda: read(m, h, (4, 0))) and raises(IndexError, lambda: read(m, h, (-5, 0))) and raises(IndexError, lambda: read(m, h, (0,))) and raises(IndexError, lambda: read(m, h, (0, 3))))([float(k) for k in range(12)], {"offset": 0, "shape": (4, 3), "strides": (24, 8)})

+++ question | A count that was stored as 2.7
--- ask
What does this print?

```python
import numpy as np

counts = np.array([3, 1, 4])
counts[1] = 2.7
half = counts.astype(np.float64) / 2
print(counts[1], half[1])
```
--- answer
2 1.0
2, 1.0
--- why
`counts` was built from whole numbers only, so its dtype is an integer type. Storing 2.7 converts it to that dtype, which drops the fraction and keeps 2, with no warning. `astype(np.float64)` then makes a new float array from the stored values, so element 1 is 2.0, and half of it is 1.0. The 0.7 was already gone before the conversion; `astype` cannot bring it back.

import numpy as np


def time_grid(duration, rate_hz):
    """Sample times from 0 to duration inclusive, at rate_hz samples a second."""
    n_gaps = round(duration * rate_hz)

--- solution
import numpy as np


def diagonal_covariance(sigmas):
    """Square float64 matrix with each sigma squared on the diagonal and zeros elsewhere."""
    n = len(sigmas)
    cov = np.zeros((n, n))
    for i, sigma in enumerate(sigmas):
        cov[i, i] = sigma * sigma
    return cov

+++ practice | How much does averaging help?
--- task
Averaging `n` noisy readings shrinks the noise. Check it by simulation. Write a function `noise_of_mean(n_readings, sigma, n_trials, seed)` that returns a `float64` array of `n_trials` numbers: for each trial, the mean of `n_readings` noise values drawn from a normal distribution with mean 0 and standard deviation `sigma`.

- Make exactly one generator, with `np.random.default_rng(seed)`, before the first trial.
- Draw each trial's readings with one call, `rng.normal(0.0, sigma, n_readings)`, trial after trial, from that one generator.
- Fill a preallocated array of results.

The same seed must give the same array every time, and the spread of the results should come out close to `sigma / sqrt(n_readings)`.
--- starter
import numpy as np


def noise_of_mean(n_readings, sigma, n_trials, seed):
    pass
--- solution
import numpy as np


def noise_of_mean(n_readings, sigma, n_trials, seed):
    """The mean of n_readings normal noise values, once per trial, from one seeded generator."""
    rng = np.random.default_rng(seed)
    means = np.zeros(n_trials)
    for k in range(n_trials):
        means[k] = rng.normal(0.0, sigma, n_readings).mean()
    return means
--- hint
Make the generator once, before the loop. A generator made inside the loop with the same seed would hand every trial the same readings.
--- hint
Start with `np.zeros(n_trials)` and write each trial's `.mean()` into its slot.
--- check test | The same seed gives the same results

--- check test | Trial 0 and trial 1 are the first two draws of one generator
(lambda g, m: abs(m[0] - g.normal(0.0, 0.02, 10).mean()) < 1e-15 and abs(m[1] - g.normal(0.0, 0.02, 10).mean()) < 1e-15)(np.random.default_rng(3), noise_of_mean(10, 0.02, 50, 3))
--- check test | Every trial is different
len(set(noise_of_mean(10, 0.02, 50, 3).tolist())) == 50
--- check test | The spread is about sigma over the square root of n
(lambda m: m.shape == (2000,) and m.dtype == np.float64 and abs(m.std() - 0.2) < 0.02)(noise_of_mean(25, 1.0, 2000, 11))

+++ question | A full array of ones
--- ask
What does this print?

import numpy as np


def cut(tel, rate_hz, t_start, t_end):
    """Rate columns of the samples from t_start up to t_end, as a view of tel."""
    first = round(t_start * rate_hz)
    stop = round(t_end * rate_hz)

--- solution
import numpy as np


class RingLog:
    """The latest `capacity` rows of `width` numbers, in one preallocated block."""

    def __init__(self, capacity, width):
        self.capacity = capacity
        self.block = np.zeros((capacity, width))
        self.next = 0        # the row the next sample goes into
        self.count = 0       # how many rows are held

    def add(self, rows):
        m = len(rows)
        if m >= self.capacity:
            self.block[:] = rows[m - self.capacity:]
            self.next = 0
            self.count = self.capacity
            return
        end = self.next + m
        if end <= self.capacity:
            self.block[self.next:end] = rows
        else:
            first = self.capacity - self.next
            self.block[self.next:] = rows[:first]
            self.block[:m - first] = rows[first:]
        self.next = end % self.capacity
        self.count = min(self.count + m, self.capacity)

    def latest(self):
        if self.count < self.capacity:
            return self.block[:self.count].copy()
        out = np.empty_like(self.block)
        tail = self.capacity - self.next
        out[:tail] = self.block[self.next:]
        out[tail:] = self.block[:self.next]
        return out
--- hint
Keep two numbers besides the block: the row where the next sample goes, and how many rows are held. Once the log is full, the oldest row is the one where the next sample goes.
--- hint
When the new rows do not fit before the end of the block, write the first part into `block[next:]` and the rest into `block[:rest]`. `latest()` reassembles the same two pieces in order into a new array.

import numpy as np


def settle_time(t, x, target, tol):
    """Time from which x stays within tol of target to the end; None if it never settles."""
    outside = np.abs(x - target) > tol

--- task
Write a function `broadcast_shape(s1, s2)` that applies NumPy's broadcasting rule to two shapes (tuples of whole numbers, each 0 or more) and returns the result shape as a tuple, or `None` if the shapes cannot be broadcast together. Do not call NumPy.

- Two lengths fit if they are equal or if one of them is 1. The result takes the other one, so a 1 against a 0 gives 0.

- The empty shape `()`, a single number, fits anything.

So `broadcast_shape((6, 1), (1, 5))` is `(6, 5)`, and `broadcast_shape((4, 3), (4,))` is `None`.

--- solution
def broadcast_shape(s1, s2):
    """The broadcast result of two shapes, or None when they do not fit."""
    n = max(len(s1), len(s2))
    a = (1,) * (n - len(s1)) + tuple(s1)
    b = (1,) * (n - len(s2)) + tuple(s2)
    result = []
    for x, y in zip(a, b):
        if x == y or y == 1:
            result.append(x)
        elif x == 1:
            result.append(y)
        else:
            return None
    return tuple(result)

import numpy as np


def overlapping_pairs(starts, ends):
    """How many pairs of half-open passes [start, end) share a moment."""
    overlap = (starts[:, None] < ends[None, :]) & (starts[None, :] < ends[:, None])

import numpy as np


def angles_between(a, b):
    """Angle in radians between a[i] and b[i], accurate even when nearly parallel."""
    cross = np.linalg.norm(np.cross(a, b), axis=1)

import numpy as np


def calibrate(true_rates, measured):
    """Per-axis scale-factor error, bias and RMS residual of measured = (1 + k) * true + b."""
    k = np.zeros(3)
    b = np.zeros(3)
    rms = np.zeros(3)
    for axis in range(3):
        A = np.column_stack([true_rates[:, axis], np.ones(len(true_rates))])
        coef, res, rank, sv = np.linalg.lstsq(A, measured[:, axis])
        if rank < 2:
            raise ValueError(f"axis {axis}: these rates cannot separate scale factor from bias")
        k[axis] = coef[0] - 1.0
        b[axis] = coef[1]
        rms[axis] = np.sqrt(np.mean((A @ coef - measured[:, axis]) ** 2))
    return k, b, rms

--- hint
`lstsq` also returns the rank: check it before trusting the fit. Work the residual out yourself as `A @ coef - y`; the residual sum `lstsq` returns is empty when there are exactly as many settings as unknowns.

+++ question | A tiny residual and a big condition number
--- ask
You solve `A x = b` with `np.linalg.solve`. `np.linalg.cond(A)` is about `1e10`, and the residual `A @ x - b` is about `1e-15` of the size of `b`. At worst, about how many significant digits of `x` can you trust?
--- choice
All of them, about 16: the residual shows `x` fits the equations to the last digit.
--- choice
About 15, since the residual is about `1e-15`.
--- choice correct
About 6: a condition number of `1e10` can eat about 10 of the 16 digits a `float64` carries.
--- choice
None: any condition number above `1e6` makes the answer meaningless.
--- why
A small residual only says that `x` fits the equations as well as floats can. With a condition number of `1e10`, many quite different `x` fit almost as well, and rounding errors of about `1e-16` can be magnified up to `1e10` times, to about `1e-6` relative. So at worst about 16 - 10 = 6 digits are right. It is a worst case, often fewer are lost, but you cannot count on that.

def quadratic_roots(a, b, c):

import numpy as np


def row_norms(v):
    """Length of each row of a float32 array, scaled so the squares cannot overflow."""
    scale = np.abs(v).max(axis=1)                 # (N,): the largest size in each row
    safe = np.where(scale > 0, scale, 1.0)        # a zero row divides by 1, not 0

import numpy as np


def combined_stats(chunks):
    """Count, mean and ddof=0 variance of all chunks together, merged one chunk at a time."""
    n_a, mean_a, m2_a = 0, 0.0, 0.0
    for x in chunks:
        n_b = len(x)
        if n_b == 0:
            continue
        mean_b = x.mean()
        m2_b = ((x - mean_b) ** 2).sum()
        delta = mean_b - mean_a
        n = n_a + n_b
        mean_a = mean_a + delta * n_b / n
        m2_a = m2_a + m2_b + delta**2 * n_a * n_b / n
        n_a = n
    if n_a == 0:
        raise ValueError("no samples")
    return n_a, float(mean_a), float(m2_a / n_a)

--- ask

import io

import numpy as np


def pack_passes(passes):
    """Bytes of an .npz: every sample joined end to end, and where each pass starts."""
    starts = np.zeros(len(passes) + 1, dtype=np.int64)
    starts[1:] = np.cumsum([len(p) for p in passes])
    samples = np.concatenate(passes) if passes else np.zeros(0)
    buf = io.BytesIO()
    np.savez(buf, samples=samples, starts=starts)
    return buf.getvalue()


def unpack_pass(blob, k):
    """Pass k back out of the bytes pack_passes made."""
    with np.load(io.BytesIO(blob)) as d:
        starts = d["starts"]
        return d["samples"][starts[k]:starts[k + 1]]

def chunk_stats(tel, col, chunk):

def horizontal_speeds(v, up):

import numpy as np


def per_bin_mean(t, x, width):
    """Mean of x in each time bin [k * width, (k + 1) * width); NaN for an empty bin."""
    bins = np.floor(t / width).astype(np.int64)
    n_bins = int(bins.max()) + 1 if len(bins) else 0
    sums = np.zeros(n_bins)
    counts = np.zeros(n_bins)
    np.add.at(sums, bins, x)
    np.add.at(counts, bins, 1.0)
    means = np.full(n_bins, np.nan)
    filled = counts > 0
    means[filled] = sums[filled] / counts[filled]
    return means

import numpy as np


def count_close_pairs(pos, radius, block):
    """How many pairs of objects are closer than radius, comparing `block` rows at a time."""
    count = 0
    cols = np.arange(len(pos))
    for start in range(0, len(pos), block):
        p = pos[start:start + block]
        diff = p[:, None, :] - pos[None, :, :]            # (b, N, 3)
        close = (diff * diff).sum(axis=2) < radius * radius
        rows = start + np.arange(len(p))
        later = cols[None, :] > rows[:, None]             # count pair (i, j) only when j > i
        count += int((close & later).sum())
    return count

import numpy as np


def smooth(x, alpha):
    """y[0] = x[0]; y[k] = y[k - 1] + alpha * (x[k] - y[k - 1])."""
    y = x.copy()
    for k in range(1, len(x)):

    return y

import numpy as np


def kalman_bank(z, r, q, x0, p0):
    """Final estimate and variance of C scalar Kalman filters; NaN measurements are skipped."""
    n_cases = z.shape[1]
    x = np.full(n_cases, x0, dtype=np.float64)
    p = np.full(n_cases, p0, dtype=np.float64)
    for zk in z:                                     # time: each step needs the one before
        p = p + q
        seen = ~np.isnan(zk)
        gain = np.where(seen, p / (p + r), 0.0)      # no measurement, no update
        x = x + gain * np.where(seen, zk - x, 0.0)
        p = (1.0 - gain) * p
    return x, p

def audit_dcms(Cs, tol):

def calibrate_log(raw, t0, t1, scale, limit):
    """New log: rates minus the window bias, over scale, wild values set to NaN; raw untouched."""
    t = raw[:, 0]
    window = (t >= t0) & (t < t1)

def fit_coast(t, h):
    """Gravity, climb rate at t[0] and RMS residual of a quadratic fit, with centered time."""
    if len(t) < 3:
        raise ValueError("need at least three samples")
    tr = t.mean()                     # raw week seconds would make the columns nearly parallel

import numpy as np


def dead_reckoning(rates, v_body, dt, psi0):
    """Heading and position from yaw rates and body velocities, as cumulative sums."""
    psi = psi0 + dt * np.concatenate([[0.0], np.cumsum(rates[:-1])])
    c, s = np.cos(psi), np.sin(psi)
    v_inertial = np.column_stack([c * v_body[:, 0] - s * v_body[:, 1],    # C.T @ v, row by row
                                  s * v_body[:, 0] + c * v_body[:, 1],
                                  v_body[:, 2]])
    pos = np.zeros_like(v_inertial)
    pos[1:] = dt * np.cumsum(v_inertial[:-1], axis=0)
    return psi, pos

import numpy as np


def close_approaches(a, b, limit, block):
    """Every (i, j, distance) with a[i] and b[j] closer than limit, nearest first, in blocks of a."""
    found = []
    for start in range(0, len(a), block):
        diff = a[start:start + block, None, :] - b[None, :, :]     # (block, Nb, 3)

import numpy as np


def channel_report(tel, sentinel):
    """Count, float64 mean and ddof=1 std of each channel's real readings, and its farthest reading."""
    x = tel.astype(np.float64)                        # a new float64 array: tel is untouched
    x[x == sentinel] = np.nan
    real = ~np.isnan(x)
    count = real.sum(axis=0)

    has = count > 0
    mean[has] = np.where(real, x, 0.0).sum(axis=0)[has] / count[has]

def pack_track(t, r):

def averaged_noise(x, sizes):

+++ question | The price of an inverse
--- ask
For a dense 3000 by 3000 system, roughly how many times the floating-point work of `np.linalg.solve(A, b)` does `np.linalg.inv(A) @ b` do?
--- choice
About the same: both factorize `A` once.
--- choice correct
About three times: the LU factorization costs about (2/3)n³ either way, and building all n columns of the inverse adds about (4/3)n³ more.
--- choice
About 3000 times: the inverse solves one system per column.
--- choice
About nine times, because it is a matrix times a matrix instead of a matrix times a vector.
--- why
Solving by LU costs about (2/3)n³ flops, plus about 2n² for the two triangle walks. Forming the inverse starts with the same factorization and then solves for all n columns of the identity, about (4/3)n³ more, for about 2n³ in total: three times the work. The columns share one factorization, so it is not n times. And the inverse route is also less accurate, because it rounds more and then multiplies by a matrix that already carries rounding error.

+++ question | Every case drew the same wind
--- ask
Which line makes every case of this study get the same wind?

```python
def run_case(k, seed=42):                    # line 1
    rng = np.random.default_rng(seed)        # line 2
    wind = rng.normal(0.0, 3.0)              # line 3
    return simulate(k, wind)                 # line 4
```
--- choice
Line 1: a default argument is evaluated only once, so `seed` is shared.
--- choice correct
Line 2: every case builds a generator from the same seed, so every case starts the same stream. It should depend on `k`, for example `np.random.SeedSequence(seed, spawn_key=(k,))`.
--- choice
Line 3: `rng.normal` needs a `size=` argument, or it returns the same number each time.
--- choice
Line 4: `simulate` must be given the generator, not the wind.
--- why
A generator's stream is fixed by its seed, so `default_rng(42)` gives the same first normal number every time it is made, and every case gets the same wind. The default value 42 is an immutable number, so sharing it does no harm, and `normal` with no size returns one number drawn from the stream. Deriving each case's stream from the master seed and the case number gives independent winds that can still be rerun one case at a time.

+++ question | A reshape that copies
--- ask
`v` is a C-order `float64` array of shape `(4, 3)`. `v.reshape(12)` is a view, but `v.T.reshape(12)` is a copy. Why?
--- choice
Transposing always copies the data, so any reshape of `v.T` works on a copy.
--- choice correct
Reading `v.T` row by row visits `v`'s memory at bytes 0, 24, 48, 72, then back at 8: no single stride walks that path, so NumPy must copy.
--- choice
Reshaping to one axis always copies; `v.reshape(12)` only looks like a view.
--- choice
`v.T` is read-only, and a read-only array cannot be reshaped in place.
--- why
`v.T` is itself a view with strides `(8, 24)`: it swaps the header, not the data. A reshape can be a view only if the new shape can be walked with fixed strides over the old memory. `v.reshape(12)` walks forward 8 bytes at a time. Reading `v.T` in row order goes 0, 24, 48, 72, then 8, which jumps back: that needs a copy, and writing into the copy never changes `v`.

+++ question | Adding 1 to a hundred million
--- ask
What does this print?

```python
import numpy as np

big = np.float32(1e8)
print(big + np.float32(1.0) - big)
```
--- answer
0.0
0
--- why
100,000,000 lies between 2^26 and 2^27, where neighboring `float32` values are 8 apart (24 significant bits). 100,000,001 is not a `float32`, so the sum rounds back to 100,000,000, and subtracting `big` leaves 0.0. The subtraction itself was exact; the 1 was lost in the addition. In `float64` the answer would be 1.0.

+++ question | Singular values and the condition number

+++ question | A fast, wrong answer
--- ask
Which of these "vectorized" versions gives a fast but **wrong** answer?
--- choice
Converting a million positions from kilometers to meters with `pos * 1000.0`.
--- choice correct
Integrating `x[k + 1] = x[k] + dt * f(x[k])` for a nonlinear `f` by computing `f` of the initial state once and multiplying it by the step numbers.
--- choice
Running 10,000 independent orbits for 100 steps, looping over the steps and updating all orbits as arrays at each step.
--- choice
Finding the first over-limit sample by scanning chunks of 100,000 with a mask and stopping at the first chunk with a hit.
--- why
Each step of a recurrence needs the state the step before produced, and for a nonlinear `f` no reshuffling of array operations removes that dependence: using the initial state for every step computes a different, wrong trajectory. The unit conversion is element by element, the orbits are independent of each other so looping over time while vectorizing over orbits is exactly right, and the chunked search gives the same index as a full scan.

+++ question | Strides after a slice
--- ask
`a = np.zeros((5, 4), dtype=np.float32)` and `b = a[::2, ::-1]`. What is `b.strides`?
--- answer
(32, -4)

32, -4

--- why
A `float32` element is 4 bytes, so `a` has strides `(16, 4)`: 16 bytes to the next row of four, 4 to the next column. `::2` on the rows steps over two rows, 32 bytes. `::-1` on the columns walks backwards, -4 bytes, starting from the last column. `b` is a view of shape `(3, 4)` with strides `(32, -4)`.

+++ question | Two letters kept, none summed
--- ask
`a` and `b` both have shape `(N, 3)`. What does `np.einsum("ni,nj->nij", a, b)` compute?
--- choice
The `(N,)` dot products of matching rows.
--- choice
The `(N, 3)` cross products of matching rows.
--- choice correct
An `(N, 3, 3)` stack of outer products: entry `[n, i, j]` is `a[n, i] * b[n, j]`.
--- choice
One `(3, 3)` matrix: the sum over all rows of the outer products.
--- why
Every letter of the inputs appears in the output, so nothing is summed away: the product is taken for every `n`, `i` and `j`, and `n` pairs row `n` of `a` with row `n` of `b`. That is one outer product per row, shape `(N, 3, 3)`. The sum over rows, one `(3, 3)` matrix, would be `"ni,nj->ij"`, and the dot products `"ni,ni->n"`.
