+++ practice | Absolute names for relative imports
--- task
Inside a package, Python turns a relative import into an absolute module name using the importing module's package name, its `__package__`. Write a function `resolve(relative, package)` that does the same arithmetic.

- `relative` starts with one or more dots, then an optional name: `".filters"`, `"..constants"`, `".."`.
- `package` is the dotted package name, such as `"gnc.nav"`.
- One dot keeps the whole package name. Each extra dot chops one piece off its end. Then the rest of the name, if any, is added after a dot.
- If `package` is the empty string (the file was run as a script), raise `ImportError`.
- If there are more dots than the package name can climb, raise `ImportError`.

So `resolve("..constants", "gnc.nav")` returns `"gnc.constants"`, and `resolve("..", "gnc.nav")` returns `"gnc"`.
--- starter
def resolve(relative, package):
    pass
--- solution
def resolve(relative, package):
    """Absolute module name for a relative import made inside `package`."""
    if not package:
        raise ImportError("attempted relative import with no known parent package")
    level = len(relative) - len(relative.lstrip("."))
    rest = relative[level:]
    parts = package.split(".")
    if level > len(parts):
        raise ImportError("attempted relative import beyond top-level package")
    base = parts[: len(parts) - (level - 1)]
    return ".".join(base + [rest]) if rest else ".".join(base)
--- hint
Count the leading dots first. `len(s) - len(s.lstrip("."))` does it.
--- hint
With `level` dots, keep `len(parts) - (level - 1)` pieces of the package name. If `level` is bigger than the number of pieces, there is nothing left to climb to.
--- check case | One dot stays in the package
resolve(".filters", "gnc.nav")
=> "gnc.nav.filters"
--- check case | Two dots climb one level
resolve("..constants", "gnc.nav")
=> "gnc.constants"
--- check case | Dots with no name are the package itself
(resolve("..", "gnc.nav"), resolve(".", "gnc"))
=> ("gnc", "gnc")
--- check case | Three dots from three levels
resolve("...frames", "sim.gnc.nav")
=> "sim.frames"
--- check test | Too many dots raise ImportError
raises(ImportError, lambda: resolve("...x", "gnc.nav"))
--- check test | A script has no package to climb from
raises(ImportError, lambda: resolve(".filters", ""))

+++ practice | The shortest relative import
--- task
Now the reverse question. You are editing a module whose package is `package`, and you want to import the module `target`. Write `relative_name(target, package)` that returns the relative form of that import, as it would appear after `from`.

- Both names are absolute and dotted, such as `"gnc.constants"` and `"gnc.nav"`.
- Find how many leading pieces the two names share. Compare whole pieces, never letters: `"gnc.navx"` and `"gnc.nav"` share only `gnc`.
- The number of dots is the number of package pieces that are not shared, plus one. After the dots come the target's pieces that are not shared, joined with dots.
- If the two names do not share their first piece, the target is outside this top-level package and cannot be reached relatively: return `None`.

So `relative_name("gnc.constants", "gnc.nav")` returns `"..constants"`, and `relative_name("gnc.nav", "gnc.nav")` returns `"."`.
--- starter
def relative_name(target, package):
    pass
--- solution
def relative_name(target, package):
    """The relative import that reaches `target` from inside `package`, or None."""
    t = target.split(".")
    p = package.split(".")
    shared = 0
    while shared < min(len(t), len(p)) and t[shared] == p[shared]:
        shared += 1
    if shared == 0:
        return None
    return "." * (len(p) - shared + 1) + ".".join(t[shared:])
--- hint
Split both names at the dots and walk forward while the pieces are equal. The count you reach is the shared part.
--- hint
The dots climb from the package up to the shared part: one dot for the package itself, and one more for each package piece below the shared part.
--- check case | A sibling of the package
relative_name("gnc.constants", "gnc.nav")
=> "..constants"
--- check case | A module inside the package
relative_name("gnc.nav.filters", "gnc.nav")
=> ".filters"
--- check case | The package itself, and its parent
(relative_name("gnc.nav", "gnc.nav"), relative_name("gnc", "gnc.nav"))
=> (".", "..")
--- check case | Pieces are compared whole
relative_name("gnc.navx", "gnc.nav")
=> "..navx"
--- check case | Deeper on both sides
relative_name("sim.gnc.orbits", "sim.nav.imu")
=> "...gnc.orbits"
--- check case | Another top-level package needs an absolute import
relative_name("numpy.linalg", "gnc.nav")
=> None

+++ practice | What a star import hands over
--- task
`from gnc import *` copies names out of the package's namespace. Write `star_names(namespace)` that returns the names it would copy, where `namespace` is a module's dictionary of names, like `vars(module)`.

- If the namespace has `__all__`, return its names as a list, in the order it lists them. If `__all__` names something that is not in the namespace, raise `AttributeError` (Python does too).
- Without `__all__`, return every name that does not start with an underscore, sorted. Notice what that includes: a module the package imported, such as `math`, is a name like any other.

So `star_names({"__name__": "gnc", "math": 1, "circular_speed": 2, "_helper": 3})` returns `["circular_speed", "math"]`.
--- starter
def star_names(namespace):
    pass
--- solution
def star_names(namespace):
    """The names `from module import *` copies out of this namespace."""
    if "__all__" in namespace:
        public = list(namespace["__all__"])
        for name in public:
            if name not in namespace:
                raise AttributeError(f"module has no attribute {name!r}")
        return public
    return sorted(name for name in namespace if not name.startswith("_"))
--- hint
`__all__` wins when it is there. Only without it do you fall back to the underscore rule.
--- hint
Check every name of `__all__` against the namespace before you return, so a stale entry is reported rather than hidden.
--- check case | Without __all__, imported modules leak out
star_names({"__name__": "gnc", "math": 1, "circular_speed": 2, "_helper": 3})
=> ["circular_speed", "math"]
--- check case | __all__ decides, in its own order
star_names({"__all__": ["orbit_period", "circular_speed"], "circular_speed": 1, "orbit_period": 2, "math": 3})
=> ["orbit_period", "circular_speed"]
--- check test | Matches Python for a real package
(lambda j: star_names(vars(j)) == list(j.__all__))(__import__("json"))
--- check test | A stale __all__ entry raises AttributeError
raises(AttributeError, lambda: star_names({"__all__": ["hohmann_dv"], "circular_speed": 1}))
--- check case | Nothing public
star_names({"__name__": "m", "_cache": {}})
=> []

+++ practice | First match on the search path
--- task
Python looks for a top-level name by walking `sys.path` in order. Write `find(name, path, folders)` that follows the same rules on a model of the disk.

- `path` is the list of folders to search, in order.
- `folders` maps a folder to what it holds: a dictionary from entry name to its kind. The kind is `"package"` (a folder with `__init__.py`), `"module"` (a file `name.py`) or `"folder"` (a folder without `__init__.py`). A folder on `path` may be missing from `folders`; it holds nothing.
- The first `"package"` or `"module"` found wins: return `("package", folder)` or `("module", folder)`, even if namespace portions were noted earlier.
- A `"folder"` is only a portion: note it and keep searching.
- If the search ends with only portions, return `("namespace", portions)`, the list of their folders in path order. If nothing was found at all, return `None`.
--- starter
def find(name, path, folders):
    pass
--- solution
def find(name, path, folders):
    """Where `import name` finds name, following the regular-before-namespace rules."""
    portions = []
    for folder in path:
        kind = folders.get(folder, {}).get(name)
        if kind in ("package", "module"):
            return (kind, folder)
        if kind == "folder":
            portions.append(folder)
    if portions:
        return ("namespace", portions)
    return None
--- hint
Walk the path once. A package or a module ends the search on the spot; a plain folder only goes on a list.
--- hint
`folders.get(folder, {}).get(name)` gives `None` both for a folder you know nothing about and for a folder without that name.
--- check case | A regular package on the first folder
find("gnc", ["repo", "site"], {"repo": {"gnc": "package"}, "site": {"gnc": "package"}})
=> ("package", "repo")
--- check case | A stray folder does not stop the search
find("config", ["repo", "site"], {"repo": {"config": "folder"}, "site": {"config": "module"}})
=> ("module", "site")
--- check case | Only portions: they merge
find("orbit", ["team_nav", "team_prop", "site"], {"team_nav": {"orbit": "folder"}, "team_prop": {"orbit": "folder"}, "site": {}})
=> ("namespace", ["team_nav", "team_prop"])
--- check case | A folder missing from the model holds nothing
find("gnc", ["ghost", "site"], {"site": {"gnc": "package"}})
=> ("package", "site")
--- check case | Not found anywhere
find("flght", ["repo", "site"], {"repo": {"gnc": "package"}})
=> None

+++ practice | Which files run
--- task
Write `files_run(dotted, path)` that works out, on the real disk, which files Python runs for `import dotted`, in order. `path` is a list of folders (`pathlib.Path` objects), searched like `sys.path`.

For each piece of the dotted name, search a list of folders. For the first piece that list is `path`; for every later piece it is the folders of the package found for the piece before it. In each folder, in order:

- `folder/piece/__init__.py` exists: a regular package. It wins; its file runs, and its folder is searched for the next piece.
- otherwise `folder/piece.py` exists: a module. It wins and its file runs. A module has no folder, so if more pieces follow, raise `ModuleNotFoundError`.
- otherwise `folder/piece` is a folder: a namespace portion. Note it and keep looking.

If the folders end with only portions, the piece is a namespace package: no file runs, and all its portions are searched for the next piece. If nothing was found, raise `ModuleNotFoundError`.

Return the list of files that ran, as `Path` objects. So for a regular `gnc` package holding `nav/__init__.py` and `nav/imu.py`, `files_run("gnc.nav.imu", path)` returns the paths of `gnc/__init__.py`, `gnc/nav/__init__.py` and `gnc/nav/imu.py`.
--- starter
from pathlib import Path


def files_run(dotted, path):
    pass
--- solution
from pathlib import Path


def _find(piece, folders):
    """(file that runs or None, folders to search next or None) for one piece of a name."""
    portions = []
    for folder in folders:
        folder = Path(folder)
        if (folder / piece / "__init__.py").is_file():
            return folder / piece / "__init__.py", [folder / piece]
        if (folder / f"{piece}.py").is_file():
            return folder / f"{piece}.py", None
        if (folder / piece).is_dir():
            portions.append(folder / piece)
    if portions:
        return None, portions
    raise ModuleNotFoundError(f"No module named {piece!r}")


def files_run(dotted, path):
    """The files Python runs, in order, for `import dotted` with this search path."""
    ran = []
    folders = path
    for piece in dotted.split("."):
        if folders is None:
            raise ModuleNotFoundError(f"{dotted!r}: a module has no submodules")
        file, folders = _find(piece, folders)
        if file is not None:
            ran.append(file)
    return ran
--- hint
Write a helper that searches one list of folders for one piece and tells you two things: the file that runs, if any, and the folders to search next.
--- hint
A regular package hands on one folder, a namespace package hands on all its portions, and a module hands on nothing at all.

+++ practice | Which copy does import find
--- task
Tests import whichever copy of a package comes first on `sys.path`. Write `first_copy(name, sys_path, files)` that says which one that is.

- `files` is a set of file paths, written with forward slashes, such as `"repo/gnc/__init__.py"`.
- `sys_path` is the list of folders Python searches, in order, such as `["repo", "venv/site-packages"]`.
- In a folder, `name` is found as a regular package when `folder/name/__init__.py` is in `files`, or as a module when `folder/name.py` is. (Namespace portions do not count here.)
- Return the first folder where `name` is found, or `None` if it is found nowhere.

So with the flat layout and the repository root first on the path, `first_copy("gnc", ["repo", "venv/site-packages"], {"repo/gnc/__init__.py", "venv/site-packages/gnc/__init__.py"})` returns `"repo"`: the tests would taste the mixing bowl.
--- starter

--- solution
def first_copy(name, sys_path, files):
    """The first folder on sys_path that holds `name` as a regular package or a module."""
    for folder in sys_path:
        if f"{folder}/{name}/__init__.py" in files or f"{folder}/{name}.py" in files:
            return folder
    return None

+++ practice | Automatic package discovery
--- task
With `[tool.setuptools.packages.find]` and `where = ["src"]`, setuptools searches `src/` for packages instead of taking a hand-written list. Write `find_packages(files, where)` that does the same search.

- `files` is a list of file paths with forward slashes; `where` is a folder such as `"src"`.
- A folder below `where` is a package when it holds `__init__.py` **and** so does every folder between it and `where`. A folder with a missing `__init__.py` breaks the chain: nothing below it counts.
- `where` itself is never a package, and files outside `where` are ignored.
- Return the dotted package names, sorted.

So `find_packages(["src/gnc/__init__.py", "src/gnc/nav/__init__.py", "tests/test_gnc.py"], "src")` returns `["gnc", "gnc.nav"]`.
--- starter
def find_packages(files, where):
    pass
--- solution
def find_packages(files, where):
    """Dotted names of the packages below `where`, found the way setuptools finds them."""
    prefix = where.rstrip("/") + "/"
    marker = "/__init__.py"
    inits = {f[len(prefix):-len(marker)] for f in files if f.startswith(prefix) and f.endswith(marker)}
    found = []
    for folder in inits:
        pieces = folder.split("/")
        if all("/".join(pieces[:i]) in inits for i in range(1, len(pieces))):
            found.append(".".join(pieces))
    return sorted(found)
--- hint
First collect every folder below `where` that holds an `__init__.py`, written relative to `where`, such as `"gnc/nav"`.
--- hint
A folder such as `"gnc/io/csvfmt"` counts only if `"gnc"` and `"gnc/io"` are in that collection too.

+++ practice | What the wheel will hold
--- task
With an explicit list, setuptools takes `packages = [...]` literally and packs only what it is told. Write `wheel_files(files, packages, package_data, where)` that lists what goes into the wheel.

- `files` is a list of source file paths with forward slashes; `where` is the folder the packages live in, such as `"src"`.
- For each dotted package in `packages`, its folder is `where/` plus the name with dots turned into slashes. Every `.py` file directly in that folder is packed. Files in subfolders are not, unless a pattern below matches them.
- `package_data` maps a package name to a list of patterns, such as `["data/*.csv"]`, written relative to that package's folder. A file in the package's folder or below it matches a pattern when both have the same number of `/`-separated parts and each part matches, as `fnmatch.fnmatchcase(part, pattern_part)` from the standard library decides.
- Return the packed files as paths relative to `where` (as they will sit in site-packages), sorted, with no repeats.
--- starter
def wheel_files(files, packages, package_data, where):
    pass
--- solution
from fnmatch import fnmatchcase


def _matches(rel, pattern):
    """True when rel and pattern have as many parts and each part matches."""
    a, b = rel.split("/"), pattern.split("/")
    return len(a) == len(b) and all(fnmatchcase(x, y) for x, y in zip(a, b))


def wheel_files(files, packages, package_data, where):
    """The files an explicit setuptools package list packs, relative to `where`."""
    root = where.rstrip("/") + "/"
    packed = set()
    for pkg in packages:
        folder = root + pkg.replace(".", "/") + "/"
        patterns = package_data.get(pkg, [])
        for f in files:
            if not f.startswith(folder):
                continue
            rel = f[len(folder):]
            if ("/" not in rel and rel.endswith(".py")) or any(_matches(rel, p) for p in patterns):
                packed.add(f[len(root):])
    return sorted(packed)
--- hint
For each package, look only at the files whose path starts with that package's folder, and work with the part of the path after it.
--- hint
A `.py` file sits directly in the folder when the rest of its path has no `/` in it. A data file needs a pattern with the same number of parts.

from fnmatch import fnmatchcase


def _discover(rels):
    """Dotted names of every folder whose chain of __init__.py files is complete."""
    marker = "/__init__.py"
    inits = {r[: -len(marker)] for r in rels if r.endswith(marker)}
    return sorted(
        ".".join(folder.split("/"))
        for folder in inits
        if all("/".join(folder.split("/")[:i]) in inits for i in range(1, folder.count("/") + 1))
    )


def _matches(rel, pattern):
    a, b = rel.split("/"), pattern.split("/")
    return len(a) == len(b) and all(fnmatchcase(x, y) for x, y in zip(a, b))


def missing_from_wheel(files, where, packages, package_data):
    """(package files the wheel leaves out, their percentage of all package files)."""
    root = where.rstrip("/") + "/"
    rels = [f[len(root):] for f in files if f.startswith(root)]
    tops = {r.split("/")[0] for r in rels if r.count("/") == 1 and r.endswith("/__init__.py")}
    package_files = [r for r in rels if "/" in r and r.split("/")[0] in tops]
    if packages is None:
        packages = _discover(rels)
    packed = set()
    for pkg in packages:
        folder = pkg.replace(".", "/") + "/"
        patterns = package_data.get(pkg, [])
        for r in package_files:
            if r.startswith(folder):
                rest = r[len(folder):]
                if ("/" not in rest and rest.endswith(".py")) or any(_matches(rest, p) for p in patterns):
                    packed.add(r)
    missing = sorted(set(package_files) - packed)
    if not package_files:
        return ([], 0)
    return (missing, round(100 * len(missing) / len(package_files)))

+++ practice | Does this version fit
--- task
Write `satisfies(version, spec)` that says whether a version meets a version specifier such as `">=1.10,<2"`.

- `version` is dotted whole numbers, such as `"1.9.3"` or `"2"`. Compare versions piece by piece as numbers, never as text: `1.9.3` is older than `1.10.0`.
- Missing pieces count as zero: `"1.10"` equals `"1.10.0"`, and `"2"` equals `"2.0.0"`.
- `spec` is clauses separated by commas, and every clause must hold. A clause is one of the operators `>=`, `<=`, `==`, `!=`, `>` or `<`, followed by a version. Spaces around the parts do not matter.
- An empty `spec` accepts every version.

So `satisfies("1.9.3", ">=1.10,<2")` is `False` and `satisfies("1.17.1", ">=1.10,<2")` is `True`.

--- solution
OPERATORS = {
    ">=": lambda a, b: a >= b,
    "<=": lambda a, b: a <= b,
    "==": lambda a, b: a == b,
    "!=": lambda a, b: a != b,
    ">": lambda a, b: a > b,
    "<": lambda a, b: a < b,
}


def _key(version):
    """Version pieces as numbers, with trailing zeros dropped so 1.10 equals 1.10.0."""
    pieces = [int(p) for p in version.strip().split(".")]
    while len(pieces) > 1 and pieces[-1] == 0:
        pieces.pop()
    return tuple(pieces)


def satisfies(version, spec):
    """True when version meets every comma-separated clause of spec."""
    have = _key(version)
    for clause in spec.split(","):
        clause = clause.strip()
        if not clause:
            continue
        op = next(o for o in OPERATORS if clause.startswith(o))
        if not OPERATORS[op](have, _key(clause[len(op):])):
            return False
    return True

import tomllib

BUILD_TOOLS = {"setuptools", "hatchling", "flit-core", "wheel"}


def _name(req):
    """The requirement's distribution name, lowercase, with runs of -_. as one dash."""
    name = ""
    for ch in req:
        if not (ch.isalnum() or ch in "-_."):
            break
        name += "-" if ch in "-_." else ch.lower()
    while "--" in name:
        name = name.replace("--", "-")
    return name


def lint(text, compiled=False):
    """Sorted list of the build-versus-runtime mistakes in a pyproject.toml."""
    config = tomllib.loads(text)
    project = config.get("project", {})
    problems = []
    if "build-system" not in config:
        problems.append("no [build-system] table")
    runtime = [_name(r) for r in project.get("dependencies", [])]
    problems += [f"build tool in dependencies: {n}" for n in runtime if n in BUILD_TOOLS]
    for n in (_name(r) for r in config.get("build-system", {}).get("requires", [])):
        if n not in BUILD_TOOLS and not (compiled and n in runtime):
            problems.append(f"not needed to build: {n}")
    if "requires-python" not in project:
        problems.append("no requires-python")
    return sorted(problems)

+++ question | NumPy in both lists
--- ask
A package has a C extension whose source includes NumPy's C headers while it compiles, and its Python code imports NumPy at run time. The build is isolated, as usual. Where does `numpy` belong in `pyproject.toml`?
--- choice correct
In both `[build-system] requires` and `dependencies`: the isolated build needs the headers, and users need NumPy to run the package.
--- choice
Only in `dependencies`: the frontend installs the runtime dependencies before it runs the backend.
--- choice
Only in `[build-system] requires`: whatever the build used is installed for users too.
--- choice
In neither: pip uses whatever NumPy is already installed on the machine.
--- why
The two lists serve two different moments. `requires` is installed into the temporary build environment and thrown away afterwards; users never get it. `dependencies` is installed for users and is never available inside an isolated build. A pure-Python package needs NumPy only at run time, so it goes only in `dependencies`. Compiled code that reads NumPy's headers is the one real case that needs NumPy at build time as well, so it goes in both, each for its own reason.

--- solution
def read_pth(text, existing):
    """(folders added to sys.path, lines run as code) for one .pth file."""
    folders, code = [], []
    for line in text.splitlines():
        line = line.rstrip()
        if not line or line.startswith("#"):
            continue
        if line.startswith(("import ", "import\t")):
            code.append(line)
        elif line in existing and line not in folders:

    return folders, code

def _safe(name):
    """Lowercase, with each run of - _ . turned into one underscore."""
    out = ""
    for ch in name.lower():
        if ch in "-_.":
            if not out.endswith("_"):
                out += "_"
        else:
            out += ch
    return out


def write_path_entry(site_dir, src_dir, dist, version):
    """Write the one-line .pth file an editable install would write; return its path."""
    pth = site_dir / f"__editable__.{_safe(dist)}-{version}.pth"
    pth.write_text(f"{src_dir.resolve()}\n")
    return pth

--- solution
import importlib.util
import sys
from pathlib import Path


class MappingFinder:
    """Finds the mapped top-level packages, and nothing else."""

    def __init__(self, mapping):
        self.mapping = {name: Path(folder) for name, folder in mapping.items()}

    def find_spec(self, fullname, path=None, target=None):
        folder = self.mapping.get(fullname)
        if folder is None or not (folder / "__init__.py").is_file():
            return None
        return importlib.util.spec_from_file_location(
            fullname, folder / "__init__.py", submodule_search_locations=[str(folder)]
        )


def install_finder(mapping):
    """Put a MappingFinder for `mapping` at the front of sys.meta_path and return it."""
    finder = MappingFinder(mapping)
    sys.meta_path.insert(0, finder)
    return finder
--- hint

def parse_wheel(filename):
    """The fields of a wheel file name, with build None when there is no build number."""
    if not filename.endswith(".whl"):
        raise ValueError(f"not a wheel: {filename}")
    fields = filename[: -len(".whl")].split("-")
    if len(fields) == 5:
        name, version, python, abi, platform = fields
        build = None
    elif len(fields) == 6:
        name, version, build, python, abi, platform = fields
    else:
        raise ValueError(f"a wheel name has 5 or 6 fields: {filename}")
    return {"name": name, "version": version, "build": build, "python": python, "abi": abi, "platform": platform}

+++ practice | Picking the wheel for this machine
--- task
pip asks its Python for a list of supported tags, most preferred first, and installs the wheel whose tag comes earliest in it. Write `pick_wheel(filenames, supported)`.

- `supported` is a list of tags such as `"cp312-cp312-manylinux_2_28_x86_64"`, most preferred first.
- Each wheel's name ends in `python-abi-platform.whl`. Any of the three fields can be a dotted set that means "any of these": `py2.py3-none-any` claims both `py2-none-any` and `py3-none-any`. A wheel claims every combination of one python tag, one ABI tag and one platform tag.
- A wheel's rank is the position, in `supported`, of the earliest tag it claims. Return the wheel with the best (lowest) rank; on a tie keep the one that comes first in `filenames`.
- If no wheel claims a supported tag, fall back to the first sdist (a name ending in `.tar.gz`) in `filenames`. If there is none either, return `None`.
--- starter

    pass
--- solution
def _claims(filename):
    """Every python-abi-platform tag a wheel's name claims."""
    python, abi, platform = filename[: -len(".whl")].split("-")[-3:]
    return [f"{p}-{a}-{q}" for p in python.split(".") for a in abi.split(".") for q in platform.split(".")]


def pick_wheel(filenames, supported):
    """The file pip would install: best-ranked wheel, else the first sdist, else None."""
    rank = {tag: i for i, tag in enumerate(supported)}
    best, best_rank = None, None
    for name in filenames:
        if not name.endswith(".whl"):
            continue
        ranks = [rank[t] for t in _claims(name) if t in rank]
        if ranks and (best_rank is None or min(ranks) < best_rank):
            best, best_rank = name, min(ranks)
    if best is not None:
        return best
    return next((name for name in filenames if name.endswith(".tar.gz")), None)

Turn `supported` into a dictionary from tag to position once, so each lookup is quick.

LEGACY = {"manylinux1": (2, 5), "manylinux2010": (2, 12), "manylinux2014": (2, 17)}


def manylinux_ok(platform, glibc, arch):
    """True when a wheel with this platform tag installs on this glibc and processor."""
    if platform == "any":
        return True
    have = tuple(int(p) for p in glibc.split("."))
    if platform.startswith("manylinux_"):
        _, major, minor, tag_arch = platform.split("_", 3)
        need = (int(major), int(minor))
    else:
        head, _, tag_arch = platform.partition("_")
        if head == "linux":
            return tag_arch == arch
        if head not in LEGACY:
            return False
        need = LEGACY[head]
    return tag_arch == arch and have >= need

def verify_wheel(path):
    """Sorted paths whose presence, hash or size disagrees with the wheel's RECORD."""
    with zipfile.ZipFile(path) as z:
        names = [n for n in z.namelist() if not n.endswith("/")]
        records = [n for n in names if n.endswith(".dist-info/RECORD")]
        if not records:
            raise ValueError("no RECORD in this wheel")
        record = records[0]
        listed = set()
        bad = set()
        for row in csv.reader(z.read(record).decode().splitlines()):
            if not row:
                continue
            name, hash_, size = row
            listed.add(name)
            if name == record:
                continue
            if name not in names:
                bad.add(name)
                continue
            data = z.read(name)
            digest = base64.urlsafe_b64encode(hashlib.sha256(data).digest()).rstrip(b"=").decode()
            if hash_ != f"sha256={digest}" or size != str(len(data)):
                bad.add(name)
        bad.update(n for n in names if n not in listed)
    return sorted(bad)

--- ask
A wheel is named `quat-2.0-cp311-abi3-manylinux_2_17_x86_64.whl`. Can pip install it on CPython 3.13 running on an x86-64 Linux machine with glibc 2.35?
--- choice correct
Yes. `abi3` means it uses only CPython's stable ABI, so a wheel built for 3.11 serves 3.11 and every later CPython, and glibc 2.35 is at least the 2.17 floor.
--- choice
No. `cp311` pins the wheel to CPython 3.11 exactly, whatever the ABI tag says.
--- choice
No. glibc 2.35 is newer than 2.17, so the functions the wheel was built against have changed.
--- choice
Only by building it from source, because a compiled wheel always matches one Python version.
--- why
The ABI tag is what ties compiled code to a Python version. `cp311-cp311` would mean "compiled against CPython 3.11's full ABI" and would load only there. `cp311-abi3` means "compiled against the stable ABI, which CPython promises not to change, starting from 3.11", so the same file works on 3.12, 3.13 and later. --- solution
def _dotted_names(text):
    """True when text is one or more valid names joined by dots."""
    return all(piece.isidentifier() for piece in text.split("."))


def parse_ref(value):
    """(module, attribute) of an entry point's object reference; ValueError if malformed."""
    if value.count(":") != 1:
        raise ValueError(f"an object reference has one colon: {value!r}")
    module, attr = (part.strip() for part in value.split(":"))
    if not (_dotted_names(module) and _dotted_names(attr)):
        raise ValueError(f"not a valid object reference: {value!r}")
    return module, attr

--- solution
import tomllib


def entry_points_txt(text):
    """The entry_points.txt a backend writes for this pyproject.toml."""
    project = tomllib.loads(text).get("project", {})
    groups = []
    if "scripts" in project:
        groups.append(("console_scripts", project["scripts"]))
    if "gui-scripts" in project:
        groups.append(("gui_scripts", project["gui-scripts"]))
    groups += list(project.get("entry-points", {}).items())
    out = ""
    for group, entries in groups:
        out += f"[{group}]\n"
        out += "".join(f"{name} = {ref}\n" for name, ref in entries.items())
        out += "\n"
    return out

def main(argv=None):

def compatible(spec):

--- task

def _key(version):
    pieces = [int(p) for p in version.strip().split(".")]
    while len(pieces) > 1 and pieces[-1] == 0:
        pieces.pop()
    return tuple(pieces)


def _accepts(spec, version):
    """True when version meets every clause of spec."""
    tests = {">=": lambda a, b: a >= b, "<=": lambda a, b: a <= b, "==": lambda a, b: a == b,
             "!=": lambda a, b: a != b, ">": lambda a, b: a > b, "<": lambda a, b: a < b}
    for clause in (c.strip() for c in spec.split(",")):
        if clause:
            op = next(o for o in tests if clause.startswith(o))
            if not tests[op](_key(version), _key(clause[len(op):])):
                return False
    return True


def newest_common(specs, versions):
    """The newest version every specifier accepts, or None."""
    ok = [v for v in versions if all(_accepts(s, v) for s in specs)]
    return max(ok, key=_key) if ok else None

+++ practice | Which versions a specifier allows
--- task
Write `allowed(spec, versions)` that returns the versions a specifier allows, in the order they are given, following the rules pip uses for these cases.

**Versions** are dotted whole numbers, optionally followed straight away by a pre-release tag: `a` (alpha), `b` (beta) or `rc` (release candidate) and a number, as in `"2.0.0rc2"` or `"1.0a1"`. Order them by their numbers first (missing pieces count as zero, so `1.10` equals `1.10.0`); for equal numbers, `a` comes before `b`, `b` before `rc`, and every pre-release before the final release; equal tags compare by their number.

**Clauses** are separated by commas, and every one must hold:

- `>=`, `<=`, `>`, `<`, `==`, `!=` followed by a version compare by that order;
- `==X.Y.*` accepts every version whose leading numbers are `X.Y` (pad a short version with zeros first, so `2` starts with `2.0`);
- `~=X.Y.Z` means `>=X.Y.Z` together with `==X.Y.*`, and `~=X.Y` means `>=X.Y` together with `==X.*`.

**Pre-releases are skipped** unless one of the clauses names a pre-release version itself. An empty spec allows every final release.
--- starter
def allowed(spec, versions):
    pass
--- solution
PRE_RANK = {"a": 0, "b": 1, "rc": 2}
FINAL = (3, 0)


def _parse(version):
    """(numbers as written, numbers without trailing zeros, pre-release rank)."""
    i = 0
    while i < len(version) and (version[i].isdigit() or version[i] == "."):
        i += 1
    numbers = tuple(int(p) for p in version[:i].split("."))
    short = list(numbers)
    while len(short) > 1 and short[-1] == 0:
        short.pop()
    tag = version[i:]
    if not tag:
        return numbers, tuple(short), FINAL
    letters = tag.rstrip("0123456789")
    return numbers, tuple(short), (PRE_RANK[letters], int(tag[len(letters):] or 0))


def _order(version):
    _, short, pre = _parse(version)
    return short, pre


def _starts_with(version, prefix):
    numbers = _parse(version)[0]
    wanted = tuple(int(p) for p in prefix.split("."))
    padded = numbers + (0,) * max(0, len(wanted) - len(numbers))
    return padded[: len(wanted)] == wanted


def _clauses(spec):
    """The spec as (operator, version) pairs, with ~= spelled out."""
    out = []
    for clause in (c.strip() for c in spec.split(",")):
        if not clause:
            continue
        op = next(o for o in ("~=", ">=", "<=", "==", "!=", ">", "<") if clause.startswith(o))
        version = clause[len(op):].strip()
        if op == "~=":
            out.append((">=", version))
            out.append(("==*", ".".join(version.split(".")[:-1])))
        elif op == "==" and version.endswith(".*"):
            out.append(("==*", version[:-2]))
        else:
            out.append((op, version))
    return out


def _holds(op, target, version):
    if op == "==*":
        return _starts_with(version, target)
    a, b = _order(version), _order(target)
    return {">=": a >= b, "<=": a <= b, ">": a > b, "<": a < b, "==": a == b, "!=": a != b}[op]


def allowed(spec, versions):
    """The versions spec allows, in the given order, with pre-releases skipped unless named."""
    clauses = _clauses(spec)
    wants_pre = any(op != "==*" and _parse(v)[2] != FINAL for op, v in clauses)
    return [
        v for v in versions
        if (wants_pre or _parse(v)[2] == FINAL) and all(_holds(op, t, v) for op, t in clauses)
    ]

+++ practice | Auditing a lockfile
--- task
A lockfile is only a lockfile if every entry is pinned exactly and carries a hash. Write `lock_problems(text)` that audits a requirements file and returns the list of problems, in the order they appear.

- A line that ends with a backslash `\` continues on the next line: join them (drop the backslash, put a space in its place).
- After joining, a `#` at the start of an entry, or after a space, starts a comment that runs to the end of it. Skip entries that are then empty.
- The first word of an entry is the requirement; the other words are options, such as `--hash=sha256:4721f391...`.
- Compare names in lowercase with each run of `-`, `_` and `.` as one `-`, and write them that way in problems. A name ends at the first character that is not a letter, digit, `-`, `_` or `.`.
- For each entry, in order: if its name was already seen, report `<name>: listed twice` and nothing else for it. Otherwise report `<name>: not pinned` unless the rest of the requirement is exactly one `==` clause with no `*`, and `<name>: no hash` unless one option starts with `--hash=`.
--- starter

    pass
--- solution
def _entries(text):
    """The file's entries, continuation lines joined and comments removed."""
    joined, buf = [], ""
    for line in text.splitlines():
        line = line.rstrip()
        if line.endswith("\\"):
            buf += line[:-1] + " "
            continue
        joined.append(buf + line)
        buf = ""
    if buf:
        joined.append(buf)
    out = []
    for entry in joined:
        if entry.lstrip().startswith("#"):
            continue
        if " #" in entry:
            entry = entry[: entry.index(" #")]
        if entry.strip():
            out.append(entry.split())
    return out


def _split_name(req):
    """(normalized name, the rest of the requirement)."""
    end = 0
    while end < len(req) and (req[end].isalnum() or req[end] in "-_."):
        end += 1
    name = ""
    for ch in req[:end].lower():
        if ch in "-_.":
            if not name.endswith("-"):
                name += "-"
        else:
            name += ch
    return name, req[end:]


def lock_problems(text):
    """Entries that are repeated, not pinned exactly, or without a hash."""
    problems, seen = [], set()
    for req, *options in _entries(text):
        name, rest = _split_name(req)
        if name in seen:
            problems.append(f"{name}: listed twice")
            continue
        seen.add(name)
        if not (rest.startswith("==") and "," not in rest and "*" not in rest):
            problems.append(f"{name}: not pinned")
        if not any(opt.startswith("--hash=") for opt in options):
            problems.append(f"{name}: no hash")
    return problems

+++ question | A cap to be safe
--- ask
Your library `quatlib` declares `numpy>=1.24,<2` "to be safe", although its test suite passes on NumPy 2. What does the upper cap do to the people who install it?
--- choice correct
Anyone whose environment also needs NumPy 2, for some other package, cannot install `quatlib` at all: the two ranges have no version in common, although `quatlib` would have worked.
--- choice
Nothing: when ranges conflict, pip ignores upper bounds and installs the newest NumPy.
--- choice
It makes their installs reproducible, the way a lockfile would.
--- choice
It only affects `quatlib`'s own CI, because users never see a library's dependency ranges.
--- why
A library's ranges travel in its metadata to every environment that installs it, and the resolver must find one NumPy that satisfies every package at once. A cap on a version the library actually supports forbids something that was never broken, and the person who hits the conflict is the user. It gives no reproducibility either: `>=1.24,<2` still floats across every 1.x release. The usual advice for libraries is a tested lower bound and no cap until a real break is found; exact versions belong in an application's lockfile.

- `"break"`: code written for the old version can fail or silently do something different. That is MAJOR.
- `"add"`: new capability, and everything old works as before. That is MINOR. (A deprecation warning is an `"add"` too.)
- `"results"`: same interface, but the numbers users get out change. For a simulation library that is at least MINOR; with `results_break=True`, the team treats it as MAJOR.
- `"fix"`: behavior made correct with no interface change. That is PATCH.
- `"internal"`: private helpers, tests, documentation. No bump on its own.

MAJOR beats MINOR beats PATCH. A release with no changes, or only internal ones, gives `None`.
--- starter

    pass
--- solution
RANK = {None: 0, "patch": 1, "minor": 2, "major": 3}


def release_part(changes, results_break=False):
    """The biggest bump the changes call for, or None."""
    label = {"break": "major", "add": "minor", "results": "major" if results_break else "minor",
             "fix": "patch", "internal": None}
    best = None
    for change in changes:
        if RANK[label[change]] > RANK[best]:
            best = label[change]
    return best

Map each kind to its label first. Then keep the biggest label seen so far.

+++ practice | The next version number
--- task

def next_version(current, changes, results_break=False):
    """The version of the next release, with the 0.y.z convention."""
    label = {"break": 3, "add": 2, "results": 3 if results_break else 2, "fix": 1, "internal": 0}
    level = max((label[c] for c in changes), default=0)
    major, minor, patch = (int(p) for p in current.split("."))
    if level == 0:

    if major == 0 and level == 3:
        level = 2
    if level == 3:
        return f"{major + 1}.0.0"
    if level == 2:
        return f"{major}.{minor + 1}.0"
    return f"{major}.{minor}.{patch + 1}"

def semver_key(version):
    """A key that sorts semantic versions in semver order."""
    core, _, pre = version.split("+", 1)[0].partition("-")
    major, minor, patch = (int(p) for p in core.split("."))
    if not pre:
        return (major, minor, patch, 1, ())
    ids = tuple((0, int(i), "") if i.isdigit() else (1, 0, i) for i in pre.split("."))
    return (major, minor, patch, 0, ids)

+++ practice | Release notes from commit messages
--- task
Many teams write every commit message as `type: text`, so a tool can decide the bump and write the changelog. Write `release(current, commits)` that returns `(next_version, notes)`.

Each message is `type: text` or `type!: text`, split at the first `: `.

- `feat` adds capability (MINOR), listed under **Added**. `fix` is a fix (PATCH), under **Fixed**. `results` changes numerical results (MINOR), under **Changed results**. `docs`, `test`, `refactor` and `chore` need no bump and are not listed.
- A `!` after any type means the change breaks users (MAJOR); it is listed under **Breaking** only.
- Any other type, or a message without `: `, raises `ValueError`.
- The release takes the biggest bump. Raise that number and reset the ones to its right. While MAJOR is `0`, a MAJOR-level release raises MINOR instead.
- With nothing to release, return `(current, "")`.

The notes start with `## <version>`. Then, for each non-empty section in the order Breaking, Changed results, Added, Fixed: an empty line, `### <section>`, and one line `- <text>` per commit, in commit order. Every line ends with a newline. For example:

```
## 2.5.0

### Added
- speed_of_sound()

### Fixed
- density() at 0 km
```
--- starter
def release(current, commits):
    pass
--- solution
SECTIONS = ["Breaking", "Changed results", "Added", "Fixed"]
KINDS = {"feat": (2, "Added"), "fix": (1, "Fixed"), "results": (2, "Changed results"),
         "docs": (0, None), "test": (0, None), "refactor": (0, None), "chore": (0, None)}


def release(current, commits):
    """(next version, changelog text) decided from type-prefixed commit messages."""
    level = 0
    notes = {s: [] for s in SECTIONS}
    for message in commits:
        if ": " not in message:
            raise ValueError(f"no type in {message!r}")
        kind, text = message.split(": ", 1)
        breaking = kind.endswith("!")
        kind = kind.removesuffix("!")
        if kind not in KINDS:
            raise ValueError(f"unknown type {kind!r}")
        bump, section = (3, "Breaking") if breaking else KINDS[kind]
        level = max(level, bump)
        if section:
            notes[section].append(text)
    if level == 0:
        return current, ""
    major, minor, patch = (int(p) for p in current.split("."))
    if major == 0 and level == 3:
        level = 2
    version = {3: f"{major + 1}.0.0", 2: f"{major}.{minor + 1}.0", 1: f"{major}.{minor}.{patch + 1}"}[level]
    text = f"## {version}\n"
    for s in SECTIONS:
        if notes[s]:
            text += f"\n### {s}\n" + "".join(f"- {t}\n" for t in notes[s])
    return version, text
--- hint
One pass over the commits can do three jobs: check the type, keep the biggest bump so far, and file the text under its section.
--- hint

+++ practice | Which requirements apply here
--- task
A wheel's metadata lists requirements, some with a condition after a semicolon: an environment marker, or an extra. Write `requires_for(lines, extras, python_version)` that returns the requirements that apply on this machine, in order, without their conditions.

- A line is `requirement` or `requirement; marker`. Strip spaces around both parts.
- A marker is three words separated by spaces: `left operator right`, where `right` is in single or double quotes.
- `extra == 'name'` holds when `name` is in the list `extras`.
- `python_version <op> "X.Y"` holds when the machine's `python_version` (a string such as `"3.11"`) compares that way with `X.Y`. The operators are `<`, `<=`, `==`, `!=`, `>=` and `>`. Compare versions as numbers: `3.9` is older than `3.10`.
- A line with no marker always applies.
--- starter

--- solution
def _version(text):
    return tuple(int(p) for p in text.split("."))


def _holds(marker, extras, python_version):
    """True when one simple marker is true on this machine."""
    left, op, right = marker.split()
    right = right.strip("'\"")
    if left == "extra":
        return right in extras
    a, b = _version(python_version), _version(right)
    return {"<": a < b, "<=": a <= b, "==": a == b, "!=": a != b, ">=": a >= b, ">": a > b}[op]


def requires_for(lines, extras, python_version):
    """The requirements that apply for these extras and this Python, conditions removed."""
    found = []
    for line in lines:
        req, _, marker = line.partition(";")
        if not marker.strip() or _holds(marker.strip(), extras, python_version):
            found.append(req.strip())
    return found

+++ practice | What pip check reports
--- task
After a manual change such as `pip install --no-deps`, `pip check` lists every installed package whose declared requirements are not met. Write `pip_check(installed, requires)`.

- `installed` maps each installed distribution to its version, such as `{"frames": "2.1.0"}`.
- `requires` maps an installed distribution to its list of requirement strings, such as `["frames>=1.3,<2", "numpy"]`. A requirement is a name followed by an optional specifier: clauses joined by commas, each `>=`, `<=`, `>`, `<`, `==` or `!=` and a version. Every clause must hold. The name ends at the first character that is not a letter, digit, `-`, `_` or `.`.
- Look names up in lowercase with `_` and `.` treated as `-`, and compare versions as numbers, with missing pieces counting as zero.
- For a requirement whose distribution is not installed, report `<pkg> <version> requires <name>, which is not installed.`
- For one whose installed version is outside the range, report `<pkg> <version> has requirement <requirement>, but you have <name> <installed version>.`
- Go through the packages in alphabetical order, and each package's requirements in order. Write names and requirements exactly as `requires` spells them.
--- starter

    pass
--- solution
def _norm(name):
    return name.lower().replace("_", "-").replace(".", "-")


def _key(version):
    pieces = [int(p) for p in version.strip().split(".")]
    while len(pieces) > 1 and pieces[-1] == 0:
        pieces.pop()
    return tuple(pieces)


def _meets(version, spec):
    tests = {">=": lambda a, b: a >= b, "<=": lambda a, b: a <= b, "==": lambda a, b: a == b,
             "!=": lambda a, b: a != b, ">": lambda a, b: a > b, "<": lambda a, b: a < b}
    for clause in (c.strip() for c in spec.split(",")):
        if clause:
            op = next(o for o in tests if clause.startswith(o))
            if not tests[op](_key(version), _key(clause[len(op):])):
                return False
    return True


def pip_check(installed, requires):
    """pip check's messages for unmet requirements, packages in alphabetical order."""
    have = {_norm(name): version for name, version in installed.items()}
    problems = []
    for pkg in sorted(requires):
        for req in requires[pkg]:
            end = 0
            while end < len(req) and (req[end].isalnum() or req[end] in "-_."):
                end += 1
            name, spec = req[:end], req[end:]
            if _norm(name) not in have:
                problems.append(f"{pkg} {installed[pkg]} requires {name}, which is not installed.")
            elif not _meets(have[_norm(name)], spec):
                problems.append(f"{pkg} {installed[pkg]} has requirement {req}, but you have {name} {have[_norm(name)]}.")
    return problems

+++ practice | Where each field sits in memory
--- task
Compiled code that shares a structure must agree on where every field sits. A C compiler lines each field up: a field of size `n` bytes starts at the next offset that is a multiple of `n`, and the whole structure's size is rounded up to a multiple of its largest field's size, so that an array of them keeps every field lined up.

Write `struct_layout(fields)` where `fields` is a list of `(name, code)` pairs, and the codes are `b` (1 byte), `h` (2 bytes), `i` (4 bytes), `q` (8 bytes) and `d` (8 bytes, a double). Return a tuple: a dictionary from field name to its offset in bytes, in field order, and the structure's total size. A structure with no fields has size 0.

So `struct_layout([("flags", "i"), ("t", "d")])` returns `({"flags": 0, "t": 8}, 16)`: four bytes of padding follow `flags`.
--- starter
def struct_layout(fields):
    pass
--- solution
SIZES = {"b": 1, "h": 2, "i": 4, "q": 8, "d": 8}


def struct_layout(fields):
    """(offset of each field, total size) with natural alignment."""
    offsets = {}
    offset = 0
    largest = 1
    for name, code in fields:
        size = SIZES[code]
        offset = -(-offset // size) * size      # round up to a multiple of size
        offsets[name] = offset
        offset += size
        largest = max(largest, size)
    total = -(-offset // largest) * largest if fields else 0
    return offsets, total
--- hint
Rounding `n` up to a multiple of `k` is `-(-n // k) * k`, or `(n + k - 1) // k * k`.
--- hint
Track the largest field size as you go; the padding at the end comes from it.

--- task

def vkey(version):

def satisfies(version, spec):
    """True when version meets every comma-separated clause of spec."""
    tests = {">=": lambda a, b: a >= b, "<=": lambda a, b: a <= b, "==": lambda a, b: a == b,

    return True


def resolve(index, requests):
    """One version per needed package with every range satisfied, or None."""

    def solve(chosen, constraints, todo):
        if not todo:
            return chosen
        name, rest = todo[0], todo[1:]
        if name in chosen:
            ok = all(satisfies(chosen[name], s) for s in constraints[name])
            return solve(chosen, constraints, rest) if ok else None
        for version in sorted(index.get(name, {}), key=vkey, reverse=True):
            if not all(satisfies(version, s) for s in constraints.get(name, [])):
                continue
            deps = index[name][version]
            if any(dep in chosen and not satisfies(chosen[dep], s) for dep, s in deps.items()):
                continue
            extended = {k: list(v) for k, v in constraints.items()}
            for dep, s in deps.items():
                extended.setdefault(dep, []).append(s)
            found = solve({**chosen, name: version}, extended, rest + list(deps))
            if found is not None:
                return found
        return None

    return solve({}, {name: [spec] for name, spec in requests.items()}, list(requests))

--- solution
import hashlib


def _norm(name):
    return name.lower().replace("_", "-").replace(".", "-")


def _lock(lock_text):
    """(normalized name, version) -> set of allowed sha256 digests."""
    entries, buf = [], ""
    for line in lock_text.splitlines():
        line = line.rstrip()
        if line.endswith("\\"):
            buf += line[:-1] + " "
            continue
        entries.append(buf + line)
        buf = ""
    entries.append(buf)
    allowed = {}
    for entry in entries:
        words = entry.split()
        if not words or words[0].startswith("#"):
            continue
        name, _, version = words[0].partition("==")
        hashes = {w[len("--hash=sha256:"):] for w in words[1:] if w.startswith("--hash=sha256:")}
        allowed[(_norm(name), version)] = hashes
    return allowed


def verify(lock_text, folder):
    """File name -> "ok", "hash mismatch" or "not in lock" for each archive in folder."""
    allowed = _lock(lock_text)
    status = {}
    for path in sorted(folder.iterdir()):
        if path.name.endswith(".whl"):
            name, version = path.name.split("-")[:2]
        elif path.name.endswith(".tar.gz"):
            name, _, version = path.name[: -len(".tar.gz")].rpartition("-")
        else:
            continue
        key = (_norm(name), version)
        if key not in allowed:
            status[path.name] = "not in lock"
        elif hashlib.sha256(path.read_bytes()).hexdigest() in allowed[key]:
            status[path.name] = "ok"
        else:
            status[path.name] = "hash mismatch"
    return status

    return bool(line.strip()) and set(line.strip()) == {"-"}


def param_names(doc):
    """The parameter names listed in a NumPy-style docstring's Parameters section."""
    lines = inspect.cleandoc(doc).splitlines()
    names = []
    for i in range(len(lines) - 1):
        if lines[i].strip() == "Parameters" and _is_rule(lines[i + 1]):
            for j in range(i + 2, len(lines)):
                line = lines[j]
                if not line.strip() or line.startswith(" "):
                    continue
                if j + 1 < len(lines) and _is_rule(lines[j + 1]):
                    break
                head = line.split(" : ")[0]
                names += [n.strip() for n in head.split(",")]
            break
    return names

def _documented(doc):

def validate(func):
    """numpydoc-style findings: GL08, or PR01 (undocumented) and PR02 (unknown) names."""
    if not (func.__doc__ or "").strip():

    real = [p for p in inspect.signature(func).parameters if p != "self"]
    return [f"PR01: {p}" for p in real if p not in documented] + [f"PR02: {p}" for p in documented if p not in real]

import math


def hohmann(r1_m, r2_m, mu=3.986e14):
    """Burns of a Hohmann transfer between two circular, coplanar orbits.

    Parameters
    ----------
    r1_m : float
        Radius of the starting orbit, in meters.
    r2_m : float
        Radius of the target orbit, in meters.
    mu : float, optional
        Gravitational parameter of the central body, in m^3/s^2.
        Default is Earth's, 3.986e14.

    Returns
    -------
    dv1 : float
        First burn, at the starting orbit, in m/s.
    dv2 : float
        Second burn, at the target orbit, in m/s.

    Examples
    --------
    >>> dv1, dv2 = hohmann(6_671_000.0, 7_071_000.0)
    >>> round(dv1, 1), round(dv2, 1)
    (111.7, 110.1)
    """
    a = (r1_m + r2_m) / 2
    dv1 = math.sqrt(mu * (2 / r1_m - 1 / a)) - math.sqrt(mu / r1_m)
    dv2 = math.sqrt(mu / r2_m) - math.sqrt(mu * (2 / r2_m - 1 / a))
    return dv1, dv2

+++ practice | The README's commands, for CI
--- task
A README rots silently unless CI runs its quickstart. Write `quickstart(readme)` that pulls the commands out of a README written in Markdown, so a CI job can paste them into a clean container.

- Find the first line that starts with `#` and contains the word `quickstart` in any mix of cases. If there is none, return `[]`.
- After it, take the first code block, which is one of:
  - a **fenced** block: a line starting with three backticks opens it, and the next such line closes it; everything between is the block;
  - an **indented** block: it starts at a non-blank line that begins with four spaces, and runs over the following lines as long as they begin with four spaces or are blank.
- If another line starting with `#` comes before any block, the quickstart has no commands: return `[]`.

--- starter

--- solution
FENCE = "`" * 3


def _block(lines, start):
    """The lines of the first code block after index start, or [] if a heading comes first."""
    i = start + 1
    while i < len(lines):
        line = lines[i]
        if line.startswith(FENCE):
            end = next((j for j in range(i + 1, len(lines)) if lines[j].startswith(FENCE)), len(lines))
            return lines[i + 1 : end]
        if line.startswith("    ") and line.strip():
            block = []
            while i < len(lines) and (lines[i].startswith("    ") or not lines[i].strip()):
                block.append(lines[i])
                i += 1
            return block
        if line.startswith("#"):
            return []
        i += 1
    return []


def quickstart(readme):
    """The commands in the README's quickstart block, prompts and comments removed."""
    lines = readme.splitlines()
    start = next((i for i, l in enumerate(lines) if l.startswith("#") and "quickstart" in l.lower()), None)
    if start is None:
        return []
    commands = []
    for line in _block(lines, start):
        text = line.strip()
        if not text or text.startswith("#"):
            continue
        commands.append(text.removeprefix("$ "))
    return commands

def simple_page(index, name):
    """The address of the project's page on a simple-API index."""
    project = ""
    for ch in name.lower():
        if ch in "-_.":
            if not project.endswith("-"):

        else:

def _normalize(name):
    out = ""
    for ch in name.lower():
        if ch in "-_.":
            if not out.endswith("-"):
                out += "-"
        else:
            out += ch
    return out


def dist_from_filename(filename):
    """(normalized project, version) of a wheel or sdist file name."""
    if filename.endswith(".whl"):
        name, version = filename[: -len(".whl")].split("-")[:2]
        return _normalize(name), version
    for ending in (".tar.gz", ".zip"):
        if filename.endswith(ending):
            name, dash, version = filename[: -len(ending)].rpartition("-")
            if not dash or not name:
                raise ValueError(f"no version in {filename!r}")
            return _normalize(name), version
    raise ValueError(f"not a wheel or an sdist: {filename!r}")

def _project(filename):
    if filename.endswith(".whl"):
        name = filename.split("-")[0]
    else:
        name = filename[: -len(".tar.gz")].rpartition("-")[0]
    out = ""
    for ch in name.lower():

        (folder / filename).write_bytes(data)

    return sorted(projects)

+++ practice | Skipping yanked releases
--- task
A broken release cannot be replaced, but it can be **yanked**: installers skip it, unless someone asked for exactly that version. Write `choose_release(releases, spec)` that picks the version an installer would install.

- `releases` is a list of `(version, yanked)` pairs; versions are dotted whole numbers, compared as numbers with missing pieces counting as zero.
- `spec` is clauses separated by commas, each `>=`, `<=`, `>`, `<`, `==` or `!=` and a version, and every clause must hold. An empty spec accepts every version.
- A yanked release is a candidate only when `spec` is a single `==` clause naming exactly that version.
- Return the newest candidate that meets `spec`, or `None`.
--- starter

    pass
--- solution
def _key(version):
    pieces = [int(p) for p in version.strip().split(".")]
    while len(pieces) > 1 and pieces[-1] == 0:
        pieces.pop()
    return tuple(pieces)


def _meets(version, spec):
    tests = {">=": lambda a, b: a >= b, "<=": lambda a, b: a <= b, "==": lambda a, b: a == b,
             "!=": lambda a, b: a != b, ">": lambda a, b: a > b, "<": lambda a, b: a < b}
    for clause in (c.strip() for c in spec.split(",")):
        if clause:
            op = next(o for o in tests if clause.startswith(o))
            if not tests[op](_key(version), _key(clause[len(op):])):
                return False
    return True


def choose_release(releases, spec):
    """The newest release meeting spec; a yanked one only for an exact == pin on it."""
    clauses = [c.strip() for c in spec.split(",") if c.strip()]
    exact = len(clauses) == 1 and clauses[0].startswith("==")
    candidates = [v for v, yanked in releases if _meets(v, spec) and (not yanked or exact)]
    return max(candidates, key=_key) if candidates else None

def _version(filename):
    if filename.endswith(".whl"):
        return filename.split("-")[1]
    return filename[: -len(".tar.gz")].rpartition("-")[2]


def release_check(dist_files, existing, classifiers, target):
    """Sorted problems with a release, found before anything is uploaded."""
    problems = [f"{f}: already on the index" for f in dist_files if f in existing]
    if not any(f.endswith(".whl") for f in dist_files):
        problems.append("no wheel")
    if not any(f.endswith(".tar.gz") for f in dist_files):
        problems.append("no sdist")
    versions = sorted({_version(f) for f in dist_files}, key=lambda v: tuple(int(p) for p in v.split(".")))
    if len(versions) > 1:
        problems.append("versions differ: " + ", ".join(versions))
    if target == "pypi" and any(c.startswith("Private ::") for c in classifiers):
        problems.append("private package: not for pypi")
    return sorted(problems)

--- task

def _resolve(relative, package):
    """Absolute name of a relative module name, from inside `package`."""
    if not package:
        raise ImportError("attempted relative import with no known parent package")
    level = len(relative) - len(relative.lstrip("."))
    rest = relative[level:]
    parts = package.split(".")
    if level > len(parts):
        raise ImportError("attempted relative import beyond top-level package")
    base = parts[: len(parts) - (level - 1)]
    return ".".join(base + [rest]) if rest else ".".join(base)


def absolute_imports(module, is_package, source):
    """The absolute module names named by the file's import statements, in order."""
    if is_package:
        package = module
    elif "." in module:
        package = module.rsplit(".", 1)[0]
    else:
        package = ""
    found = []
    for line in source.splitlines():
        words = line.split()
        if not words:
            continue
        if words[0] == "import":
            for part in line.strip()[len("import"):].split(","):
                found.append(part.split()[0])
        elif words[0] == "from":
            target = words[1]
            found.append(_resolve(target, package) if target.startswith(".") else target)
    return found

+++ problem | The RECORD of a src-layout wheel
--- task

import base64
import hashlib
from fnmatch import fnmatchcase


def _safe(name):
    out = ""
    for ch in name.lower():
        if ch in "-_.":
            if not out.endswith("_"):
                out += "_"
        else:
            out += ch
    return out


def _matches(rel, pattern):
    a, b = rel.split("/"), pattern.split("/")
    return len(a) == len(b) and all(fnmatchcase(x, y) for x, y in zip(a, b))


def record_for(files, where, package_data, dist, version):
    """The RECORD text of the wheel built from this src tree."""
    root = where.rstrip("/") + "/"
    rels = {f[len(root):]: data for f, data in files.items() if f.startswith(root)}
    marker = "/__init__.py"
    inits = {r[: -len(marker)] for r in rels if r.endswith(marker)}
    packages = [f for f in inits if all("/".join(f.split("/")[:i]) in inits for i in range(1, f.count("/") + 1))]
    packed = set()
    for folder in packages:
        prefix = folder + "/"
        patterns = package_data.get(folder.replace("/", "."), [])
        for rel in rels:
            if rel.startswith(prefix):
                rest = rel[len(prefix):]
                if ("/" not in rest and rest.endswith(".py")) or any(_matches(rest, p) for p in patterns):
                    packed.add(rel)
    lines = []
    for rel in sorted(packed):
        data = rels[rel]
        digest = base64.urlsafe_b64encode(hashlib.sha256(data).digest()).rstrip(b"=").decode()
        lines.append(f"{rel},sha256={digest},{len(data)}")
    lines.append(f"{_safe(dist)}-{version}.dist-info/RECORD,,")
    return "\n".join(lines) + "\n"

import tomllib
from fnmatch import fnmatchcase


def _safe(name):
    out = ""
    for ch in name.lower():
        if ch in "-_.":
            if not out.endswith("_"):
                out += "_"
        else:
            out += ch
    return out


def _ignored(path, patterns):
    parts = path.split("/")
    for p in patterns:
        if p.endswith("/"):
            if p[:-1] in parts[:-1]:
                return True
        elif "/" in p:
            if path == p.lstrip("/"):
                return True
        elif fnmatchcase(parts[-1], p):
            return True
    return False


def hatch_wheel_files(text, files, gitignore):
    """The wheel paths hatchling would ship for this project."""
    config = tomllib.loads(text)
    wheel = config.get("tool", {}).get("hatch", {}).get("build", {}).get("targets", {}).get("wheel", {})
    folders = wheel.get("packages")
    if folders is None:
        guess = _safe(config["project"]["name"])
        folders = [f for f in (f"src/{guess}", guess) if f"{f}/__init__.py" in files][:1]
        if not folders:
            raise ValueError("Unable to determine which files to ship inside the wheel")
    patterns = [p.strip() for p in gitignore if p.strip() and not p.strip().startswith("#")]
    shipped = set()
    for folder in folders:
        folder = folder.rstrip("/")
        parent = folder.rpartition("/")[0]
        for f in files:
            if f.startswith(folder + "/") and not _ignored(f, patterns):
                shipped.add(f[len(parent) + 1:] if parent else f)
    return sorted(shipped)

PRE_RANK = {"a": 0, "b": 1, "rc": 2}
FINAL = (3, 0)


def _parse(version):
    """(numbers as written, numbers without trailing zeros, pre-release rank)."""
    i = 0
    while i < len(version) and (version[i].isdigit() or version[i] == "."):
        i += 1
    numbers = tuple(int(p) for p in version[:i].split("."))
    short = list(numbers)
    while len(short) > 1 and short[-1] == 0:
        short.pop()
    tag = version[i:]
    if not tag:
        return numbers, tuple(short), FINAL
    letters = tag.rstrip("0123456789")
    return numbers, tuple(short), (PRE_RANK[letters], int(tag[len(letters):] or 0))


def _order(version):
    _, short, pre = _parse(version)
    return short, pre


def _holds(op, target, version):
    if op == "series":
        numbers = _parse(version)[0]
        wanted = tuple(int(p) for p in target.split("."))
        numbers += (0,) * max(0, len(wanted) - len(numbers))
        return numbers[: len(wanted)] == wanted
    a, b = _order(version), _order(target)
    return {">=": a >= b, "<=": a <= b, ">": a > b, "<": a < b, "==": a == b, "!=": a != b}[op]


def _clauses(spec):
    out = []
    for clause in (c.strip() for c in spec.split(",")):
        if not clause:
            continue
        op = next(o for o in ("~=", ">=", "<=", "==", "!=", ">", "<") if clause.startswith(o))
        version = clause[len(op):].strip()
        if op == "~=":
            out += [(">=", version), ("series", ".".join(version.split(".")[:-1]))]
        else:
            out.append((op, version))
    return out


def _marker_true(marker, extras, python_version):
    for condition in marker.split(" and "):
        left, op, right = condition.split()
        right = right.strip("'\"")
        if left == "extra":
            if right not in extras:
                return False
        else:
            a = tuple(int(p) for p in python_version.split("."))
            b = tuple(int(p) for p in right.split("."))
            if not {"<": a < b, "<=": a <= b, "==": a == b, "!=": a != b, ">=": a >= b, ">": a > b}[op]:
                return False
    return True


def _name_and_spec(req):
    end = 0
    while end < len(req) and (req[end].isalnum() or req[end] in "-_."):
        end += 1
    return req[:end].lower().replace("_", "-").replace(".", "-"), req[end:].strip()


def numpy_choice(metadata, requested, python_version, available):
    """The newest NumPy that every applicable requirement line allows, or None."""
    clauses = []
    for package, extras in requested.items():
        for line in metadata.get(package, []):
            req, _, marker = line.partition(";")
            if marker.strip() and not _marker_true(marker.strip(), extras, python_version):
                continue
            name, spec = _name_and_spec(req.strip())
            if name == "numpy":
                clauses += _clauses(spec)
    wants_pre = any(op != "series" and _parse(v)[2] != FINAL for op, v in clauses)
    ok = [v for v in available
          if (wants_pre or _parse(v)[2] == FINAL) and all(_holds(op, t, v) for op, t in clauses)]
    return max(ok, key=_order) if ok else None

LEGACY = {"manylinux1": (2, 5), "manylinux2010": (2, 12), "manylinux2014": (2, 17)}


def _platform_rank(tag, glibc, arch):
    """A sort key for a platform tag on this machine, or None if it does not fit."""
    if tag == "any":
        return (1, 0, 0)
    if tag == f"linux_{arch}":
        return (0, -1000, 0)
    if tag.startswith("manylinux_"):
        _, major, minor, tag_arch = tag.split("_", 3)
        floor = (int(major), int(minor))
    else:
        head, _, tag_arch = tag.partition("_")
        if head not in LEGACY:
            return None
        floor = LEGACY[head]
    if tag_arch != arch or glibc < floor:
        return None
    return (0, -floor[0], -floor[1])


def _interpreter_rank(py, abi, minor):
    if py == f"cp3{minor}" and abi == f"cp3{minor}":
        return (0, 0)
    if abi == "abi3" and py.startswith("cp3") and py[3:].isdigit() and int(py[3:]) <= minor:
        return (1, -int(py[3:]))
    if abi == "none" and py in ("py3", f"py3{minor}"):
        return (2, 0)
    return None


def best_file(files, python, glibc, arch):
    """The wheel pip picks for this machine, else the first sdist, else None."""
    minor = int(python.split(".")[1])
    have = tuple(int(p) for p in glibc.split("."))
    best, best_key = None, None
    for name in files:
        if not name.endswith(".whl"):
            continue
        pys, abis, plats = name[: -len(".whl")].split("-")[-3:]
        keys = []
        for py in pys.split("."):
            for abi in abis.split("."):
                for plat in plats.split("."):
                    i = _interpreter_rank(py, abi, minor)
                    p = _platform_rank(plat, have, arch)
                    if i is not None and p is not None:
                        keys.append(i + p)
        if keys and (best_key is None or min(keys) < best_key):
            best, best_key = name, min(keys)
    if best is not None:
        return best
    return next((name for name in files if name.endswith(".tar.gz")), None)

--- task

An API maps each function name to its list of parameters, in order: `"dt"` is required, `"frame=eci"` is optional with the default `eci`. Names starting with `_` are private: ignore those functions entirely.

**MAJOR** (code written for the old version can break, loudly or silently) when any of these is true:

- a function's old parameters are no longer its first parameters, in the same order: one was removed, they were reordered, or a new parameter was put before an old one (positional calls would shift);
- an optional parameter became required, or its default changed;
- a function gained a new required parameter.

**PATCH** when `fixed` is true.

def _params(params):
    """Parameter name -> default text, or None when required; in order."""
    out = {}
    for p in params:
        name, eq, default = p.partition("=")
        out[name.strip()] = default.strip() if eq else None
    return out


def bump_from_diff(current, old_api, new_api, fixed=False, results_changed=False, results_break=False):
    """The next version, decided from the public API's changes."""
    old = {k: _params(v) for k, v in old_api.items() if not k.startswith("_")}
    new = {k: _params(v) for k, v in new_api.items() if not k.startswith("_")}
    level = 0
    for name, before in old.items():
        if name not in new:
            level = 3
            continue
        after = new[name]
        if list(after)[: len(before)] != list(before):
            level = 3
            continue
        for p, default in before.items():
            if default is not None and after[p] != default:
                level = 3
            elif default is None and after[p] is not None:
                level = max(level, 2)
        for p, default in after.items():
            if p not in before:
                level = max(level, 3 if default is None else 2)
    if any(name not in old for name in new):
        level = max(level, 2)
    if results_changed:
        level = max(level, 3 if results_break else 2)
    if fixed:
        level = max(level, 1)
    if level == 0:
        return current
    major, minor, patch = (int(p) for p in current.split("."))
    if major == 0 and level == 3:
        level = 2
    return {3: f"{major + 1}.0.0", 2: f"{major}.{minor + 1}.0", 1: f"{major}.{minor}.{patch + 1}"}[level]

--- solution
def _v(version):
    return tuple(int(p) for p in version.split("."))


def health(installed, numpy_floor):
    """Sorted reasons why compiled packages in this environment may fail to load."""
    numpy = installed.get("numpy")
    problems = []
    for name, info in installed.items():
        built = info.get("built_against")
        if built is None or name == "numpy":
            continue
        if numpy is None:
            problems.append(f"{name}: NumPy is not installed")
            continue
        b, n = _v(built), _v(numpy["version"])
        if b[0] == 1:
            loads = n[0] == 1 and n >= b
        else:
            loads = n[0] <= 2 and n >= _v(numpy_floor)
        if not loads:
            problems.append(f"{name}: built against NumPy {built}, cannot run on NumPy {numpy['version']}")
        if info["installer"] == "conda" and numpy["installer"] == "pip":
            problems.append(f"{name}: conda package next to a pip-installed NumPy")
    return sorted(problems)

--- solution
def _norm(name):
    out = ""
    for ch in name.lower():
        if ch in "-_.":
            if not out.endswith("-"):
                out += "-"
        else:
            out += ch
    return out


def _key(version):
    pieces = [int(p) for p in version.strip().split(".")]
    while len(pieces) > 1 and pieces[-1] == 0:
        pieces.pop()
    return tuple(pieces)


def _meets(version, clauses):
    tests = {">=": lambda a, b: a >= b, "<=": lambda a, b: a <= b, "==": lambda a, b: a == b,
             "!=": lambda a, b: a != b, ">": lambda a, b: a > b, "<": lambda a, b: a < b}
    for clause in clauses:
        op = next(o for o in tests if clause.startswith(o))
        if not tests[op](_key(version), _key(clause[len(op):])):
            return False
    return True


def plan_install(requirements, indexes, internal, lock=None):
    """Normalized name -> (index url, version), with internal names kept on the first index."""
    plan = {}
    for req in requirements:
        end = 0
        while end < len(req) and (req[end].isalnum() or req[end] in "-_."):
            end += 1
        name = _norm(req[:end])
        clauses = [c.strip() for c in req[end:].split(",") if c.strip()]
        exact = len(clauses) == 1 and clauses[0].startswith("==")
        sources = indexes[:1] if name in internal else indexes
        best = None
        for url, projects in sources:
            for version, yanked, sha in projects.get(name, []):
                if (yanked and not exact) or not _meets(version, clauses):
                    continue
                if lock is not None and sha not in lock.get(name, set()):
                    continue
                if best is None or _key(version) > _key(best[1]):
                    best = (url, version)
        if best is None:
            raise LookupError(f"no allowed file for {name}")
        plan[name] = best
    return plan

import importlib
import site
from pathlib import Path


def _load(reference):
    module, _, attr = reference.partition(":")
    obj = importlib.import_module(module.strip())
    for piece in attr.strip().split("."):
        obj = getattr(obj, piece)
    return obj


def _console_scripts(text):
    group, found = None, []
    for line in text.splitlines():
        line = line.strip()
        if not line or line.startswith("#"):
            continue
        if line.startswith("[") and line.endswith("]"):
            group = line[1:-1].strip()
        elif group == "console_scripts":
            name, _, reference = line.partition("=")
            found.append((name.strip(), reference.strip()))
    return found


def installed_commands(site_dir):
    """Command -> (distribution, reference, "ok" or "broken") for everything in site_dir."""
    site.addsitedir(str(site_dir))
    commands = {}
    for info in sorted(site_dir.glob("*.dist-info")):
        meta = (info / "METADATA").read_text()
        dist = next(line[len("Name:"):].strip() for line in meta.splitlines() if line.startswith("Name:"))
        entry_points = info / "entry_points.txt"
        if not entry_points.is_file():
            continue
        for name, reference in _console_scripts(entry_points.read_text()):
            try:
                _load(reference)
                status = "ok"
            except (ImportError, AttributeError):
                status = "broken"
            commands[name] = (dist, reference, status)

import doctest
import inspect


def _is_rule(line):
    return bool(line.strip()) and set(line.strip()) == {"-"}


def _documented(doc):
    lines = inspect.cleandoc(doc).splitlines()
    names = []
    for i in range(len(lines) - 1):
        if lines[i].strip() == "Parameters" and _is_rule(lines[i + 1]):
            for j in range(i + 2, len(lines)):
                line = lines[j]
                if not line.strip() or line.startswith(" "):
                    continue
                if j + 1 < len(lines) and _is_rule(lines[j + 1]):
                    break
                names += [n.strip() for n in line.split(" : ")[0].split(",")]
            break
    return names


def _public(module):
    if hasattr(module, "__all__"):
        names = [n for n in module.__all__ if inspect.isfunction(getattr(module, n, None))]
    else:
        names = [n for n, obj in vars(module).items()
                 if not n.startswith("_") and inspect.isfunction(obj) and obj.__module__ == module.__name__]
    return sorted(names)


def check_module(module):
    """GL08, PR01, PR02 and doctest findings for the module's public functions."""
    findings = []
    runner = doctest.DocTestRunner(verbose=False)
    for name in _public(module):
        func = getattr(module, name)
        if not (func.__doc__ or "").strip():
            findings.append(f"{name}: GL08")
            continue
        documented = _documented(func.__doc__)
        real = list(inspect.signature(func).parameters)
        findings += [f"{name}: PR01 {p}" for p in real if p not in documented]
        findings += [f"{name}: PR02 {p}" for p in documented if p not in real]
        tests = doctest.DocTestFinder().find(func, name, globs=vars(module))
        if any(runner.run(t, out=lambda s: None).failed for t in tests):
            findings.append(f"{name}: doctest failed")
    return findings

pip replaced conda's NumPy underneath a conda SciPy built against the old one, and conda was never told. Rebuild the environment, letting conda install every compiled package, and use pip only last, for what conda lacks.
--- choice
conda environments cannot hold packages from PyPI at all; uninstall pip.
--- choice
SciPy needs to be upgraded with pip too; mixing is fine as long as everything is upgraded.
--- choice
The environment needs to be activated again after a pip install.
--- why
conda keeps its own record of what it installed and builds its compiled packages against each other. pip knows nothing about that record: it swapped NumPy's files and left SciPy compiled against a NumPy that is no longer there, which is the ABI problem, surfacing at import time. The rule is one owner for the compiled stack: conda first, pip last for PyPI-only packages, and never conda again in that environment. If something has to change, rebuild the environment from its file.

+++ question | Where to run the quickstart
--- ask
Why should CI run the README's quickstart commands in a fresh container, instead of a developer checking them on their own laptop?
--- choice correct
The laptop already has the right Python, cached wheels, earlier installs and config files the README may never mention, so the commands can pass there and fail for a stranger; a clean container has none of that.
--- choice
Containers run Python faster, so the ten-minute limit is easier to meet.
--- choice
A README cannot be read on a laptop without Sphinx.
--- choice
CI is the only place where doctests can run.
--- why
The ten-minute test is about a stranger's machine, and the worst place to simulate one is the machine where the project was written. Every forgotten step, such as an extra dependency, a data file fetched once by hand or an environment variable, is already done there. A job that starts from a bare image and pastes the README's commands meets the project the way a new engineer does, and fails the day the README stops being true.

+++ question | uv and the impostor
--- ask
Your internal index serves `gnc-toolkit` 0.1.0. A stranger uploads `gnc-toolkit` 99.0.0 to the public index. You install with uv, with the internal index configured as an extra index and the public one as the default, and no other settings. Which version does uv install?
--- choice correct
0.1.0 from the internal index: by default uv stops at the first index that has the name, and it searches extra indexes before the default one.
--- choice
99.0.0: every installer takes the highest version across all indexes.
--- choice
uv refuses to install because two indexes disagree.
--- choice
99.0.0, unless `gnc-toolkit` is pinned with hashes.
--- why
pip collects candidates from every index and takes the highest version, which is exactly what dependency confusion exploits. uv's default `first-index` strategy is different: the first index (in its search order, where extra indexes come before the default) that has any version of the name is the only one used for it. Asking uv to behave like pip, with `--index-strategy unsafe-best-match`, brings the attack back. Stronger defences still: a single proxy index that never serves public packages with internal names, and a hashed lockfile.

+++ question | Yank, do not replace
--- ask
You published `gnc-toolkit` 1.4.0 to the internal index, and an hour later found its wheel is missing a data file. Why is "delete it and upload the fixed files as 1.4.0 again" the wrong move, compared with yanking 1.4.0 and releasing 1.4.1?
--- choice correct
Anyone who already installed or locked 1.4.0 would hold a different file under the same name and version, so hash checks fail and "which 1.4.0?" has no answer; a yank steers new installs away while exact pins keep working.
--- choice
Because uploading takes longer than yanking.
--- choice
Because yanking deletes the release from every machine that installed it.
--- choice
Because 1.4.1 is required by semantic versioning for any upload after the first.
--- why
A released file name is permanent for a reason: lockfiles record its hash, mirrors copy it, and colleagues reproduce results with it. Swapping its bytes silently breaks all of that, and PyPI refuses to reuse a file name even after deletion. Yanking marks the release so that installers skip it for ranges, while a requirement pinned exactly with `==` still gets it, so nothing that depended on it breaks. The fix then ships as 1.4.1, a PATCH, with a test that checks the data file is in the built wheel.
